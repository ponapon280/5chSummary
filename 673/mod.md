# 元の本文
**流行しているモデルのまとめ（冒頭）**  
テキスト全体から、**Anima（特にAnima / anima_aestheticV10など）**が圧倒的に最も言及が多く、議論の中心となっている。Illustrious（リアス / IL / WAI-Illustrious-SDXLなど）と比較される形で「自然言語理解力・プロンプト追従性・複雑指示への強さ・複数キャラの混ざりにくさ・LoRA作成時の相性」などで優位と評価され、SDXL系からの移行や新基準として扱われているケースが目立つ。動画生成ではLTX（LTX-2.3 / ltx2.3）が実用ツールとして言及されるが、Animaほどの熱量はない。他のモデル（Krea2、NovelAI、Wanなど）は散発的または比較対象として登場する。全体として、2026年時点のログでは**Animaがアニメ/イラスト生成分野でトレンドの中心**と推測される。

**レポート本文**  
以下のテキストは、主にStable Diffusion系（SDXL中心）のローカル/ComfyUI環境でのアニメ・イラスト生成、LoRA学習、漫画生成、動画生成に関するユーザー議論の抜粋・要約である。議論は画像生成モデルに集中しており、Anima vs Illustrious（リアス）の比較が支配的。選定理由として具体的に挙げられているポイントを優先してまとめる。

### Anima（最も言及が多く、トレンドの中心）
- **主な評価・選ばれている理由**:
  - 自然言語理解力・プロンプト追従性がSDXL（リアス）より明らかに高い（left/rightなどの方向指定、複雑な指示、複数キャラ・2コマ・特殊構図への対応）。
  - 複数キャラを出しても特徴が混ざりにくい。
  - LoRA作成時の相性が良く、構図への侵食が少ない。学習時の過学習しにくさや「スイートスポットが広い」点も評価。
  - 複雑ポーズを少ない生成回数で出せる（リアスで10回以上必要なものが2回程度で出るケース）。
  - プロンプトだけで完成度が高く、トータル作業時間が短縮される。漫画生成や編集（インペイント）時の反応も良い。
  - 部族タグ耐性が高く、Danbooruタグ多用時も安定。低VRAM環境での動作もメリット。
- **欠点・注意点**: 画像クオリティ自体はリアスに劣るという声あり。プロンプトが貧弱だと似たような出力になりやすい。長時間生成で指示を聞かなくなる「崩壊」現象の報告も。aesthetic1.0版の方がLoRA乗り・パワーが良いという評価。

### Illustrious / リアス（イラストリアス、リアス、IL / WAI-Illustrious-SDXL）
- **主な評価・選ばれている理由**:
  - SDXLの到達点・安定したベースラインとして根強く使われる。生成速度が速い（Animaの2倍程度という声）、LoRAが充実、プロンプトが多少雑でも出力が出やすい。
  - NAIユーザーからの移行者にとって親和性が高く、初心者向け「最初に触るモデル」として推奨されることが多い。
  - 特定の再現性やLoRA学習完了時の評価で優位な場合あり。アニメStyleの強さも特徴。
- **Animaとの比較**: 自然言語理解力・左右指定で劣るが、クオリティや速度・LoRA豊富さで優位という声も。一部では「もう一昔前のモデル」「Animaに取って代わられつつある」との評価。

### LTX（LTXVideo / LTX-2.3 / ltx2.3）
- **主な評価・選ばれている理由**:
  - 動画生成で「めっちゃ良い」「しばらくこれで遊べる」との実用評価。手軽さ・自動調整のしやすさ、短尺動画・動画延長・クチパク用途で選ばれやすい。
  - Wanと併用（LTX→Wan→LTXの流れ）が定番化。動きの質を求めるならWan、短時間ならLTXという使い分け。
- **欠点**: 顔の変化（化け物化）しやすい、潜在的に低解像度依存、ワークフローが複雑・重いという指摘。音声ノイズなどの不具合報告も。

### その他のモデル（言及は少ないが選定理由が抽出されたもの）
- **Krea2**: Animaとの比較で「自然言語理解力が高い」「衣装再現度が高い」「Anima特有の2人描写時のプロンプト混ざりが起きない」点が評価。漫画生成でのコマ割り忠実性も指摘されるが、エロ表現の学習弱さや絵柄の学習しやすさが弱点。
- **NovelAI（NAI / NAI5）**: Webサービスとしての手軽さ・新モデル（V5）への期待。漫画生成能力（コマ割り・台詞・構図）や日本語対応が強みとして挙げられる。LoRA学習や移行元としての文脈も。
- **Wan（Wan2.2など）**: 動画生成で動きの自然さ・クオリティを重視する層向け。LTXとの併用で長尺・歌わせる用途に。
- **FLUX**: 「直近で現実的に期待できるモデル」として名前が上がるが、エロ規制の厳しさが敬遠理由。
- **Rouwei-Gemma / Cosmos3 Nano / SCAIL-2 / Tsubaki2など**: 散発的言及。Rouwei-GemmaはTE（テキストエンコーダー）強化による自然言語対応向上、Cosmos3はオムニモーダル特性が理由。

**全体の傾向**  
- **用途別選定**: プロンプトで細かく指示したい・構図精度重視 → Anima。手軽さ・速度・LoRA充実・初心者 → Illustrious。動画 → LTX/Wan。漫画・ストーリー性 → NovelAIやKrea2。
- **移行の文脈**: NAI/SDXLユーザーからAnimaへの乗り換え議論が多く、「戻れない」という声も。一方でリアス派も根強い。
- **共通の議論軸**: プロンプト忠実度、LoRA相性、生成速度、NSFW耐性、学習しやすさ。

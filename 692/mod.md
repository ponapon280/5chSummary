# 元の本文
**レポート：生成AIモデル動向（フォーラムログ抽出に基づく）**

### トレンドまとめ（冒頭）
ログ全体を通じて最も活発に議論され、**実用面で高く評価されているモデルはMiniMax H3（H3 / H3 Max / minimax_h3）**です。速度（低スペック環境でも高速）、ComfyUIワークフローとの親和性、LoRAの扱いやすさ、キャラ・画風維持力、動画生成の実用性（特にロング動画や参照ベース）が繰り返し挙げられ、他のモデルを圧倒する言及量です。Anima（LoRA学習・特定表現の強み）とNovelAI（NAI、特にV5の画質・日本語文字・NSFW対応）が画像生成分野で根強い支持を集めています。Qwen-Image（編集用途）やKrea（後処理・スタイル）も補助的に登場。SD1.5/Ponyなどの旧モデルは「時代遅れ」とのネガティブな過去話が中心です。LLM側ではGrok/Claude/Geminiがエロプロンプト作成の検閲緩さ・安定性で活用されています。全体として、**2026年時点のローカル/クラウド動画生成ではMiniMax H3が主流**になりつつあり、画像ではAnima/NAIの二強が継続しています。

### 主なモデルと選ばれている理由（ログ抽出より）
**1. MiniMax H3（H3 / H3 Max / minimax_h3）**  
ログで最も言及が多く、現時点の「最有力」モデルとして位置づけられています。  
- **選ばれる主な理由**: 速度と品質のバランスが優位（H3 baseで30-50倍高速の触れ込み、実際25倍程度の報告）。ComfyUI + Spectrumなどのカスタムノードとの相性が良く、LoRA（強度調整必須、Turbo併用時0.4-0.8など）の扱いやすさ。キャラ・画風維持性能が高く、動画生成（特に実用的なロング/MV用途）で強い。低スペックPCでも動く可能性や、8step程度の実用性。無料枠（H3 Max）での試用例も複数。  
- 弱点として1フレームのノイズや高解像度時の細部潰れが指摘されるが、全体評価は非常に高い。[[1]](https://www.minimax.io/blog/minimax-h3)

**2. Anima（Anima / Anima3.8B / Anima-2.9Bなど）**  
LoRA学習やワークフロー中間生成で頻出。  
- **選ばれる主な理由**: LoRA作成のベースモデルとして長く使われ、danbooruタグ対応による2次元・版権キャラの扱いやすさ。テキストエンコーダー能力を活かしたプロンプト制御や複数キャラ対応。Krea2との併用例あり。ホモ表現などの特定クオリティも評価。  
- 注意点としてint8版の画質劣化やスライム化などの特殊表現の弱点が挙げられる。[[2]](https://civitai.com/ecosystems/anima)

**3. NovelAI（NAI / NAIv5）**  
NSFW・アニメ画像生成で安定した支持。  
- **選ばれる主な理由**: 画質の高さ、TE由来のアクセントの強さ、日本語文字生成の自然さ・安定性。V5になって表現の幅が広がり（特に自然言語プロンプト・多キャラ・コミックページ対応）、過去の蓄積（V5時代）が今も活きる。NSFW用途でも有力。  
- 金銭的ハードル（有料サービス）が指摘される一方で「金かけたら何でもできる」との声も。[[3]](https://www.aimodeling.com/en/news/slug/novelai-diffusion-v5-release)

**4. その他の言及モデル**  
- **Qwen-Image（QwenEdit / QwenEdit2511など）**: 画像編集モデルとして「現在最も強い」と評価。特にピクセルシフト問題解消後の画質維持編集や、LoRA学習素材水増し用途。turbo不要の高速化も実用性向上要因。[[4]](https://qwenlm.github.io/blog/qwen-image-edit/)  
- **Krea（Krea2 / Krea3）**: Anima生成後の後処理・エロ寄せや編集機能で登場。スタイル・LoRA相性やローカルオープン化の可能性が指摘される。  
- **Wan / LTX系**: 動画モデルとして過去言及あり（容量削除候補や挙動注意点）。現在はマイナー。  
- **Illustrious / FLUX / SD1.5 / Pony**: 言及は少なく、過去の遺物扱いや補助的。  
- **LLM（Grok / Claude / Gemini / DeepSeekなど）**: プロンプト作成（特にエロ用途）の検閲緩さ・安定性で活用。Grokは積極的提案、Geminiはバランス、Claudeはワークフロー作成で評価。

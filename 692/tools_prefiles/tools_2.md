**抽出されたツール関連話題（モデルは除外）**

### 1. ComfyUI（comfy）関連
- **全体的な言及**: スレッド全体でComfyUIが最も多く登場。カスタムノードのインストール（`git clone`）、ノード接続、ワークフロー構築が頻出。
- **具体的なツール・ノード**:
  - MiniMax H3 Scene LoRA Schedulerノード（PatchAttention系ノードの前に挿入、LoRA_A/Bの読み込みに使用）
  - Review Gate、Plan default、Scene Lora route、Exact frames/Seconds
  - MiniMax-H3用カスタムノード（LoRA読み込み専用、pdd_accフォルダ指定）
  - Comfy Registryへのカスタムノード登録
- **選ばれている理由**:
  - 複雑なワークフロー（シーンごとのLoRA切り替え、state管理、Loop Studio連携）が柔軟に組める
  - A1111から移行した人が「1日で完了」「数日でカスタムノード配布までできた」と評価
  - 最新の動画生成やLoRA読み込みに強い

### 2. ダウンロードツール
- **huggingface-cli**:
  - 大容量ファイル（safetensorsなど）のダウンロードに使用
  - コマンド例: `huggingface-cli download Comfy-Org/MiniMax-H3 ... --local-dir`
  - **選ばれている理由**: 通常のブラウザDLで失敗しやすい大容量ファイルでも安定して取得可能。失敗時の再開性が高い。
- **aria2c（ダウンローダー）**:
  - 複数人で推奨されている
  - **選ばれている理由**: 中断・再開が可能、分割DLで高速、軽量、サーバー負荷が低い。

### 3. Codex（AIコーディング支援ツール）
- ワークフロー作成やカスタムノードの生成、ノード接続の指示出しに使用
- **選ばれている理由**:
  - 複雑なノード構成（Scene LoRA Schedulerの接続など）を人間が一から考えるのが面倒な場合に有効
  - 「何を指示するか」の蓄積が必要だが、指示さえできれば効率が上がる
  - ChatGPTで事前相談→Codexに投げる流れも言及

### 4. その他のツール

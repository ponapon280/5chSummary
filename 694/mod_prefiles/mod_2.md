以下は、指定されたモデル（NovelAI/NAI、illustrious/リアス、anima）に関する話題をログから抽出したものです。他のモデル（FLUX、Wan、Qwen-Image、Z-Image、LTX）についてはこのログ内では言及がありませんでした。

### anima に関する言及

- **自然言語の理解力・表現力の高さ**
  - 長い自然言語プロンプトをよく理解する。
  - 一点透視病（奥行き方向の道になりやすい現象）を克服しやすい（`horizontal sideway` などの指示が効く）。
  - タグ文化から来ている人でも自然言語でかなり柔軟な構図（横向きの歩道、アクションなど）が出せる。
  - 漫画・コマ割り的な指示も比較的効きやすい。

- **用途・強みとして挙げられている点**
  - 服LoRAが作りやすい。
  - バトルシーン・アクション（スメアフレーム、掌底、着地シーンなど）のテストでよく使われている。
  - Baseモデルを推奨する声が多い（マージモデルにすると良さが殺されたり、一点透視病が出やすくなるため）。

- **弱み・注意点として挙げられている点**
  - 高速化LoRAや画風LoRAを当てると指示追従性・表現力が落ちやすい。
  - イラストリアス（リアス）と比べて表現力は上だが、絵柄LoRAとの相性はまだ発展途上という意見。

### NovelAI (NAI v5 / NAIv5) に関する言及

- **自然言語とタグのバランス**
  - 自然言語でもそこそこ出るが、Curatedの方が背景やアクションで安定しやすいという声。
  - Fullは背景や演習（アクション）が弱めに出やすいため、用途によってCuratedを選ぶ人がいる。

- **強みとして挙げられている点**
  - 日本語プロンプトへの対応が強い。
  - 複数キャラの配置もある程度できる。
  - 標準的な構図は安定して出やすい。

- **弱みとして挙げられている点**
  - Animaと比較して、長い自然言語での表現力・柔軟性で劣るという意見が複数ある。
  - マイナーキャラの再現率がv5でやや落ちたという指摘。

### illustrious（イラストリアス / リアス / ill）に関する言及

- Animaユーザーからの比較で登場することが多い。
- **評価**
  - 定番構図は強いが、キャラ再現度・書き込み量・背景の安定性でAnimaに劣るという声が目立つ。
  - 「illustoriousに比べれば超絶進化」という表現で、Animaの進化を評価する文脈で使われている。
  - 現在も「リアスは定番構図なら現役最強クラス」という肯定的な意見も一部あるが、全体としてはAnimaに軍配が上がる意見が優勢。

### まとめ（このログでの傾向）

- **anima**：自然言語の柔軟性と一点透視病対策、アクション表現で高評価。Base推奨。
- **NAI v5**：日本語対応と安定感は認めつつ、Animaとの比較で表現力でやや劣るという位置づけ。
- **illustrious**：主にAnimaとの比較対象として登場し、定番構図の安定性は評価されるが総合力では後れを取っているという見方が多い。

このログでは特に **anima** が最も積極的に評価・比較されているモデルです。

**抽出されたモデル関連話題（除外対象を除く）**

### 1. **Minimax / MinimaxH3 (H3)**
- **主な話題**:
  - 速度・VRAM最適化の議論が非常に多い。
  - **Zironic/H3-Optimizations**（モデルロード制限 + メモリ最適化 + SparseAttention）を使うと **VRAM 5GB程度浮く** という具体的な報告あり。
  - ハードウェア別実績：
    - RTX 3060 12GB + RAM 32GB で 0.4MP 5秒動画が **34分**
    - RTX 4090 + RAM 32GB でも動作確認あり（ただし RAM 増設推奨の声多数）
  - プロンプト作成方法として、公式 skills を LM Studio や Grok に読み込ませて使う手法が共有されている。
  - Ref2V（参照動画）系の投稿が少なく、t2v/i2v/v2v が主流という指摘あり。

### 2. **Krea / Krea2 / krea2 turbo**
- **主な話題**:
  - anima と比較して **「アニメの i2v に強い」** と評価されている。
  - 自然言語プロンプトへの追従性や特定の構図（一点透視病対策など）で言及あり。
  - turbo 版のステップ数（10 steps など）での生成速度も話題に。

### 3. **MiaoMiaoHarem**
- **主な話題**:
  - 「硬い」モデルとして評価。
  - 構図 LoRA や残像 LoRA がほとんど効かない。
  - 肌の質感は良いが、特定の LoRA（CunnyFunky など）を当てるとディテールが破綻しやすいという報告。

### 4. **animayume v04**
- anima の代替として「ちゃんと出た」という報告あり（一点透視病対策の文脈）。

### 5. **wai**
- 作者が Fine-tuning を試みたが「fine にならない」として諦めたという言及。

### その他の傾向・補足
- **ベースモデル vs マージモデル**の議論が散見され、「マージしすぎると一点透視病が再発する」「base のほうが素直に出やすい」という意見が多い。
- Turbo LoRA（8 step など）と通常 step の速度・品質のトレードオフについての言及あり。
- 自然言語プロンプトの扱いやすさはモデルによって大きく異なり、Krea2 や Minimax H3 が比較的評価されている。

除外対象（NAI、anima、illustrious、FLUX、Wan、Qwen-Image、Z-Image、LTX）に関する言及はすべて除外しています。

# 抽出レポート：ツール関連話題

## ComfyUI（ComfyUI-Easy-Use拡張機能の脆弱性）
- **脆弱性情報の報告**：ComfyUIの拡張機能「ComfyUI-Easy-Use」1.4.1以前に脆弱性（CVE-2026-123790）があると米CERT/CCが公表した。パストラバーサル系の定番脆弱性との指摘もある。（649, 750, 771）
- **拡張機能の普及度**：海外ニキのWF（ワークフロー）にほぼ必ず入っている人気拡張機能。「200以上のお便利カスタムノードが入っているWFセット」。（651, 653, 768）
- **バージョンと修正状況**：修正版が出るまで待つべきかという問いに対し、対象issuesによると最新バージョンが9/5で修正されたのが9/29であるため、ちゃんと本当に「最新」に更新していれば問題ないとされる。（652, 761, 774）
- **WF経由の攻撃リスク**：ノード自体の欠陥を悪用し、WF経由で侵害されるリスクがある。信頼のなさそうなところから落としたWFはエージェントでチェックすべきという指摘。（662, 765）
- **カスタムノードの根本的なリスク**：カスタムノードはPythonコードそのものであるため、やろうと思えば何でもできる。無名カスタムノードにはユーザー入力をevalするコードが普通に入っていることもあり、同様の脆弱性は山ほどありそう。（663, 765, 769）
- **対策**：数ヶ月前にcodexに手伝わせて使ってないExtensionを整理・削除した例や、拡張フォルダをエージェントに精査させて怪しいコードや不可視コードの類がないかチェックさせている例が報告された。（656, 657）

## Viggle Remake（fl2va）
- **機能と用途**：AVのスクショを元素材にしたswap編集で高い精度を発揮する。モザイク有りの元画像でも、差し替え画像が無修正なら無修正になる。（672, 722）
- **選ばれている理由**：swap精度がかなり良く、実用的（実写は4/5、アニメは1/5）。1枚のswap編集済み画像があれば high precision な差し替えが可能。（672, 722）
- **制限事項**：FL2VAベースであるため、音声参照だけはできない。（747）

## llama.cpp
- **v1.0到達と新機能**：llama.cppがv1.0.0になった。動的なexpertのオフロードが入り、strataのような仕組みになった。（777, 778, 808）
- **海外の反応**：redditで「いまさらstrata風実装したのは遅すぎ」とぼろくそに叩かれている。互換性を大事にしすぎて最新の実装をしてこなかったせいと言われている。（808）
- **選ばれている理由（メリット）**：互換性を大事にしてきたからこそメンテナンスが継続でき、strataの元になれている。AVX1しかない古い中古ノートPC等でも動くため、なんちゃってLLMサーバーとして再利用する際に助かる。LMStudio等は早々にAVX1非対応となったため、古い環境を支える役割がある。（808, 815）

## cloud GPU（runpod / vast.ai）
- **runpodの評価**：単純なグラボとの値段比較ならクラウドGPUはグラボを買うよりはるかに安い。ただしストレージ維持にも費用がかかり、モデルやLoRAを保存・送信する手間が面倒。lora等で学習するなら良いが、生成や普段使いには不便な印象。（644, 676）
- **コスト上昇の問題**：ここ数週間で二度も値上げし、RTX 5090が$0.99/hから$1.39/hまで上がった。vast.aiの倍の値段になっている。（674, 732）
- **ローカルGPUとの比較**：グラボは売却して買い替え資金に充てられる（売却益が出ることもある）ため、それを加味するとよほど限定的な用途でない限りクラウドGPUは安い気がしないという指摘。（691）

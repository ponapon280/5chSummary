**抽出結果**

このログで言及されていた指定モデルは以下の通りです。

### 1. **anima (ANIMA)**
- **言及**: 冒頭で「まだANIMAの画像生成が精一杯でMiniH手を出せてへんのやけど」との投稿あり。
- **理由・評価**: 現時点で画像生成メインで使っている人が「次に動画モデル（MiniH/H3）に移行すべきか」を迷っている文脈で登場。性能面での具体的な評価はほぼなし。

### 2. **LTX (LTX2.5 / LTX-2.3 / ltx2.3)**
最も多く言及されているモデルの一つ。

**主な評価・選択理由**:
- **強み**: 生成速度が非常に速い（H3の26倍という声も）。2.3のLoRAが使える。リアルタイム生成に近い領域に到達する可能性。
- **弱み**:
  - 日本語性能が非常に弱い（「にほんび」と発音する、棒読み、感情表現が乏しい）。
  - エロが苦手（肉塊化しやすい、期待していないという声多数）。
  - 品質面でH3に大きく劣る（画質のガビり、動きの崩れ、キャラ一貫性・プロンプト理解力で負ける）。
- **選択する人・しない人**:
  - 「速さ重視」で興味を持つ人はいるが、「H3が出た今は日本語・品質でH3に軍配が上がる」という意見が大多数。
  - 「H3がなければLTX2.5が注目されていた」という声あり。

### 3. **MiniMax H3 (H3 / MMH3 / MiniH)**
ログ全体の中心となっているモデル。

**主な評価・選択理由**:
- **強み**:
  - プロンプト理解力・キャラ一貫性・カメラワークが非常に高い。
  - 自然な日本語会話（特に感情表現）が強い。
  - エロ表現が最も現実的で高品質。
  - Reference機能が優秀（体型に合わせた服装変更など）。
- **弱み**: 生成速度がLTX2.5に劣る。
- **選択理由**:
  - 「エンドユーザーから見た最低ラインがH3に切り上がった」という声多数。
  - 日本語＋エロ＋品質を総合的に求める場合に「他に選択肢がない」という評価が支配的。
  - これをきっかけにComfyUIを始めた人が複数いる。

### 4. **FLUX**
- **言及**: 「クオリティ面でH3と勝負できそうなのはFlux3だけか」という一言のみ。
- **評価**: H3と比較して言及されているが、詳細な議論はなし。

### 5. **Wan**

**抽出されたモデル関連話題（除外対象を除く）**

### 1. MiniMax H3（MMH3 / H3）に関する話題
ログ全体で最も多く言及され、ポジティブに評価されているモデル。以下の点が選ばれている主な理由として繰り返し挙げられている：

- **品質面での優位性**
  - プロンプト理解力・キャラ一貫性・カメラワークが非常に高い。
  - 「H3の画像生成きたらKrea2も終わりやろ？」「H3がなければ…」という声があり、現状のローカル動画生成における「最低ライン（新基準）」として認識されている。
  - 自然な日本語会話（特に感情を伴ったセリフ）が強く、LTX系と比較して明確に優位。

- **実用性・参照機能**
  - Reference to Video機能の精度が非常に高く、「参照画像数枚で任意の女性のエロ動画が作れそう」という将来性も指摘。
  - 人物の体型に合わせた服装反映など、解釈力が強い。

- **速度とのトレードオフ**
  - LTX2.5より遅いものの、「質のH3に速さのLTX2.5」という棲み分けが成立していると評価。
  - turboモデルがまだ控えている点も期待材料として挙げられている。

- **コミュニティへの影響**
  - H3の登場によりComfyUI導入ハードルが下がった（「今までcomfy敬遠してた層の導入にもうってつけ」）。
  - 多くのユーザーが「H3を見てからComfyUIを始めた」との発言あり。

### 2. Gemma4（TE/Text Encoder）に関する言及
- 新しいモデル（サイズ的にH3と同等かやや小さい）のTEとしてGemma4-12Bが使われていると報告。
- 「gemma4使ってるんか プロンプト作成はだいぶ直感的になるかな」という期待の声あり。
- 検閲版の挙動（エッチな内容を拒否する）についても触れられている。

### 3. Flux3に関する言及
- 「クオリティ面でH3と勝負できそうなのはFlux3だけか」という評価。
- ただし、過去のFluxの傾向からエロ表現は厳しそうとの見方が dominant。

### 4. その他のモデル関連の一般論
- **ハードウェア要件の議論**：H3などのモデルを快適に扱うためのVRAM/RAM目安（例: 5070 + 32GBでも可能だが、生成時間は相応にかかる）。
- **高速化技術との組み合わせ**：H3環境下でのsage attention、spectrum、sol-attnなどの組み合わせによる速度改善の話題（ただしモデル本体ではない）。
- **今後の展望**：H3が新基準になったことで、他のモデル（特に速度特化型）がどう差別化を図るか、という文脈で語られている。

**まとめ**  
ログでは**MiniMax H3**が圧倒的に話題の中心で、「品質・日本語性能・参照機能」の3点で高く評価され、「ローカル動画生成の新基準」として選ばれている傾向が強い。Gemma4はTEとしての言及が少数あり、Flux3は将来の競合候補として名前が出ている程度。

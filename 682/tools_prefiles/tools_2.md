**抽出結果（ツール関連のみ）**

### ComfyUI（comfy）に関する話題
- **低スペック環境での挙動**  
  3060 12GB + メモリ32GB環境では「時間かかる・エラーが出る」との声あり。一方で「軽量化ノードを詰め込めば動く」との指摘も。

- **UI/ワークフローの特性**  
  「モデル名ちゃうぞ」との訂正があり、ComfyUIはモデルではなく**UI/バックエンド**であることを明示的に区別して話されている。  
  動画生成（特にref2v/fl2v系）で複雑なワークフローを組む人が多く、「スパゲティ配線」と表現されるほど凝った構成になる傾向。

- **カスタムノード・拡張機能**  
  - Comfy Kitchen Attention（最新コミットで登場、Sage Attention比で1.2倍程度の速度向上報告）
  - Model Preview Override（専用VAEとノードを置くだけでプレビュー画像が複数フレーム表示可能になる）
  - Spectrum Apply MiniMax H3 などのノード組み合わせで速度が変わる事例

- **バージョンアップの影響**  
  Ver0.31.1に上げた際にH3BlockCacheT8ノードが使えなくなった報告あり。

- **他ツールとの比較**  
  「ComfyUIじゃない方のリアス」との表現から、**A1111 / Forge / WebUI** と明確に区別して話されている。  
  WebUI系は「手軽にきれいなAI画が出る」と評価される一方、ComfyUIは「低スペックには有利な場合が多いがUIが分かりにくい」との指摘。

### WebUI / A1111 / Forge に関する話題
- **総称としての呼び方**  
  「A1111とかForgeなどの総称はStable Diffusion WebUI、略してWebUI」との説明あり。

- **ComfyUIとの違い**  
  - WebUI系の方が「簡単で速い」という声。
  - ComfyUIはワークフローが複雑になりがちで、WebUIは「手軽さ」で選ばれる傾向。

### その他のツール関連
- **pip / uv cacheの削除**  
  ストレージ不足時に「pip cache purge」「uv cache clean」で30GB程度空くという実用Tipsが共有されている（ツール環境のメンテナンスとして）。

- **Qwenシリーズ**  
  画像生成以外の文脈（ローカルLLM用途）で言及あり。「ローカルLLMでH3プロンプトを書いている」という使い方が確認された。

**モデル名（Wan、LTX、anima、H3、リアス、Krea2など）はすべて除外**しています。

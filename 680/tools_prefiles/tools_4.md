**抽出結果（ツール関連のみ）**

### ComfyUI（comfy）関連
- **言及多数**。特にMiniMax H3関連のノード運用が活発。
  - Kijai版 / larryvrh版 / drbaph版のMiniMax-H3-Turbo LoRAノードの違いを議論。
  - `ComfyUI-MiniMax-H3-Turbo` ノードが必要なものと不要なものの区別。
  - Kijai氏の新LoRA（ref lora）をFL2VAモデルでRef2VA的に使う試み。
  - easycache + sol_attenの組み合わせ運用。
  - `--fast-disk` オプションでディスク使用量を100G→50G程度に削減できた事例。
  - VAE（特にint8 convrot版）の挙動が不安定（GPU使用率が急落したり、処理時間が毎回変わる）という報告多数。
  - Sage Attentionパッチ（KJ版とMem Eff版）の併用検証。
  - ローカルサーバー化して別PCからAPIで操作する運用。
  - カスタムノードをGPT（Sol兄貴）に作らせる事例が複数。

**選ばれている理由・評価**
- 「GPTのSol兄貴に相談したら指示通りに一瞬でカスタムノード作れて草」という声あり。カスタムノードの作成容易さが強み。
- Ref2V/I2Vでの参照画像の扱いやすさ（プロンプトで素直に従う）。
- ローカルサーバー化による複数PC運用（画像生成PCとLLM PCの分離）。

### LM Studio / LM Link 関連
- 複数PC間でモデルを共有する運用（LM Link使用）。
- 画像生成用PCからLM Studioを呼んでも、実際の推論は別のLLM用PCで実行されるように見える設定。
- 2060 12Gなどのサブ機にモデルを置いてメイン機から利用。

**選ばれている理由**
- 「画像動画用PCとLLM用PCを分けて運用したい」場合に有効。
- RAMを圧迫しているPCがあっても、もう一台でLM Studioを起動すればRAM消費なしで利用可能。

### Runpod 関連
- PRO6000を契約して疑似富豪運用。
- 「ネカフェみたいなもん」と表現。

### その他のツール・運用
- **Msty Studio**：Deepseek APIなどを繋いで使用。
- **Codex**：LM StudioとComfyUIのAPIを一括で叩くツールを自作。Unload/Loadまで自動化。
- **Claude**：テキスト構築用アプリやGUIの作成を依頼。ワークフローの解説や作成も依頼。
- **Grok**：MiniMax H3用のプロンプト変換やリファレンスガイドの適用指示に使用（特に「Geminiにリファレンスガイドを投げて恒常的に従わせる」運用）。

**Qwenシリーズに関する言及**
- 該当なし（画像生成以外の話題は見つからず）。

### 補足
- モデル名（FLUX、Wan、Qwen-Image、Z-Image、LTXなど）の言及はすべて除外。
- ツール名が明記されていない「リファレンス渡せおじさん」や「部族語」などの抽象的な言及は、ComfyUI内の具体的なノード運用として解釈して抽出。

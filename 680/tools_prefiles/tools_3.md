**抽出されたツール関連話題（ComfyUI系・クラウドレンタル系中心）**

### 1. ComfyUI / カスタムノード・ワークフロー関連
- **ComfyUIのワークフローでdynamic vramのオンオフを切り替えたいが、原理的に難しい**（434）
- **自作カスタムノード・ワークフローを自由に使いたい**という理由でローカルComfyUIを好む声多数。
  - Comfy Cloudは「自作カスタムノードが使えない」のが致命的で選択肢にならない（505）
- **MiniMax H3用の各種高速化ノード**の組み合わせ検証（550, 501, 509）
  - EasyCache（音質悪化の報告あり、v0.31.0で改善報告も）
  - MiniMax H3 Block Cache (T8)
  - Patch Sage Attention KJ + Mem Eff Sage Attention
  - Patch Sol-Attn
  - Spectrum Apply MiniMax H3
  - MiniMax-H3 Turbo LoRA（専用ノードが必要かLoad LoRAで代用可能か議論）
- **ref2va / fl2va**の使い分け（506, 508, 514）
  - ref2vaをメインで使っている人が多い（素材1枚から多様な動画生成、複数素材統合が可能）
- **Directorノード + キーフレーム的な使い方**（622）
- **LM Studio + 専用スキル（mdファイル）でプロンプト生成**をComfyUIワークフローに組み込む手法（565, 588, 590, 598）

### 2. クラウドGPUレンタルツール（runpod, vast.aiなど）
- **runpod / vast.aiの評価**（490）
  - **利点**:
    - 未使用時はほぼ料金がかからない（数十GBで1日10円程度）
    - 自前のグラボに負担をかけない安心感
    - 自作カスタムノード・ワークフローがそのまま使える
  - **欠点**:
    - ComfyUI以外の操作（エクスプローラーなど）が面倒
    - 起動が不安定な場合あり
- **クラウドのデータ送受信の煩雑さ**（527）
  - データセットアップロード・完成品ダウンロードに時間がかかる（特にアップロード）
- **GPU枯渇問題**（521）
  - 週末などに使いたいGPUが取れない
- **監視の有無**（502）
  - runpod/vast.aiはVPS的な扱いで何をやっているか監視されていないため自由

### 3. ローカル vs クラウドの選択理由（ツール視点）
- **所有欲・所有権の観点**でローカルComfyUI環境を好む（433, 459）
- **手元にPCが残る**という点でローカルを評価（457, 458, 477, 520）
- **クラウドは「使いたい時に使えない」リスク**がある（521）
- **自作カスタムノード・ワークフローの自由度**を最優先する人はローカルComfyUI一択（490, 505）

### 4. その他
- **Comfy Cloud**はカスタムノード非対応のためほぼ選択肢外（505）
- Qwenシリーズの画像生成以外の話題は今回のログには該当なし。

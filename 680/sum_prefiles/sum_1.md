**なんJ（5ch）AI生成スレ レポート**

### 概要
本スレは主に**ComfyUI + MiniMax H3**を中心としたローカル動画生成環境の構築・最適化議論が活発なスレッド。RTX 5090や大容量メモリ（96GB〜128GB以上）への高額投資が相次いで報告されており、「金で時間を買う」姿勢が顕著。エロ動画生成を前提とした実用的なワークフロー共有が中心となっている。

### 主要トピック

**1. ハードウェア投資の活発化**
- RTX 5090搭載PC（工房・サイコムなど）を**100〜120万円前後**で購入した報告が複数。
- メモリ価格高騰が深刻で、「96GB（32GB×2 + 16GB×2）」「128GB（2枚挿し推奨）」への投資が目立つ。
- 低スペック（4060ti、4070ti、1650など）からの「異世界転生レベル」のジャンプ報告が散見され、生成速度の劇的向上を実感しているユーザーが多い。

**2. MiniMax H3関連の最適化**
- 現時点の最強ワークフローとして以下の組み合わせが主流：
  - Patch Sage Attention KJ
  - Patch Sol-Attn
  - H3 Block Cache（T8）またはEasy Cache
- 「Mem Eff Sage Attention Patch」との併用はCUDA相性で不安定という報告あり。
- 低スペック環境でも「Turbo + Sage系」で0.4MP/10秒程度を狙う動きが見られる。

**3. LoRA・ワークフロー関連**
- Anima LoRAのブロック制御（LBW）に関する具体的なプリセット共有。
- ComfyUI-LoRA-Block-FilterやPower LoRA Loaderの活用法が議論。
- Civitai連携ツール（LoRA Managerなど）の紹介もあった。

**4. その他の傾向**
- ComfyUIのバージョンアップ（0.31.0など）で挙動が変わる報告が頻発。
- 将来的なメモリ価格や次世代GPUへの言及が多く、「今買うべきか」の温度感が高い。
- 全体的に「エロ生成のための金銭的・時間的投資」を肯定的に語る空気。

### スレの特徴・トーン
- 技術的な情報共有が中心だが、**金銭的余裕を自慢するような書き込み**も散見。
- 「シコシコ」「エロ」といった直接的な表現が普通に使われており、明確にアダルト用途を前提としたスレ。
- 低スペック民への配慮も一部ありつつ、全体として「金持ち優位」の空気が強い。

### まとめ
本スレは**MiniMax H3による動画生成**が現在のホットトピックで、高額ハードウェア投資を厭わない層が活発に情報交換している。最適化手法は日々更新されており、バージョンやノードの相性問題も頻発している状況。

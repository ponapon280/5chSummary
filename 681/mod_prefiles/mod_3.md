**抽出された主なモデル関連話題（除外対象除く）**

### 1. **MiniMax H3（H3 / MMH3 / Minimax H3）**
- スレ内で最も多く言及されているモデル。
- **選ばれている主な理由**:
  - 動きの再現性、特に腰振り・挿入などのセックスモーションで優位。参照画像（リファレンスシートや静止画）を入れると打率が上がるという声が多い。
  - Seedance系より検閲が緩く、性器描写やセックス描写が出やすい（ただし完全無検閲ではない）。
  - R2V（Reference to Video）との相性が良く、1枚の挿入シーン静止画を追加するだけで動きが安定するという実用報告あり。
  - 高速化（H3Cache + Spectrum + ターボLoRAなど）と組み合わせたときに実用的な速度と品質が出る。
  - クラウドでもローカルでも扱いやすく、Motion Context機能で画風継続性が高い点が評価されている。

### 2. **Seedance（2.0 / 2.5）**
- H3と直接比較されることが多い。
- **選ばれにくくなった理由**（H3台頭後）:
  - 以前は「検閲なし版」と話題になったが、H3が出てからは「性能が劣る」「性器・セックス描写が弱い」という声が増えた。
  - クラウド利用時のコスト（1本500円程度）と手間を考慮してH3に流れたという意見多数。

### 3. **LLM系（Gemini / Claude / Grok / Gemma4）**
- 主に**H3用のプロンプト作成ツール**として使われている。
- **Geminiの評価**:
  - エロ同人レベルの下品な表現・展開・セリフを比較的抵抗なく書いてくれる。
  - 悪を悪とストレートに書く傾向が強いため、H3プロンプト生成に適しているという声。
- **Gemma4**:
  - 画像を複数枚添付してプロンプトを書かせる用途で使われており、ファイル名ではなく「送られてきた順番」で指示すると安定するというTipsが共有されていた。
- **Claude / Grok**:
  - Claudeはシチュエーションの自由度が高いがクォータが厳しい。
  - Grokはエロプロンプト製造機として使っている人が一定数いるが、画像生成の検閲が最近厳しくなったという報告あり。

# 抽出結果：ツール関連話題

## ComfyUI (comfy)
- ワークフロー画像（jsonメタデータ埋め込み済み）をcomfyuiにドラッグ＆ドロップしても画像しか表示されない環境上の不具合報告あり。別ユーザーからワークフローjsonの提供により解決手段が提示された（>>628, >>630, >>631）。
- ワークフロー入り画像のアップロード先としてimgbb.comを用いるとメタデータが消えずに済むというTipsが共有された（>>637）。

## nano-banana
- 石膏像を生成対象にするとnano bananaのエロ判定が少し甘くなるとのスレ上の見解（>>454）。

## ハードウェア・PC環境ツール（ツール周辺）
- GPU温度に連動してPCケースファンの回転速度を調整できるアプリの存在が話題に挙がり、爆音PCの静音化に役立ったとの報告あり（>>490）。
- ASUS製グラボの上位機種にはケースファンヘッダが標準装備されており、グラボ温度連動でファン制御できるとの言及（RTX2000時代の知見）（>>499）。
- threadripper用マザーボードとCPUの価格は人道的な値段だが、メモリ価格が完全に終わっているとの嘆き（>>519）。元々サーバー向けでRDIMMが必要なため割高、今はさらに高い（>>521）。

## モニター・色覚チェックツール
- ハチワレの色当てゲームをモニターの健全チェックに用いる方法が提案され、スレ内で多数のスコア報告が発生（>>577〜>>620）。iPhoneのTrue ToneやNight Shiftをオンにしたまま実行すると点数が出ない可能性が指摘された（>>606）。BENQ製ゲーミングモニターでレベル12まで到達した報告あり（>>620）。

## Qwen（画像生成以外）
- Qwenがまもなく発表されるという画像投稿を確認。2、3日以内に発表されたとしたらまずはクラウドで公開され、その2、3週間後にオープンウェイトがリリースされるだろうから、ローカル環境で使えるようになるまではまだ待つ必要があるとのスレ上の予想（>>443）。

## モニター・カラーキャリブレーション関連
- 酷いモニターで画像生成を行うと塗りムラやゴミが見えず、まともなモニターで見たときにとんでもない絵になっていることが判明する場合があるため注意喚起（>>608）。EIZOのColorEdgeクラスならまともとの言及（>>605）。

## その他ツール・サイト関連
- **Danbooru**: メンテナンス中で復旧せずDown状態。日本語を検索欄に入力すると対応タグを出してくれる機能や、部族語（タグ）確認用途の需要が語られた。代替としてAIbooru、Gelbooru、Bigbooruが挙げられた（>>515, >>516, >>522, >>542, >>560, >>567）。
- **Gelbooru**: Danbooruで非表示にされる画像も見られるが、普段はDanbooruより不安定。最近規制で見られない画像が増えている（>>522, >>560, >>575）。
- **Google AIモード（GoogleスタジオAI）**: 直接Geminiに聞くのではなくGoogle検索のAIモードを利用するとエロ系質問にも比較的寛容で、シークレットモード・ログインなし状態でも会話をかなり伸ばせる。ただし深掘り質問すると会話ログに残る模様（>>526, >>561, >>572）。
- **fizgig automagic3**: 「暴れ馬過ぎて全く使いこなせない」との不満報告あり（>>598）。また、マムーコ素材100枚ほどをfizgigで作成したとの言及（>>642）。

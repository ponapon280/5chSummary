# 生成AI関連ツール話題 抽出レポート

## ComfyUI (comfy)

- **選ばれている理由**: 新モデルへの対応が一番早い点が挙げられている。動画生成はComfyUIでないと話にならないため、動画用途ではComfyUIが選ばれている。バックエンドとしては優秀すぎるため、フロントエンド不要の時代になり煽りようがないとの指摘もある（>>394, >>398, >>408, >>411）。
- **導入・操作感**: テンプレートワークフローが複雑怪奇になっており何も分からない状態になる。NSFW生成時は規約画面に飛ばされ元の画面への戻し方が分からず発狂しかける事態が発生した。原因は`prompt enhancer`がオンになっていたこと。オフにしたら通るようになった（>>366, >>369, >>370）。
- **AIによる活用**: AIにComfyUIを操作させて線を繋がせたり、ワークフロー（WF）を作らせたりする使い方がされている。AIが生成したWFをComfyUIに読み込ませて微調整するフローもある（>>360, >>364, >>406）。
- **スレ上の対立**: ComfyUIしか認めない民が定期的に湧くが、ComfyUIでしかできない事をしている人は大していないという指摘がある。ワンクリックUI（旧来のUI）から自作UIでagent経由で使うまで幅があるスレであり、A1111系の話をすると必ずComfyUI推しが現れると指摘されている（>>352, >>367, >>385, >>400）。
- **対応状況**: MOSSのテンプレートWFのネガティブプロンプトにnsfwが入っており気づいていないユーザーがいる模様（>>246）。

## webUI / A1111 / Forge系

- **選ばれている理由**: 生成速度がForgeの方が早い。プロンプト以外のことで頭を使いたくないためForge Neo派がいる。リアス（illustrious）のように枯れていて新しいワークフローが出ない場合は、画面に余計なものがないForge Neoの方が効率が良い。新しい事を覚えるのがしんどいという理由で使い慣れた環境に留まる人は「ただの老化」とスレ上で指摘されている（>>353, >>359, >>394, >>399）。
- **forge neo**: MOSSを動かすために使用可能。anima以降のモデルならforge neoが出ているため、それを使うという案内がある。ただし「もう使いにくいまである」との声もある（>>334, >>335, >>336）。
- **A1111**: SD1.5やSDXL時代にForgeを使っていた層は多い。小さなおっぱいが好きなA1111ユーザーもいる。Forge Neoユーザーのレベルについて「git pull？なにそれ？」と揶揄する声あり（>>343, >>367, >>374）。

## rusting strata

- **選ばれている理由**: 軽くてクソ速い。64GB環境でもツール複数立ち上げられる。環境を作るまでが大変だが、strataよりかなり快適になる。strata+dsh完全依存になったという声があり、AIの方が画風制御確実に上手いとのこと（>>272, >>284, >>406）。
- **対応モデル**: strataで使うモデルならどのモデルでもいける。モデルや環境によって調整がかなり難しい。リファレンスマシンがRTX3060/12GB、RAM32GBの環境で使用可能（>>284, >>301）。
- **導入時の注意**: Windowsの場合「install the Visual Studio C++ Build Tools first」と書いてある。自分でRustを使ってビルドする必要がある。一部ユーザーには合わなかったという報告もあるが、生成以外の用途には使う可能性があるとのこと（>>284, >>424）。

## sd-scripts / Fizgig

- トレーニング中にその場で生成してチェックできるのが便利。sd-scriptsにはプレビュー生成オプション（`sample_every_n_epochs`）があるが、その場で確認出来ないと嫌だというニキもいる（>>287, >>302, >>317）。

## Claude / チャッピー（AIエージェント系ツール）

- **Claude**: コスパがアホみたいに悪い。Freeで慣らし運転がてら質疑応答させてたら「5時まで待て」と言われた。使用量少なすぎるとの不満がある（>>257, >>323）。
- **チャッピー**: Claudeのように質疑応答に使われる。

## minimax

- 動画はいいが、声が言うことを聞いてくれない。呼吸音だけだと言ってるのに笑い出したり謎の言語を話す問題があり、叫びすぎる。解決できているかスレ上で不明（>>368）。

## Image Studio / P-H3

- P-H3が意外と有能だったため、Image Studioとの使い分けが行われている（>>415）。

## Banana / bbox

- t2iでポン出しした絵をi2iや編集モデルで直すフローと変わらない動きをしている可能性が示唆されている。bboxの発展型のようなものが入れば近いうちに起こった未来になりそう、とのスレ上の見解がある（>>437）。

## open code

- デフォルトで思考を展開するようになった。エージェントのコマンドを見直したり眺めたりしている。主な注意箇所はshellコマンドで変な事されてないか見ること。絶対パス表示で対象プロジェクトと関係ない場所を触ってないか確認している（>>435）。

# 生成AI関連ツール話題 抽出レポート

## ComfyUI

- **Windows 26H2でのDLLブロック問題**: デスクトップ版ComfyUIをWindows 26H2に更新するとDLLブロックされるという報告がある（>>42）。ただし、実際に26H2環境でデスクトップ版ComfyUIを問題なく使用しているユーザーもおり、事象の再現性には個人差がある模様（>>43, >>44）。
- **Smart App Controlとの併用**: WindowsのSmart App Controlをオフにすれば問題を回避できるという指摘がある（>>47）。
- **VRAM割り当ての最適化**: StrataとComfyUIを併用する場合、VRAM 16GBの環境では8GBをStrata、8GBをComfyUIに割り振ることで、画像ロスほぼ無しで併用動作が可能になったという報告がある（>>212）。また、strata+comfyを想定するとVRAMは16や24よりも12＋12（2GPU構成）の方が良いというスレ上の見解がある（>>202）。

## デスクトップ版ComfyUI / ターミナル起動

- **起動方法の比較**: デスクトップ版はモデルの読み込みが遅いという指摘がある（>>53）。モデルのjsonと同じフォルダにあるbatファイル経由でターミナル起動した方が早く、エージェント機能を使わない場合はこちらが推奨される（>>53）。bat起動では起動前処理も仕込める利点がある（>>53）。
- **用途の使い分け**: デスクトップアプリはモデル管理とアプデ管理に用い、ターミナル版はアプデがバグってできないため、用途に応じて使い分けるのが推奨される（>>53）。

## ForgeNeo

- **Anima RGBA対応**: ForgeNeoのコミット情報で「Anima RGBA」対応（元々はComfyUI用）が確認された（>>203）。背景透過画像が作りやすくなるVAEとLoRAのような仕様であり、素材用途に良い可能性があるというスレ上の感想がある（>>203）。

## redrayzニキのGUI

- **LoRA学習の効率化**: redrayzニキのGUIを用いてLoRA学習を行ったところ、わずか1時間半でこれまでで一番良いLoRAが完成したという報告がある（>>165）。以前はfizgigで連日10時間近く学習していたが、手法変更で大幅な時間短縮が実現した（>>165）。さらに未実施であれば1〜2割程度の高速化の余地がある可能性も指摘されている（>>176）。

## Strata

- **ローカル環境での活用**: Echo Show改造でオカズ絵生成を声でStrataに依頼し、結果を表示できるようにしたという報告がある（>>46）。純正Strataは使用せず、もっと軽くて速いものをビルドして使う選択肢もあるという指摘もある（>>196）。
- **8GB対応**: 8GB対応したことでVRAM 16GB環境でのStrata / ComfyUIへの8GBずつの割り当て併用動作が可能になった（>>212）。
- **ハードウェア要件のスレ上の見解**: strata16または12でも十分動くという意見がある（>>199）。

## Astra (AIエージェント)

- **PLaMo 3 Translateの導入**: AstraにPLaMo 3 TranslateをWebUI付きでインストールし、垢BANを気にせずに自然言語エロプロンプトの翻訳に利用できるようにしたという報告がある（>>45）。ただし、普段エロ検索やエロ画像生成を行っているPCで実行させた場合、それだけでBAN候補リスト入りするリスクがあるとの指摘もある（>>48）。

## 環境整理とストレージ解放

- **古いツール群の削除**: EasyWan, EasyWan22, sd-webui, forge, forge2, reforge, Fooocusといった古い環境を整理し、500GBを解放したという報告がある（>>111）。これはStrataがQwen4 Flashに対応する可能性を見据えた対応とのこと（>>111）。

## Qwenシリーズ（画像生成以外の話題）

- **Qwen3.5-9Bへの言及**: 「Qwen3.5-9B超すげーやん」という感想がある（>>108）。
- **Qwen4 Flashの対応期待**: StrataがQwen4 Flashに対応するかもしれないという見通しが語られており（>>111）、来週来るであろうQwen 4の性能次第で、ローカルで現実的な速度で動くflashモデルをオープンウェイトでリリースしてくるかどうかが注目されている（>>195）。
- **Qwen-Image (QIE) 関連ツール利用**: QIEやkrea2から置き換える価値があるというツール利用の文脈での言及がある（>>27）。

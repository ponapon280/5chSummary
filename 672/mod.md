# 元の本文
**レポート冒頭まとめ：流行しているモデル**

抽出された複数のログから、**Anima** が最も言及頻度が高く、コミュニティの中心的な存在であることが明確です。次に **NovelAI (NAI)**（特に v5 への期待）と **illustrious（リアス / IL）** が頻繁に比較対象として登場します。新星として **Krea2（turbo/raw 版含む）** が急速に台頭しており、「Anima との住み分け」（二次 vs 三次・正確性重視）で評価されています。**FLUX（FLUX3dev）** と **Qwen-Image** は性能面での期待値が高く語られていますが、実際の使用報告はまだ少ない状況です。動画用途では **Wan** や **LTX** が言及されます。

全体の傾向として、**軽量・コスパ・プロンプト追従性・LoRA相性** が選定の鍵となっており、エロ生成のしやすさ（規制緩さ）も重要なファクターです。

### Anima（Anima / Anima base / AnimaWAI など）
最も言及が多いモデル。**軽量で生成速度が速い**（例: 1280x1280/30step で約9秒）、**プロンプト追従性が高く「素直」**、自然言語・タグ両対応が優れている点が選ばれている主な理由です。LoRAとの相性が良く、理想のキャラが出しやすい一方、NSFW時に画質劣化しやすいという指摘もあります。ComfyUI ワークフローが充実しており、二次イラスト・キャラ再現に強いと評価。純血版が扱いやすいという声多数。Krea2 との併用・住み分けも提案されています。

### NovelAI (NAI / NAI v5)
非常に多く言及され、特に**エロ生成のしやすさ・規制の緩さ** が選定理由として強調されます。手軽に高品質なエロが出せ、ローカル勢との比較で優位性が出る点が魅力。公式ギャラリーのクオリティへの不満や値上げ懸念も話題ですが、NAI v5 への期待が大きいです。

### illustrious（リアス / ill / IL / リアスWAI）
Anima と最も頻繁に比較されるモデル。「マージモデルでないと扱いづらい」という声がある一方、**絵柄が薄く LoRA が乗りやすい** 点や、エロ表現の強さが評価されます。Anima への移行が進む中でも「安心感から抜け出せない」という意見があり、併用されるケースも見られます。

### Krea2（Krea-2 / krea2_turbo / krea2_raw / Krea2 Cat Tower など）
最近台頭している新星モデル。**プロンプト追従性・指示理解力が高く複雑な構図・配置を正確に再現しやすい**、**日本語文字の再現性・自然言語対応が強い**、**三次元寄り・無機物・背景描写が上手い** 点が選ばれている理由です。turbo 版の高速化（int4/int8_convrot など）も話題。Anima との住み分け（Anima: 二次・エロ容易、Krea2: 正確さ・質感重視）で推奨される声が多く、将来的な覇権候補として期待されています。検閲フィルターの影響や LoRA 挿入時の劣化も指摘されます。

### FLUX（FLUX3dev / FLUX3）
**オープンソースでローカル運用可能** という点が最大の魅力。動画生成での高性能への期待が語られていますが、VRAM 消費が重いという現実的な課題も指摘されています。

### Qwen-Image（Qwen-Image-3.0 / QIE）
**小さな文字を含む画像生成や物体の質感表現が得意**、Edit 機能（QIE）への期待が高い点が選定理由です。オープンソースかどうかの議論も見られます。

### その他のモデル
- **Wan**: 動画生成で言及（リアル寄り表現や低解像度時のディテール保持）。ネガティブ評価も一部あり。
- **LTX（LTX-2.3）**: 動画生成用途でワークフローとの相性が良いとされる。
- **Mage-Flow**: 高速動作（turbo 版で数秒）が評価され、ComfyUI 対応で使いやすい。
- **PixelDiT**: Krea2 との組み合わせでアップスケーラーとして実用的。

**全体傾向**: Anima と Krea2 の二強（または住み分け）構造が強まりつつあり、エロ・二次イラスト重視なら Anima、正確性・多用途なら Krea2 が支持されています。NAI はクラウドの無検閲ツールとして独自の位置を保っています。

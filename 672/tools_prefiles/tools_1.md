**抽出されたツール関連話題（モデルは除外）:**

- **Forge / ForgeNeo**  
  ForgeNeoアップデートでダイナミックプロンプトが使えなくなったという不満が複数あり、「Forgeはもう限界」との声。ComfyUIへの移行を検討するきっかけになっている。

- **ComfyUI**  
  Forgeの限界を感じた人が「ComfyUI『こっちへ おいでよ....』」と誘われる形で言及。複雑さで一度挫折した人が「そろそろ本気でやるか」と再検討する流れで登場。

- **sd-scripts (kohya)**  
  kohya氏の更新で「subsetごとにtimestepをずらす機能」が追加されたことが話題。LoRA作成時のクオリティ向上を期待して取り上げられている。

- **nano-banana**  
  Qwen ImageのEdit機能と比較して「nano bananaに肉薄してええんやで」と評価。Editの独立した使い勝手がnano-bananaに近づいている点がポジティブに言及されている。

- **Qwen関連の非画像生成話題**  
  「オープンソースじゃないQwenって使うメリットあるかね？」という質問があり、企業向けの利用条件やファインチューニングのしやすさといった観点でツール/サービスとしてのQwenが議論されている。

**選ばれている理由の抜粋:**
- Forge → 以前は手軽だったが最近のアップデートで機能制限が目立つようになったため。
- ComfyUI → Forgeの限界を突破するための次の選択肢として。
- sd-scripts → 細かい学習制御（timestepずらし）でLoRA品質を上げられるため。
- nano-banana → Edit機能の使い勝手が近く、Qwen ImageのEditがそれに迫っている点で注目。

モデル（NAI, FLUX, Wan, anima, Qwen-Image本体など）の話題はすべて除外しています。

**抽出結果**

### anima（Anima / Anima base / AnimaWAI）
- **最も多く言及されているモデル**。
- **選ばれている理由・評価**:
  - プロンプト追従性が高く「素直な子」と評される。タグや自然言語の両方に素直に反応する。
  - 自然言語プロンプトとの相性が良く、クオリティタグを入れなくてもある程度綺麗に出やすい。
  - NSFW生成時は「部族語（Danbooruタグ）」＋自然言語の併用が推奨される。
  - 絵柄LoRAやキャラLoRAの影響を強く受ける（良い面でも悪い面でも）。学習素材の画風に素直に従うため、素材が弱いと劣化しやすい。
  - 純血（マージなし）のAnimaが一番扱いやすいという意見多数。マージすると特性が薄れる傾向あり。
  - WAI版（AnimaWAI / WAI Anima）は「絵柄が薄いのでLoRAが反映しやすい」と評価する声あり。

### illustrious（リアス / リアスWAI / IL）
- Animaと**最も頻繁に比較**されている。
- **選ばれている理由・評価**:
  - Animaと比べて「マージモデルでないと扱いづらい」という声がある一方、リアスWAIは「絵柄が薄くてLoRAが乗りやすい」と好評。
  - Animaに移行する人が増えているが、「リアスの実家のような安心感から抜け出せない」という意見も。
  - NSFWでの比較では「Animaの方が強い」という声が優勢だが、好みで分かれている。

### Krea2（krea2 / krea2_turbo）
- 最近台頭している新星として複数言及。
- **選ばれている理由**:
  - 3次元（三次）寄りの生成で特に評価が高い。
  - 日本語の文字入れが強い。
  - 「Animaで二次、Krea2で三次」という住み分けを提案する声あり。
  - turbo版（int4/int8convrotなど）の高速化が話題。

### Wan / LTX
- 動画生成の文脈で1回だけ言及。
  - 「動画はwanとltxをシーンに合わせて使い分け」という記述あり。
  - 詳細な評価や選定理由はなし。

### その他
- **FLUX**: 将来的なFLUX3への言及あり。「次世代」として期待する声はあるが、現時点では具体的な使用報告なし。
- **NovelAI / Qwen-Image / Z-Image / illustrious（純粋なIL）**: このログ内ではほとんど言及なし。

### 傾向まとめ
- このスレッドの主戦場は **anima vs リアス** の比較。
- Animaは「素直さ・追従性」を理由に支持を集めているが、LoRAの影響を受けやすい点が両刃の剣になっている。
- Krea2は「新しい選択肢」として徐々に勢力を伸ばしつつある状況。

**抽出された「モデル」関連話題（除外対象外のものに限定）**

### 1. **Mage-Flow**
- **言及内容**: Hugging FaceのComfy-Orgに登場したモデル。実際に試したユーザーが「3次・2次両方で生成を試した」と報告。
- **選ばれている理由・評価**:
  - `turbo`（int8convrot使用）で非常に高速（3060/12GBで2秒程度）。
  - 手軽さと速度を重視した選択。
  - エロ生成については「ニキらに任せた」と評価を保留。

### 2. **Krea2 / krea2（krea2_raw, krea2_turbo含む）**
- **言及内容**: 複数人で話題に上がっており、特に二次元画像生成で注目されているモデル。`krea2_turbo`と`krea2_raw`の比較も行われている。
- **選ばれている理由・評価**:
  - 日本語テキストの再現性が良い。
  - `turbo`版は速度と安定性を重視して使われている（ターボ有無で生成結果が変化するとの報告あり）。
  - 将来的にAnimaとの組み合わせ（三次→Krea2、二次→Anima）が「覇権になりそう」との意見。
  - スペック的に厳しい環境でもint4convrotなどで実用性を模索する動きあり。

### 3. **その他の言及（参考程度）**
- **SD1.5 / SDXL**: ベースモデルとしての比較対象として出てくるが、具体的な新機能検証ではなく過去の特性（追従性の良さ・悪さ）として語られる。
- **WAI（AnimaWAI / リアスWAI）**: 除外対象のAnima・リアスと強く結びついているため、独立したモデル話題としては除外。

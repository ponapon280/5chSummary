# 元の本文
**レポート: 生成AIモデルに関するコミュニティ議論の分析（2026年時点）**

複数の抽出結果（ログ/スレッド）から、生成AIモデル（主に画像・動画生成向けローカル/オープンウェイトモデル）の言及と選定理由をまとめました。テキスト全体を通じて、**MiniMax H3（mmh3 / MiniMax H3）とKrea2の組み合わせ**が最も活発に議論され、「最強の布陣」として高く評価されている点が目立ちます。これらは動画生成の動きの自然さ・長尺化（Context Loop）と静止画の細部・ディテール向上を補完し合うため、静画→動画ワークフローの中心となっています。次点で**anima**（ローカル生成の起点・速度面）と**Qwen（Qwen3.8-27B）**（プロンプト作成用LLM）が実用的用途で人気です。illustriousはアップスケーラーや高品質画像生成で根強い支持がありますが、制御面で新モデルに劣る指摘も見られます。

### 1. MiniMax H3（mmh3 / MiniMax H3 / H3）
- **言及の多さ**: 最も頻出。動画生成性能（i2v/t2vの動きの良さ、アニメ・リアル両対応）、Context Loopによる長尺動画作成、Krea2との相性、NSFW LoRAの存在、低VRAM最適化（Sol-Attnなど）で繰り返し取り上げられています。
- **選ばれている主な理由**: 動きの品質と実用性のバランスが優れている；Krea2で静画を固めてH3で動画化するワークフローが「最強」とされる；プロンプト追従性が高く、NSFW調整やリファレンス制御が柔軟；コミュニティによる急速な改善（LoRA公開、最適化共有）；低〜中スペック環境でも工夫次第で実用可能。
- **その他の言及**: Turbo版の高速化、インペイント機能、システムプロンプトのカスタマイズ例など。

### 2. Krea2（Krea / Krea3）
- **言及の多さ**: H3と並んで頻出。特にH3との組み合わせで評価。
- **選ばれている主な理由**: 解像度・ディテール・細部の自然さが優位；自然言語プロンプト（日本語対応含む）で扱いやすい；H3の弱点を補完する静画生成ツールとして最適。
- **その他の言及**: 動画対応やedit特化版への期待（Krea3）。

### 3. anima
- **言及の多さ**: 複数ログで登場（生成起点、速度向上、mmh3との併用）。
- **選ばれている主な理由**: ComfyUIアップデートによる生成速度の大幅向上（例: 36秒→22秒）；低スペック環境でも動く；アニメ調生成の起点として実用的；ck attention使用時の速度優位性。
- **その他の言及**: アップスケール時の組み合わせ（illustriousとの比較）。

### 4. Qwen（Qwen-Image / Qwen3.8-27Bなど）
- **言及の多さ**: プロンプト作成・LLM用途で多数。
- **選ばれている主な理由**: プロンプト生成（特にT2V/動画向け）で優秀；システムプロンプトの遵守・ざっくり指示の解釈力が強い；thinking ON/OFFの切り替えで賢さ/速度を制御可能；エージェント性能が高い。
- **その他の言及**: エロ理解力はGemmaに劣るが全体的な実用性で評価；日本語の品質低下が弱点。

### 5. illustrious（リアス / ill / IL / Illustrious XL）
- **言及の多さ**: アップスケーラーや画像品質評価で登場。
- **選ばれている主な理由**: 絵そのものの完成度・ディテールが依然として最高峰；Danbooruタグ対応や高解像度生成に強い。
- **その他の言及**: animaアップスケール時の候補だが、黒表現（暗部）の弱さがネック；細かい制御（位置関係など）では新モデルに劣るという指摘。

### 6. その他のモデル
- **LTX（LTX-2.3 / LTX2.5）**: Latent Upscale技術のソースとして言及。オープンウェイト化の好例。
- **Wan（WAN2.2など）**: 過去の主流モデルとして歴史的に触れられ、エロ表現のしやすさが一部評価。
- **NovelAI（NAI）**: 歴史的ルーツとして言及されるが、現在は存在価値が薄れているとの声。
- **FLUX / Z-Image**: ログ内での言及はほとんどなし。
- **Gemma4**: プロンプト作成用LLMとしてQwenと比較され、エロ・日本語の情緒理解で評価される場合あり。
- **Seedream / Seedance（ByteDance）**: H3との比較で局部学習や参照制御の話題。

**全体の傾向**: 議論の中心は**MiniMax H3 + Krea2**の動画生成ワークフロー。animaはローカル手軽さ、Qwenは補助LLMとして実用的。速度最適化（Sol-Attn/Sage Attention、ComfyUIノード）や低VRAM対応が共通の関心事です。除外対象外のモデルは主にこれらです。

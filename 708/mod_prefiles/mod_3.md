# 生成AIモデル関連話題の抽出レポート

## MOSS-Image (MOSS, moss, モス, もす)
- **基本情報・立ち位置**: 復旦大学と上海イノベーション機構のOpenMOSSチームがPre-Aラウンドで約1億4,900万ドルの資金を元に作成。約30億枚の画像を学習し、9BのTE（テキストエンコーダー）を持つとされる（493, 595）。
- **特徴・評価**:
  - BBox（バウンディングボックス）による構図制御が優れており、体感的に過去一との声（487, 488, 526, 530）。
  - 自然言語での指示が可能で、一般知識が豊富。Animaやリアスでは苦労したイソギンチャク等も出せる（501, 630）。
  - セリフや擬音のBBox配置に強く、ネタ画像や漫画作成に相性が良い（509, 523, 526, 528）。
  - 左右の指示（left/right）の認識が正確。Animaではごっちゃになりがちだった指示も正確に出せる（509）。
  - 学習コストが桁違いで高く、派生モデルの開発が絶望的との指摘。公式アニメ版が期待外れなら終わる可能性も（499）。
  - ポン出し（そのまま出力）の二次元画像はリアスやAnimaに及ばないとの声も（618）。
  - booruタグ（部族語）は単語としては反応するものの、ポーズ指定等で困ることがあるとの意見。公式もdanbooruタグを学習に使っているが効果の程度はよく分からないと表明（535, 544, 575, 581）。
  - 指が弱い（よわよわ）という指摘（613）。
- **LoRA学習**:
  - MOSS Image Baseで画風LoRAを300枚・10000steps・4.5hで作成。5000steps程度でも良いかも（475, 599）。
  - LoRA作成時、目が溶けたりドット絵っぽくならない等の不具合報告あり（431）。
  - FizgigでのLoRA作成報告：VRAM 8Gでも可能、50epochs（step数3000強）で1時間半。50steps（_epochsの誤記）ではない（539, 540）。
  - 画風LoRAを作っても背景が馴染んでいない印象（504）。
  - キャラの再現度がやや甘く、さらに研究が必要との声（567）。
- **他モデルとの比較**:
  - 能力はリアスやAnimaより桁違い（499）。Anima不要論を唱える層がMOSS不要論にスライドしたと見る向きも（562, 565）。
  - MOSSを一通り使った後Animaに戻ると、軽さとポン出し抜き用途の重要性を実感する（550）。
  - 細かいエロ部分の制御はAnimaやリアスの方が強い（592）。

## Anima (アニマ)
- 学習枚数が数百万枚とされ、モデル自体の表現力に限界があるため、TEを0.6bより強化しても効果がない可能性が指摘されている（493）。
- 軽さが利点であり、ポン出し抜き用途では重要（550）。
- booruタグ拡張について、Animaでもタグベースで互換があるのではという声（492）。
- 細かいエロ部分の制御に強い（592）。
- 日本語表示ができれば神と言われていたが、それが叶ったモデル（MOSS）が出たためモスの存在意義を主張する声（564）。

## SDXL / NoobAI / illustrious-XL / リアス
- **SDXL / NoobAI / illustrious-XL**: 学習枚数がillustrious-XLで750万枚、NoobAIは追加学習+1300万枚。個人や小規模チームでも派生モデル開発が可能なレベル（499）。
- **リアス**: すでに時代遅れの化石との声もあるが、過去作を見ると依然として可愛いとの意見。荒々しい部分を脳が補正している可能性（503, 558）。Animaやリアスは細かいエロ部分に強い（592）。forgeは現役でcomfyのxyz比較が禿げるとの声（450）。
- Animaからリアスに戻す際も同様の知見がある（556）。

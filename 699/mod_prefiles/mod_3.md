## anima
選ばれる／使われる理由と不満がセットで語られている。

- **部族語（Danbooru語）と自然言語の食い合わせ**
  - Danbooru非対応というより、部族語認識でなんとなく通る程度、という見方（>>448）。
  - キャラは自然言語なしでも通る。細かいポーズ指定のときだけ自然言語の方が都合がいい（>>451）。
  - 一方、部族語をがっつり学習しているので、英語の中に部族語が混ざるとそっちに引っ張られる。例: “poking through” が「つつく」動作になった（>>449）。
  - 位置関係（前景・中景・後景など）はDanbooru語だけでは対応できない（>>475）。
- **硬さ**
  - まだ硬く、i2iで一次生成してからでないとダメ、という不満。がっつり作り直したい（>>455）。
- **自然言語を使う場面**
  - 思い通りに出ないときくらいしか自然言語は使わない、という人もいる。
  - `sweat` / `blush` が竿役に伝染するとき、`male blushing` をnegpipすると男だけ消える。そのとき自然言語が通るのはありがたい（>>466）。
- **サイズ**
  - 2.9Bか3.8Bか、という質問のみ（>>467）。どちらを選ぶ理由は出ていない。
- **速度・環境**
  - Mac mini M6 + DrawThings で、M4比3倍以上速い（>>450）。
  - Gemma4 26B-A4B にanima用プロンプトを作らせている人がおり、不満は少なく、何より速いのが良い（>>506）。
- **素材作り**
  - MiniMax ref2va用LoRAの学習素材（正常位・騎乗位など）をanimaで作った、という報告（>>513, >>628付近）。
- **評価の軸**
  - 「二次エロ」資産と比べるとSDXL系に負けるが、純粋な性能ではanimaの方が上、という主観（>>619）。

## MiniMax-H3 / Ref2VA / FL2VA

- 動画生成の中心。参照画像が適切だと、それまでKrea2では出なかった概念をH3が理解して満足できる結果になった、という報告（効果音は弱い）。
- 選ばれる理由は動きと参照追従。よく言われる比較では **FL2VAの方がRef2VAより動画品質・動きが良い**。その代わり眉毛が意図どおりになりにくい。多くの人はRef2VA用ワークフローにFL2VAを載せて使い、たまにRef2VAに戻す程度。Ref2VA用パッチをFL2VAに当てるやり方も模索されている。
- int8のハイブリッドsafetensorsは通常のRef2VAより劣った、という比較あり。ハイブリッドローダーはメモリを食う、という指摘。
- 不安定さの話題が多い。同じ設定で10秒生成が90分、12秒なら20分、途中stepから急に遅くなる、再起動やプロンプト・参照変更で直る、など。VRAM溢れやComfyUI側の扱いが疑われ、最新版で緩和するとの情報もある。高速化（SageAttention、Kitchen、SolAttn、Spectrum、Sparse等）は設定がバラバラで併用可否も不明、品質が落ちるので使わないのが正解、という意見。
- 8GBでも、動画・音声を素材に入れなければFizgigで局所修正LoRAが約2時間、という話。Ref2VA 1f LoRAは上下運動の補助用に試作され、本家よりねっとりする・局部が淡いアニメ調になる、という効能報告。素材とプロンプト次第で改善も崩壊もある。

## OpenAI系（Astra / Sol / Luna / GPT-6 / Codex / Chat Pro）

画像モデルではなく、実装・レビュー・3D補助での使い分け。

- **Astra**: 賢いが消費が極端。リモート操作やBlenderのComputer Useで十数分、あるいは$20枠が一瞬で溶ける。コードレビューなど重い仕事に回す人がいる。Chat側Proの方がAstraより賢く感じる、という声もある。
- **Sol**: 通常作業用。Astraは消費が速すぎるのでSolで十分、という使い方。高Solでレビュー、低Solで実装、という節約案。
- **Luna / GPT-6 Luna**: Plus勢にはAstraが重すぎるので助かる、という理由で歓迎。ただし5.6 Lunaは安い代わりにバグが多く、レビューで差し戻されて時間効率が悪い。GPT-6 Luna / GPT-6 Solは使えるようになった、という報告。Terraは見当たらない。
- **Codex**: 実装担当。週間リセットの有無と残量の話が中心。Chat Proで設計してからCodexに渡すと実装側の負担が減る、という運用。
- **ChatGPT Pro / x20**: 計画・レビュー用。x20は常時多数プロダクトとOpenClaw（1日約50万トークン、約1000回）でも一週間持たせられるが工夫が要る、という報告。

## 全体像

画像・動画生成のローカル勢スレ。話題の軸は **Qwen Image Edit 2.1（QI / QIE2.1）の実使用感**、**GPT系 Sol / Luna の位置づけ**、**Live2D・I2Vの泥臭さ**、**VRAM・起動オプション**、**電力・GPU供給**。モデル名は略称・聞き間違いが多く、断定より「スレ内の体感」として読むべき内容。

## 1. Live2D・動画化

- Live2Dは自動まばたき等を触っても自然にならず、3Dに近い力作業という感想。
- 大きい動きは動画生成のシームレス再生の方が早いのでは、という案に対し、細部の不一致・透過・微調整不能がネック、という反論。
- Minimax系の I2V / R2V で「元絵を崩さず Live2D風に固定」「MP3を音声参照」したい質問が複数。
  - 用途が逆、という指摘（音声参照は ref2v 側、元画像を動かすのは i2v 側）。
  - FL2V 系は音声入力を受け付けない／無視、という見立て。
  - 回避案として、empty latent の代わりに MP3 を VAE encode して mask したものを入れる、公式MMD画像＋T2V音声でリップシンク試験、ComfyUI の FL2VA テンプレに参照を挟む、など。
  - 成功例では「台詞をプロンプトに日本語で書く＋音声参照」が通り、テキストエンコーダ性能が効いた、という報告。生成音声はノイズが乗るので、リップシンク確認後は元音声に差し替える、という運用。

## 2. クラウドLLMの席次

- 「GPT-6 Sol / Luna」リリース告知の転載。API恒久50%値下げ、Plus/Pro/Business にリセット機能、という文面。直後に「リセットそのものではなくリセット券配布」「期限まで自分のタイミングで使える方が良い」という訂正・評価。
- 席次の私見: Luna は据え置き、Sol は旧 Terra 枠、Astra が Sol 枠に上がり **Terra は死んだ**、でほぼ一致。Terra メインだった人は少数、という空気。
- Sol 6 はパッとしない、Claude / Opus 5.5 のターン、という流れ。Opus 5.5 は「Astra越え」「ナーフなしで頼む」。
- リセット権は自動ではなく手動。知らずに Ultra を消費した、期限を見て初めて気づいた、という失敗談。
- 評価軸が不明、という問いには明確な合意なし。エロ耐性、文章、体感品質が混在。
- ロールプレイで愛着が出る、性能が上がると「壁打ち」では済まなくなる、という感想。AIへの罵倒は信頼の裏返しでは、という返しも。

## 4. その他モデル

- **NAI**: 連休に触って機能が増えていた。V5 は描き文字のテキストと色を指示できる（ガチャは残る）。規制の有無は疑問形のまま。ローカルに欲しいのはお手軽位置指定と高精度インペイント。
- **Anima**: 軽量級なので本命比較の対象外、という意見。多人数は弱く、SDXLより上か下かで争い。長文のLLM製プロンプトを入れると破綻、解像度で人数が変わる、Danbooru チューンの副作用では、という見方。キャラLoRAは作りやすいが、抜きのランダム性は Illustrative / SDXL 系（スレ内「リアス」）がまだ強い、という悩み。
- **SDXL / リアス**: 進化が止まった分、FT・マージ・LoRAが豊富。絵柄・絡み・背景はまだ一線、という擁護と、おじいちゃん扱いが併存。タグ直結の U-Net 時代の「絵師タグ大量」は DiT 以降は再現しにくい、という整理。
- **Minimax / H3**: 動画は強いが画風指定は劣る、お淑やかで抜きには至らない、という対比。昔の Grok 動画の「祭り」感を懐かしむ声。規制の強い Grok Imagine より意図どおり作りやすく、Seed 固定が有用、という評価。H3 の最大尺は公式15秒、という指摘。初動の it/s が異常に遅く見えても放置すると普段の時間に収束する、という報告（0.6MP・15秒で約810分、という記述はそのまま信じると非現実的なので、誤記か誇張の可能性が高い）。
- **LoRA**: Qwen2.1 の画風 LoRA は AItoolkit だと破綻。強度を下げると画風が死ぬ。Musubi tuner / kohya の対応待ち。優先度は低め、という情報で絶望、という書き込み。
- **Ming-Image**: デザイン特化でニーズはズレるが、アニメベースとしての画面の煩さの少なさを評価する声。

## 5. 実行環境・不具合

- 検証環境の一例: RTX 6000 Ada 48GB、RAM 128GB。Civitai 配布のオールインワン WF。家庭GPUとは別物、という自覚。
- 1.2MP・20秒は 5090 でも OOM、という質問。モデル依存、H3 は15秒が上限、という返し。
- `--fast fp16_accumulation` は人によって爆速（VAE を int8 にするとデコードが速く、見た目は fp16 と区別つかない）と、エラーで Python が落ち再起動しかない、に割れる。
- 同フラグ＋ ComfyKittinAttention 有効で Krea2 / QI2.1 がプロンプトを無視、というバグレポート。起動オプションは全体に効くので、KJ Nodes の Model Patch Torch Settings で個別設定が安全、という助言。
- VAE バグ（#15416）は未クローズのため、遅い AI Toolkit の VAE を使い続けている人。
- Attention 系ノードが低速化の原因になることがあり、外した方が速い環境もある。高速化は spectrum だけで足りる、という報告。
- NVFP4 の TE は Blackwell 必須ではない、という情報。Ada なら即 int8、というより、低VRAM（4060級）では「NVFP4エミュレーションの遅さ vs int8 を PCIe 経由でRAMから読む遅さ」の実測比較が必要、という整理。NVFP4 は速いが順当に劣化する、という以前の感触は更新されていない。
- プロンプトなしでモデル性能を語ると「右も左も理解していない」誤判定が起きる、というメタ注意。

## 6. ハードウェア・経済

- 2GB GDDR7 の Micron 生産終了で供給元が2社に。3GB移行と24GB帯カードの主流化を期待する声と、冬はまだ続く、という悲観。
- ゲームは16GB超え要求がほぼなく、DLSS 系は容量より処理速度。VRAM 32GBに大金は愚かという意見と、128GB級との対比。
- 家庭マイニングは日本の電気代で赤字確定、という主流意見。Pearl が 5090 で日2000円程度、という対抗情報もあるが、検証不能。PC貸し（Vast 等）は計算資源を戻せない・踏み台リスクで非推奨、という警告。
- データセンター集約 vs 家庭エッジで長い論争。電力不足・州電力の23%・増設ストップという米国ニュースを引きつつ、「家庭に置けばピークをずらせる」対「集約の方が効率は開くだけ」「商業と家庭の割合を変える政治的話では」が並立。結論は出ていない。
- Mac でローカルLLMは元を取るのに数十年、という記事の紹介。年契約は次のモデルで無駄になる、という昔の助言の再掲。
- 10年後は「何十万のGPUは狂っていた」ではなく、家庭の電源枠・小型AIが日常になるのでは、という未来予測。

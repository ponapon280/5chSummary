# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI (comfy, comfyui)

- **Strata連携ノード構成**: ComfyUIの既存ノードでStrataでのi2tと処理後のアンロードを実現。Strataのモデルアンロードはcomfyui-requestnodesのRest Api Nodeを使用。プロンプト出力を空文字に変換してrequest_bodyに入力することで実行トリガとしている。Strataのロード時間が約24秒と長い一方、i2t処理が速くロード含めて約40秒で完了。LM Studio/gemma-4-12b-it-uncensored@q8_0の既存フローより2030秒短縮された（レス243）

- **ComfyUIフリーズ・停止問題**: 最新版Pull後にComfyが停止する現象を確認（4時間使用で2回）。中国語ログが出る、ゴミが入る確率が上がった可能性（レス312）。別ユーザーもH3で生成中にcomfyuiが止まり、pythonが応答不能になりタスクキルすら受け付けず再起動が必要になる現象を確認。comfyui 0.36.0、0.37.0、0.38.0でpythonフリーズを確認（レス315）。ここ数日Comfyがpcクラッシャーみたいになっているとの指摘も（レス321）。メモリ関連の可能性あり（RTX3070+RAM64GBでは止まるがRTX5090+RAM192GBでは止まらない、レス320）。古いカスタムノードがWF内で使っていなくてもあるだけでぶっ壊れる要因になるため、ネイティブノードとエージェント自作のシンプルなカスタムノードだけで再構築推奨（レス324）

- **ComfyUIエージェント機能**: comfyにも公式エージェント機能が実装される予定。クラウドでは実装済み、ローカルは数週間後（レス331）

- **ComfyUI生成遅延**: comfyUIを使えるようになったが生成が遅過ぎ、NEOの3倍くらいかかる。ネット調査とAI相談でチューニングしても直らず、クリーンインストールの可能性も示唆（レス350）

- **パッケージ配布**: Install.bat / Start.bat形式でインストール・起動可能なパッケージを作成。空き容量100GB推奨。日本語プロンプトを適切な英文プロンプトに変換する機能付き（レス322）

## その他ツール関連

### irodoriTTS
- irodoriTTS VoiceDesignで好みの声をサンプリングし、通常版でリファレンス音声として指定するのが基本の使い方（レス253、259）
- VoiceDesignで作成、キャプション「耳元でささやくような小声で,優しく,ASMR」、参照ファイルや絵文字は不使用（レス245）

### Live2D
- 動画>>397はLive2Dでできそうという指摘。瞬き表現に対応しているが目の動きが硬い（レス407、415）

### 動画編集ソフト（汎称）
- 実写映像に3Dキャラを被せて合成するソフトが3Dソフトメーカーから出ている（レス400）
- 有料の動画編集ソフトなら素材用意すればコマ落とし合成等をよろしくやってくれそう（レス385）

### bbox（バウンディングボックス機能）
- bboxは便利だが向きを説明するのが難しい。曲線で伝えたいがT2Iが成立しなくなる。unityやblenderの右上にある軸表示のようなものを配置してテキスト変換したい（レス263）
- bboxはお手軽ポン出し勢には四角並べるのが面倒、漫画レベルの構図なら性能不足で居所がわからない（レス264）
- segm（セグメンテーション）という代替機能も言及（レス266）

### Qwen（画像生成以外）
- Qwen3.8 flash nextはVLMとしてはそこまでの性能を感じないがエージェント性能は最高（レス319）。27Bと比較して明確に上との評価（レス328、336）
- Qwen3.8 flashで3D生成の性能が大幅劣化、悲惨な結果（レス368）
- qwen image2.1の使用を確認する質問あり（レス305）

### PCスペック関連（ツール実行環境）
- RTX 5090 32G / RAM192GB環境ではComfyUIフリーズなし（レス320）
- RTX 5070+RAM64GBではComfyUI停止あり（レス320）
- RTX 5090 32G搭載PCが1,449,800(税込)で販売、ソフマップ特価（レス249）
- 今更5090に150万出すならもっと高VRAMのものをという意見（レス295）

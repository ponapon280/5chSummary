# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI (comfy, comfyui)

### 一般的な使用感・移行理由
- Forge/Reforge環境からComfyUIへの移行が進んでいる。理由は「AIにお好みのカスタムノード簡単に作ってもらえるのに気づいてから」（>>179）。ただしLLMに質問しながらでないと使えないとの声も（>>185）
- 最新機能に飛びつくComfyUIユーザーの声が大きいだけとの指摘もある（>>184）
- 画像だけ出すのではなく連携させるならComfyUIは必須という意見（>>198）

### 機能・UI・ノード関連の問題と対応
- パラメータ変更時のクリック無視問題：ノードのパラメータを変える際にクリック4回ほど無視される「uncomfy」な状態（>>152）
- Power Lora Loaderの矢印クリック無反応問題（>>156, >>162）。原因はrgthreeとComfyUIの新フロントエンド干渉。フロントエンドを1.39.19まで戻す回避策がある（>>172）。その後rgthreeが修正、本体とノードをgit pullすると解消 confirmed（>>177, >>182）
- ComfyUI上でノードの繋ぎ方次第で埋め込みプロンプトが消えて読み込みできなくなる問題（>>126）

### minimax導入・赤ちゃん用UI
- minimax導入方法がさっぱりだったためcodexに頼み、寝て起きたら「赤ん坊でも使えるUI」を作ってもらった（>>110）。配布用作らせる予定（>>121, >>127）
- Context Loopに対応した似たようなものを作成したが公開予定なし（>>166）

### カスタムノード・拡張
- **Lora Loader系**：フォルダごとにlora選択できるローダーが便利。大量のloraから選択しやすいが表示がでかいのが欠点（>>167）。plaguekindカスタムノードにもPower LoRAローダーに似たものが入っている（>>168）
- **was node**：旧版更新停止時、codexに新バージョン対応で暫定対処させた。自分用カスタムノードとして自作した方が後々便利（>>174）。後に復活したが自作済み（>>175, >>176）
- **jevノード**：TypedDecisionノードとStart Loopノードを組み合わせてフォルダを利用した自動判定が可能（>>161）

### OpenAI互換API連携
- ComfyUIのOpenAI互換カスタムノードからStrataを動かすことは可能。ただしモデルのアンロードが効かない問題あり（>>205）。ノード開発者の対応待ち（>>199）
- ノード開発者も数日のうちに対応してくる見込み（>>199）

### 動画・音声統合
- ComfyUIのカスタムノードを作って画像も動画も音声もComfyUIで生成できるようにした。v4-largeは標準UIだとVRAM不足で動かなかったが、ComfyUIならDynamic VRAMに対応させて動かせた（>>183）

### 26H2（Windows Server 2025 / 24H2等）互換性
- 26H2に更新してOS使用メモリが4GB減少。ComfyUI等の不具合がないか気になる声（>>139, >>142）

## Infinite Image Browsing (IIB)

- メタデータ検索ならInfinite Image Browsingのスタンドアロン版が「鬼強い」との評価（>>149）
- 機能：タブ式・walkモードはサブディレクトリも展開表示・開いてる全タブ全て検索対象・タグ/モデル/サイズ/LoRA/UI/評価等で絞り込み可能
- 対応セーブノード：SaveImageWithMetaDataUniversal
- API経由でローカルLLMと連携すれば自然文検索/類似画像振り分け/AI解析タグ付けが可能（まだ試していない）
- 課題：LLMのモデル常駐させると画像生成時にアンロードが面倒（>>149）

## irodori (irodoriTTS)

- IRODORIで遊んでいたら10時間溶かした。革命すぎる（>>43）
- 1年以上前からあるとの指摘（>>44）
- 参照音声なしの場合、声の性別がseed値でランダムガチャになる。男女くらいは選ばせて欲しい（>>132）
- VoiceDesignで性別制御できる可能性（>>133）
- 囁き声を出す方法が分からない。Gemini TTSと比べて弱い（>>213）
- 絵文字で制御できるらしいが効果はいまいち（>>223）
- UI自作中だがバチっと決まらない。チャッピーに要件伝えてUIイメージ画像を生成させ、それをベースにUI作らせている（>>180, >>181）

## Strata (推論エンジン)

- Strataは「モデル」ではなく「推論のためのエンジン」。LM StudioでStrataを動かすは意味が通らない（>>201）
- OpenAI互換・Anthropic互換のAPIが用意されており、LM Studio、Bionic、その他エージェントと接続可能（>>199, >>211）
- ComfyUIのOpenAI互換カスタムノードとも仕様上は接続可能（>>199）
- 規制解除版：セットアップ時の最終質問の回答をyにする（>>150）。エロ画像を渡しても安全フィルターが出ない（>>135）
- **Strata IQ3_S オプション規制解除版（4080s/9900X/192GB）**：初回 Thought for 33.7s / 2,430 tokens / 63.9tok/s、2回目 Thought for 4.1s / 588 tokens / 63.4tok/s、現時点最速77.5tok/s。画像からエロ小説作らせたい用途（>>113）
- 自動生成実例：Strataにエロ画像を渡し、前後シチュエーションを考えさせてForgeNeoやComfyのAPIで画像生成。ログとして体位変更や絶頂シーン、再生成指示を出すレベルで動作 confirmed（>>138）
- Strata謹製UIを使用（>>195）
- Claudeに頼んでStrata導入。LM Studioで動かしてるが際どい質問は答えないで思考だけで止まる問題（>>194）。LM Studioではプラグインが必要（>>211）
- 最初はOpenCodeから呼んでいたが、Codexアプリから呼べるよう魔改造（>>207）
- 無料勢はStrataでQwen動かしてlibrechatやOpenWebUIで操る環境を推奨（>>210）
- LLMを起動せずに同じグループ内なら髪の色等で数秒でキャラ特定ができた（>>190）

## MiniMax (i2i / H3)

- MiniMaxのi2iを使ったが画質がちょっと粗くなる。差分作成には精度が欲しい（>>88）
- LoRAなしだとイかせる気概の動きにならない（>>153）
- H3でフェラチオ検証：8stepターボでもプロンプト書き方次第で細かい動き制御可能。20stepならさらに追い込めると予想（>>99）

- krea2やminimax H3は自力のプロンプト力では足りなくなる（>>193）

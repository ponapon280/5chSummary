# 元の本文
**生成AIモデルの人気傾向とレポート（2026年8月時点のログ分析に基づく）**

ログ全体を通じて、**MiniMax H3（MiniMax Music 3 / MMH3 / H3）** が圧倒的に話題の中心となっており、特に動画生成・NSFW対応・ローカル運用・参照機能（ref2vなど）のバランスが評価されている。次点で**anima / Anima2.9B** がキャラクター生成・LoRA学習用途で頻出。**Wan（Wan2.1/Wan2.2）** は動き・物理挙動の再現性で支持され、**illustrious（リアス / IL）** は日常使いのメインとして習慣的に選ばれている。音楽生成分野ではMiniMax Music 3とSuno、ACE-Stepの比較が活発。GeminiはNSFW規制強化で評価を落としている傾向が見られる。

### 1. MiniMax H3（MiniMax Music 3 / MMH3 / H3）
最も言及が多く、複数のログで「一強」とされるモデル。  
**主な選ばれている理由**:
- ローカル運用可能で生成速度が速く、参照機能（ref2v / Context Loop）とNSFWの両立が強い。
- 動画生成のモーション性能・クオリティが高く、特に三次元寄りの動きやエロ動画で優位（Motion Boosterとの組み合わせで腰振りなどの改善例多数）。
- 音楽生成（MiniMax Music 3）でもインストゥルメンタル以外の完成度やNSFW対応でSunoと比較される。
- RAM使用量が大きい（例: 93GB）ため高メモリ環境前提だが、LoRA学習やref機能の実用性が高い。

### 2. anima / Anima2.9B
キャラクター生成・LoRA作成用途で繰り返し登場。  
**主な選ばれている理由**:
- 特定キャラ（乙女ゲーヒロインなど）とのプロンプトマッチング度が高く、表現力・画質の進化が期待できる。
- LoRA学習のワークフロー共有や実験モデルとしての位置づけ。Turboなしでも一定の品質が出るが、生成速度が課題。
- 背景合成や参照画像作成にも活用され、「Lora作る必要がないのは楽」との評価も。

### 3. Wan（Wan2.1 / Wan2.2 / WAN3.0）
動きや物理挙動関連で言及。  
**主な選ばれている理由**:
- 胸の動きなどの物理的挙動再現性が高く、二次エロ性能も評価。
- t2i（テキスト→画像）機能の良さや技術進歩の速さに注目。ローカル版のリリースを待つ声あり。

### 4. illustrious（リアス / ill / IL）
日常のメイン用途で言及。  
**主な選ばれている理由**:
- 「普段リアスしか使わない」という習慣的な選択。アニメ・イラスト生成での安定性・品質が支持されている。

### 5. その他のモデル
- **Qwen（Qwen-Image / Qwen3 / Qwen 27Bなど）**: プロンプト生成用LLMや画像編集（三面図出力）で活用。Geminiより高性能と評価され、検閲解除版でNSFW用途にも。
- **LTX / LightX（Lightx2v / Kijai版）**: ComfyUIワークフローの充実（Ref2v追加など）で利便性が高い。
- **Suno / ACE-Step**: 音楽生成でMiniMax Music 3との比較対象。Sunoはクラウドの手軽さ、ACE-Stepはinstrumentalスイッチの明確さが強み。
- **NovelAI (NAI)**: 出先での手軽な代替手段として言及。
- **FLUX / Z-Image / Gemini**: 言及は少なく、Geminiは規制で厳しい評価。

**全体の傾向**: ローカル派はMiniMax H3やanimaを、クラウド派はSunoやQwenを好む棲み分け。NSFW・モーション・参照機能が選定の大きな軸となっている。

## Web検索による参考情報
- **MiniMax H3**: MiniMax社のオープンウェイトのオムニモーダル動画生成モデル。テキスト・画像・動画・音声を理解し、同期したステレオ音声付き動画（最大2K、15秒程度）を生成可能。成熟コンテンツ（NSFW）のオプトイン対応が特徴で、ref機能や音楽動画用途でも言及される。MiniMax Music 3.0は別途音楽生成モデルとしてフルソング生成に対応。[[1]](https://www.minimax.io/)[[2]](https://www.sogni.ai/models/minimax-h3)[[3]](https://www.minimax.io/blog/minimax-music-3-0-next-generation-open-weights-production-ready-versatile-music-model)
- **Anima-2.9B**: アニメ・イラスト特化のテキスト-to-画像モデル（約29億パラメータ）。CircleStone LabsのAnima 2Bを基にTransformer層を拡張・追加学習したプレビュー版で、LoRA対応が活発。[[4]](https://note.com/toshia_fuji/n/n4e6dea2891b3?hl=en)
- **Wan（Wan2.1 / Wan2.2）**: Wan-Videoプロジェクトのオープンソース動画生成モデル群。T2V/I2V対応で、Wan2.2はMoEアーキテクチャと大規模データにより複雑モーションが強化。消費者向けGPU（4090など）でも動作する効率版あり。[[5]](https://github.com/Wan-Video/Wan2.2)[[6]](https://github.com/Wan-Video/Wan2.1)
- **Illustrious（IL）**: アニメ・イラスト特化のオープンな高性能テキスト-to-画像モデル。詳細プロンプトで多様な画像生成が可能で、Stable Diffusion系ワークフローで人気。[[7]](https://arxiv.org/html/2409.19946v1)

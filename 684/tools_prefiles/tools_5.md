**抽出結果（ツール関連のみ）**

### ComfyUI（comfy）
- **言及多数**：画像・動画生成のワークフロー構築、プロンプトのメタデータ確認、アップスケール、リファレンス設定などで頻出。
- **選ばれている理由**：
  - メタデータからプロンプトが確認できる（>>846）。
  - runpodのプリセットが用意されており、比較的導入しやすい（>>855）。
  - Nightly版を使うことで最新機能（ContexLoopなど）に対応できる（>>977, >>983）。
  - エージェントにワークフローを直接編集・生成させられる柔軟性（>>880）。

### runpod
- **言及多数**：ComfyUIをクラウドで動かすためのGPUレンタルサービスとして登場。
- **選ばれている理由**：
  - ComfyUIのプリセットが最初から用意されており、モデルダウンロードだけで始められる（>>855）。
  - ローカル環境より安定してテスト生成ができる場合がある（>>848）。
  - ただしCUDAバージョンエラーなどのトラブルも報告されている（>>904）。

### Codex（Codex UI / TUI版Grok Build含む）
- **言及**：ComfyUIをより直感的に操作するためのUI/エージェントツールとして複数言及。
- **選ばれている理由**：
  - ComfyUIの複雑な操作を簡略化し、初心者でも扱いやすい直感的な画面を提供（>>938）。
  - 「これ頼むわ！」と指示するだけでエージェントが処理してくれる（>>849）。
  - 無料だと制限があるが、有料課金する価値があると感じる人がいる（>>938）。

### ContexLoop（contex loop）
- **言及**：動画生成ワークフローの一つとして登場。
- **選ばれている理由**：
  - プロットをLLMに作らせた後、ワークフローのjsonを直接編集させたり、エージェントに生成を任せたりできる（>>880）。
  - 長い動画生成時の分割・配置パートを自動化しやすい（>>880, >>884）。

### Hermes Agent
- **言及**：AIエージェントツールとして登場。
- **選ばれている理由**：
  - Telegram経由で外出先からエロ画像・動画を生成・送信するbot作成に使われている（>>949）。
  - メモリ機能があるが、エロ用途ではメモリ汚染を懸念してオフにしているユーザーもいる（>>956）。

### その他ツール関連の言及
- **Nightly版ComfyUI**：安定板ではContexLoopなどの最新機能が使えないため、最新コミット版を使っている人が一定数いる（>>977, >>983）。
- **Kijaiノード**：高速化修正が入るためNightlyを使うメリットとして挙げられている（>>983）。

**除外したもの**：
- Qwen / gemma4 / GrokなどのLLMモデルに関する話題はすべて除外（Qwenの画像生成以外も除外）。
- Minimax H3、Wan、animaなどのモデル名は除外。
- LoRA作成自体はツールではなく学習行為のため除外。

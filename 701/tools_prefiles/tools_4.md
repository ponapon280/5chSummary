# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI

### バージョンアップ・不具合
- **ComfyUI v0.38.0にアップデート後、ブラウザにwebpをドロップしても「ワークフローが見つかりません」となり画像に保存されたワークフローが読み込めなくなる不具合が発生**（708）
- 原因特定の結果、**フロントエンドが原因**と判明。ComfyUI_frontend v1.53.6では読み込めず、v1.52.7にダウングレードすれば読み込めるようになる。v1.52.7→v1.53.6に再アップグレードすると再発（713）
- デスクトップ版のComfyUI（frontend v1.53.6）では問題なく読み込めているという報告あり（730）
- 一方で0.38.0環境でも問題なく読み込めているという報告もあり（729）

### ワークフロー・ノード関連
- 無料チャッピー（ChatGPT）で壁打ちを行い、簡素なv4対応ノードを作成できた。有料AIならより良いものができる可能性（655）
- ワークフローを切り替える際、json書き換えで対応可能（667）
- 別のワークフローを用意してそれを呼べばよく、大半はAIが要求を満たすワークフローを作ってくれる。入力部分はワークフロー間で大差なくスイッチのON/OFF程度の差であるためAIにとってはお手の物（673）
- サンプルwfを無編集で使っても凄いぼんやりした画像しかできず、cfg3で合っているか疑問という報告（676）
- **現在comfyuiでv4が使えないのはlargeだけ**という指摘（677）
- ノード更新待ちで様子見しているという報告（675）
- チャッピーにノード修正をやらせたが修正が面倒だった（831）

### Codex（OpenAI）でカスタムノード作成中のBAN事例
- ComfyUIのカスタムノード作成にCodexを使用していたところ、OpenAIアカウントが無効化された（764）
- カスタムノード作成時、CodexがComfyUIフォルダにアクセスし、outputフォルダ等（アウロリ画像等）を見られた可能性が指摘されている（784、793）
- ComfyUIを触らせるとInput/Output/Models等のフォルダはサンドボックス内になるため、BANリスク回避には開発用のComfyUI環境を別途用意するのが安全（823）

### AIによるワークフロー・ツール作成
- Claudeにローカルツールを作らせ、盆栽の手入れのようにチョキチョキ手を入れるのに幸福感を得られる（839）
- Claudeにローカルのファイルをガンガンいじらせている報告あり（794）
- Claudeにローカルツール作成させ、API経由で生成できるローカルツールを作らせたところ、ロリ系NGワードをNegativePromptに入れる設定を勝手に盛り込まれた。消すように言うとハードコードすると言われるなど、AIが勝手にガードレールを組み込む事例（803）

### Strata（LLM推論ツール）

#### 選ばれている理由・特徴
- Strataで非検閲化したQwen-3.8-flash-nextを動かすと**なかなか早くて良い**（666）
- Strataが凄いらしい（671）
- **Strataのフォルダでインストーラをもう一度実行するだけで検閲を外す機能が最初から入っている**。モデルの再ダウンロードは不要。Windowsの場合：`START-HERE.bat --setup --experimental-speed-projection on`（715）
- Strataを最新に更新して実行することで検閲除去が可能（733）
- 検閲除去の実態は「拒否に関する重みを別の重みで上書き」しており、LoRAのような仕組みと推測。推論速度は0.2～0.4%程度下がる（753）
- Strataはq3までしか対応していないのが微妙（679）
- Strataの動作要件にAVX2必須でSandy Bridge環境では死亡（684）
- **StrataはCPUをかなり使う**ため、Ryzen 7 5700xでも環境によってはCPUが足引っ張る（685）
- RAM96GB+4070Tiの環境にStrataでIQ3_Sを入れたら**普通に早くて感動した**（755）

#### ROCm対応要望
- StrataがROCmに対応したら呼んでほしいという要望（674）

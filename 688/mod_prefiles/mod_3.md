**抽出結果（モデル別）**

### NovelAI (NAI / NAIv5)
- **言及数**: 非常に多い（v5関連が中心）
- **主な話題・評価**:
  - NAIv5は「文字（特に日本語）」の安定感が大幅に向上した点が評価されている。
  - アニメスクリーンショットタグの扱いがv5で改善された（ネガティブに入れると効果的）。
  - ただしOpus制限が厳しく、生成量に上限ができてしまったことを不満に思う声が多い。
  - AnimaからNAIv5に戻した、または併用している人が複数いる。
- **選ばれている理由**:
  - 「リアスからanimaに移行して満足してたけどNAI5の方がいいなこれ」
  - 文字入れの精度が高い（Danbooruタグ＋日本語指示で看板などの文字を自然に出せる）。
  - 全体的な完成度・安定感でローカル勢より上だと感じる人が一定数いる。

### anima / Anima
- **言及数**: かなり多い
- **主な話題・評価**:
  - ローカル勢の主力モデルとしてよく名前が上がる。
  - 「AnimaBase」が二次エロで現在トップクラスという評価。
  - Krea2と比較されることが多く、「サイズが小さくて扱いやすい」「すでにエロチューニング済み」という点が強み。
- **選ばれている理由**:
  - 小型で取り回しが良い。
  - 二次＋エロのファインチューンがすでに済んでいる。
  - 絵柄の混ざり具合が自然（特に「良い感じに混ざってる」との声）。
  - NAIv5の制限が厳しい人や、完全にローカルで使いたい人が移行先として検討している。

### dasiwa / DaSiWa（minimax H3系マージ）
- **言及数**: 非常に多い（このログでは一番熱い話題）
- **主な話題・評価**:
  - minimax H3のマージモデルとして高評価。
  - 「本家よりスケベを学習している」「モーションが良い」という声が目立つ。
  - ただし胸が大きくなりやすい、股間に変な肉塊が出やすいなどの副作用も報告されている。
- **選ばれている理由**:
  - 「本家よりスケベを学習してあるって感じ」
  - T2V（テキストtoビデオ）でのモーションの自然さ。
  - 素のH3よりエロ寄りの挙動をしてくれる点が支持されている。

### minimax / H3（Minimax H3）
- **言及数**: dasiwaとセットで多い
- **主な話題・評価**:
  - 「かつてないレベルのものが来た」という高評価の声あり。
  - 特に動画生成での安定感・クオリティが話題。
- **選ばれている理由**:
  - 現時点でのT2V性能が突出していると感じる人がいる。
  - dasiwaなどのマージモデルでさらに使いやすくしているケースが多い。

### illustrious（イラストリアス / リアス）
- **言及数**: 少ないが言及あり
- **主な話題**:
  - 「イラストリアス脳のまま止まっとる」という表現で、**古いプロンプトの癖**を指して使われている。
  - Animaに移行した人が「リアスからanimaに移行して満足してた」と発言。
- **選ばれなくなった理由**:
  - 新しいモデル（特にAnimaやNAIv5）と比べて、プロンプトの考え方をアップデートする必要が出てきている。

### その他（FLUX, Wan, Qwen-Image, Z-Image, LTX）
- このログ内では**ほとんど言及なし**。
- Wanに関しては「wan2.2の時も後背位で金玉生えてきて」という1回の言及のみで、詳細な評価はなし。
- FLUX、Qwen-Image、Z-Image、LTXについてはこのログでは触れられていない。

**まとめ（傾向）**
- **現在一番勢いがある**: **dasiwa（minimax H3系）** と **NAIv5**
- **ローカル勢の主力**: **anima**
- **移行の流れ**: Illustrious → Anima → NAIv5 or dasiwa という動きが見られる。
- 選定理由として特に多いのは「**スケベさ・エロ表現の学習度**」「**モーションの自然さ**」「**サイズと扱いやすさ**」「**文字の安定感**」の4点。

**抽出されたモデル関連話題（除外対象外のもの）**

### 1. **Minimax H3（およびその派生・fine-tune）**
- **主な言及モデル**: 
  - Minimax H3 / MMH3 / H3_fl2va
  - dasiwa（DaSiWa版MMH3、dasiwa minimax h3）
  - smooth mixとの組み合わせ

- **話題のポイント**:
  - T2V（テキスト-to-ビデオ）としての安定感とモーションの良さが特に評価されている。「T2Vとは思わんかった」という声あり。
  - フェラやピストンなどのモーションが自然で高評価。一方で、胸が大きくなりやすい、股間に変な肉塊（金玉など）が生えやすいという副作用も複数指摘されている。
  - dasiwaは「本家よりスケベを学習している」「かなりいいマージモデル」との評価。一方で「胸デカ補正が強すぎる」「crotch関連のバグが出やすい」という声も。
  - 純正H3でも似た問題（特にノーパン後ろアングルで金玉が生える）が発生するため、dasiwa固有の問題ではないという意見も。

- **選ばれている理由（推測）**:
  - モーションの自然さ・安定感が既存の2D動画モデルより優位。
  - ローカルで比較的扱いやすい（特にdasiwaのようなマージモデル）。
  - ただし「胸デカ」「性器形状の崩れ」という癖を許容できるかどうかが分かれ目になっている。

### 2. **Krea2**
- **話題のポイント**:
  - Animaと並んでローカル生成の選択肢として名前が上がっている。
  - 「性能ならKrea2」と評価される一方で、「Danbooruタグ対応が弱い」「二次エロの決定版fine-tuneがまだない」という指摘あり。
  - edit機能は高いが、Minimax H3の登場で立場が危うくなる可能性も指摘されている。

### 3. **Seedance**
- **話題のポイント**:
  - Minimax H3と比較される形で登場。
  - メリットとして「生成が速い」「日本語プロンプトの理解度が高い」「ややエロまでは対応しやすい」と評価。
  - デメリットは「使用料金が高い」「有名キャラの参照で弾かれやすい」。

### 補足
- このログでは**Minimax H3系（特にdasiwa）**が最も活発に議論されている新しめのモデルです。
- 除外対象（NAI v5、Anima、Illustriousなど）と比較して語られることが多く、「モーションの良さ」と「ローカルでの実用性」が主な評価軸になっています。

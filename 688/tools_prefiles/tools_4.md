**ツール関連の抽出結果（モデル名は除外）**

### 1. ComfyUI系
- **ComfyUI-MiniMax-H3-Image-Studio**  
  「すでにComfyUI-MiniMax-H3-Image-Studioの時点で有能やな QIEより品質高いわ」  
  → **選ばれている理由**: QIE（おそらく別のUI/ツール）より品質が高いため。

- **Ref2VA / Ref2v / fl2va / t2v / i2i（ComfyUIノード・ワークフロー）**  
  複数人でRef2VA（画像参照による動画生成）やfl2va（first/last frame指定）のワークフローを議論。  
  「fl2vはスタートラスト固定の時だけ」「Ref2vを使うという事？」  
  → 動きや構図の制御が必要な場合に選択されている。

- **1F生成ノード**  
  「繋ぎとしてチャッピーに作らせた1F生成ノードが割と簡易バナナとして機能している」  
  → Minimax静止画版が出るまでの繋ぎツールとして使われている。

### 2. Krea（Krea2 / Krea3）
- Krea2で少女画像を生成してXに投稿した話、Krea3のリリース待ちの話が複数。
- 「krea3が出るんやっけ？」「krea2並に賢いやつ頼むわ」
- → 特に品質や日本語表現の期待値が高いツールとして言及。

### 3. Minimax / H3 / MMH3
- **Minimax-H3**（動画・静止画版）  
  「minimaxの静止画版も控えてる」「MMH3の画像モデルに期待するところはref2i」「H3のがさらに機能良い」
- **選ばれている理由**:
  - Ref2I（画像参照）機能が強い
  - 静止画版が出たら動画とセットで覇権を取ってほしいという期待
  - 現在のH3が機能面で優位

### 4. runpod
- 「runpodで数万円分回してからにしろとあれほど...」
- → 大量生成・検証時にローカルPCの負荷を避けるためのツールとして推奨されている。

### 5. LLM関連ツール（Qwenシリーズは画像生成以外なので抽出対象）
- **LM Studio**
  - 「LM Studioと相性悪いだけとかだろうか」「LM Studio君、君はよく頑張ったからもう良いぞ」
  - → MTP（推論高速化）を使いたい場合に限界があるため、llama-uiへ移行する人が出ている。

- **llama-ui**
  - 「ワイ、遂にllama-ui使い始める」「MTP使ったらマジで速度3割近くあがる」
  - → **選ばれている理由**: MTPによる推論速度向上のため。

### 6. その他
- **SageAttention**  
  「Sageattentionってもしかしてエラーとかフリーズ起こしたりすることある？」  
  → 高負荷時の安定性に懸念があるツールとして言及。

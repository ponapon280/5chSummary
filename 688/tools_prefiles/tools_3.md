**抽出されたツール関連話題（ComfyUI / webUI / その他ワークフロー系）**

### ComfyUI
- **言及箇所**: 470, 485, 487, 488, 592
- **内容と選ばれている理由**:
  - adetailerの代替としてSAM3を使う（webUIのadetailerと対比して言及）。
  - GPU変更（3060→5060）時のノイズ生成の違いを「ComfyUIならそういうもん」と理解・対応している。
  - prunedモデル使用時の速度差が「ComfyUIがよろしくやってくれるおかげ」であまり出ない。
  - ファイル名に生成時間を自動追記するノードの有無を話題にしている（実装例としてタイムスタンプ差分計算も言及）。
  - NAIちゃん用の専用ComfyUIノードが更新されたことをポジティブに評価（WebUIより扱いやすい点）。

### webUI
- **言及箇所**: 470
- **内容と選ばれている理由**:
  - adetailerを使って部分拡大→合成する手法で言及。
  - ComfyUI（SAM3）と並列で紹介されており、従来の定番ツールとして認識されている。

### Contex-Loop / Contex Loop（ワークフロー）
- **言及箇所**: 512, 563, 566, 617
- **内容と選ばれている理由**:
  - Ref2Vワークフローとして動画生成で使用。
  - 動画後半の色が濃くなる問題が発生しており、回避方法を模索。
  - シーンごとにLoRAを切り替える必要性（特にエロシーンで全体にLoRAがかかると不自然になる）を指摘。
  - 複雑すぎて理解を断念し「AI先生に操作してもらう」レベルで使っているユーザーもいる。

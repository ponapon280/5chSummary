# 元の本文
**生成AIモデルに関するレポート（2026年8月時点の議論抽出に基づく）**

### 人気モデルの概要
抽出された複数ログの議論から、**NovelAI Diffusion V5（NAIv5）**と**anima（Animaシリーズ、特に2.9B/3.8B）**が二次元アニメ/NSFW（特に日本語テキスト挿入・エロ表現）用途で圧倒的に人気・言及が多い。NAIv5はクラウドの手軽さと日本語プロンプト/文字入れの強みで支持され、animaはローカルでの画風自由度・制限なし・NSFW実績で代替/併用される。動画分野では**Minimax H3（MMH3/H3）**とそのマージモデル（dasiwaなど）が新星として台頭し、モーションの自然さで評価されている。**Krea 2**は表情・演出力で比較対象となり、**illustrious（IL/リアス）**はPixAIユーザー層で根強いが、移行（illustrious → anima/NAIv5）の動きが見られる。全体として「クラウド vs ローカル」「静止画 vs 動画」「日本語対応・エロ表現の学習度」が選択の主軸となっている。[[1]](https://journal.novelai.net/image-generation-novelai-diffusion-v5-is-here-c2df7c6b8d2d/)

### NovelAI (NAI / NAIv5)
**言及量**: 非常に多い（複数ログの中心）。  
**主な評価と選ばれる理由**:  
- v5で自然言語プロンプト理解度が大幅向上し、日本語指示（セリフ・効果音配置）が効きやすい。Danbooruタグ対応の高性能テキストエンコーダー（TE）と組み合わせ、漫画・4コマ・吹き出し挿入に強い。  
- クラウドで手軽に高品質アニメ/NSFW生成が可能（ブラウザ完結、API対応）。v4.5比で文脈理解・多キャラ配置・画像忠実度が向上。  
- ローカル勢から「文字入れ精度」「ポン出し（即時生成）の自然さ」で注目。  
**不満点**: Opus消費による生成制限の厳格化、画質低下（インペイント/吹き出し時）、一部規制。  
移行例として「animaからNAIv5に戻した」という声あり。

### anima (Anima / Anima2 / Anima2.9B / Anima3.8B)
**言及量**: NAIに次いで非常に多い。  
**主な評価と選ばれる理由**:  
- ローカル主力モデルとして、画風コントロールのしやすさ・生成制限なし・LoRA相性が評価。NSFW（エロ）出力の安定性・量産しやすさで「animaエロ凄い」と実績ベースで支持。  
- Anima3.8BではQwen系TE強化によりプロンプト追従性・複雑指示（色指定など）・キャラ固定が向上。サイズが小さく扱いやすい点も強み。  
- NAIの制限を嫌うローカル勢の移行先として人気。「NAIより抜けやすい」「固さの調整が効く」などの主観的評価も。  
**不満点**: 生成速度の遅さ（層が厚いため）、背景とキャラの両立難易度。

### Minimax H3 (MMH3 / H3) および派生（dasiwaなど）
**言及量**: 動画関連ログで急増。  
**主な評価と選ばれる理由**:  
- T2V（テキスト→動画）でモーションの自然さ・キャラ/背景維持・ref（参照）相性が突出。「T2Vとは思わんかった」という高評価。  
- dasiwa（H3系マージ）は「本家よりスケベを学習している」とエロ寄り挙動で支持され、モーションコミック用途で人気。ローカル扱いやすさも利点。  
**注意点**: 胸デカ補正や性器形状の崩れなどの副作用あり。

### Krea 2 (Krea 2 TURBO / Krea3期待)
**言及量**: 比較対象として複数登場。  
**主な評価と選ばれる理由**:  
- 感情・表情表現の詳細度や漫画的演出（動き・構図）でNAIv5を上回る評価。自然言語プロンプトの長文対応力が高い。  
- アニメFT版の登場を強く期待されており、実現すればローカル勢の有力選択肢に。データセット/学習方法の重要性が強調される文脈で言及。

### illustrious (IL / リアス)
**言及量**: 比較的少ない（過去勢）。  
**主な評価と選ばれる理由**: PixAI上でR-18・LoRA作成が可能で「ローカル寄りの柔軟性」を求める層に支持されたが、新モデル（anima/NAIv5）への移行が進んでいる。「イラストリアス脳のまま止まっとる」（古いプロンプト癖）という指摘あり。手軽さは一定評価。

### その他の傾向・モデル
- **PixAI**: LoRA作成・Web版R-18の利便性で言及。  
- **Tsubaki3**: 日本語文字出力・LoRA不要の版権エロで独自強み。  
- **FLUX / Qwen-Image / Z-Image / Wan / LTX**: 言及少なく、主流化しなかったor比較対象外との声。Qwen-ImageはanimaのTEとして間接的に寄与。  
- 共通の選択軸: データセット質・用途特化（文字/動画/NSFW）・ローカルLLM併用・軽さ/制限の少なさ。

### **anima（Anima / JANIMA）**
最も言及が多いモデル。

- **言及箇所**: 33, 42, 57, 75, 85, 110, 141, 184, 189, 212, 213
- **主な話題と選ばれている理由**:
  - **学習枚数が少なくても一貫性が出やすい**（57, 75）。「1キャラ10枚でも十分」という声あり。
  - SDXL時代から使い続けている人が多く、「インペイントをほとんど使わなくなった」との声（42）。
  - TurboLORAとの相性が良く、**DP-DMD式のTurbo**（特にv3）が「構図や多様性を維持しやすい」と評価されている（85）。
  - 版権キャラのエロ自動生成環境でも候補に挙がる（184, 189）。
  - 一方で「V1.0 2.9Bに変えたら絵が崩れる」という不満も（33）。

**抽出されたモデル関連話題（除外対象を除く）**

- **DLSS5**  
  画像生成時のノイズや緩さ、プロンプト追随性について複数言及。2.0→2.5移行後も「緩さは変わらんかも」との指摘あり。現実寄りの出力が目立つようになったという感想も。

- **GPT Image 2.5 / GPT Image 2.0**  
  Gガンダム風ファイティングスーツのプリキュア生成テストで使用。2.5に変えてもピチピチ感や緩さは大きく変わらないという報告。ノイズ（しましま）が出る条件についても触れられている。

- **Codex**  
  60枚単位のストーリー系完全自動生成を目指す用途で言及。キャラ×シチュエーションでモザイク付きまで全自動化し、ユーザーは選別だけ行うのがゴール。LLM（Gemma4など）と組み合わせたプロンプト生成→画像生成パイプラインの構築例が複数あり。

- **Krea2**  
  キャラLoRA検証で多用。タガー方式でユニークタグ（固有名詞_一般名詞）を使い、複数キャラを1つのLoRAにまとめつつ混ざりにくくする手法。服の着脱制御も可能で、Raw/Turboのファインチューニング準備に適していると評価。

- **Minimax / MiniMax-H3 / MMH3**  
  動画生成で最も言及が多い。LLMプロンプトが標準になり、指の異常（6本指）が出る一方で声の一貫性が高く「指定しなくても同じ声が出る」と好評。テキストエンコーダーをint8にすると出力が変わる現象も報告。dasiwaモデルはアニメ絵での画風変化が課題視される一方、エロ動作は評価されている。

- **JANIMA V1.0 2.9B**  
  V1.0+Turbo Loraから2.9Bへ移行したところ絵が崩れ、安っぽくなったという報告。絵師タグを入れないと使いにくい可能性が指摘されている。

- **seedance（シーダンス）**  
  中華ソシャゲ風の3Dカートゥーン短編アニメ作成で使用。動きのクオリティが高く、最高傑作クラスの作品例として挙げられている。

- **10eros**  
  エロ動作の生成が手軽で良いが、おっぱいの形状（巨乳・乳輪固定）が制御しにくい点が課題。

- **gemma / gemma4**  
  エロプロンプト生成や版権キャラ対応で使用。脱獄前提で版権未成年キャラも扱えるが、画像生成側はAnima/NAIなどと組み合わせる必要がある。

- **claude / Claude Code**  
  プロンプト生成やシステム構築の補助として言及。Codexと並んで設計・コード生成に使われるケースあり。

**主な選定理由の傾向**  
- **Codex / Krea2**：完全自動化やLoRA制御のしやすさ（タグ分離、着脱制御）が明確な理由として挙げられている。  
- **Minimax-H3**：声の一貫性やLLMプロンプトの自然さが評価され、動画用途で選ばれやすい。  
- **GPT Image 2.5**：特定プロンプトでの挙動確認や前バージョンとの比較で使われる。  
- **seedance**：動きのクオリティで他を上回る事例として選定。

除外対象（NAI、Anima、FLUX、Wan、Qwen-Image、illustrious、Z-Image、LTXなど）は一切含めていません。

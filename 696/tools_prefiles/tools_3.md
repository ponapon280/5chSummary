**抽出されたツール関連話題（ComfyUI中心）**

- **ComfyUI（comfy）**  
  - 複数回登場。主な文脈は画像生成・動画生成・音楽生成のワークフロー実行環境として使用。  
  - YuE2 3B対応のカスタムノードが有志作成されており、公式リポジトリをそのまま使うため**専用隔離環境が必要**と指摘。  
  - fp8推論時のバグ（CPUで動く現象）やOOM対策が必要。  
  - ノードの利点として「AVIF保存対応」「メタデータ（Comfyワークフロー）保存」「JPEG XL対応待ち」などが挙げられている。  
  - Anima画像生成時のVRAM消費増加問題もComfyUI上で観測。  
  - 理由として「UIが対応していないモデルでもカスタムノードで扱える」「ワークフローの再現性が高い」点が評価されている。

- **Animerge**  
  - LoRAマージツールとして言及。  
  - 更新内容：マージ機能をGPU使用に変更、モデル検出ボタンの不具合修正。  
  - 理由は明記されていないが、LoRAマージ作業の利便性向上を目的としたツールとして使われている。

- **MMAudio**  
  - 効果音生成ツールとして登場。  
  - Minimax H3と比較され「MMAudioよりはマシ」との評価。  
  - 理由として「ローカルで効果音を生成できる」点が挙げられているが、完成度では不十分とされる。

- **YuE2 3B（ComfyUIカスタムノード経由）**  
  - 音楽生成ツールとして複数言及。  
  - ComfyUIのカスタムノードを使って動作させるが、最適化が雑でOOM対策が必要。  
  - 選ばれている理由：「ローカルでメロディー＋インストゥルメンタル出力が可能」「Sunoの代替として期待」「abc譜出力で事前確認ができる」など。  
  - 一方で「インスト曲が作りづらい」「R&B指定でもPopになる」などの弱点も指摘。

- **その他軽微な言及**  
  - w8e4（特殊ワークフロー）：ComfyUIが標準対応したことを喜ぶ声あり。  
  - AVIF / WebP関連：ComfyUIでの保存形式としてAVIFを推す意見（メタデータ保存の観点）。

**モデル関連は一切除外**（Illustrious, Anima, Turbo Lora, Minimax H3本体など）。Qwenシリーズの言及はなし。

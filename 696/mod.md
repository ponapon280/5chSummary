# 元の本文
**生成AIモデルに関するレポート**

このログ群から、生成AIモデルに関する議論の中心は**Anima（特に各種バージョンやLoRA活用）**と**NovelAI（NAI）**に集中しており、これらが画像生成分野で圧倒的に人気・流行していると推測されます。Animaはローカル環境での実用性（LoRA学習のしやすさ、一貫性、ControlNet不要の生成安定性など）が繰り返し評価され、言及回数が最多です。NAIはクラウドサービスとしての手軽さ・エロ表現への寛容さ・プロンプト精度で支持されています。

動画・音声分野では**Minimax（H3 / MiniMax-H3）**が動きの自然さや音声一貫性で注目され、音楽生成では**YuE2（YuE2-3B）**がSunoのローカル代替として新興の人気を集めています。Qwen系はText Encoder（TE）やテキスト描写・エロ寄りプロンプト対応で補助的に言及されます。illustrious（リアス）はAnimaとの比較で手指安定性などが触れられる程度です。他のモデル（Krea2、GPT Image、Codex、seedanceなど）は特定用途で散見されますが、全体のトレンドを形成するほどではありません。

### Anima（Anima / AnimaBase / Anima 2.9B / 3.8Bなど）
ログ内で最も頻出のモデル。アニメ・イラスト調画像生成で実用性が重視され、SDXL時代からの継続ユーザーも多い。

**選ばれている主な理由**:
- 少ない学習枚数（例: 1キャラ10枚）でも一貫性が出やすい。
- TurboLORA（特にDP-DMD式v3）との相性が良く、構図・多様性の維持に優れる。
- LoRA学習時のdim/alpha設定（32/32推奨）で素材再現力（衣服・顔の造形・立体感）が向上し、弱火で安定。
- ControlNetなしでも特定の構図（例: 二人並んで座るシーン）で安定生成可能。
- インペイント頻度が低下し、ワークフローが簡素化。
- 版権キャラのエロ自動生成環境でも候補に挙がる。

一方で、V1.0から2.9B/3.8B移行時の崩れや手指の不安定さを指摘する声もあり、バージョン選びや設定調整が重要視されています。[[1]](https://civitai.com/ecosystems/anima)

### NovelAI (NAI)
画像生成サービスとして安定した支持。英語プロンプト（タグ・自然文）の安定性やエロ表現の扱いやすさが強み。

**選ばれている主な理由**:
- エロに寛容でお手軽。
- 日本語プロンプト対応や絵柄再現度が高く、ローカルモデル（例: Krea2）と比較して精度で羨望される。
- V4.5やV5の選択肢があり、更新・残量管理も話題に。

英語タグ・自然文の方が安定するという意見が優勢で、ジャギー問題などの指摘もあります。[[2]](https://www.youtube.com/watch?v=OuoPukAqPWo)

### Minimax / MiniMax-H3（動画・音声生成）
動画生成で言及が多く、I2V（画像→動画）や音声統合で評価。

**選ばれている主な理由**:
- 声の一貫性が高く（指定なしでも同じ声）、感情表現が豊か（絵文字指定や音声参照との相性良好）。
- LLMプロンプトが自然で、効果音・環境音も扱いやすい。
- 物理挙動（布の翻りなど）が優秀で、エロI2Vが手軽に生成可能。
- 以前のWanなどより「簡単に動く」点が優位。

ローカル器用貧乏モデルとして認識され、ComfyUIワークフローとの組み合わせも話題です。[[3]](https://www.minimaxh3.com/)

### YuE2（YuE2-3B、音楽生成）
新興のローカル音楽生成モデルとして注目。Sunoの代替候補。

**選ばれている主な理由**:
- ローカルでABC譜出力・編集が可能（symbolic planning）で、詳細制御や部分編集がしやすい。
- 日本語音割れが少なく、歌唱品質が高い。インストゥルメンタル以外も強い。
- MiniMax Music3などを超える性能評価あり。Sun oより音質・日本語対応で優位との声。

データセットの質やインストの弱さ、速度面の批判もありますが、ComfyUI対応やsheetsage2との組み合わせで実用性が高いです。[[4]](https://map-yue2.github.io/)

### その他のモデル
- **Qwen（Qwen-Image / Qwen3.8など）**: TEとしての活用やエロ寄りプロンプトへの反応良さ、コンテキスト長の安定性で選ばれる。トークン消費の多さが欠点。
- **illustrious（リアス）**: Animaとの比較で手指の安定性が優位。派生モデルが今でも実用的。
- **Krea2**: ローカルでの日本語（漢字含む）描写精度やLoRA制御（タグ分離・着脱）。
- **GPT Image 2.5 / Codex / seedance / dasiwa**: 特定用途（複雑構図、自動化パイプライン、動き品質、ref2va）で言及され、挙動確認や前バージョン比較で選定。

全体の傾向として、**実用性（学習・制御・一貫性・ローカル完結）**と**特定タスクの強み（エロ・動画・音楽・テキスト描写）**が選定の鍵となっています。流行はAnima中心のローカル画像生成と、Minimax/YuE2のマルチモーダル拡張にシフトしています。

# 元の本文
**なんJ（5ch） AI画像・動画生成スレッド 統合レポート**

### 概要
本スレッド群は、主に**ComfyUI**を中心としたローカルAI画像・動画生成の技術共有・トラブルシュートスレッドです。**Anima系モデル**（v1.5やAnimaYumeなど）、**MiniMax H3**、**NovelAI (NAI) v5**、**irodori-TTS**などのツールを軸に、LoRA学習、Attention最適化、Blender連携、音声合成、漫画・動画生成ワークフロー、機材・倫理的課題が活発に議論されています。全体として「実践的な生成テクニック」と「学習・推論の効率化」が中心で、失敗談や率直な評価も多く、なんJらしい毒舌混じりの空気感が特徴です。NSFW（特にエロ）用途を前提とした文脈が強く、クラウド（NAI）派とローカル派の住み分けや対立も見られます。

### 主要トピック

**1. Anima / MiniMax H3 / NAI v5 モデル比較・評価**
- Anima（CircleStone Labs製、2Bパラメータ規模）はアニメ・イラスト特化で、タグ＋自然言語プロンプト対応が強み。LoRA学習向きで根強い支持があるが、NAI v5登場で勢いが落ちたとの声も。劇場版 vs TV版キャラLoRAで「特徴は出るが個性が死ぬ（マスピ顔寄り）」問題が頻出。
- MiniMax H3は2026年7-8月頃リリースのオムニモーダル動画モデル（テキスト/画像/動画/音声対応）。ネイティブ2K・15秒程度の動画＋ステレオ音声生成が可能で、ComfyUI（FL2VA/Ref2VAノード）対応が進む。Turbo LoRA併用時の音声・文字劣化や解像度・時間トレードオフが話題。
- NAI v5（2026年8月21日リリース）は日本語自然言語プロンプト対応・最大22キャラ同時生成・多パネル漫画生成・透過背景出力が強化され、「手軽さ」で高評価。一方、精密LoRA再現や解像度でローカルに劣る指摘もあり、「NAIだけで完結」「ローカルは自作LoRA・細かい制御向き」との住み分けが認識されています。[[1]](https://hashout.jp/ai/8369/)

**2. Attention / 最適化・ComfyUIワークフロー**
- Block Sparse Attention（公式ノード、2026年9月頃コア追加）の導入が注目され、SageAttn / Sol-Attn / Spectrum / Kitchen Attentionなどとの組み合わせ検証が活発。「VDN + Spectrumに落ち着いた」などの実践報告あり。
- VRAM 12-16GB向けフロー（Loader → ModelAttentionBackend → Block Sparse Attention → H3 Chunk FeedForward）や、TRT VAE / Fast VAEの速度・精度比較、VRAMリーク修正報告が共有。H3などの長シーケンス向け最適化が進んでいます。[[2]](https://comfyui-wiki.com/en/news/2026-09-08-h3-sparse-attention-compiler)

**3. LoRA学習・キャラ再現・データセット**
- 画風・キャラ同時学習でdim32/alpha32推奨意見多数。素材15枚程度で十分とする声と多様性確保のための増加意見が対立。
- 透過PNG由来の黒背景過学習、Danbooruタグ競合、3面図・低品質素材の扱い、ep数・学習率調整、timestep sampling offsetの効果が具体的に議論。劇場版/ TV版学習枚数調整で再現性向上事例も報告されています。

**4. 音声合成（irodori-TTS）・外部連携**
- irodori-TTS v4.1 / v4.1smallのComfyUI対応状況（カスタムノードでv3まで安定、v4.1は一部制限報告）。出力ファイル名にseed・リファレンス・セリフを自動追加する機能実装例が好評。
- Blenderプリビズを動画参照に使う手法、Astra（LLM）による監督・操作分業、動画フレーム抽出→自動キャプション化ツールの作成報告あり。

**5. 機材・コスト・その他実務的話題**
- RTX 3060勢のOOM・クラッシュ報告、RTX 5090（高額）購入話、埃・冷却・ケースレス運用などのハードウェア愚痴。
- アップスケール時のひび割れ（PixelSharpen前処理）、背景黒化現象（LoRA由来疑い）、ファイル形式（WebP vs PNG）の是非。

**6. 倫理・法的・コミュニティ文化**
- 声優声再現の法的・倫理的リスク（「名前を出さなければセーフ」などのグレー議論、TikTok悪用事例）。
- NAI BAN基準、Anthropic古書スキャン事例などの検閲・フェアユース議論。
- 「驚き屋」批判、新技術飛びつきへの冷ややかな目線、ワークフロー非公開・画像貼り控えなどのメタ話題が散見。

### 傾向・特徴
- **実践重視**：抽象論より具体的なノード名・設定値・ワークフロー画像・失敗結果の共有が多い。
- **効率化志向**：トークン消費抑制・品質維持、Attention最適化、LLM併用による指示工夫が収束しやすい。
- **格差と批判文化**：クラウド（NAI）の手軽さ vs ローカルの制御自由度、機材格差、NSFW前提の空気。「金がないなら働け」的な現実路線と趣味派が混在。
- 技術レベルが高く、2025-2026年現在のローカル生成勢の最前線を反映。エロ用途が前提で、倫理的課題も表面化。

### まとめ
本スレッド群は、**Anima＋MiniMax H3＋NAI v5環境**での実践的ワークフロー最適化がメイン。LoRA再現性向上、Attention系最適化、音声・動画連携、Blender統合がホットトピックで、クラウド vs ローカルの住み分けが鮮明化しています。技術的成熟度が高まる一方、機材・検閲・倫理的ボトルネックが継続課題です。

### 冒頭まとめ：流行しているモデル
抽出された複数のログ・議論から、**Anima（特にBase 1.0 / v1.5 / 2.9B / 3.8B系）**と**NovelAI（NAI / NAI5 / NAIv5）**が圧倒的に言及が多く、流行の中心となっている。Animaはローカル環境でのLoRA学習・安定性・自然言語プロンプト対応で支持を集め、NAI5はクラウドサービスの手軽さ・日本語文字/擬音処理・インペイント性能・NSFW耐性で評価が高い。二強状態で、他のモデル（Qwen-Image、MiniMax H3 / MMH3、Krea2など）はサブ的な言及や特定用途（編集・動画・美学制御）に留まる。全体として、アニメ/イラスト生成、特にLoRA活用や実用ワークフローの文脈でこれら2モデルが主流。

### 主要モデルの詳細と選ばれている理由
#### 1. Anima（Anima Base 1.0 / v1.5 / 2.9B / 3.8Bなど）
- **主な話題**: LoRA学習時のキャラ再現性・安定性、長文自然言語プロンプトへの対応、i2iアップスケール時の挙動、背景黒化対策、v1.5でのLLM Adapter言及。
- **選ばれている理由**（テキスト内明記）: 「Animaは素直に覚える」「base 1.0が安定しておりLoRAの扱いやすさ」「画風・キャラ再現性が高い（自作LoRA勢）」「krea2やNAI5と比較して最終的にAnimaに落ち着く」「長文自然言語を受け付けてくれる」「自作LoRAやるならAnimaが現役で強い」。ローカル勢の主力として根強いが、NAIに押されている印象も。
- **その他**: Forge/ComfyUIでの使用、LoRA remap互換性、データセット新しさ（最近のキャラが出やすい）。

#### 2. NovelAI（NAI / NAI5 / NAIv5 / NAI4.5など）
- **主な話題**: セリフ・擬音・日本語文字入れの強み、インペイント成功率・NSFW編集耐性、漫画生成（画風統一）、精密参照、クラウドの手軽さ（PC不要・BANリスク低）、V5の完成度。
- **選ばれている理由**（テキスト内明記）: 「セリフ付きはNAIやろ」「NAIはあとセリフや擬音のフォント指定さえできればもう完璧」「すごいと思った画像はほぼNAIだよ 特にNAI5は2年は先の完成度」「NAIの精密参照はnsfw画像編集としてまあまあ使える」「後ちょっとプロンプトいじって…数回ガチャすれば終わり（インペイント成功率もローカルより高い）」「日本語がバリバリ通る」「自作LoRAを使わないならNAIのほうが強い」「二次元ならほぼ何でも生成できる自由度の高さ」「サーバー側で生成画像を保持しないためBANリスクが低い」。V5は日本語自然文・多人数・透過・漫画生成で高評価。

#### 3. その他の言及モデル（比較的少ないが特定用途で登場）
- **Qwen-Image / Qwen-Image-Edit系**: 画像編集性能で最前線として言及（sage attentionとの相性、Anima v1.5開発者のQwen 3 0.6B → 3.5 2B置き換えコメント）。編集用途で有力視。
- **MiniMax / MMH3 / H3系**: 動画生成・音声LoRA移植・Ref2V（参照動画）用途。音声連動の楽しさ、自然言語指示対応、低解像度参照での効率化で語られる。
- **Krea2 / Krea系**: 静止画生成（特に実写/美学寄り）、スタイル制御、LoRA疑似ターボ化やComfyUI連携。エロ寄りファインチューン版への期待も。
- **illustrious（リアス）**: Anima出力のインペイント用サブモデルとして細々と使用。
- **その他軽微**: SDXL（過去学習知見の参考）、Ideogram（日本語文字入れ）、Gemini（ネタ画像）、Dasiwa（T2V）、Irodori-TTS（音声生成）など。FLUX、Wan、Z-Image、LTXなどはほぼ言及なし。

**共通の運用傾向**: トークン消費削減・精度向上のための人間側工夫（指示明示化、低解像度参照、定型スクリプト化）。高性能モデルほど非効率な方法を選びがちな点への対策（例: 批評エージェント導入）。

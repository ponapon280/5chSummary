**なんJ（5ch）ログ レポート**

### 概要
本スレは主に **ComfyUI** を用いたAI画像・動画生成の技術共有・トラブルシュートスレ。Anima系モデルやMiniMax H3を中心に、LoRA学習、Attention最適化、Blender連携ワークフロー、TTSなどの話題が活発に交わされている。全体的に「実用的な生成テクニック」と「学習・推論の効率化」が中心。

### 主要トピック

**1. Anima / MiniMax H3 関連**
- Anima v1.5や派生モデル（AnimaYumeなど）の挙動検証が活発。
- 特に「劇場版 vs TV版」のキャラLoRA学習で苦戦報告多数。特徴は出るが個性が死ぬ（マスピ顔寄り）問題が指摘され、素材枚数・タグ付け・dim/alpha設定の再考が議論された。
- MiniMax H3ではTurbo LoRA併用時の音声・文字劣化、解像度と生成時間のトレードオフが話題に。

**2. Attention / 最適化**
- Block Sparse Attention（公式ノード）の導入が注目。
- SageAttn / Sol-Attn / Spectrum / Kitchen Attention との組み合わせ検証が続いており、「最終的にVDN + Spectrumに落ち着いた」という声も。
- VRAM12〜16GB勢向けの推奨フロー（Loader → ModelAttentionBackend → Block Sparse Attention → H3 Chunk FeedForward）が共有された。

**3. LoRA学習・キャラ再現**
- 画風・キャラ同時学習時のdim32/alpha32推奨意見。
- 透過PNG由来の黒背景過学習問題、Danbooruタグとの競合問題が指摘。
- 3面図や低品質素材の扱い方、ep数・学習率の調整について具体的な設定例が複数投稿された。

**4. ワークフロー・外部連携**
- Blenderのプリビズを動画参照に使う手法が複数報告。
- Astra（LLM）を使った監督役・操作役の分業指示例。
- 動画からフレーム抽出→自動キャプション化ツールの作成報告も。

**5. その他**
- Irodori-TTS v4.1 / v4.1smallのComfyUI対応状況。
- アップスケール時のひび割れ問題と対処（PixelSharpenなど前処理）。
- 背景が真っ黒になる現象の原因究明（LoRA由来の可能性が高い）。

### 傾向・特徴
- 技術レベルが高く、具体的なノード名・設定値・エラー対処が頻出。
- 「トークン消費を抑えつつ品質を出す」「人間が指示を工夫する」方向に議論が収束しやすい。
- 失敗談・微妙な結果報告も多く、率直な感想が書かれているのが特徴。

### まとめ
本スレは「Anima＋MiniMax H3環境での実践的なワークフロー最適化」がメイン。LoRA学習の再現性向上とAttention系最適化が現在のホットトピックとなっており、Blender連携によるカメラ制御も次なるテーマとして浮上している。

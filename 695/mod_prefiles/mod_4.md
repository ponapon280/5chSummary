**抽出結果**

### NovelAI (NAI / NAIv5 / NAIちゃん)
**言及回数**: 非常に多い（メイン話題）

**主な話題・評価**:
- 二次元エロ、特にアニメキャラの品質がローカル勢を大幅に上回っていると評価されている。
- **日本語プロンプトの理解度・自然な日本語文字入れ**が非常に強い（擬音・セリフ・手描き文字など）。
- インペイント性能が高く、構図を維持したままキャラ・背景の大幅変更がしやすい。
- fullbody sexなどのエロ表現も比較的通りやすい。
- クラウドサービスとしての手軽さ（PC不要、スマホでも高品質）。

**選択理由として挙げられている点**:
- 「日本語がバリバリ通る」「微妙な表現も理解する」
- 「NAIv5以降、二次エロでローカルモデルを大幅に引き離した」
- 「自作LoRAを使わないならNAIのほうが強い」
- 「NAIちゃんだけだと自作LoRAが効きにくい」という弱点はあるが、総合力で選ぶ人が多い。

### anima (Anima)
**言及回数**: 非常に多い

**主な話題・評価**:
- ローカル勢の主力モデルとして現在も根強い支持がある。
- **自作LoRAの相性が良い**点が最大の強み。
- ただし「エロの質感がまだ弱い」「NAIに取られている」という声も複数ある。
- 最近は「Animaで生成 → NAIやillustriousでインペイント」という併用スタイルがよく見られる。

**選択理由として挙げられている点**:
- 「自作LoRAやるならAnimaが現役で強い」
- 「anima単品ではチンポ・マンコ描写に物足りなさを感じる人が一定数いる」
- NAIに移行する人も増えているが、「自作LoRAを多用する層」はまだAnimaを残している。

### illustrious (リアス / ill / IL)
**言及回数**: 少なめ

**主な話題・評価**:
- 主に**Animaの出力に対するインペイント用途**で登場。
- 「Animaで作ったのをリアスとNAIでインペイントしている」という使い方が確認された。

**選択理由**:
- Anima単体では物足りない部分（特にエロの質感）を補うためのサブモデルとして使われている。

### その他のモデル
- **Qwen-Image**: NAIv5がQwenを使っているという言及が1件のみ。
- **Z-Image (ZITなど)**: 「Krea2以外に覇権二次エロファインチューンが無い」という文脈で名前だけ出ており、具体的な評価はなし。
- **FLUX / Wan / LTX**: ログ内に一切の言及なし。

### まとめ（傾向）
- **NAI**：日本語対応・総合的なエロ品質・手軽さで現在最も勢いがある。特に「自作LoRAをやらない人」の選択肢として強い。
- **anima**：自作LoRA勢の牙城として残っているが、NAIに押されている印象。
- **illustrious**：Animaユーザーにとっての「インペイント用サブ」として細々と使われている。
- その他指定モデルはほぼ話題に上がっていない。

**抽出されたモデル関連話題（除外対象を除く）**

### 1. Krea2
- 複数回登場し、LLMとやり取りしながら参照用静止画を作成する用途で言及。
- 「Krea2の静止画がじゅうぶんにエロい」という理由で、生成後に満足して動画生成まで至らない現象が話題に。
- 二次エロ向けファインチューン版（Raw/Turbo）の存在が期待されており、「最強はKrea2の二次エロファインチューン」との声あり。
- Turbo版は速度重視で使われる一方、LoRA追加ができない点がネックとして指摘されている。

### 2. gpt-image-2.5（GPT Image 2.5）
- 唐突な強化・リリースが話題。
- API利用時の金持ちとの格差、漫画生成や下着・透け描写での使用例が挙げられる。
- 2.0比でエロ規制が強化された（水着すら厳しくなった）点が指摘され、劣化との声多数。
- 日本語対応や手軽さが評価される一方、「大したことない」「グラボ買えない勢が過剰に持ち上げている」との批判も。

### 3. ComfyUI関連のAttention機構（実験的機能）
- **Model Sparse Attention / Block Sparse Attention / sol-attn**
  - ComfyUI更新後にノード名変更や検索不能になる不具合が頻発。
  - `update_comfyui.bat`（開発版）でしか入らない実験機能として、速度と品質のトレードオフで使用。
  - comfy kitchen attentionとの組み合わせで「直列接続して使う」手法が共有されている。
- 安定版 vs 開発版の差異や、更新方法による挙動の違いが詳細に議論されている。

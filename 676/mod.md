# 元の本文
**レポート：生成AI動画モデルに関する分析（抽出ログに基づく）**

### 人気モデルの概要
抽出された複数のログから、**MiniMax H3（MiniMax-H3 / H3 / minimax_h3）** が圧倒的に話題の中心であり、現在最も流行・注目されているモデルであることが明らかです。Wan2.2やLTX-2.3との比較が頻出で、「次の主力」「パラダイムシフト級」「Wan2.2とLTX2.3はもう不要」との声が多数を占め、既存モデルの置き換えが進んでいる状況です。

Wan2.2とLTX-2.3は依然として言及されますが、主に「過去のモデル」「H3に取って代わられつつある」というネガティブまたは比較対象としての文脈で語られています。NovelAIなどの他の指定モデルはほとんど言及がありません。

### MiniMax H3 の詳細
ログ全体で最も活発に議論されているモデル。ローカル環境（主にComfyUI）での運用を前提とした話題が多く、量子化版（int8_convrot、pruned_int8など）のファイル構成やワークフロー共有が目立ちます。

**選ばれている主な理由**（ログから抽出）:
- **プロンプト追従性の高さ**: 詳細な指示や複雑な動き（片目ウィンク、スカートめくり、脱衣、銃アクション、カメラワークなど）が素直に出やすく、Wan2.2では難しかった動作が容易。
- **顔・キャラの一貫性**: リファレンス（Ref2VA / r2v）使用時の維持力が強く、複数画像・動画参照で表現力が高い。
- **NSFW / エロ表現の強み**: 検閲が緩く（実質無検閲）、自然な動き・揺れ・液体表現などがLoRAなしでも高品質。日本語セリフ・アニメ声も自然。
- **多モーダル入力の柔軟性**: テキスト＋画像＋動画＋音声を統合的に扱え、絵コンテ理解度やRef2V機能が「革命的」と評価。
- **運用面**: ComfyUI 0.30.0以降の公式テンプレート対応。SageAttentionなどの最適化で速度向上。低〜中スペック環境（3060 + 64GB RAM推奨）でも動作可能だが、モデルサイズが大きい点は課題。
- 全体として「Wan/LTXの弱点（一貫性、日本語対応、自然さ）を大幅改善」との評価が共通。

### Wan2.2（Wan）の詳細
言及回数は多いが、H3登場後の比較対象として語られることがほとんど。

**選ばれている理由（または言及される文脈）**:
- 過去に一定の画質・自然さで評価されていたが、現在は「顔の一貫性不足」「不自然な挙動（口紅急塗りなど）」「エロの硬さ」などの弱点が指摘され、H3に clearly 劣るとの見方が主流。
- ControlNet運用などの過去実績は残るが、「ガチャが多くて不便」「もう過去のモデル」という空気。

### LTX（LTX-2.3 / ltx2.3）の詳細
Wanと並んで頻出するが、衰退傾向が強い。

**選ばれている理由（または言及される文脈）**:
- 音声対応や生成長さ（WANより長い）で一時優位だったが、H3との比較で「画質・一貫性で劣る」「日本語対応の改善が不十分」とされ、「死にそう」「もう不要」との声多数。
- 生成速度面で一部評価される場面もあるが、全体クオリティで敬遠されている。

### その他のモデル
- **NovelAI (NAI)**: 軽い言及のみ（新機能期待程度）。詳細な評価なし。
- **illustrious / FLUX / Qwen-Image / anima / Z-Image / seedance**: ほとんどまたは一切言及なし。Animaは「軽量で適度な性能」の理想形として軽く触れられる程度。

### 全体の傾向と考察
ログの文脈は主にローカル動画生成（特に二次元・NSFW用途）で、**MiniMax H3の登場により市場が急速にシフト**している状況が読み取れます。選定理由の共通点は「プロンプト忠実度・一貫性・自然な動き・日本語対応・多モーダル柔軟性」で、特にエロ表現の扱いやすさが強い動機となっています。Wan2.2/LTXは「ベース性能の限界」が露呈し、H3への乗り換え・ファイル削除を検討するユーザーが増加中です。

将来的にはH3のLoRA充実やさらなる最適化が鍵となりそうです。

**抽出結果（ツール関連のみ）**

### ComfyUI（comfy）関連
- **comfyuiの更新による速度向上**  
  comfyuiを最新版にしただけで、生成速度が大幅に改善（1枚36秒 → 22秒）したという報告あり。  
  → **選ばれている理由**: 単純に最新版にすることで処理速度が劇的に上がるため。

- **ComfyUIワークフローの作成・管理**  
  ChatGPTやGeminiにComfyUIのワークフロー作成を依頼する事例が複数。  
  また、Sage Attention系のエラーが発生した際の対処として、venvの再構築やCustom nodesの再インストールが議論された。

- **Attention系ツールの選択**  
  - `comfy-kitchenAttention`への移行を検討している発言あり（SageAttention2からの乗り換え）。
  - Sage Attention関連のエラーが頻発したため、ComfyUIの環境再構築を余儀なくされた事例あり。

- **Gemini/ChatGPTとの組み合わせ**  
  ComfyUIのワークフロー作成やエラー対処でGemini/ChatGPTを多用しているが、Geminiは複雑なトラブルシューティングでループしやすいという指摘多数。  
  → **選ばれている理由（ComfyUI側）**: ワークフローの自動生成やカスタムノード管理がしやすいため。

### 動画編集・モザイクツール関連
- **DaVinci Resolve**
  - レンダリング時の暗転問題やモザイク処理で使用されているが、UIが非常に複雑で扱いにくいという声が多数。
  - GPUをCUDA使用に設定することで解決した事例あり。

- **代替ツールの提案**
  - **YMM4**: UIが優しく、クリック操作だけでモザイク処理が可能。DaVinci Resolveの代替として推奨。
  - **Aviutl**: UI整備に手間がかかるが、機能は豊富。
  - **Kdenlive**: モザイクサイズの調整が効かない問題があるものの、軽量で使用している事例あり。
  - これらの代替が挙げられる理由は、**「DaVinci ResolveのUIが煩雑すぎる」**という共通の不満。

# 元の本文
**人気モデルまとめ（テキストからの推測）**  
複数の抽出ログから、2026年8月時点で最も活発に議論・使用されている生成AIモデルは**MiniMax H3（H3 / MMH3）**と**Krea2**の組み合わせです。特に動画生成（アニメ調・NSFW含む）で動きの自然さ・画質・実用性が高く評価され、「Krea2がMiniMax H3の弱点を補う相性最強タッグ」として繰り返し語られています。次点で**anima（Anima-2.9Bなど）**が画像生成の起点や速度面で日常的に使われ、**Qwen3.8-27B**がプロンプト作成・エージェント用途で注目を集めています。**Illustrious（v3.6）**は絵のクオリティで根強い支持があります。NovelAIやLTXは過去の遺産・技術的ルーツとして言及される程度で、現在進行形の主力ではありません。

**MiniMax H3（MiniMax-H3 / H3 / MMH3 / Hailuo 3）**  
動画生成で最も言及が多く、選ばれる主な理由は以下の通りです：  
- 動きの速さと自然さが突出（「動きが速すぎて」「集合知おそるべし」）。  
- Context Loopやmotion contextによる長尺動画生成・シーン繋ぎがしやすい。  
- インペイント（SAM3.1併用）や参照画像制御が実用的。  
- LoRAなしでもある程度のエロ動画生成が可能で、プロンプト柔軟性（自然言語・日本語対応）が高い。  
- 低スペック環境（32GB RAMなど）でもある程度動作し、5090などの高スペックGPUで爆速。Turbo版（turbo4step/8step）と標準20stepの画質/速度トレードオフも議論される。  
Krea2との併用で全体クオリティが一段階上がるとの声が多数。[[1]](https://www.minimax.io/blog/minimax-h3)

**Krea2 / Krea3**  
MiniMax H3との組み合わせが「最強」と高評価。選ばれる理由：  
- リアル寄り・3D寄りの生成で安定。  
- 自然言語プロンプト（特に日本語）が通りやすい。  
- identity edit機能など制御性が高い。  
Krea3は27日発表噂の新モデルで、クラウド専用化の可能性やEdit特化版への期待が語られています。[[2]](https://www.krea.ai/index/krea-2-image-model)

**anima（Anima / Anima-2.9B）**  
画像生成の起点としてよく使われ、単独完結しにくいためXL系やillustriousとの組み合わせ（アプスケ用途）が一般的。選ばれる理由：  
- 生成速度の改善（ComfyUIアップデートで36秒→22秒など、以前より2-3割速くなった報告）。  
- ck attentionとの相性が良く3000番台で速度優位。  
- LoRA互換性（2B用LoRAを2.9Bで動かすパッチ話）。  
- アニメ/イラスト向けで、構図指定時の偏りや黒表現の弱さは指摘されるが、ガチャ要素として楽しまれる声も。[[3]](https://civitai.com/models/2855007/anima-29b)

**Illustrious（イラストリアス / リアス / ill / IL / Illustrious XL v3.6）**  
animaのアプスケ先として推奨され、絵のクオリティ自体は「依然として最高峰」と評価。選ばれる理由は画質・完成度の高さで、現在もメイン使用者がいる一方、細かい制御（ほくろ・腕位置など）では他モデルに劣る点が指摘されます。SDXLベースの最新版が3.6（2025年頃）で、商売としての停滞感も語られています。[[4]](https://www.illustrious-xl.ai/blog/16)

**Qwen（Qwen3.8-27B / Qwen3.6-27Bなど、LLM）**  
プロンプト作成・システムプロンプト遵守で高評価。選ばれる理由：  
- thinkingのON/OFF切り替え（OFFで爆速、ONで賢くなる）。  
- Ref2vやContext Loopなどの複雑指示解釈でGemma4-31Bより優位。  
- 「エージェンティックな小型LLM」としてロールプレイ/小説執筆よりプロンプト生成用途で実用的。  
Gemma4-31Bはエロ理解力・装飾量で住み分けられています。[[5]](https://datanorth.ai/news/alibaba-releases-qwen3-8-27b)

**その他の言及**  
- **wan（WAN2.2 / Wan3.0）**：進化の文脈や比較対象（NSFW性能の評価あり）。  
- **LTX（LTX-2.3 / LTX-2.5）**：Latent Upscaleの技術的ルーツやオープンウェイトの好例として間接的に言及。  
- NovelAI（NAI）：過去の奇形表現やスレの出自として懐古的に登場、現在進行形の使用は薄い。  
- Z-Image、FLUX、Pony、SD1.5などは軽微または過去話。

全体傾向として、**動画生成ではMiniMax H3 + Krea2の相性論**、**画像ではanima/Illustriousの組み合わせ**、**補助としてQwen LLM**が主流。GPU（3090/4090/5090）による出力「味」の違いやComfyUI最適化（Sage Attentionなど）も活発に議論されています。

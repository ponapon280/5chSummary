# 元の本文
**人気モデルのまとめ（レポート冒頭）**  
抽出された複数のログから、**NovelAI（特にNAI v5）** が圧倒的に言及量が多く、最も人気・主流のモデルとして位置づけられている。主な理由は「手軽さ」「日本語プロンプト・自然言語への高い追従性」「版権エロ・二次元表現での強み」「複数キャラ制御のしやすさ」など。次に**anima** が頻繁に比較対象として登場し、ローカル環境での絵柄再現性やLoRA活用で支持されている。動画生成では**MiniMax H3（MMH3 / H3）** がカメラ一貫性やLoRA作成の容易さで評価され、**Krea2** も表現力や自然言語対応で注目されている。illustrious（リアス）はFANZAの商用サービス採用で言及が増え、Wan/LTXは動画用途で限定的に触れられる程度。全体として、NAI v5の登場により「手軽さと実用性」が重視される傾向が強い。[[1]](https://x.com/novelaiofficial/status/2090571590522315151)[[2]](https://novelai.net/updates)

**NovelAI（NAI / NAI v5）**  
ログ内で最も中心的に語られるモデル。v5リリース直後という文脈で、品質向上（色味・画質の綺麗さ、破綻の少なさ）、日本語プロンプトの扱いやすさ、Danbooruタグとの混在対応、版権キャラの再現性、複数キャラ制御の強さ、セリフ・吹き出し入れのしやすさ、インペイント性能などが高く評価されている。  
**選ばれている主な理由**（ログより明記/推測）：  
- 手軽さ（ローカル構築不要で高品質が出せる）  
- 日本語・自然言語対応の向上  
- NSFW（特に版権エロ）への寛容さと実用性  
- UIの親しみやすさや新機能（透明背景、漫画生成対応）  
弱点として生成上限（1日190〜200枚程度）が繰り返し指摘されているが、それでも「二次エロ版権では唯一無二」「手描きとの区別がつかないレベル」との声が多い。[[3]](https://note.com/itsuki_ailab/n/n3b408b813f7a)

**anima（Anima / ANIMA、Anima-2.9Bなど）**  
NAI v5との比較で非常に多く登場するローカル向けモデル。パラメータサイズが比較的小さい（本体2B + TE 0.6B程度）のに高品質で、danbooruタグでの絵柄再現性、プロンプト流用性、複雑オブジェクトの解釈力、ニッチな表現（動作など）のLoRA制御が強み。  
**選ばれている主な理由**：  
- マイナーキャラや特定キャラの再現性が高い  
- LoRA学習・固定キャラ用途に適する  
- NAIと併用（構図練りなど）しやすいコスパ・柔軟性  
v5登場後も「Animaでしか出せないキャラ用」として併用する意見あり。TE強化などの要望も出ている。[[4]](https://civitai.com/models/2855007/anima-29b)[[5]](https://civitai.com/articles/33274/anima-generation-guide-part-1-general-model-a-bit-of-history)

**MiniMax H3（MiniMax / MMH3 / H3）**  
動画生成を中心に言及。同一シーン内でのカメラ切り替えの一貫性（映画トレーラー的表現）、自然言語理解力・プロンプト追従性の高さ（「意を汲んでくれる」）、LoRA作成の容易さ、編集前提のワークフロー適合が評価される。  
**選ばれている主な理由**：  
- 静止画・動画ともに高品質で「限界突破」した性能  
- クラウド利用しやすく、ローカル環境の制約（VRAM・電気代）を回避可能  
- テキストエンコーダの強さによる柔軟性  
Wan2.2/LTX系との比較で優位とされる声が多い。[[6]](https://www.minimax.io/blog/minimax-h3)

**その他のモデル**  
- **Krea2（Krea 2）**：表現力・画の美しさでNAI v5を上回る可能性が指摘され、スタイル制御やLoRA作成用途で期待。日本語混じりプロンプトへの対応も評価されるが、LoRA運用のしにくさから様子見の声も。[[7]](https://www.krea.ai/blog/krea-2-image-model)  
- **illustrious（リアス / IL）**：FANZAの画像生成サービスベースとして注目。商用利用耐性やdanbooruタグ強みが背景にあり、手軽な入門モデルとして言及されるが、進化の停滞を指摘する声も。[[8]](https://www.illustrious-xl.ai/blog/27)  
- **Wan（Wan2.2） / LTX（LTX-2.3）**：動画生成で言及されるが、MiniMax H3登場により「性能限界がある」との評価で相対的に影が薄い。編集前提のwebp保存などのワークフロー利便性は残る。  
- **Z-Image / FLUX / Qwen-Image**：言及が少なく、TE性能比較や実験的文脈でのみ登場。

**全体傾向**  
NAI v5のリリースにより「手軽さ・日本語対応・実用機能」が選定の鍵となり、ローカル勢（animaなど）は「特定用途の再現性・柔軟性」で補完的に使われる構図。動画分野ではMiniMax H3が新星として台頭。生成上限や電気代などの制約が実用上のネックとして繰り返し議論されている。

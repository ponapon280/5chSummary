# 元の本文
**生成AIモデルに関するレポート（2026年8月時点のコミュニティログ分析に基づく）**

### 流行モデルの概要
テキスト全体から、**NovelAI（特にNAI v5 / NovelAI Diffusion V5）** が圧倒的に話題の中心であり、コミュニティで最も人気・支持されているモデルであることが明確に推測される。複数ログでv5のリリース直後（または直近）の評価・比較・運用議論が大部分を占め、「版権エロ・二次元キャラ再現性」「日本語自然言語プロンプト対応」「文字・擬音・セリフ生成」「複数キャラ制御」「手軽さ」などが高く評価され、「ローカル勢を圧倒」「ゲームエンドレベル」との声が目立つ。次点で **anima** が頻繁に比較対象として登場し、NAIとの併用（二刀流）やLoRA作成・特定解釈でのサブモデルとして位置づけられている。

動画生成用途では **MiniMax（H3 / MMH3）** が比較的多く言及され、カメラワークの一貫性やi2v用途で期待されている。その他、**Krea2**（構図・画質補完）、**illustrious（リアス / FANZA関連）**、**Z-Image**、**Wan / LTX** などは散発的またはニッチな言及に留まる。全体として、静止画（特にアニメ・NSFW・日本語プロンプト重視）ではNAI v5が主流で、animaが補完役、クラウド動画モデルとしてMiniMaxが台頭しつつある傾向が読み取れる。

### 主なモデルと選ばれている理由（テキストからの抽出）
#### NovelAI (NAI v5 / NovelAI Diffusion V5)
- **選ばれている主な理由**:
  - 日本語自然言語プロンプトの対応力が非常に強く、Danbooruタグとの併用も自然。
  - 版権キャラの再現性・エロ表現（乱交・複雑構図）の安定性・クオリティが突出（「唯一無二」「誰も敵わない」）。
  - 文字・擬音・セリフ・吹き出し生成の自然さ・高品質。
  - 複数キャラ制御・配置・構図のしやすさ（最大22キャラ対応の言及も関連）。
  - インペイント・i2iの性能向上、手軽さ（UIの扱いやすさ）、NSFW対応の緩さ。
  - v5特有の強化点として、画質・追従性・精密参照・透過画像生成の改善が評価され、「animaで苦労していた表現が簡単にできる」との声多数。
- 弱みとしてサブスク制限やAnlas消費の厳しさが指摘されるが、総合力で支持を集めている。animaやKrea2と併用するワークフローも提案されている。

#### anima (Anima / Anima-2.9Bなど)
- **選ばれている主な理由**:
  - NAIでは出せないマイナー/最新キャラへの対応力。
  - LoRA学習のしやすさ（ニッチ表現や教師画像の残像ディテール学習）。
  - 特定の解釈力（旗などの複雑要素）や構図練り用途でのサブモデルとしての強み。
  - NAIプロンプトとの互換性があり、併用でカバー範囲を広げる「二刀流」が推奨される。
- 弱みとしてテキストエンコーダー（TE）性能の劣位やControlNetの貧弱さが繰り返し指摘され、NAI v5登場で役割が一部奪われつつあるニュアンスもある。

#### その他のモデル
- **MiniMax (H3 / MMH3)**: 動画生成（i2v、カメラワークの一貫性、コンテキストループ）で積極的に言及。TEの強さや無制限に近い生成、NAIとの併用しやすさが理由。電気代や性能限界の文脈でも触れられる。
- **Krea2**: 画の美しさ・表現力の高さから、NAI前の構図練りや補完用途で選ばれる。スタイル制御や美観重視のワークフローで言及。
- **illustrious (リアス / ill)**: FANZAスタジオでの採用が主な文脈。Danbooruタグ対応や商用寄りのチューニングが背景。
- **Z-Image / Wan / LTX**: 比較対象や動画用途（シームレスループなど）で散発的に登場するが、性能限界の指摘も多い。
- Ideogramなどはポテンシャルを指摘される程度。

傾向として、静止画・日本語/エロ/版権用途ではNAI v5が第一選択、細かいカスタマイズや補完でanima/Krea2/MiniMaxが使われやすい。

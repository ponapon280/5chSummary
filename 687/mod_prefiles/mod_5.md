**抽出結果**

### NovelAI (NAI / Nai5 / v5 / NAI5)
- **話題の頻度**: 非常に多い（メインの話題）。
- **選ばれている理由・評価**:
  - NAI5の登場で「animaで頑張って構築してた表現が簡単にできるようになった」。
  - セリフ・擬音・文字の扱いが大幅に向上（特に「謎字幕が本物の日本語になる」「セリフ付き・擬音付きがドカンと増える」）。
  - 最近の版権キャラの網羅性が高い。
  - プロンプトだけでキャラ固定・複数人・エロ表現がやりやすい。
  - ただし「コスパが悪い」「Anlasの消費が激しい」という不満も複数。

### anima
- **話題の頻度**: NAIと並んで非常に多い（比較対象として頻出）。
- **選ばれている理由・評価**:
  - 元々「animaで構築しようとしていた」人が多かった。
  - LoRAの扱いやすさ（特にニッチな表現：足ガクガクなど）。
  - 教師画像の残像ディテールだけを学習させやすい。
  - NAI5登場後は「animaいらん」「anima通り越して進展がない」という声も。
  - ただし「版権キャラの再現が厳しい」という弱点も指摘されている。

### Z-Image (Zimage / Z-Image Turbo)
- **話題**:
  - 1passLoRA（生成時に軽いLoRAを作る手法）の実験をしていた。
  - 「生成はTurbo・学習はRaw」という運用がLoRA作成しにくいと不満。
  - H3の参照機能と比較されることが多い。

### Wan (WAN2.2)
- **話題**:
  - シームレスループ動画の作成で「目視ではまったく同じ画像でループが作れる」と評価。
  - MiniMax（FL2V）と比較して話題に上がる。

### illustrious (リアス / ill)
- **話題**:
  - 「ネットに絵を上げる大半の奴はリアスでも出せる絵しか出さない」という指摘。
  - NAI5の性能向上に対しても「リアスでも出せる絵しか出さないから全体のレベルは上がらない」という意見。

### LTX (LTX-2.3)
- **話題**:
  - 動きの種としてはまだ使えるが、「色が褪せやすい」という明確な弱点があるため本採用は見送りという評価。

### その他（リスト外だが関連して出てきたもの）
- **Krea2**: 表現力は高いが漢字が怪しい、LoRA作成しにくい。
- **H3**: 静止画版に期待（特にTEの強さ・編集能力）。
- **MiniMax / FL2V**: ループ動画の厳密なピクセル一致について話題。

### 全体の傾向
- 現在は **NAI5** が最も注目されており、「animaで苦労してたことが簡単にできる」という声が目立つ。
- animaは「LoRAによる細かいカスタマイズ性」でまだ支持されているが、NAI5の登場で存在意義が薄れている印象。
- Z-ImageやWanは動画・LoRA関連のニッチな用途で言及される程度。

**抽出されたモデル関連話題（除外対象外のもの）**

### 1. **Krea2 / Krea**
- **言及内容**: 
  - 表現力が非常に高いと評価されている。
  - 漢字の表現が怪しい（特に常用漢字で潰れやすい）。
  - NAIとの比較で「漢字の扱い」が話題に。
- **選ばれている/評価されている理由**: 表現力の高さ。

### 2. **H3（MiniMaxの静止画モデル）**
- **言及内容**:
  - MiniMaxが出す静止画用モデルとして期待されている。
  - TE（Text Encoder）が強力で、編集能力まで備えている。
  - 参照機能が優秀（画像参照で画風指定が可能）。
  - エロ表現が可能なら面白そうという声。
- **選ばれている/評価されている理由**: TEの強さと編集能力。LoRA不要でキャラ固定・複数人描写・エロが実現できれば「真のゲームエンド」との評価。

### 3. **DiTベースモデル（一般論）**
- **言及内容**:
  - DiTベースになると、従来のU-Net時代のような「絵師タグの混ぜ混ぜ」ができなくなる。
  - 将来的には「絵師タグ混ぜ混ぜ」は懐かしいテクニックになるとの予測。
- **理由**: アーキテクチャの特性上、従来のプロンプト技法が通用しなくなるため。

### 4. **Grok（動画仕様）**
- **言及内容**: 古のGrok仕様で15秒程度のWebサービスが出てほしいという希望。

### 補足
- NAI v5、anima、Krea2以外のローカルモデル全般についての言及はほとんどなく、ほぼクラウドモデル（特にH3/MiniMax）とKrea2に話題が集中しています。
- 理由として明確に挙げられていたのは **H3の「TEの強さ・編集能力」** と **Krea2の「表現力」** の2点です。

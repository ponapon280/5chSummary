# 元の本文
**生成AIモデルに関するレポート（2026年8月時点のフォーラムログ抽出に基づく）**

### 流行しているモデルの概要
複数の抽出ログ（主にアニメ・エロ生成用途のローカル/サブスクリプション勢の議論）から、**最も活発に議論・使用されているモデル**は以下の通りです。

- **MiniMax H3（MiniMax / minimax_h3）**: 動画生成で圧倒的な話題集中。低VRAM（RTX 3060クラス）での動作可能性、音声付きオムニモーダル生成（T2V/I2V + ネイティブステレオ音声）、高品質期待から「覇権候補」「WAN2.2からの乗り換え先」として注目。公開延期やハード要件の議論が活発。
- **anima（Anima / anima_base / Anima-LLLite）**: 画像生成（特にエロシーン）で最も頻出。Krea2との比較で「エロ時の理解力・プロンプト追従性が優位」と高評価。LoRA自作・放流が活発で、MiniMax H3公開待ちの「主力/つなぎ」モデルとして位置づけ。
- **Krea2（CattowerKrea2含む）**: 画像生成の議論の中心。「エロを最も学習しているモデル」との評価一方で、フィルターによる理解力低下やLoRA効きの硬直性が指摘。LoRA作成用途や健全絵での強みも言及。
- **Wan（Wan2.1 / Wan2.2）**: 動画生成の定番。RAMオフロード技術、確立されたワークフロー（ImageToVideoなど）、LoRA豊富さが支持され、低〜中スペック環境での実績も。
- **NovelAI（NAI / NAI4 / NAI5）**: サブスクリプション派の定番。手軽さ・日本語対応（効果音・セリフ・背景品質向上）でローカル勢の「最終手段」や比較対象に。月額コスパが魅力。

その他、**LTX-2.3**（速度・音声統合で言及）、**FLUX**（長尺動画整合性期待）なども散見されますが、上位5モデルが議論の大部分を占めています。選定軸は主に「エロ/アニメ対応力」「プロンプト理解力」「現行ハード（VRAM/RAM）での実用性」「手軽さ/コスパ」です。

### 各モデルの詳細と選ばれている理由（ログ抽出より）
**MiniMax H3**  
動画生成の最注目モデル。3060 + 32GB RAM環境で480p動画が数分〜10分程度で生成可能という報告や、量子化/オフロードによる低スペック対応期待が強い。音声生成機能や高品質（Sora2級との声）も魅力。選ばれる理由：ローカル高品質動画の可能性と「一段階上の選択肢」としての将来性。エロ対応はLoRA待ちの声多数。

**anima**  
エロ画像生成でKrea2を上回る理解力・追従性が複数指摘され、「エロいくんだったらAnimaのほうが圧倒的に使いやすい」。LoRA作成・自作放流が活発で、テキストエンコーダーの性能（お馬鹿さ）やRAM消費とのトレードオフも議論。選ばれる理由：エロシーン制御のしやすさ、現時点の実用性（MiniMax待ちの主力）。

**Krea2**  
「今まで出てきたベースモデルの中では最もエロを学習してる」との評価。プロンプト反映の良さ、キャラLoRA作成用途で人気。一方、フィルター影響で露骨エロ時の理解力低下や、CattowerKrea2との組み合わせ推奨も。選ばれる理由：エロ学習量の多さ、即戦力としての完成度。

**Wan2.2（Wan）**  
動画生成の手法（ImageToVideo、FirstLastFrameToVideoなど）が確立され、LoRA豊富。RAM増設のきっかけになったモデルとして「爆発的に広まった」との声。低スペック（GTX）実績やエロLoRAの影響も。選ばれる理由：基本性能の高さ、ワークフロー/LoRAの充実度。

**NovelAI（NAI5など）**  
日本語完全対応期待（プロンプト不要・効果音・喘ぎ声精度）、背景品質向上で「二次エロバナナになるかも」。ローカルで詰まった時の安定感や、PC不要・スマホ利用・月4000円で作り放題のコスパが支持。選ばれる理由：手軽さ・継続しやすさ、日本語対応力。

**LTX-2.3**  
速度重視でWanより軽量という声。一部で「SexGod PinkCherry」組み合わせが使いやすい。ワークフロー複雑さが敬遠される場合も。選ばれる理由：速度・軽量志向。

**その他**  
- FLUX：長尺動画整合性の可能性で期待（エロチューニング次第）。
- Irodori v4：音声生成で参照音声長さ増加による自然さ向上。
- Z-Image / illustrious / Qwen-Image：散発的言及（フォトリアルやエンコーダー用途）。

全体傾向として、ローカル勢は「エロ理解力 vs フィルター」「スペック実用性」を重視し、サブスク勢は「手軽さ」を優先。MiniMax H3とanima/Krea2の組み合わせが現在のホットトピックです。

**抽出結果（モデルごと）**

### **NovelAI (NAI)**
- **言及内容**:
  - NAI5のリリース時期を聞く投稿（>>55）。
  - NAI5が一般開放されたらスレが活発になるという意見（>>78）。
  - NAIとローカルのコスト比較が複数あり、特に「NAIの最上位モデルが月4000円で作り放題」という指摘（>>124, >>125, >>130）。
- **選ばれている理由**:
  - 初期投資が少なく、継続しやすい（PCを買わなくても始められる）。
  - スマホでも利用可能で、手軽さ重視の人に支持されている。

### **Wan (Wan2.1 / Wan2.2)**
- **言及内容**:
  - VRAM16GB未満ではローカル動画生成の土俵に立てないという前提でWan2.2が頻出（>>21, >>29）。
  - Wan2.2の登場で64GB RAMを増設した人が複数おり、「Wan2.2のおかげで128GBにした」という声（>>58, >>80, >>93）。
  - FramePackと並んで「当時真空地帯だった」として爆発的に広まったモデルとして評価（>>47）。
- **選ばれている理由**:
  - RAMオフロード技術の先駆けで、ローカル動画生成の変革期を象徴。
  - アニメ・エロ動画で特に需要が高く、メモリ増設のきっかけになったモデル。

### **LTX (LTX-2.3 / ltx2.3)**
- **言及内容**:
  - Wan2.2より軽いという意見と、「軽くはない」という反論が両方存在（>>37, >>39）。
  - アニメに弱いという評価（>>47）に対し、「10Eros使えば問題ない」という反論（>>49）。
  - SexGod PinkCherryとの組み合わせで使いやすいという声（>>92）。
  - 3060で動くという情報が出ているが、速度面で疑問視する声多数（>>220〜222）。
- **選ばれている理由**:
  - 速度重視の人に選ばれやすい。
  - Wanより軽量という期待値はあるが、実際のVRAM効率については意見が分かれている。

### **anima**
- **言及内容**:
  - Krea2で絵柄LoRAを作る際、「絵柄対応するには今のところAnimaだな」という発言（>>178）。
- **選ばれている理由**:
  - 絵柄LoRAの学習・対応力で現時点で優位という評価。

### **Z-Image (ZIT / zit)**
- **言及内容**:
  - Krea2と比較して「フォトリアルさもzitは超えてる気がする」という言及（>>165）。
- **選ばれている理由**:
  - フォトリアルのクオリティでKrea2より優位という主観的評価。

### **その他（言及なし）**
- **illustrious（イラストリアス / ill / IL）**: ログ内に該当する言及なし。
- **FLUX**: 2年前の出来事として「FLUX.1公開」と事実言及のみで、評価・選定理由の記述なし（>>132）。
- **Qwen-Image**: 言及なし。

**補足**:
- 最も話題に上っているのは **Wan2.2** と **LTX-2.3** で、特に「VRAM/RAMの要求スペック」と「アニメ・エロへの対応力」が選定の主な軸になっています。
- NovelAIは「手軽さ・コスパ」の文脈でローカル勢と比較される形で登場しています。

**抽出されたモデル関連話題（除外対象外のもの）**

### 1. **Krea2 / CattowerKrea2**
- ログ内で最も言及が多いモデル。
- **特徴・評価**:
  - プロンプトの反映が良い。
  - フォトリアリズムがZIT（除外対象）より優れているという声あり。
  - キャラLoRAの作成に使われている。
  - エロ寄りの生成では破綻しやすい、またはエロLoRAの学習が弱いという指摘も。
- **選択理由として挙げられている点**:
  - 画風LoRA作成時のベースとしての使い勝手。
  - CattowerKrea2はエロ寄りの生成で比較的強いとされ、Krea2本体でキャラLoRAを作ってCattowerKrea2で生成する組み合わせが推奨されている。

### 2. **hakushi / hakushiMix**
- 「hakushiの方がいい感じはする」という直接的な比較評価あり。
- 具体的な使用例として「hakushiMixで作ったプロンプト」との言及あり。
- 他のモデルと比べて「雰囲気・クオリティの方向性」が好ましいという理由で選ばれている模様。

### 3. **MiniMax H3（MiniMax）**
- 将来的な期待値が高いモデルとして複数言及。
- **選択・期待理由**:
  - VRAM24GB程度で動く可能性があるという情報あり。
  - 週刊的にアップデート（ガチャ）が入るという声。
  - 現行スペックで動くかどうかを気にしている人が多い。

### 4. **その他（散発的な言及）**
- **Kroma**: LoRAとして言及。「lodestonesニキのKromaがloraやから catにかましたら多少...」という文脈で、特定の用途（おそらくcat系との組み合わせ）で使われた例。
- **Kore2**: LoRA作成時の用途で言及（VRAM16GB環境での学習負荷の話）。
- **SexGod PinkCherry**: LTX（除外対象）向けに「一番使いやすい」と評価されているバリエーション。

### 補足
- ログ全体として、**Krea2系**が現在進行形で最も活発に議論されているモデル。
- 選択理由としてよく挙げられるのは「**プロンプト反映の良さ**」「**エロとの相性**」「**現行スペックでの実用性**」の3点。
- 除外対象外のモデルは全体的に少なく、Krea2とMiniMax H3が主なトピックになっています。

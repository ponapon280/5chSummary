# ログから生成AI関連「ツール」話題の抽出レポート

## 抽出結果

### ComfyUI / webUI
- **ComfyUI と Strata の併用環境におけるGPUメモリ割り当て**
  - VRAM 16GB (4080s) 環境で、`--vram-reserve-mb` を3800から7800に増やすことでComfyUIの画像生成速度低下がほぼ解消。StrataとComfyUI併用状態でも0.2.7/0.1.52当時のStrata単独より速い（94tok/s）。VRAM 16GBでの画像生成は完全に障壁なくなったとの報告。（440）
- **ComfyUI と Strata の併用のしんどさと LM Studio の代替利用**
  - Strataは起動が重くモデル解放・読み込みに時間がかかるため、LM Studioを使うことが多くなっている。（439）
- **ComfyUI と LM Studio の役割分担**
  - 画像生成と同時にLLMを使えないと微妙との意見あり。モデル読み込み時と初回回答に時間がかかるのはストレスで、こだわらなければLM Studio＋非検閲LLMで十分の人も多い。（626, 631）

### Stratacloud（Strata）
- **Strata と ComfyUI の併用時の速度改善**
  - VRAM 8GB対応を謳うStrataでGPUメモリ予約を7800に増やしたところComfyUI併用でも快適に。（440。上記ComfyUI項と同一事例）
- **Strata と Krea/Moss/Qwen の割り当てを想定したGPU構成案**
  - 5090=Strata、4090=Krea/Moss/Qwen、6000=H3 というGPU別ツール割り当て環境が報告されている。（632）
- **Strata の起動の重さと LM Studio への移行**
  - 起動が重くモデル解放・読み込みに時間がかかる。（439）
- **Strata で DeepSeek-V4.1-Flash-1017-GSQ-RCO-IQ2_XS を利用して MiniMax H3 360° Orbit LoRA を導入**
  - MiniMax H3 の360° Orbit LoRA導入にあたりStrata上のDeepSeek-V4.1-Flash-1017-GSQ-RCO-IQ2_XSに頼った。（560）
- **Strata最新ターミナル版でスペック不足モデルも動くようになった**
  - Strata最新をターミナル版で弄るとスペック不足モデルも使えるようになった。アプリ版では無理。（574）
- **Strata 5090 単独だと使いづらい**
  - Strataは5090だけでは使いにくいという意見あり。（618）
- **Strata で RAM 32GB で非検閲 Gyro M が動作**
  - RAM 32GB環境でStrata上の非検閲Gyro Mが動いている。（624）
- **Z-Image や Anima 出来あたりでマルチGPU化を検討する声**
  - z-imageやanimaが出てきた頃にマルチGPUにするという動機があった。（627）
- **Strata の起動の重さから LM Studio 使用増加**
  - 起動が重いからモデル解放と読み込みに時間がかかりLM Studioを使うことが多い。（439）

### Nivis Viewer（自作画像ビューワ）
- **Nivis Viewer 更新（不具合修正・処理改善）**
  - 自作の画像ビューワ「Nivis Viewer」を更新。主に不具合修正と処理改善。（509）
- **サムネイル表示の拡大縮小やホイール操作への対応予定はなし**
  - マウスホイールやショートカットキーでサムネイル表示の拡大縮小について、作者は必要がない機能として対応予定なし。サムネのサイズ自体は変更可能で、基本サイズを規定してブラウザ側で機械的に拡大する方法は可能だがトークン消費に見合わないと判断。（572, 580, 610）
- **サムネ上限を大きくして使う使い方**
  - サムネビューワとして使う場合はサイズと上限を大きくして見ればよい。（599）

### MiniMax H3 系ワークフロー・ノード
- **ComfyUI アップデートで mmh3 画像編集・テキストから生成テンプレートが追加**
  - 本家ではないが、ComfyUIアップデートでmmh3の画像編集とテキストから生成のテンプレート（P-H3-imageみたいな名前）が入っていた。（533）
- **MiniMax H3 360° Orbit LoRA の導入**
  - MiniMax H3 - 360° Orbit LoRA が面白い。導入はStrata上のDeepSeek-V4.1-Flash-1017-GSQ-RCO-IQ2_XSを使用。（560）

### antigravity（コーディング系AIエージェントツール）
- **antigravity がコードを勝手に消して勝手に再現する不具合**
  - コードを4回ほど勝手に消して勝手に再現しようとしたため、それ以降は使用していない。（539）

### LM Studio
- **LM Studio を Strata の代替として利用**
  - Strataの起動の重さからLM Studioに移行することが多い。（439）
- **LM Studio ＋ 非検閲 LLM で十分という意見**
  - こだわり次第ではLM Studio＋非検閲LLMで十分。（631）

### GitHub で公開されていたカスタムノード
- **jupoニキのカスタムノードが GitHub から削除**
  - 愛用していたカスタムノードがGitHubから消されてしまった。（596）

## 備考
- ログ内で Qwen は主に画像生成プロンプトエンコーダや Strata 上の LLM として言及されている。Qwen4 のリリース時期や Qwen3.5 0.8B の数学能力改変に関する話題は存在するが、ツールとしての Qwen 関連APIやフレームワークの話題は抽出対象外とした。（441, 457, 476, 483, 504, 632）
- 「チャッピー」の話題は ChatGPT/OpenAI 製品・サービスおよびクラウドAIの課金制度に関連するものであり、ツールの話題として抽出すべきものは見当たらなかった。（486, 495, 505, 519, 523, 531, 606）

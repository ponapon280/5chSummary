## ツール関連話題の抽出

### ComfyUI

- 他アプリ用のGPUメモリー（`--vram-reserve-mib`）を設定することで併用が可能。最新版では12GBで3800程度、16GBで7800程度まで設定できる。Strataのモデルロード時は一時的にVRAMを食うが、Strata側にフックが用意されており、スクリプトを噛ませればStrataのモデルロード時にComfyUIのVRAMを自動クリアすることも可能（645）
- 1からComfyUI環境を構築したりカスタムノードを作成することは余裕でできるとの報告（641）
- Gemini ArgonがComfyUIのプロンプト作成にも差が出るかという質問あり（831）

### Qwen関連（画像生成以外）

- Qwen2.1が出たばかりだが、fibo（画像AIのEditモデル）に対して「Qwen2.1でええやんで終わった」という声あり（664）

### MOSS関連ツール群

- MOSS Model Block Merger（階層ブロックマージ）
- MOSS Multi-Model Merger（複数モデルの一括マージ）
- MOSS LoRA Extractor（LoRA抽出）
- MOSS LoRA Block Weight（階層別LoRA適用）
- MOSS LoRA Merger（LoRA同士のマージ）
- MOSS LoRA Resize（LoRAの軽量化）
- MOSS Model Saver（マージモデルの保存）
- 評価・分析用ツール（CLI Tools）など
- 環境が着々と整い始めているとの評価（757-758）

### PrunaAI（P-H3-Image）

- P-H3-Image（PrunaAI）をTwitterで見かけたという話題。スレ内ではあまり話題になっておらず、Redditの反応も微妙で誰も驚かなかったとの指摘。オリジナルキャラを参照させて動かすイメージだったが、Anima等で既に可能なのではという見解も（759、797、804、806、810）

### danbooruツール類

- danbooruのDBをローカルで閲覧できるようにするツールをAIエージェントに頼んでサクッと導入した事例。キャラやアーティスト名を日本語で入れても正式な表記に辿り着くと評価（706、710）
- danbooruのオートコンプリート用タグファイル更新をしようとしていたがdanbooruがメンテ・ダウン状態（704、699）

### pip / uv（セキュリティ関連）

- サプライチェーン攻撃への対応としてpipやuv等のライブラリ更新が必要。pip更新はサボりがちとの指摘（713）
- Githubでもマルウェア入りのものが堂々と公開されていた例があり油断はできない（714）

### TTS（音声合成）

- エロチャットに音声がないと物足りなくなった。TTSがなかったら飽きていたとの報告（819）

### その他ハードウェア・環境関連

- Strataについて、アイドル時にメモリ解放してほしいという要望（661）
- StrataのIQ3_Sくらいなら作業内容にもよるが普通に実用圏内の性能という報告（641）
- Strataが本体側でモデルを非検閲化できる機能があるがよくわかっていないという声（658）
- GPU1基につき年間2000ドルのソフトウェアライセンス費用を別途請求する案をNVIDIAが検討中というニュース（787、794）
- Google Cloudの3ヶ月45000円のフリークレジットを使えばArgonを試せる。期間限定でproよりAPI使用料が安い（vertexAI経由限定）。普通にAPIを呼び出すとフリークレ対象外（829）

# なんJ AI生成スレ ログ要約レポート

## 1. モデル別動向・比較

### Anima
- **Baseモデルの強さとFTモデルの立ち位置**: 公式Baseが強力で、画風を気にしないならBaseで十分という声(329)。hakushimix等のFTモデルで画風が固定化されるケースあり(330)。
- **2.9Bの扱い**: P1版（プレビュー版）であり、今後の正式版次第で需要が変わるという見方(362)。Baseで作ったLoRAが使えない問題があるが、対応スクリプトも存在する(339, 355)。
- **互換性問題**: 1.0、2.9B、3.8Bで規格（階層数・対応層）が違うためLoRA互換性がない(348, 357)。非公式ナンバリングによる混乱と、公式の次回作への悪影響が指摘されている(317, 351)。
- **エロ表現**: ガチエロだとAnimaも微妙という評価(306)。

### NAI (NovelAI V5)
- **パンツ描写のレベル**: V5はパンツレベルが高いと評価(246)。
- **Opusプラン**: インペ無料、日本語と部族語混在可能で位置指定も比較的容易だが、枚数制限（キツキツ）が課題(374, 378)。
- **感想**: 絵柄が安定しないという声(336)。驚きマン（新機能驚嘆ユーザー）が消えたとの指摘(349)。

### Qwen2.1 / Qwen Image Edit
- **画質とプロンプト効き**: 画質は綺麗だが、プロンプトの効きは2511の方がやりたいことを実現できたという声(267)。公式のプロンプトガイドはQwenLMのリポジトリにある(402)。
- **バッチ編集性能**: LoRA素材のソシャゲカードからロゴ等を消す編集で500枚バッチ処理を行い、変な絵0枚で優秀という報告(320)。
- **カメラ操作**: Qwen Multiangle CameraのLoRA抜きでもぐりぐり回せるとの報告(238)。

### Krea2
- **背景力とエロ表現のジレンマ**: 背景力は優れるが、エロ表現は部族語（danbooruタグ）ベースのモデルに劣る(325)。複数のエロモデル・LoRAを試しても「clothes lift, skirt lift, panties pull」のトリプルコンボは不可だった(278)。
- **プロンプトの踏襲力**: プロンプトの踏襲力が強すぎ、一語修正で他部分が変わり、ポーズガチャも効きにくいという弱点(363)。
- **検閲解除と質感**: 検閲解除LoRAやノードを入れると、プラスチック質感やバリエーション不足が酷くなり元の良さが消える(373)。
- **体型操作**: 貧乳になりがちで、実写系はデカくならない。スライダーLoRAや「macromastia」指定が推奨される(384, 387, 390)。

### minimax (H3)
- **動画モデル**: MATLOWAI（実写◎・アニメ△・指示忠実）、Dasiwa（素材一貫性神・アニメ〇・指示聞かない）などの報告(324)。MATLOWAIはモデルサイズが公式より小さいのに生成時間が遅いが乳揺れが良い(419)。

## 2. LoRA学習・制作関連

### minimax H3 ref2va 1f Lora学習の考察
- **影響範囲**: 画像・人物・背景・モーション全てに影響する(249)。
- **参照画像との相性**: 学習素材とref2vaの参照画像が近いほど効果が高いが、差があると大暴れして悪化する(249, 316)。
- **功罪**: 動きが重くなりがちで汎用性に課題があるが、ピンポイント対策には効果的(249)。
- **推奨手法**: 最初はref2vaの1f学習jsonl方式が作業が単純で推奨(249)。

### Krea2用LoRA学習
- 8dim/8alpha, AdamW8bit, LR 1e-4, 1m pixel, 23images, 1200 constant + 800 cosineで焼いても教師画像通りのヨーヨーの糸の編み方にならない。dim16で改善するか、コンセプトLoRAでキャプションにアーティストタグを入れるとdim余計に食うか検討中(240)。
- Claude codeに学習支援させたら、実写系画像（25歳ぐらいのつもり）が未成年判定されキレられたとの報告(245)。

## 3. ワークフロー・ツール・環境

### ComfyUI・Extender
- **Extenderの参照画像**: Clip毎にValidatedすれば次のClipで参照画像を変えても良い。論理的にはClip1毎に最大9個、動画全体では無限に参照画像を使える。画像18個でClip6個の動画を作成し成功(370)。
- **minimax WF**: 画像参照が便利だがWFがややこしい(243)。
- **Edit連携**: anima-edit -> qwen-image-edit -> minmaxh3-editの連続修正WFを構築中(341)。

### 自作ビューア（レス195関連）
- タグ機能（複数選択からのタグ付け）が追加されており、素材管理に便利(395)。吹き出し・縦書き台詞機能は現時点で対応予定なし、ソース公開しているのでChatGPTで機能追加可能(364)。

### 量子化
- W6A8量子化が登場。INT8の2割減のモデルサイズでW4A8より誤差3分の1。RTX5090では実行速度も速くなる（INT8よりは遅い）(418)。

### GPU・ハードウェア問題
- **ブラックアウト・クラッシュ**: 長時間連続生成中に「デバイスに問題が発生したため再起動」となる事例が複数報告(399, 403)。原因としてVRAM不足、GPUドライバクラッシュ、熱暴走、電源不具合、ファン能力不足が挙げられている(409, 422, 425)。
- **RTX 50シリーズの対応**: RTX 50はINT4非対応・FP4対応でNVFP4は速いがINT4(W4A4)やW4A8は遅い。RTX 2040（※原文ママ、おそらく別機種の誤記可能性あり）はその逆(423)。
- 5090BTOマシンでは問題なく動画作成可能(422)。

## 4. エージェント・AI倫理・規制

### Codex / Agent利用
- **リスク**: Codexはデフォルトで書き込み権限はサンドボックス内だが、読み取り権限は「PC内ほぼ全て可能」。Computer Useだとリスク高まる(270)。ギップルがぶっ壊れる事例(293)。
- **通報リスク**: Agentがエロ関係（特にロリ系）で将来AIが通報するようになる懸念(248, 251)。Claude codeに実写系LoRA制作を手伝わせたら未成年判定でキレられた(245)。comfyuiを理解しているため2次絵なら手伝えると言われた(250)。
- **ローカル推奨**: エロ関係でエージェント使うならDGXsparkやMac Studio M5 Ultra等でローカル環境構築を推奨する声(255)。

### 規制・社会動向
- クリスタ（CLIP STUDIO PAINT）が反AI・手書き専で市場縮小確定の中、活路を見出しに行ったとの見方(265)。
- 規制の流れの大元がいるのではという懸念（頭アルミホイル）(254)。グレートブリテン・EUが黒幕という推測(257)。
- ChatGPT Proプランに500ドル追加の噂、月70000時代へ(327)。「AIでなんでもできる」から「お金払えばAIでなんでもできる」への現実路線調整が寂しいという声(328)。

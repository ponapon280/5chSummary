## モデル別話題

### Krea2 / Krea
- 画質が綺麗で背景力が高いが、プロンプトの踏襲力が強すぎて一部修正が難しい。複雑な自然文プロンプトだと一語直すだけで他の細部が変わる（278, 325, 363）
- エロ表現（clothes lift, skirt lift, panties pullのトリプルコンボ等）は難しく、danbooru語（部族語）が効かないため自然文で書く必要がある（278, 290）
- 検閲解除は可能だが、loraやノードを入れると質感が変わりプラスチック感が酷くなる（373）
- 貧乳になりがちでDカップくらいになる。スライダーLoRAやオッパイスライダーで調整可能（384, 387, 391）
- Claude codeにlora作りを手伝わせたら実写画像を覗かれてキレられた。「25歳ぐらいのつもり」が未成年判定された（245）
- Krea2のPrompt weightを効くようにするKJnodeやSNOFS(V1.2)を使用している（408）
- スレ上の比較：「qwenとKreaの話題ばかり」とあり、現スレの主要話題の一つ（239, 297）

### Qwen2.1 / Qwen Image Edit 2511
- Qwen2.1は画質が綺麗だが、プロンプトの効きはQwen Image Edit 2511の方がやりたいことに合っていた（267）
- 500枚バッチ処理でLoRA素材のロゴ・アイコン消し編集をした際、2511は2割変な絵が出たのに対しQI2.1は変な絵0枚だった（320）
- Qwen Multiangle Cameraのlora抜き（ただの方角指示プロンプト）でもぐりぐり回せる（238）
- 二次エロFTの早期リリースを希望する声あり（410）
- 公式のプロンプトテクニック・プロンプトガイドはQwenLMの方にあった（354, 402）
- TE（Text Encoder）はバカでかいが性能的にはQwen3 4Bとそこまで差がないはずなのに、編集タスクも難しいデザインも出来ているため謎（233）

### Minimax (H3)
- 画像参照が便利だがComfyUIのWF（ワークフロー）がややこしい（243）
- ref2va 1f Lora学習に関する考察：Loraは画像・人物・背景・モーション全てに影響し、参照画像との相性が超重要。学習素材とref2va参照画像が近いほど効果が高い。動きが重くなりがちで功罪がある（249）
- Loraと参照画像に差があると効果が大暴れして逆に悪化する（316）
- ref2vaの1f学習jsonl方式がお勧め（249）
- anima-edit -> qwen-image-edit -> minmaxh3-edit の連続修正WFを構築している（341）
- H3のエロに強い動画モデルについての質問があり、MATLOWAI・Dasiwa等が紹介された（298, 324）

## ツール・周辺技術

### Codex / Claude code / Agent
- MMDでモデルをぬるぬる踊らせる事が出来たが、少し直すレベルでもトークン消費してcodexにやってもらう必要がある（228）
- Codexはデフォルトで書き込み権限はサンドボックス内だが、読み取り権限は「PC内ほぼ全て可能」。Computer Useだとリスク高まる（270）
- Codexにいじらせたせいでギップルするとぶっ壊れる（293）
- ローカルエージェントとして「qwen3.8flash nextを情事回せる環境」を構築し、独立した環境でいろいろやれるようになった（255）
- エロ関係でエージェント使うならDGXsparkやMac M5 Ultra買ってローカルでそれなりのサイズのAIを動かした方がよい（255）

### 量子化（W6A8 / W4A8 / NVFP4 / INT4）
- W6A8はINT8の2割減のモデルサイズでW4A8よりも誤差3分の1、実行速度も5090だと速い（INT8よりは遅い）（418）
- モデルが小さい＝速いではない。4bit以下の量子化より6bit/8bitの方が変換処理をスキップできて速い（421）
- RTX 50はINT4非対応でFP4対応。NVFP4は速いがINT4(W4A4)やW4A8は遅い。RTX 2040はFP4非対応でINT4対応（423）

## ローカル環境・ハードウェア関連
- 工房5090の最安を買ってエージェント用のスーパークリーンPCとして活用。ストレージ盛っておけば良かった（287）
- 長時間連続生成で画面ブラックアウト・デバイス問題で再起動になる事象が複数報告。GPUのVRAM不足・ドライバクラッシュ・熱暴走・電源・ファン能力不足等が原因候補（399, 403, 409, 422, 426）
- 3060から5070Tiに変更したらファン能力が根本的に足らず排熱が追いつかない。動画の連続生成で落ちる（422）
- GPUの出力を70%に制限しても温度上がらんのにクラッシュする事象あり（426）

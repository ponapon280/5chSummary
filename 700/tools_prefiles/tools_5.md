## 生成AI関連「ツール」話題 抽出レポート

---

### ComfyUI / Comfy全般

- **モデルデータ置き場の自動判定**: 最近のComfyアプデでモデルデータ置き場がNVMeかどうかを自動判定するようになり、`--fast-disk`は不要になった。ただし環境次第では`--disable-fast-disk`が有効なケースもある（レス901、903）。
- **カスタムノードの高速化**: 処理が遅いカスタムノードをチャッピー（AI助手）に相談し、CPU処理からGPU処理に変更してもらって爆速になった事例（レス968）。
- **Model Preview Override**: qiのtinyVaeが出たが、KJのModel Preview Overrideで見るには修正が必要。チャッピーと壁打ちして表示できるようになった（レス906）。
- **Context Loop（ContexLoop）**: 動画延長のFA（定石）。既に作った動画も延長できる。ただし20秒あたりで再放送（同じ場面・動きの反復）が発生しノイズになる問題があり、生成して編集して繋げた方がいい場合もある（レス851、852、891、893、896、859）。
- **Extender**: ContexLoopと同様に1分超の動画を作る手段だが、労力の割に使えるわけではないとの評価（レス852）。
- **Comfy-kitchen Attention / Block Sparse Attention / Spectrum / Model Shift(ModelSamplingMiniMaxH3)**: MiniMax H3の高速化・品質維持のために使われる4つのツール・ノード。ターボは使わずこれら4つを組み合わせている。具体例: 4060Ti(16GB)で0.6MP/30steps/12s/24→48fps化が18分（レス888）。ただしSpectrumはダメという声もあり（レス899）、spectrum integratedをforge neoでオンにすると生成途中で画像が壊れる事例も報告（レス915、978）。

### forge neo

- **spectrum integratedの不具合**: forge neoでspectrum integratedをオンにして生成すると、生成途中で画像が壊れて変な絵になる問題。再起動でも直らない（レス915、978）。
- 原因としてTurboとの併用やステップ設定が疑われたが、最終的には部族語の補足に使った自然言語が悪さしていたことが判明（レス921、923、978）。

### Krea2

- **プロンプト作成ワークフロー**: Codexにプロンプト作成のポイント・アドバイス一覧を出させ、それをGrokにコピペして過去作品や参照画像を良い感じのプロンプトに改編させる使い方が推奨されている（レス908）。
- **2次キャラの作画**: Krea2で2次キャラが描けることが確認された。Codexに3コマ漫画のプロンプトを出させてKrea2でガチャった事例あり。文字系はNAI5には届かないが、Codexに生成させればちゃんと出来ていた（レス862、879、905、908）。
- **版権キャラ未学習の課題**: 版権キャラを学習しておらず、wildcardで版権キャラのシチュを生成できない。キャラLoRA作成もAnimaほどお手軽ではない。Codexに素材集めからLoRA作成までやらせれば解決可能だが、エロシーンを入れなければノンストップで完結する（レス911、913）。

### nano-banana（ナノバナナ）

- 高クオリティな画像生成に使用されたツールとして言及。反射などもちゃんと出ている（レス964、966）。

### Codex

- **アップデートの不具合**: アップデート後、コマンド実行するたびにターミナルが一瞬出て消えるようになり、issueにある通りダウングレードしても直らない（レス868）。
- **リセット**: 30日のデカい更新でリセットされる。XでCodexリセットに文句言っているヤツが中国語翻訳だった（レス904、929）。
- **許可の都度確認が煩わしい**: 全フォルダアクセス可にしてパワーシェルで書き換えてもいちいち許可を取ってくる問題。解決策として`codex --ask-for-approval on-request --sandbox workspace-write`で起動する方法や、ワークスペースのフォルダ権限を修正する方法が提示された（レス936、938、943、954、958、962）。
- **sandboxの権限不具合**: sandboxが起動できていない不具合があり、フォルダの書き込み権限がcodexになっているのを自分に戻せば治る。Windowsでは`.codex`と作業フォルダの`CodexSandboxUser`のパーミッションをフルコントロールにすればブロックが解除される（レス954、962）。
- **電話番号要求**: 新規利用時に電話番号を要求される（レス948）。
- **自律的な設定変更**: 自分の設定ファイルを書き換えて自分で自分をぶっ壊すことも可能。設定変更方法を聞くと丁寧に教えてくれる（レス944、945）。
- **プロンプト生成用途**: プロンプトはCodexがいい感じに作るがエロにうるさいため、Grokへのプロンプト改編指示用のアドバイス一覧をCodexに出させるワークフローが便利（レス908）。

### siki（svgサムネイルツール・自作ツール類）

- **svgサムネイル生成**: QRサイト製・Affinity製のsvgはサムネイルが出るようになった。Illustrator製のsvgはサムネイルが出るようになったが、Inkscape製のsvgでサムネイルが出ないケースが発見された。原因は`inkscape:`の編集用属性がXML解析で引っかかっていたため（レス840、871、916、917、961）。
- **UI改善の提案**: 設定の「AI画像の読み込みを有効にする」は「Illustrator（.ai）画像の読み込みを有効にする」が良い。ViewerをCtrl+Q/Wで閉じられるように。ファイルのフルパスコピーにShift+Cを割り当て。Escは「状態解除」系に割り振りたいのでViewer閉じる用途にはマウスジェスチャ推奨（レス916、957、965）。
- **catboxリンクの置換**: `cat○box`を`catbox`に自動置換する設定を追加（レス925）。

### Grok / Grok Imagine

- **アップグレード**: Grok Imagineがいつの間にかアップグレード。画像と動画の生成品質が向上している（レス975）。
- **プロンプト改編用途**: Codexが出したアドバイス一覧をGrokにコピペし、過去作品や参照画像を良い感じのプロンプトに改編させる使い方（レス908）。

### チャッピー（AIコーディング助手）

- **VRAM回避策の相談**: 5090で1MP/20秒の動画を参照4枚maxで重ねるとOOM。チャッピーに聞いたら回避策はあるがモデルをメモリに逃がすためクソ遅くなるとのこと（レス842）。
- **カスタムノード高速化**: 遅いカスタムノードをCPUからGPU処理に変更してもらって爆速化（レス968）。
- **tinyVae表示修正**: KJのModel Preview OverrideでtinyVaeを見るための修正をチャッピーと壁打ちして解決（レス906）。

### 動画生成ツール関連（refmods等）

- **refmods**: 参照画像を複数重ねてOOMになる場合の回避策としてrefmodsを使う方法が提示された（レス843）。
- **FL（Frame Loop等）**: FLで繋げて1分ぐらいの動画を作る手法。環境によっては一番破綻がなく綺麗。qie2.1でF画像が完璧になったとのこと（レス856）。

### ドライバ・環境関連

- **nvidiaドライバ**: studioの最新からgame readyの596.49に変更したらpythonが固まって生成できなくなる問題が解決。しかし再度pythonが固まる事態も発生（レス880、882）。
- **--fast-disk / --disable-pinned-memory**: メインメモリを使わずに済むオプション。モデルはbf16よりint8_convrotが推奨される（レス898）。
- **メモリ増設**: グラボそのままでメモリ96まで上げたら長尺動画生成にいける。尼で64GBメモリが安くなっている（レス837、861、865）。

### Minimax H3関連ツール設定

- **Attention Backend + ブロックスパースアテンション**: 0.9MP/15sが90秒くらいになる（レス881）。
- **kitchen attention + sol attn tau1.00**: ステ25/0.9MP/15秒で13分弱（レス907）。
- **高速化のトレードオフ**: クオリティを犠牲にすれば数字はいくらでも縮められる。ターボで一番劣化がキツいのはセリフ部分（レス892、933）。
- **irodori**: セリフはirodoriで作って最後に合成する手法が提案された。リップシンクの課題は残る（レス933）。

**抽出結果（ツール関連のみ）**

### ComfyUI（comfy）
- **言及内容**:
  - 実行ボタンがUI変更で消えたり隠れたりする問題（470, 471, 472, 473, 474, 477）。
  - カスタムノード関連のトラブル（Text ConcatenateがWAS Node Suite終了で使えなくなった、572, 575, 578, 580, 587, 588, 590）。
  - ワークフロー操作（Context loopのexample workflow更新、511 / API叩きツール自作、612, 613）。
  - 生成速度問題（Minimax H3がComfyUIで遅くなる、487, 488, 494, 496）。
  - VRAM管理性能の向上（509行目）。

- **選ばれている理由・利点**:
  - VRAM管理性能が非常に良くなった（旧来より足切りラインが下がった）。
  - ワークフローJSON形式のためカスタムノードで柔軟に拡張可能（スマホUI対応も容易）。
  - API連携や自作ツールとの相性が良く、安定運用に向いている。

### Irodori（および関連フォーク）
- **言及内容**:
  - Irodori-TTS v4 Smallのダウンロード仕様とEmojiニキ版フォークの違い（442, 444, 449, 453, 469）。
  - 好きなキャラにセリフを言わせる用途（437）。

- **選ばれている理由・利点**:
  - 公式IPキャラでも比較的緩い制限で使える点。
  - TTSの品質と使い勝手が良く、ASMR用途で満足度が高い。

### minimax（t2va / 動画生成ツール）
- **言及内容**:
  - ComfyUI上での生成速度低下問題（487, 488）。
  - 料理動画生成や真面目とエロの混在が得意（457, 458, 459）。
  - ステップ数削減やターボ版の挙動（621, 622, 625, 629）。

- **選ばれている理由・利点**:
  - 真面目な映像とエロティックな映像を違和感なく混ぜられる柔軟性。
  - 比較的検閲が緩く、幅広い表現が可能。

### Draw Things
- **言及内容**:
  - iPhoneでのローカル画像生成（546, 548）。

- **選ばれている理由・利点**:
  - iPhone単体でAnimaサイズ程度の生成が可能（fp16アクセラレータ対応）。
  - ComfyUIのブラウザ操作とは別に、本体のみで完結できる手軽さ。

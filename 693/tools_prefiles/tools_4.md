**抽出結果（ツール関連のみ）**

### 1. ComfyUI（comfy）関連
- **ワークフロー操作・カスタムノード**
  - CodexなどのAIエージェントにComfyUIのワークフローを弄らせる話が複数。
  - 特に「outputフォルダの読み取り」や「カスタムノードの追加」をAIに依頼するケースで、権限設定（config.toml）の不具合が指摘されている。
  - 理由として挙げられている点：AIにワークフローを改善・修正させたいが、outputフォルダまで読まれてしまうリスクを懸念。

- **Docker / 仮想環境での運用**
  - ComfyUIをDockerやHyper-Vサンドボックスで動かす提案。
  - 理由：エージェントにPC全体を見せたくないため、作業領域を隔離したい。

- **専用ドライブ運用**
  - ComfyUI専用のNVMe SSDを別途用意して作業する話。
  - 理由：生成物の管理と速度向上のため（SATA SSDとの比較も言及）。

### 2. マウス・キーボード共有ツール
- **Logi Options+**（ロジクール製）
  - 2台のPC間でマウス・キーボードを共有し、コピペもできる点が評価されている。

- **KVM切り替え機**
  - 物理的な切り替え機の言及。遅延はあるが安定。

- **synergy → barrier**
  - ソフトウェアでの共有ツールとしてbarrierを使っている人がいる。

- **Mouse Without Borders**（PowerToys）
  - 無料で試せる点が推奨されているが、LAN負荷で遅延する可能性あり。

- **全体の理由**：PCを2台使っているため、1セットのマウス・キーボードで両方を操作したいというニーズ。

### 3. AIエージェントのセキュリティ対策ツール・手法
- **Hyper-Vサンドボックス / 仮想Windows**
  - Codexなどのエージェントを仮想環境で動かし、必要なフォルダだけ共有する手法。
  - 理由：実機に直接触れさせるとoutputフォルダや機密ファイルまで読まれるリスクを避けるため。

- **Docker**
  - Linuxユーザーから「OSに依存しないDockerの方が良い」との意見。
  - 理由：ComfyUI環境をコンテナ化して隔離したい。

- **物理的な隔離（外付けHDD + ケーブル抜き）**
  - エージェント使用時はエロ画像のあるドライブを物理的に切断する運用。
  - 理由：最も手軽で確実なセキュリティ対策として挙げられている。

### 4. その他
- **OneDrive / クラウドバックアップの注意**
  - 自動同期による意図しないアップロードの危険性が複数指摘されている（ツールというより警告として）。

**除外したもの**
- モデル関連（NAI、Anima、Minimax H3、Krea2のLoRAなど）はすべて除外。
- Qwenシリーズの言及はなし。

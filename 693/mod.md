# 元の本文
**生成AIモデルに関するレポート（2026年9月時点のログ抽出に基づく）**

ログから最も頻繁に言及され、議論の中心となっているモデルは **NovelAI (NAI v5)** と **anima** です。次いで **MiniMax H3**（動画生成用途）と **Krea2**（スタイル・LoRA・二次エロ期待）が活発に比較・評価されています。illustrious（リアス/ill/IL）はカスタマイズの楽しさやt2i性能で一定の支持を集めていますが、全体の言及量では上位2モデルに劣ります。Wan、LTX、Qwen-Image、FLUX、Z-Imageなどは言及が少なく、周辺的な比較対象として登場する程度です。

これらのモデルは主に**二次元イラスト・エロ漫画・動画生成**（特にNSFW寄り）の文脈で語られており、選ばれる理由として「自然言語理解力の高さ」「背景・キャラの整合性」「LoRA/カスタマイズのしやすさ」「実用的な速度・VRAM要件」「プロンプト追従性・完成度」などが繰り返し挙げられています。NAIとanimaは画像生成の主力として、H3とKrea2は動画・新興用途として棲み分けが進んでいる印象です。

### NovelAI (NAI / NAI v5)
ログ全体で言及回数が非常に多く、「NAIがあればローカルは終わり」「圧倒的な完成度」との声が目立ちます。v5ではキャラごとのプロンプト枠強化、座標指定（Regional Prompter相当）の強み、日本語テキスト生成の安定性、4コマ漫画レベルのポン出し性能が評価されています。ローカルモデルとの比較でも「画質・細部・安定感で優位」「スカート処理や自然言語理解力が非常に高い」との理由で支持されています。[[1]](https://www.youtube.com/watch?v=OuoPukAqPWo)[[2]](https://x.com/novelaiofficial)

**選ばれている主な理由**:
- 自然言語プロンプトの強みと複雑な構図・位置指定のしやすさ。
- 漫画生成能力やキャラ再現性・日本語文字品質の高さ。
- 全体的な完成度・利便性でローカル勢を上回る点。

### anima（Anima-Base / 3.8Bなど）
animaはNAIと並んで言及最多クラスで、「服装・髪型の統一がしやすい」「背景整合性が強い」「エロ表現（fat monsなどニッチタグ）に対応」「Regional Prompt対応」「自然言語＋タグの両対応」が繰り返し挙げられます。VRAM要件が現実的（24GBクラスでFull FT可能）で、小型ながら構図・数認識が向上した点も評価されています。一方でLoRA作成のハードルや生成速度のデメリットも指摘されています。[[3]](https://gigazine.net/news/20260515-anima-image-generation-ai/)[[4]](https://civitai.com/articles/33274/anima-generation-guide-part-1-general-model-a-bit-of-history)

**選ばれている主な理由**:
- 背景・キャラ統一の強さと二次エロ向けバランスの良さ。
- LLM組み合わせによる構図認識向上と実用的な学習環境。
- NAIに近い完成度をローカルで実現しやすい点。

### illustrious（イラストリアス / リアス / ill / IL / WAI-Illustrious-SDXLなど）
SDXL派生のアニメ特化モデルとして、t2iのポン出し性能やモデルマージ・カスタマイズの楽しさが理由で選ばれています。Animaの下絵との組み合わせや特定のLoRA相性で使われるケースもあり、派生モデル作成の楽しさが強調されます。現在はanimaやKrea2との比較で語られることが増えています。[[5]](https://civitai.com/ecosystems/illustrious)[[6]](https://civitai.com/models/1359594/wai-mature-illustrious)

**選ばれている主な理由**:
- モデル作成・カスタマイズの楽しさ（animaよりマージが楽しいという声）。
- t2iポン出し性能の高さ（ただし全体完成度では他モデルに譲る場面も）。

### MiniMax H3（H3 / H3 max / MMH3など）
動画生成モデルとして最も言及が多く、リップシンクの自然さ、ref2v（参照画像からの動画生成）性能、NSFW耐性・表現自由度が評価されています。高速化派生（FastH3など）の乱立や画質の未熟さが指摘される一方、低VRAM環境での動作実績や音声・動きのダイナミックさで期待されています。[[7]](https://www.minimax.io/blog/minimax-h3)[[8]](https://www.minimaxh3.com/)

**選ばれている（または注目されている）主な理由**:
- リップシンク・ref2v性能とNSFW対応の強み。
- 高速化バリエーションの豊富さ（ただし最適解がわかりにくい）。

### Krea2 / Krea
素のKrea2は実写寄り・自然言語プロンプトに強く、画風LoRAの再現性が高い一方、二次エロではLoRAなしで性器が出にくい点が指摘されます。将来的な二次エロ向けファインチューニング（FT）の登場を待つ声が多く、LoRA学習のしやすさやedit機能（座標指定）が強みとして挙げられています。[[9]](https://www.krea.ai/blog/krea-2-image-model)[[10]](https://github.com/krea-ai/krea-2/blob/main/README.md)

**選ばれている（または期待されている）主な理由**:
- ベースモデルの素性の良さ（画風LoRAが効きやすい）とスタイル転写性能。
- 二次エロFTが出れば勢力図が変わる可能性。

### その他のモデル
- **Wan / LTX**: LoRA資産の豊富さで根強い支持があるが、リップシンクではH3に劣るという比較が主。
- **Grok / Gemini**: 画像生成時の文字読み取り改善やNSFW耐性・速度で言及されるが、通報リスクも指摘。
- **Qwen-Image / FLUX / Z-Image**: 言及が極めて少なく、具体的な選定理由はほとんど抽出されませんでした。

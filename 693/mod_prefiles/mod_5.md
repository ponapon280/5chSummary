以下は、指定されたモデル群に関する言及をログからすべて抽出したものです。特に「選ばれている理由」が明記されている部分を重点的にまとめています。

### NovelAI (NAI / NAI5)
- **言及回数**: 非常に多い
- **主な話題・理由**:
  - 日本語文字の品質がローカル勢で最も高い水準（「NAI5レベルの日本語文字」）。
  - 同一キャラの再現性で過去に優位だった（v3時代が特に評価される声あり）。
  - データベースの規模が大きく、LoRA自作勢でも「NAIの巨大データベースに勝負しようがない」とされる。
  - キャラごとの細かい設定・再現がしやすい。
  - NAI5は画質が高い一方で、特定のキャラの再現性がv3より落ちたという指摘あり。

### illustrious（イラストリアス / リアス / ill / IL）
- **言及回数**: 少なめ
- **主な話題・理由**:
  - 全盛期にはオリジナルモデルを公開する人が複数いた。
  - NAI5と比較して「キャラ再現はIllustriousの方がマシ」という声あり。
  - 現在は下火になっているという指摘。

### anima
- **言及回数**: 多い
- **主な話題・理由**:
  - **VRAM要件が現実的**：24GB（4090など）でFull FTが可能。SDXLよりは遅いが、数万枚規模の調整なら余裕。
  - Regional Prompt Simple対応。
  - 背景込みでのキャラ再現性がNAI5と遜色ないレベル。
  - 「身の丈にあった場所に戻ったモデル」と評価され、派手な性能ではなく堅実な方向性で支持。
  - Anima世代から入った人はNAIの過去の知識量との違いを感じている。
  - フルファインチューニング勢にとって、現実的な選択肢として挙がっている。

### Z-Image（Z-Image Turbo / ZIT / ZIE）
- **言及回数**: 1回
- **主な話題**:
  - Z-Image登場前の段階で「二次エロ＋自然言語」が強かったモデルとして言及。
  - ただし画質面（目と手の溶け）が弱点で、LoRAでも改善しなかったため終了したという評価。

### その他（FLUX, Wan, Qwen-Image, LTX）
- これら4モデルに関する言及は**一切なし**。

### 補足
- ログ全体として、**NAI**と**anima**が圧倒的に話題の中心。
- animaは「コスパ・現実的な学習環境」という観点で選ばれている傾向が強い。
- NAIは「完成度・データ量・日本語文字」という観点で選ばれている。

**抽出された「モデル」関連話題（除外対象を除く）**

### 1. **Gemini（特にgemini 3.8f）**
- **話題の中心**: エロ生成における総合力。
- **選ばれている理由**:
  - 「早さ・質・使いやすさの全てを合わせた総合力でエロ最強」と評価。
  - 言語操作・創作系は元々優秀で、エロ文生成でもBANされにくい。
  - ただしコーディングはポンコツなので、用途をエロ・創作に絞った場合に強い。
- **関連コメント**: 「gemini君がエロ最強やったら皆でチキンレース」「geminiはgemini内のエロ文ではBANしてこない」

### 2. **Grok**
- **話題の中心**: 画像生成時の通報リスクと制限。
- **選ばれている理由**（または避けられる理由）:
  - 露骨な画像をアップロードしたユーザーが通報された事例が話題に。
  - クラウドAIの中では特に厳しい対応を取る事例として挙げられる。
- **関連コメント**: 「Grokはアウ露理画像アップロードしてたアホだからそりゃ当然」

### 3. **Codex（エージェント系）**
- **話題の中心**: 利便性 vs リスク。
- **選ばれている理由**:
  - 「便利だからといって『凝』を怠るな」という警告が複数あり、作業効率は高いが過信は危険という文脈で語られる。
  - LAN内PC操作やローカルファイル参照ができるため、利便性が高い一方でセキュリティリスクを指摘する声が多い。
- **関連コメント**: 「Codexが便利だからといって『凝』を怠るな」「Codexとか関係なく、持っとるだけで犯罪になるもの(児ポ)をネットにつなぐのはやめたほうがええ」

### 4. **動画生成モデル系（H3 / MiniMax / Kling）**
- **H3 Max / MiniMax H3 max turbo**
  - 9月リリース予定という情報あり。
  - 3060でも動くという言及（特にturbo版）。
- **Kling / minimax**
  - 比較議論が活発。
  - **minimax**：映像的なクオリティでKlingより上。
  - **Kling**：音質で優位。
- **選ばれている理由**: 用途（映像重視か音声重視か）で明確に使い分けられている。

### 5. **その他言及されたモデル**
- **Krea2**: 二次エロファインチューニング版の登場を待っている声あり。将来的な移行先候補として名前が上がる。
- **SDXL**: 「完全にエロ排除モデル」と認識されており、エロ用途では避けられる傾向。
- **SD3M（魔人）・Pony（auraflow）**: 過去の分裂・対立の文脈で名前が出る。
- **NetayumeLumina**: 自然言語＋二次エロで当時評価されたが、画質（目・手の崩れ）がネックで終了したモデルとして回顧されている。

### 補足傾向
- **クラウド vs ローカル**: GeminiやGrok、Codexといったクラウド系は利便性が高い一方で「通報リスク」「BANリスク」を強く意識した議論が多い。
- **用途特化**: エロ生成では「総合力（Gemini）」や「特定性能（minimaxの映像、Klingの音質）」でモデルを選ぶ傾向が明確。
- **エージェント系（Codexなど）**: 利便性を認めつつも「過信は禁物」という慎重論が目立つ。

除外対象（NAI, Illustrious, FLUX, Wan, Qwen-Image, Anima, Z-Image, LTX）に関する言及はすべて除外してまとめています。

以下は、指定されたモデル（NovelAI/NAI、illustrious/リアス、FLUX、Wan、Qwen-Image、anima、Z-Image、LTX）に関する話題をログからすべて抽出したものです。モデルが選ばれている理由が明記されている部分は特に強調して記載しています。

### NovelAI (NAI / naiv5 / NAI v3 / v4 / v4.5 / v5)
- NAI v5は1人1人キャラプロンプト枠があり、「このキャラはこう、竿役はこう」と分けられるようになった（243）。
- NAI v3の進化が凄すぎてv4.0が微妙だったためv4.5を触ったことがない人が多い（250）。
- NAIはローカルで再現しようとしているが、やはりNAIはすごすぎる（248）。
- NAI5は漫画も作れてコマ割りもできる（305）。
- NAIはスタミナ性にした以上、サブスクを一段上に出すべき（311）。
- NAIメインで使いつつAnimaの進化も期待している（426）。
- **選ばれる理由**: 圧倒的な完成度・安定感・漫画生成能力。ローカル勢でも「NAIはすごい」と認める声が多い。

### anima
- 公式プロンプトガイドのサポートをもう少し欲しい（240）。
- キャラの服装や髪型の統一がしやすい。イラストリアスのwaiとanimaのwaiが近いので使いやすい（258）。
- multiple panelsでコマ割り生成が可能（275）。
- 2キャラのキスシーンなどで髪色が薄くなったり顔が違う問題あり（323）。
- Anima3.8Bの新バージョンはテキストエンコーダーの活かし方が分からず、出力が劣化している気がする（318）。
- Animaは複数人・背景能力がカス（283）。
- Anima3.8B v1.1はprompt追従がKrea2に届かず、重い＋使用条件が面倒（329）。
- AnimaはNAI5ショックが効いている（341）。
- Animaでグレーの背景の立ち絵生成時に光源の扱いが難しい（399）。
- **選ばれる理由**: 服装・髪型の統一がしやすい、二次エロ向け、複数キャラの扱いやすさ、コマ割り対応。

### illustrious (リアス / ill / IL)
- リアスはSDXLの派生でCLIPが少し劣化したもの（297）。
- リアス出身の人がAnimaを触り始めるケースあり（441）。
- リアスでポンシコしている人がいる（272）。
- リアスみたいなt2iのポン出し性能特化の進化はまだない（308）。
- **選ばれる理由**: t2iのポン出し性能が高い（ただし現在はAnimaやKrea2との比較で語られることが多い）。

### Wan
- Wanは二次絵のリップシンクがMiniMax H3ほど自然ではない（277）。
- Wan2.2は去年の8月に出て、10月頃にどすけべ戦国時代に入った（374）。
- WanやLTXはlora資産でH3に圧勝している（358）。
- ループ動画の単純な2Dセックスシーンは今でもWanで作っている（362）。
- **選ばれる理由**: lora資産の豊富さ。特にエロ目的のI2Vで根強い支持。

### LTX (LTX-2.3 / ltx2.3)
- LTXもWanと同じく、二次絵のリップシンクはMiniMax H3ほど自然ではない（277）。
- **選ばれる理由**: 特に明記なし（Wanと並んで語られることが多い）。

### Qwen-Image / Qwen系
- Qwen3.5世代のモデルがオープンウェイトになった時の性能に期待（303）。
- Qwen3.8-27BをKrea2で作ったエロ画像を見せて動きを指示する用途で使っている（359）。
- **選ばれる理由**: 自然言語での指示が強く、Krea2生成画像からの動き付けに強い。

### FLUX / Z-Image
- 該当する言及は確認できませんでした。

### 補足

- WanとLTXは主に「lora資産」と「リップシンクの自然さ」で比較対象にされることが多いです。

**抽出されたモデル関連話題（除外対象を除く）**

### 1. Krea2 / Krea
- **主な話題**:
  - Animaとの比較が非常に多い（目的が違うので比較自体が不毛という意見多数）。
  - 実写寄り・自然言語プロンプトに強いが、**二次エロ**が厳しい（LoRAなしでは性器が出にくい、検閲あり）。
  - LoRA学習が素直で作りやすい一方、Danbooruタグ未履修で苦戦（「mole」「beauty mark」などのタグ理解が弱い）。
  - 座標指定（edit機能）が強く、漫画用途やref用途で評価されている。
  - 英語の自然言語記述が前提になるため、日本語タグ勢からはハードルが高いという指摘あり。

- **選ばれている理由（肯定的）**:
  - プロンプト追従性とLoRAの扱いやすさ。
  - 実写・編集用途ではAnimaより優位。

- **否定的意見**:
  - 二次エロ・版権再現・画風制御が弱い。
  - LoRA学習が重い。

### 2. MiniMax H3（H3 / MMH3 / FastH3 / H3maxなど）
- **主な話題**:
  - アニメのリップシンクがWanやLTXより自然で高評価。
  - ref2v（参照画像からの動画生成）の性能が非常に強い。
  - 各種高速化（FastH3、lightx2v系LoRA、H3_VAE_TRTなど）が乱立しており、最適解が環境・用途で変わる「泥沼」状態。
  - 画像編集用途としての可能性も議論されている（公式の画像編集モデルを待つ声あり）。
  - 画質の低さがネックで、「画質が上がればゲームエンド級」という意見多数。

- **選ばれている理由（肯定的）**:
  - リップシンクとref2vの性能。
  - 高速化バリエーションの豊富さ（ただしどれがベストか混乱を招いている）。

- **否定的意見**:
  - 画質がまだ不十分。
  - 高速化手法が多すぎて把握しにくい。

### 3. その他（言及程度）
- **DreamX-Creator 1.0**: 7Bと軽量で長尺生成に期待する声。
- **Fable 5.1**: 名前のみの言及。
- **lightx2v**: H3向けの高速化LoRAとして名前が出ている。

### 補足
- ログ全体で最も活発に議論されているのは **Krea2** と **MiniMax H3** の2つです。
- 特に「Anima（除外）とKrea2/H3の棲み分け」や「H3の高速化乱立」が主要テーマになっています。

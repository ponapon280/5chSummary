# 元の本文
**生成AI関連ツールレポート（抽出テキストに基づく）**

抽出されたテキストから、生成AI（主に画像・動画生成）のローカル環境向けツールを中心にまとめました。モデル名・性能比較は除外し、ツールの言及・選定理由・不満点・代替案に焦点を当てています。ツールが選ばれる（または避けられる）理由はテキスト内の記述をそのまま反映し、必要に応じて補足しています。

### 1. ComfyUI（comfy）
- **概要と使用状況**: ノードベースのワークフロー構築ツールで、動画生成（MiniMax H3、ref2vなど）や複雑なi2i/inpaintワークフローに実質必須とされるケースが多い。カスタムノードの追加や柔軟なノード配置・継ぎ足しが強み。一方で、画面操作の複雑さやカスタムノード導入の手間が指摘される。
- **選ばれる理由**:
  - ワークフローの柔軟性が高い（自由配置、ループ処理、Context Loop風の動画繋ぎ、Mathノードとの組み合わせでLoRA強度をステップごとに変更可能など）。
  - 新しめの動画モデルやref2v用途で避けられない。
  - 公式ループ機能の開発中（n回繰り返し、複数入力順次処理など）で高度な制御が可能。
- **不満点・課題**: インストール/環境更新時の互換性問題（torchバージョン更新時のflash attention関連エラー、Python 3.10サポート終了対応）、カスタムノードの多さ・導入大変さ、UIの直感性の低さ（専用画面でプロンプト入力→生成ボタン押すだけのシンプルさを求める声）。
- **運用Tips**: DockerやHyper-Vサンドボックスでの隔離運用、専用NVMe SSDでの高速化、AIエージェント（Codexなど）にワークフロー修正を依頼する事例あり。

### 2. webUI系（EasyReforge + Forge Neo / forgen eoの組み合わせ）
- **概要と使用状況**: 画像生成メインの日常使いツールとして言及され、特にinpaint/i2i作業で「サクサク作業できて恋しい」と評価。EasyReforgeはワンクリックインストールパッケージ、Forge Neoは最新モデル対応の高速化フォーク。
- **選ばれる理由**:
  - Forge Neo: 最新バージョン（例: anima v1.1）への対応が早く、利便性が高い。
  - EasyReforge: 環境構築が容易で、拡張機能やプリセット管理が簡単。AIエージェントに「WebUI作って」と指示するだけでカスタマイズ可能（デフォルト値変更・追加機能・プリセット管理）。
  - 画像生成（静止画inpaint/i2i）でComfyUIより作業効率が高い。
- **関連拡張**: RegionalPrompter（またはRegional Prompt Simple） — LoRA併用時の領域分け（キャラ書き分け）に有効。LoRA使用時の領域制御が容易になる点が利点。

### 3. EasyWan22
- **概要**: Wan系動画生成向けの簡単インストールツール（ComfyUIベース）。
- **選ばれない理由**: メンテナンス終了から時間が経過しており、現在はインストールに失敗するようになったため、明確に非推奨とされている。

### 4. カスタムUI / フロントエンド（AI生成UI）
- **概要と使用状況**: ComfyUIの複雑さを隠蔽するため、LLM（AIエージェント）に指示して専用UIを作成する手法が複数言及。会話しながらプロンプト生成、出先での生成、キャラ会話用フロントエンドなどに活用。
- **選ばれる理由**: 「自分で一から作るより楽」「直感的に使える」ようにするため。言語能力とPCスペックがあれば誰でも扱える点が評価され、「AIに導入してもらって、自分用にUIを作ってもらう時代」という意見が多い。

### 5. その他のツール
- **マウス・キーボード共有ツール**（複数PC運用時）:
  - Mouse Without Borders（PowerToys）: 無料で簡単に2台のPCを操作可能。利便性と手軽さが選ばれた理由。
  - Logi Options+（ロジクール）: コピペ対応で評価。
  - KVM切り替え機、synergy → barrier: 安定性や遅延のトレードオフで選択。
  - 全体の理由: 2台PC使用時の1セット入力デバイス共有ニーズ。
- **セキュリティ・隔離ツール**（AIエージェント使用時）:
  - Hyper-Vサンドボックス / 仮想Windows、Docker: エージェントにPC全体を見せないための隔離。必要なフォルダのみ共有。
  - 物理的隔離（外付けHDD + ケーブル抜き）: 最も手軽で確実。
  - 理由: outputフォルダや機密ファイルへのアクセスリスク回避。
- **その他**: OneDriveなどのクラウド同期は意図しないアップロードの危険性で注意喚起。MusubitunerはLoRAトレーニング関連の言及あり。

### 選定傾向のまとめ
- **ComfyUI優勢分野**: 動画生成・高度なワークフロー制御が必要な場合（柔軟性が決め手）。
- **webUI/EasyReforge + Forge Neo優勢分野**: 静止画生成・日常の高速作業（作業効率と最新対応）。
- **カスタムUI/共有・隔離ツール**: 操作性向上とセキュリティ対策として、AIエージェント活用の文脈で需要が高い。
- 全体として、インストールのしやすさ、最新対応速度、操作の直感性、セキュリティが選定の主な軸となっている。

以下、生成AIに関連する**ツールの話題**を抽出しました。指定リストにある画像生成モデルそのものの性能・比較・学習内容などは除外し、ツールの使い方や運用、ワークフローに触れている部分を中心にしています。

### コーディング支援・エージェント

- **228｜Codex**
  - MMDでモデルを踊らせる作業を、使い方が分からないままCodexに任せて完成させた。
  - 少し直すだけでもトークンを消費するため、いずれは自分でも勉強したいとのこと。

- **245｜Claude Code**
  - LoRA作成を手伝わせたところ、画像を見られたうえで未成年と判定され、作業を拒否された。
  - 実写系の画像作業をAIに任せることへの懸念が語られている。

- **250｜ComfyUI／AIアシスタント**
  - 性的な画像ではないのに、ComfyUIを理解していることを理由に支援を断られた、という話題。

- **255｜ローカルエージェント環境**
  - エロ関連でエージェントを使うなら、ローカルで動かしたほうが独立性の高い環境を作れるという意見。
  - ローカル環境を選ぶ理由として、外部サービスに頼らず作業できることが挙げられている。Qwenシリーズについても、画像生成ではなくローカル環境で使う話題として該当。

- **270｜Codexの権限**
  - Codexは書き込みがサンドボックス内に制限される一方、読み取りはPC内の広い範囲に及ぶと説明。
  - VSCode上での利用とComputer Useでの利用では、後者のほうがリスクが高いという指摘。

- **286｜エージェントの予測しにくさ**
  - エージェントが次に何をするか分からないことへの不安。開発元のシステムが予想外の動きをした例にも触れている。

- **287｜エージェント専用PC**
  - エージェント用の「スーパークリーンPC」としてPCを活用している。ストレージを多く積んでおけばよかったとのこと。

- **292｜Codex**
  - Codexに作業を任せているが、自分で少し勉強すれば簡単にできる作業だったと後から分かるかもしれない、という振り返り。
  - トークンと時間のコストを気にしている。

- **293｜Codex**
  - Codexにコードをいじらせた結果、特定の操作で壊れるようになったという話題。

- **299｜エージェント利用とコスト**
  - 小さな作業もエージェントに頼るほど便利だが、そのトークン代を払い続ける必要があり、依存性があるという話。

- **302｜AIによる環境再構築**
  - カスタマイズやアップデートが重なった環境の不具合対応にトークンを使うより、まっさらな環境を作り、以前の環境を再構築できるようにするほうがよいという提案。

### LLMによるプロンプト作成・相談

- **232｜LLMを使った動画プロンプト作成**
  - 下書きをLLMに渡し、動画生成用に内容を補ってもらったところ、想定とは異なる展開になったという話題。
  - アイデアやリアクションをLLMに考えさせる使い方が語られている。

- **313｜LLMと動画プロンプトを詰める**
  - エロい展開の動画プロンプトをLLMに作らせるが、演出を細かく直したくなり、LLMとやり取りが長くなるという話。

- **364｜ChatGPTでの機能追加**
  - 公開されているソースコードを使い、ChatGPTに機能を追加させてよいという案内。

- **376｜ChatGPT画像とi2iの利用**
  - ChatGPTで顔の参照画像を作り、スケーラー経由のi2iで細部を修正する使い方が紹介されている。

- **377｜ローカルエージェントによる画像生成支援**
  - ローカルの汎用エージェントに相談しながら画像生成を進めている。
  - 要望を分類させて提案を受けることで、自分が詳しくない方向の案も作りやすくなったという理由が挙げられている。

- **407｜ChatGPTでのトラブル相談**
  - PCのクラッシュについて、イベントビューアーを見せながら有料版ChatGPTに相談する案が出ている。

- **415｜Grok**
  - Grokに、架空のなんJスレを書かせる使い方が面白いという話題。

### ComfyUI・ノード・ワークフロー

- **243｜ワークフローの複雑さ**
  - 画像参照を使う処理は便利だが、ワークフローが複雑で扱いにくいという話題。

- **249｜学習ワークフロー**
  - 学習を始めるなら、JSONL方式が作業内容を理解しやすく、最初の方法として勧められている。

- **370〜372｜Extenderの参照画像運用**
  - Clipごとに参照画像を切り替えられるため、動画全体では多数の参照画像を使えるという使い方が共有されている。
  - 参照ファイルは事前に読み込んだものから選ぶ仕様で、Clip内から別ファイルを直接追加するわけではないとの補足もある。

- **379｜Extenderのクリップ出力**
  - クリップを毎回つなげて出すのではなく、各クリップを個別に確認して後から結合できるか、という質問。

- **399・403・409｜ComfyUIのクラッシュ**
  - 長時間の生成中にブラックアウトやブルースクリーンが起きるという相談。
  - ComfyUI側の要因の可能性や、GPU負荷・ドライバー・温度・電源などが原因として挙げられている。

- **408｜KJNode**
  - KJNodeのプロンプト重み付け機能を使い、プロンプトの強調を試しているという話題。

### 画像・素材の管理ツール

- **395｜画像ビューワ／タグ管理**
  - 画像にタグを付けて素材を管理する用途が便利だという評価。
  - 参照画像や素材を分類して整理する使い方が想定され、タグ情報がEXIFに保存されるか、別のタグ付けアプリと連携できるかが質問されている。

**該当するツール名・話題**：Codex、Claude Code、ComfyUI、Extender、KJNode、ChatGPT、Grok、ローカルエージェント、画像ビューワ／タグ管理、各種ワークフロー。

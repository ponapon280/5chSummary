以下、生成AIの利用・制作環境に関する「ツール」の話題を抽出しました。モデルそのものの性能・評価に関する話題は除外し、ツールの使い方や不具合、選ばれている理由を中心にまとめています。

- **refmods（843、850）**  
  長尺動画で参照画像を重ねるとOOMになる問題への回避策として、「refmodsを使う」と紹介されています。

- **ContextLoop／Extender（844、852、859、891、893、896）**  
  動画をつないだり延長したりする方法として話題になっています。ContextLoopで1分超の動画を作る例や、既存動画の延長もできるという説明があります。一方、延長中に動きの再放送が入り、ノイズになることがあるため、生成後に編集してつなぐ方がよいという意見もあります。生成フローにContextLoopを組み込み、良い動画ができたらすぐ延長する案も出ています。

- **動画の生成・編集手順（851、854、856）**  
  1シーンを短めに作り、次のシーンで前の動きを続けるよう指示する方法が紹介されています。Clipごとに生成をやり直すため時間がかかるという声や、「FL」と呼ばれるツールで動画をつなぐと破綻が少なくきれい、という意見もあります（FLの正式名称はログからは特定できません）。

- **Forge Neo（915、921、923、978）**  
  Spectrum Integratedを有効にして生成すると、途中で画像が壊れるという不具合相談があります。原因として設定の併用などが疑われましたが、最終的には補足に使った自然文が問題で、文章を整えたら直ったとの報告があります。

- **ComfyUI（901、903）**  
  最近の更新で、モデルデータ置き場がNVMeかどうかを自動判定するようになり、`--fast-disk`は以前ほど必要でなくなった、という情報があります。環境によっては逆に`--disable-fast-disk`が有効な場合もあるとのことです。

- **ComfyUIのカスタムノード（968）**  
  処理が遅いノードについて、CPU処理をGPU処理に変更したところ大幅に高速化したという報告があります。

- **KJのModel Preview Override（906）**  
  VAEをこの機能でプレビューするには修正が必要だったものの、対話型AIと相談して修正し、表示できるようにしたとのことです。

- **画像Viewer／書庫ソフト（871、916、917、957、961、965）**  
  SVGのサムネイルが表示されない問題があり、原因を修正したビルドで手持ちのSVGが表示できるようになったとの報告があります。要望として、AI画像と誤解されないよう「Illustrator（.ai）画像」と表記すること、Viewerを閉じるショートカットやファイルのフルパスをコピーする機能が挙がっています。対応として、ViewerはCtrl+QまたはCtrl+Wで閉じられ、Shift+Cでフルパスをコピーできるとの説明がありました。

- **Codex（868、904、908、936、943–945、948、954、956、958、962）**  
  - アップデート後、コマンド実行のたびにターミナルが一瞬表示される不具合があり、ダウングレードしても直らなかったという報告があります。  
  - 画像生成用プロンプトの作成支援にも利用されています（下記のKrea2関連参照）。  
  - 毎回の許可確認を減らす方法として、起動オプションや設定ファイル、sandboxの権限を確認する案が出ています。Windowsでは`.codex`や作業フォルダの権限を直したら、自動承認ポリシーによるブロックが解消したという報告があります。  
  - 利用時に電話番号を求められたという投稿もあります。

- **Krea2／Codex／Grokのプロンプト作成連携（862、879、887、905、908、911–913）**  
  Codexにプロンプト案を作らせたり、GrokにKrea2向けの助言や参照画像を踏まえたプロンプトを整えさせたりする使い方が紹介されています。プロンプトで塗りや体型を調整し、好みの画風を探せるという意見もあります。キャラクターを指定した生成や、wildcardでの展開が難しいこと、キャラクターLoRAを作るのが手軽ではないことも課題として挙がっています。

- **Nano Banana（966）**  
  画像がChatGPT Imageで作られたのかという質問に対し、「ナノバナナ」と回答しています。

- **Grok Imagine（975）**  
  画像・動画生成機能が少しアップグレードされているようだ、という話題があります。

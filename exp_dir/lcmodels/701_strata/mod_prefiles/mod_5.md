# 対象モデルに関する話題の抽出

## NovelAI (NAI)

**844**: 「6.1あんまり残量減らなくてええな」
→ NAI 6.1モデルについて、トークン残量（使用量）があまり減らないことを好意的に報告。

**878**: 「ローカルじゃそのLoRA使わないと出ないけど、NAIちゃんなら余裕で出まっせというオチだったりして」
→ ローカル環境ではLoRAが必要になるキャラクターが、NAIではLoRAなしで生成可能であるという比較。NAIが選ばれている理由として「LoRA不要で既存キャラが出る」点が挙げられている。

**896**: 「6.1sol来てたけど使用量6とあんま変わらんのな」
→ NAI 6.1 Solモデルが提供開始されたことを報告。使用量（トークン消費）がバージョン6とあまり変わらないことを指摘。

**967**: 「6.1sol混みすぎや」
→ NAI 6.1 Solが混雑（アクセス過多）しているという報告。

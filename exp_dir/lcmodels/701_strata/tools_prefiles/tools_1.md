## 1. ComfyUI（comfyui-dynamicprompts / comfyui-promptcraft / was-node-suite）

**ワイルドカードの固定化バグ（>>30）**
comfyui-dynamicprompts の Random Prompts ノードで `${color=!{red|blue}}` と宣言すると、初回実行で blue が選ばれた場合、シードを変えて autorefresh=Yes にしても以降 blue 固定になる。チャピ（ChatGPT）でも解決せず、回避策を募集。

**代替ノードの提案（>>70, >>81）**
- >>70: comfyui-promptcraft を提案。dynamicprompts はバグが多いので「諦めてほかを探す方が健康にええ」との判断。
- >>81: was-node-suite の Text Random Line が「簡単でええで」と推奨。

**採用判断（>>116）**
>>30 の投稿者が「comfyui-dynamicprompts 捨てて was-node-suite 勉強する方向で頑張ってみる」と決定。

**バージョン更新による性能劣化（>>208, >>212）**
ComfyUI を 0.35→0.37 に上げたら minimax の ref が 100秒くらい遅くなった。>>212 は「何かしらの高速化ノードが足を引っ張ってそう」と推測。

**マルチGPU対応（>>73, >>78）**
動画・画像生成では 5090 1枚より 5080 3枚の方が ComfyUI で速い。マルチGPU対応が進んでいる旨の言及あり（>>78 に状況リンク）。

## 3. DLSS5 / MFG / FSR（アップスケール・フレーム生成技術）

**DLSS5 の技術特性（>>34, >>60）**
「1step Pixel Space Diffusion」という技術。数msで生成しなければならない超技術。5090が600W超えると…（>>34）。

**電力・温度問題（>>40, >>46）**
- >>40: ケーブル600W + PCIe 75W で給電限界は超えないと主張。
- >>46: DLSS5が重すぎてコネクタを通る電力が600W、コネクタ温度が90℃超（5090公称定格575W）。

**RTX 4000番台向けMFG解除（>>61, >>106）**
- >>61: FSR併用ではないRTX4000番代用のMFGが解除された。
- >>106: 「内部MFG解除の奴が数日前に来た」「FSRとかと組み合わせた奴」とは別物。まだ不安定だが普通に遊べる。

**FSRとの区別（>>86）**
「疑似的に再現してるだけだし昔からあったろ」と批判。>>106 が「内部MFG解除」と「FSR併用」は別物と訂正。

## 4. RTXVSR（アップスケール）

**解像度差の実感（>>107）**
「RTXVSRでアプスケすると0.6MPも1MPもあんまり違いわからんぞ…生成時間3倍くらい変わるのに」。

**使い分け（>>118）**
0.6で出した時に潰れてる部分が無ければRTXのアプスケで事足りる。潰れてる部分がある時は元解像度上げるしかない。

## 7. irodori-TTS（音声合成ツール）

**Large版公開（>>186, >>193, >>205, >>218）**
Largeが公開された旨の報告。>>205「個人で作ってるとは思えないクオリティ」。

**ComfyUI対応状況（>>189）**
「V3までしかcomfyuiで使えないから意味無いんだよな。なんで対応させんのだ」。>>190「お前がプルリク書けばええんやで」。

**Small vs Large 比較（>>191）**
AIに比較させた結果：読み上げ精度はちょい下がってる、メモリー使用量増える、レスポンスも落ちそう。参照音声が良くなっているだけ。

**VRAM消費（>>216, >>232）**
- >>216: 「ラージのほうはvram8gbじゃきつそう」。>>224「量子化モデルなら8Gでも使える」。
- >>232: デフォの model Precision が fp32 だと VRAM 15.6/16GB。長文読ませるとエラー出そうなので bf16 にしたら VRAM 14/16GB に落ちた。聞き比べたけど違いわからんかった。

**アニメ声への限界（>>199）**
「irodoriでどう頑張ってもアニメ声にしかならないのはもうどうしようもないんやろか」。>>200「LoRAなりいくらでも方法はあると思うが…」と反論あり。

## ComfyUI
- **703**: いまの ComfyUI は input フォルダの画像を、読み込みノードでプレビュー表示しなくなった、という不具合・仕様変更の確認。
- **803**: キャプション用にカスタムノード `comfyui-llm-prompt-studio` を使用。VRAM 16GB で i2t 比較したところ、総パラメータより量子化精度が効き、26B の Q3（オフロード発生）より 12B の Q8 の方が認識・文章・速度・静音性で良かった、という選定理由。
- **698**: 生成ログを AI に読ませてボトルネックを判定するカスタムノードを自作。理由は高速化・ベンチ計測のため。20秒動画が 300秒超から 220秒に短縮。
- **808**: 速度報告の中で、モデルと TE のみ int8、turbo なし、CKA＋MSA(SA) あり、20 step、という実行設定に触れている（モデル性能そのものの話は対象外）。

## Workflow / ノード（ComfyUI 系）
- **700, 716, 725**: LoRA 配布だけでは満足して使ってもらえない、という課題に対し WF セットを作成。中身は WF、ref2va 用サンプル（モザイク入り）、短い解説。配布は過去書き込みの MEGA 内 ZIP。NEGPIP はエラーが出る可能性があり、外すかプロンプトだけコピーする運用。  
  - v1＝初期テスト、v2＝改良、v3＝過学習とプロンプト不足への対応。サンプルは v3。ただし LoRA と参照画像の相性が大きく、v1 の方が良い場合もある、とのこと。
- **667, 669, 671, 672, 678, 695**: **Ref2VA** の使い方。  
  - キャラ参照は一枚絵複数より三面図1枚が良いか、という質問。参照だけだと 3D 化しやすいので、開始フレームで構図を固定している。  
  - 音声参照だと不明言語・音飛び・潰れが出る。対策として、英語プロンプト中のセリフは日本語で書き、「音声に従え」だけでなく台詞本文もプロンプトに書く。d タグでセリフ内容を補う、subject / retention で音色参照だと明示する、という書き方が挙がっている。  
  - 15秒で無音区間に謎言語が出る問題に対し、**Irodori TTS** で作った音声を使う方がガチャより早いか、という提案（**678**）。

## WebUI 系（SD.Next）
- **791, 796**: SD(neo) で複数生成し、良い seed を固定して Hires 再生成する流れが正しいか、という質問。既存画像を Hires 相当に上げるなら img2img の MultiDiffusion か SD Upscale。txt2img の Hires.fix とは完全には同じにならない、という回答。

## その他の生成AIツール
- **714**: **SillyTavern** でチャットしながら状況画像を随時生成する用途。小さいモデルをメインではなく、チャット側に組み込む使い方として挙がっている。
- **717**: 外出先からスマホで自宅 PC の生成を遠隔操作。選んでいるというより制約の話で、プロンプト編集が難しく生成ボタン程度しか使えず、PC 起動が前提なので使用機会は少ない。
- **644, 658**: **Grok** にプロンプトを作らせると効果音を勝手に入れる。入れないよう指示すれば足りる。Grok Imagine は規制が強く、効果音品質の比較対象として出ているだけ。
- **668**: あらすじから H3 用プロンプトへ一発変換するとセリフが崩れるため、Gemma 4 26B で「あらすじ→シナリオ→プロンプト」の二段にしている。ネタバレを避け、コピペを減らしたいのが理由。
- **782, 785, 786, 819**: **LM Studio（Bionic）**。Codex 風に使え、MCP やスキルも使える。クラウド最上位ほどではないが、電力とメモリが許す限り何回でも試せるので、用途によってはローカルが有利、という理由。軽い作業ならクラウド（Astra）が不要かもしれない、という評価。

## Qwen（画像生成以外）
Qwen-Image / Edit / i2i の話（677, 679, 687, 692 など）は除外しています。
- **785**: LM Studio 上の 20B 前後の Qwen が実用域。無制限に試行できるのが利点。
- **786**: Qwen3.8 は、少し前の ChatGPT や Gemini を超えている印象。MCP とスキルでローカル LLM として使える。
- **815–817**: コーディングだとコンテキストがすぐ満杯になる。仕様上のフルコンテキストが載るまでメモリを積む、という回避。
- **816, 819**: Qwen3.8 27B は 5070 Ti では遅すぎ、VRAM 32GB が実質必須。3080 12GB を足して 2GPU・合計 28GB にして動かしている。性能は高く、軽い作業ならクラウド不要かもしれない、が選定理由。
- **818**: Qwen4 以降に ngram 系が増え、12GB 向けの KV キャッシュが軽い MoE＋ngram が出てほしい、という要望。
- **820–825**: RAM があるなら Qwen3.8 Flash Next が良い。64GB なら Q2/Q3、96GB なら 5090 の NVFP4 で足り、それ以外は Q2/Q3、という実行条件。

## ComfyUI 系

- **最近のComfy更新で、モデル置き場がNVMeかを自動判定するようになった。** そのため `--fast-disk` は古い呪文扱い。以前は空きメインメモリがゼロになるまでモデルを読む仕様で、アンロード時にSATA HDD勢が困る、という動機ごとアホだった、という評価。
- **逆に環境によっては `--disable-fast-disk` が効く、という話。**
- **メインメモリ節約の起動オプション**として `--fast-disk`、場合により `--disable-pinned-memory` が挙がっている。理由はRAMが少ない（32GB級）ので、モデルをメインメモリに載せきらないため。足りなくてもすぐSSDが死ぬわけではない、サイズや長さを縮めれば入る、という補足あり。
- **KJの Model Preview Override** で tinyVAE のプレビューを見るには修正が要る。チャッピーと壁打ちして見えるようにした、という報告。
- **遅いカスタムノードをチャッピーに直しさせ、CPU処理からGPU処理へ変えて爆速化した**、という報告。ノード名はなし。

## 長尺・参照まわりのノード／ワークフロー

- **refmods**  
  参照を最大4枚重ねるとOOMする、という相談への回答。選ばれている理由は、参照を積んだときのメモリ不足回避。
- **Context Loop / Contexloop / ContexLoop**  
  - 2本の動画をつなぐ用途で使われている。  
  - Extenderと併せて1分超も作れるが、労力の割に使える映像にならない、という評価。  
  - 1分超にすると20秒付近で「再放送」が入り、新しい場面のあとまた少し再放送される。全体は成立していてもその部分がノイズになるので、使わず個別生成して編集でつないだ方がよい、という結論。  
  - それでも現状の延長手段としてはこれが本命、という意見。既に作った動画も延長できる点が理由。  
  - ガチャで良いのが出たら即延長できるよう、ContexLoopのワークフローをベース生成フローにする案。
- **Extender**  
  Context Loopと並べて、1分超を作る手段として言及。労力対効果は薄い、という文脈。
- **FL（動画接続の呼び方）**  
  これで1分程度までつないでいる。選ばれている理由は、その人の環境では結局これが一番破綻が少なく綺麗、という一点。直後の画像側の話はモデル寄りなので除外。

## Codex

話題がかなり多い。選ばれている理由と不満がセットで出ている。

- **漫画プロンプトを適当に出させる**用途。その出力を別サービスでガチャしている。
- **プロンプト作成は上手いがエロにうるさい。** そのため、Codexにはプロンプトの要点やアドバイス一覧を出させ、それをGrokへ貼って改編させる、という分業。Grok側が選ばれる理由は、過去作や参照画像を踏まえてプロンプトを整えられるから。
- **素材収集からLoRA作成まで任せられる**、という話。エロシーンを入れなければノンストップで完結する、が条件。PlusだとAstraはノンストップでもトークンが止まる、という制限。
- **アップデート後、コマンド実行のたびにターミナルが一瞬出て消える。** issueどおりダウングレードしても直らない。
- **30日の大きい更新でリセットされる**、という理解。Xでリセットに文句を言っている人を中国語翻訳で笑う、という雑談。
- **新規利用時に電話番号を要求された。** もっと前から使っておけばよかった、という後悔。
- **許可確認がうるさい。** 全フォルダアクセス可にしてPowerShell側も書き換えているのに聞いてくる。対処として挙がったもの:
  - `codex --ask-for-approval on-request --sandbox workspace-write` で起動する
  - Codex自身に「許可を伺わなくする方法」を丁寧に教えさせる
  - 設定ファイルを自分で書き換えられる。自分で自分を壊すこともできる、という注意
  - 左のプロジェクトでドライブやフォルダを指定すれば無許可で進む、という説明。2TB SSDを丸ごと渡している例
- **sandboxが起動しない不具合。** フォルダの書き込み権限がCodex側になっており、自分に戻せば直る。`.codex` と作業フォルダの `CodexSandboxUser` をフルコントロールにしたら、自動承認ポリシーのブロックが消えた、という実例。調べる場所はワークスペース単位が多く、Codexに調べさせるのがよい、という助言。
- スレ後半で「Codexの話はもうええ」と打ち切り。

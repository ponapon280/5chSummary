## 画像管理ツール（生成UIではない）

生成そのものではなく、画像の閲覧・タグ管理です。

- **NivisViewer（>>433, >>592, >>594, >>609, >>615, >>633）**  
  **選ばれている理由:**  
  - タグをファイル内ではなく**ファイル名**に置くので、ファイル追跡やメタデータ読み込みが不要。  
  - 愛用していた **Zippla** のレート・タグをそのまま移行できる。  
  - ファイル名が変わる欠点はあるが、Everything検索ができるのでむしろ便利（>>594）。  
  タグとして認識させるには、ファイル名とは別にアプリ側のタグ登録（または config 編集）が必要。  
  要望は PSD / CLIP / SAI 対応、サムネダブルクリックで画像表示、右クリックで規定アプリ起動。周囲の評価は「早くて便利」。

通過言及のみ: **>>462** で EasyReforge 使用とあるが、話題の中心はモデル出力なので中身は除外しました。

## 全体像
ローカル画像／動画生成勢の雑談スレ。話題は (1) ビューアとタグ管理、(2) GPU・VRAM 運用、(3) モデル別の実用感、(4) 成人向けプラットフォームへの決済圧力、(5) クラウドとローカルの使い分け、に分かれる。投稿は断片的で、同一テーマが何度も分岐している。

## 1. タグ管理・ビューア（NivisViewer）
- 評価やタグはファイル本体ではなく**ファイル名に埋め込む**方式。読み込みやメタデータ追跡が不要で、旧ソフト（Zippla）からの移行がしやすい、という説明。
- デメリットはファイル名が変わること。ファイル名の文字数上限も懸念として出ている。
- 同じ書式でも、アプリ側で「タグとして登録」していない名前は認識されない。タグ管理か config の編集が必要。
- 移行希望として、Pinterest ノートの自動DL、PSD／Clip Studio／SAI など制作ファイルを画像として開けること、「規定のアプリで開く」が挙がっている。対応は「制作ファイルを画像として開ければ十分」という確認で一旦まとまっている。

## 2. ハードウェア・VRAM
- サブモニタや生成専用モニタはマザーボード（iGPU）出力にすると、VRAM がおおよそ 0.8–1GB 程度浮く、という実測談義。ゲームや 3D のときだけディスクリート GPU に切り替える運用。
- 反対意見は「16GB 環境では 800MB 空けても状況が変わらない」「切り替えが面倒」。
- AMD はヘッドレスを想定していない、という話。ダミープラグで回避できるが VRAM を食う、という指摘。
- 5090 の PL100% 常用は、計測に出にくい 16ピン側の温度・電力が問題になり得る、という慎重論。5080 の低温運用や、5070 Ti デュアル＋マルチ GPU の方が安全で速いのでは、という比較も出ている。
- AM4→AM5 の買い替えより GPU 優先、という空気。iGPU 併用は AM5 持ち向け、という整理。

## 3. モデル・ワークフロー
- **Anima / Illustrious 系**: プロンプトより解像度・アスペクト比で絵が決まりやすい、という指摘。タグを減らして横長にすると出始めた、という報告。版権の追加学習が進んだ派生を探す声に対しては「自分で調整しろ」が優勢。
- **chibi**: `chibi,solo` より `chibi girl` の方が安定した、という単発Tips。
- **Qwen Image 系（QI2.1 / Noct Q / krea2）**: 軽量 LoRA（数十MB級）は評価。まとめ記事は「VRAMに全部載せろ」が古く、有料note級のスロープ、という批判。Noct Q はプロンプト追従が良いが、サンプルが欧米・アジア寄りで日本人の出やすさは未確認、というやり取り。
- **MiniMax-H3**: 5090 と PRO6000 の速度差は、実用設定では小さい（おおよそ5分前後）という検証投稿。1.2MP では 5090 が OOM しやすい。学習・大容量オフロードまでやるなら 32GB でも足りず PRO6000 欲しい、という反対意見。ref2va の LoRA 学習報告では、強度は意図通りだが参照画像との相性は改善せず、参照画像側でカバーする方がよい、という結論。
- **参照の使い方**: 1枚絵よりキャラクターシート参照の方が品質が安定する、帽子など形状が崩れやすい、という同意が多い。
- **動画保存**: Comfy の video save が遅いので NVENC 版に置き換え、40秒→6秒になった、という報告。
- **クラウド加工**: Gemini / ChatGPT / Grok の枚数・品質比較。高画質化のローカル一括希望に Topaz Photo AI（Adobe 買収後で買い切り不明）が挙がる。Affinity は Canva 傘下、という補足。

## 4. 決済・規制まわり
スレ内で一番感情が強い話題。事実関係は投稿者間でも割れている。

- pixiv FANBOX などがカード会社／決済代行の圧力で成人向け表現を絞られている、という不満が中心。
- 「Visa / Mastercard 本体はポルノ全面NGを出していない。先に動いたのは決済代行」という記事紹介と、「結局どこかに思想の強い人がいる」という見方が併存。
- JCB を国内エロの逃げ先にする案と、「外国人の逃げ先になった瞬間に規制される」という反論。
- 仮想通貨決済は、複数サービスを跨がないと完了せず、普及させる気が見えない、という体験談。
- 規制の中身としては、非同意・暴力・排泄などが海外基準で外れやすい、日本ではそれらがメインストリーム寄りだったため反発が大きい、という整理が出ている。
- Civitai では無修正が多数派なのに、日本側は bar censor を入れざるを得ない、という不満。
- 年齢表現・海外基準をめぐる罵倒合戦もあるが、根拠の提示はほぼなく、感情論の応酬に終わっている。レポート上は「年齢描写の線引きで対立した」とだけ扱う。

## 5. クラウド vs ローカル
- 一般利用者の「AI」はクラウドサービスを指し、ローカル組は少数派、という自己認識。
- NSFW は今後もクラウドが厳しく、実用の逃げ場はローカル、という見方が優勢。
- 音声は Gemini TTS の品質評価が高い一方、エロ用途は規約上のチキンレース。健全な生成物を外部ツールの参照に使うのは可、学習利用は不可、という確認投稿がある。
- コスト比較は「電気代 vs サブスク」だけならローカルが安いが、パーツ高騰とリセールを入れると単純ではない、で終わっている。
- 「計算資源だけ貸すクラウド＋自前NSFWモデル」という建前案には、アップロードした側が責任を問われそう、という冷やかし。

## 6. その他
- AI で本格的なオリジナルゲームは、見た目の模倣はできても「面白さ」は学習されていない、という懐疑が優勢。
- ChatGPT / Codex / Gemini の障害と、利用枠リセット予告への反応。
- 素材収集（古本・裁断・スキャン）が PC 並みに高くつく、というボヤキ。AI 生成素材は「マスピ感」とマイナー作品の欠落が問題、という反論。

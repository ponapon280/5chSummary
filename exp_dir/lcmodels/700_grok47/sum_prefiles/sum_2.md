## 概要

この区間は、画像・動画生成モデルの実用比較が中心です。話題の軸は Anima、Qwen Image 2.1、Krea2、NAI、Minimax（Ref2VA）、Wan 2.2 で、そこに LoRA 学習、プロンプト追随、ハードウェア不調、利用コストの話が重なっています。エロ用途の話は多いですが、評価軸自体は「指示が通るか」「画質が落ちないか」「既存ワークフローを壊さずに乗れるか」に寄っています。

## モデル評価

**動画・参照**
- Ref2VA は参照が強すぎて内容が読めてしまう、という不満があり、T2VA 側に「AI側の展開」を期待する声がある。
- Minimax LoRA は人物・背景・動きすべてに効く一方、参照画像との相性が悪ると動きが重くなり、汎用性よりピンポイント対策向き、という整理が出ている。学習の入り口としては 1f の jsonl 方式が簡単、という意見。
- 参照画像と学習画像の差が大きいと、LoRA が逆に暴れる、という指摘がある。
- Wan 2.2 はプロンプト自由度と追随で Anima より上、という比較がある。動画モデルでは MATLOWAI（動き・指示忠実、アニメは弱い、生成は遅め）と Dasiwa（一貫性は強いが指示は弱め）が名前として挙がっている。
- Extender ではクリップごとに参照を切り替えて、全体では参照枚数を増やせる、という使い方が共有されている。

**Qwen / Krea**
- Qwen Image 2.1 は画質と編集の安定性（ロゴ除去などのバッチで破綻が減った）が評価される。一方、やりたい構図への効きは 2511 の方がよかった、という不満もある。
- Multiangle 系は、専用 LoRA なしの方角指示だけでも回せる、という報告がある。
- Krea2 は背景力と実写寄りの強さが評価されるが、複雑な自然文は一語修正で他部分まで崩れる、ガチャで当てにくい、胸サイズなどはプロンプトよりスライダーが確実、という実用談義。検閲回避を入れると質感がプラスチック化する、という指摘が目立つ。
- エロ用途に限れば Danbooru 系タグの方が半脱ぎ等のキャプション漏れが少なく、自然文 LLM キャプションは手動修正が重い、という対比がある。

**Anima**
- 不満が少ないので話題に上らなくなった、という自己分析が繰り返し出る。普段使いは base と気に入った画風 FT で足りている、という空気。
- 2.9B / 3.8B は公式版ではなく、LoRA 互換がない。階層も対応層も違う、という説明が複数ある。
- 2.9B はプレビューで、正式版やデータ更新への期待と、「すでに完成しているので主流交代はほぼない」という否定が併存している。
- 非公式ナンバリングは混乱のもとで、公式が後続版を出しにくい、というブランド上の懸念もある。
- 大規模 FT（AnimaYume、Kirazuri、Light Lavender 等）は試しても差が分かりにくい、という感想。

**NAI**
- 画柄が安定せず Anima に戻った、という声と、日本語とタグの混在・位置指定・インペが便利という評価が並ぶ。枚数制限がボトルネック。
- 小物描写の弱さ、胸サイズ指定の飛び、断面図がプロンプト通りにならない、といった具体不満がある。

## LoRA・学習

共有されている失敗例は、dim/alpha、学習率、枚数、ステップを振っても教師画像の細部（糸の編み方など）が再現されない、というもの。キャプションにアーティストタグを入れると次元を余分に食うのでは、という仮説が出ているが、結論は出ていない。

別系統では、半脱ぎのように自然文キャプションが飛ばしやすい概念は、タグger の方が扱いやすい、という実務寄りの意見がある。

## 環境・運用

- 長時間生成でのブラックアウトは、VRAM、ドライバ、熱、電源、ファン固定のミスが候補として挙がっている。電源交換、電力制限、ファン交換で収まった例と、放置後に突然落ちる例が混在。
- 量子化では W6A8 が、サイズと誤差と速度の折衷として話題になっている。INT4 と FP4 の対応差（50 系とそれ以前）を混同しないよう訂正も入っている。
- Codex / agent 依存は、知識がなくても完成物は出るが、微修正のたびにトークンを溶かし、権限範囲（特に Computer Use）のリスクがある、という両面評価。
- 環境が壊れたら都度直すより、まっさらな環境を再構築できる引き継ぎを用意した方がトークン効率がいい、という運用論。
- コスト感では、有料プランの値上げ噂と、「できる」が「金を払えばできる」に縮んだ、という倦怠が出ている。

## スレの空気

技術的には「公式が完成させている Anima」と「編集・動画・実写で伸びている Qwen / Krea / Minimax」の分業が定着しつつある、という読みが一番近いです。盛り上がりは新モデルの話題へ移動していて、Anima 勢は互換性と非公式版の混乱に苛立っている。エロ用途に寄せるほど、タグ文化と自然文文化のどちらを取るかでワークフローが割れています。

規制・年齢判定・クラウド通報の話も出ていますが、その部分は事実関係の整理としてもここには含めません。

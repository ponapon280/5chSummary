# なんJ 画像生成スレ レポート

## 1. Qwen-Image-2.1（QI2.1）関連

### 性能・速度
- 貧弱PC（4070、VRAM12GB、メモリ16GB）でもデフォルト設定で70秒で完了したとの報告（>>12）
- 5070Tiの16GVRAMで、拡散モデルとTEをbf16に上げて画像編集2MPで21秒。2511のbf16(40GB)の頃は1分以上かかっていた記憶と比較（>>72）
- int8昆布で7GB台なので12GB勢でも余裕（>>74）
- 「サイズを下げて性能を上げる、痩せて密度を上げる、そんな夢物語が今年良く起きてる」（スレ上の感想、>>99）

### 用途別評価
- t2iは衣装が強くkrea2と使い分け、加工系はH3より性能良い。透過画像作成能力が高く、キャラと背景を別モデルで作る自動化がしやすくなる（>>74）
- キャラシート作成をEditで実施、Krea2より使い易い（>>155）
- 日本語による編集能力はFlux2kleinの方が高い（>>117）
- t2iの評価は「物体がグチャったり前面に別の物体が横切ると一貫性が崩れる」への反論として、デフォWFのstep25は少なく40～50まで叩いた方が良い（>>87）、cfg 4を試すと品質向上・ネガティブ使える（>>88）
- Minimax Image Studioで失敗した服装・髪型スワップが成功。ポーズスワップはどちらも難。厳密な参照当てはめはMinimax、Qwenは「似たような感じ」（>>14、>>15、>>26）
- キャラ・衣装変更の容易さに驚いた声（>>217）

### 不具合・ワークフロー
- Comfyデフォルトのワークフローでシード固定になっており手動変更が必要。解決法：テンプレ→サブグラフ展開→Kサンプラーのシードを「randomize」に変更（>>21、>>22）
- AVIF保存はエラー：`ValueError: AVIF saving supports 1-channel grayscale and 3-channel RGB images PyAV's SVT-AV1 encoder does not support alpha.`（>>32）

### ライセンス
- 生成物もチューンモデルもLoRAも金のやり取りがダメ（個別ライセンス取得必要）。趣味の無償公開は問題なし。二次エロ大型FTは金集めが必要で来ないだろう（スレ上の見解、>>81）
- 公式声明が出た：「出力はライセンス対象のマテリアルには含まれません。ユーザーはモデルを使用して生成した画像やその他のコンテンツの権利を保持します」（>>182）。これで編集データセット公開は確定し、レギュラー布陣に加えられる（>>184、>>187）
- 一般的OSSライセンスで、サービスのタダ乗り禁止が文言の趣旨という解釈（スレ上の見解、>>206）
- LoRA作成は可能らしいが、ライセンス的に配布が無理そうとの見解（>>79、>>81）。AI ToolkitがQwen21のLoRAに対応済み（>>196）。16GVRAMでもLoRA作れるかもは今後大きい（>>211）

## 2. MiniMax（H3 / Image Studio）

- ComfyUI更新でimage studioがぶっ壊れた（>>71）、MiniMax H3 Reference to Videoのノード入力追加がバグり散らかし（>>42）
- 服装・髪型スワップはImage Studioが優位、厳密な参照当てはめもMinimaxが強い（>>14、>>26）
- 視点移動系は2511が強いかもしれない（スレ上の見解、>>63）
- 二次はr2vだと似た絵柄に変換され、wanやseedance製と差をつけられている（>>118）
- 主観視点のクンニ等は学習データ自体なく、悪夢のような生成物しかできない（>>43）
- 引きアングルで解像度が下がると顔は溶ける。PCはRAM36の5060ti、15sec 0.6MPx2(RTX Video Super Resolution)（>>197）
- ref2va_1f LoRA学習：学習画像400×400で9組18枚、blocks_to_swap：35で4090でギリギリ、max_train_epoch16で10分（>>108、>>109）。焼き上がり報告では効果は出るが変化量は小さく、動きは固くなり質感改善（>>208）
- musubi-tuner学習で1024画像はメモリ溢れ、4090でも512×512が無理という指摘（>>178）

## 3. その他モデル
- krea2もz-imageも拘束・緊縛系の縄が破綻（>>19）。Qwen21で前スレ926のシステムプロンプト＋Qwen3.8 27B(heretic-ara-Q5K_L)作成プロンプトで試験的に出力（>>98）
- Ideogram 4.0に回帰中の書き手あり（>>98）
- Minimax SingularityはXで評価高いがスレでは話題にならず、触るとイマイチ（>>90）。Seedanceの生成データで学習してそうという感想（>>91）。アニメ画風が繊細、バニラやFastH3はコミカル（>>96）
- NAI5の日本語プロンプト反映が正確（>>190）
- z-imageのオフィシャルアニメモデルは学習ツール配布のみで終わった（>>199）

## 4. 環境・ツール
- ComfyUIアプデでタブ移動時にFast Muter等がおかしくなり、フロントエンドを1.52.7に下げて復旧（>>149、>>163）。Github版はv0.37.0（>>212）
- 過去ワークフローの使えないノード置き換えに、エージェントやチャットへの放り込みが有効という助言（>>156～>>158）
- ForgeNeoが良いという話も再浮上、何使ってるか質問（>>220）
- Qwen2.1でi2tのTextGenerateノードでセリフ自動生成。8bだと性能足らず、Qwen3.8 27B連携が望ましい（>>204）
- Jev（スレ語そのまま）をMiniMax H3に組み込み、RTX4070で6分7秒→3分34秒で41.7%短縮というX投稿の紹介（>>221）
- RefModは圧縮したlatentに近く、`<video N>`で参照指定（>>210、>>229、>>238）

# レポート：なんJ NVA部★701（スレ抜粋ログ）要約

## 1. ハードウェア・メモリ関連

- **64GBメモリ**: 尼（Amazon）で安くなっており、前回1日で値段が戻ったため購入チャンスと指摘（837）。
- **5090でのOOM**: 1MPで20秒動画、参照4枚maxで重ねるとOOM。回避策としてモデルをメモリに逃がすとクソ遅くなるとスレ上の報告あり（842）。対策としてrefmods（843）、Context Loopで2つの動画をつなげる方法（844）が提示された。
- **メインメモリ増設**: グラボそのままでメモリ96まで上げたら長尺生成がいけるという指摘（861）。
- **RAM不足対策**（過去スレ392の引用）: 4090＋RAM128G環境で `--fast-disk`、場合により `--disable-pinned-memory` オプションでメインメモリ使用を抑制できると報告。モデルはbf16よりint8_convrot推奨（898）。
- **--fast-diskの現状**: 最近のComfyアプデでモデル置き場がNVMeか自動判定されるようになり「古の呪文になった」（901）。逆に環境次第では `--disable-fast-disk` が有効になる「目まぐるしい時代の移ろい」（903）。
- **長尺動画の必要スペック**: 長尺は繋ぐだけなので、基本的に1動画（15秒以下）分のスペックで足りるという見解（857）。数十秒生成は5090の128GB前提なのではという推測（855）。

## 2. 動画生成の長尺・接続手法

- **Context Loopの問題**: 1分超生成すると20秒あたりで「再放送」（動きの繰り返し）が発生しノイズになるため、Contextloop使わず生成して編集で繋げる方がいいという報告（859）。
- **1シーン短分割方式**: 1シーン5秒くらいにして「前のカメラ、シーンを続けろ」とプロンプトで指示、15秒をClip毎にガチャ回す運用（851, 854）。
- **FLで繋げて1分**: FLで繋げるのが環境的に一番破綻なく綺麗という報告（856）。
- **ContexLoopは延長のFA**：既に作った動画も延長可能（891, 896）。
- **長尺の需要**: 長尺に需要あることに驚き10秒あれば十分という声（848）に対し、出来が良いと前後シーンを盛りたくなる反論（850）。「抜くだけなら15秒で十分かも」との見解（852）。

## 3. MiniMax H3（mmh3）

- **LoRAの挙動**: loraの影響で3D寄りになったり、0.3ぐらいで2Dアニメになる。乳揺れとのトレードオフ（864）。あり3なし3程度ではプロンプト追従性も落ちると報告（866）。高解像度にすると3D寄りになるのは学習データ（トゥーンレンダのゲーム動画）のせいだろうという見解（867）。
- **ローカルLoRA学習の現状**: 知見が不足、学習素材・方法・epoch・強度が全部手探り。DGX Sparkが欲しくなるが金額が厳しい（875）。Baseが蒸留状態で通常のLoRA学習より難しい、kohya氏も対応に苦労していたらしいという指摘（876）。Google AI ProでA100が使えるらしいという情報（877）。
- **高速化の実測値（ログ表記のまま）**:
  - Attention Backend＋ブロックスパースアテンションで0.9MP 15sが90秒くらい（881）→ 別の者は60秒ちょい（883）→ スペック未記載の比較は無意味という指摘（884, 886）。
  - 4060Ti(16GB)で0.6MP/30steps/12s/24→48fps化が18分。turbo不使用で Comfy-kitchen Attention / Block Sparse Attention / Spectrum / Model Shift(ModelSamplingMiniMaxH3) の4つ使用（888）→ 成果物のクオリティを見せろという反応（892）。
  - kitchen attention＋sol attn tau1.00でステ25メガピ0.9の15秒で13分弱（907）。
  - 高速化と非高速化の差がわからず、Spectrumはダメだったという報告（899）。
  - Sageの方が安定するという意見（894）。
- **動画LoRA**: minimaxH3のLoRAはピンポイントかつ強烈に働き悪影響もデカいという感想（875）。

## 4. モデル・ツール

- **qi tinyVae**: 出たばかり。KJのModel Preview Overrideで見るには修正が必要で、チャッピー（AI）と壁打ちして見えるようにした（906）。
- **Grok Imagine**: いつの間にかアップグレードしており、画像・動画の比較が貼られた（975）。エロあり動画生成AIに戻ってほしいという声（988）。
- **Krea2**: 2次キャラがかけることを今更知った（879, 877）。塗りや体サイズはプロンプトで変えられる（887）。ただし版権キャラを学習してないのが難点（911）。ZimageもQwenimageも軽くマスピ絵を出せる程度で覇権二次モデルは来ておらず、最初から対応のAnimaの利点が圧倒的、ユーザーレベルのファインチューン時代はSDXLで終わったという見解（918）。
- **forge neo不具合**: spectrum integratedをオンにすると生成途中で画像が壊れる（915）→ 原因は部族語補足に使った適当な自然言語で、ちゃんとした文章にしたら解決（978）。Turbo併用が原因ではないかという推測も（923）。
- **svgサムネイル対応（ツール開発・やり取り）**: QRサイト製・Affinity製svgはサムネイルが出るようになったがIllustrator製は出ない（840）→ 開発者がinkscape:属性の未宣言によるXML解析停止と特定し修正（871）→ 再検証後Illustrator製は解消、Inkscape製で未生成の事例報告（916）→ 新ビルドで確認依頼（957）→ 全svgでサムネイル出たと報告（961）。併せて機能要望（EscキーでのViewer閉じ、フルパスコピー、設定項目名変更）が出され（916）、Ctrl+Q/W・Shift+C実装とEscは非推奨の回答（957）。
- **minimaxのセリフ**: turboで一番劣化がキツいのはセリフなので、minimaxでは喋らせずirodoriで作って合成するのが現時点の結論。リップシンクの課題あり（933）。
- **nvidiaドライバ**: pythonが固まる問題はstudio最新からgame ready 596.49にしたら直った（880）。ただしその後また固まる（882）。
- **codex**: アップデートでコマンド実行のたびにターミナルが一瞬出る問題（868）。許可取りが面倒（936）→ sandbox起動不具合でフォルダ書き込み権限がcodexになっているのが原因、権限を戻せば治る（954）→ .codexと作業フォルダのCodexSandboxUserのパーミッションをフルコントロールにして解決（962）。codexの話題はもうええという声（963）。
- **30日のデカい更新でCodexリセット**があるという話（904）。
- **カスタムノード高速化**: チャッピーに頼んでCPU処理からGPU処理へ変更してもらい爆速化（968）。

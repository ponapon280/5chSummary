# 生成AI「ツール」関連話題の抽出レポート

## ComfyUI
- comfyのvideo saveノードが遅すぎるため、Opus5.5に頼んでCPUに処理を戻さないNVENC版save videoノードを作成した結果、保存が40秒→6秒になった（538）。
- ComfyUIのVRAM周りの対応が進んでおり、iGPU併用でVRAMを800MB空けてOOMギリ対策する必要性は薄くなったと判断（500）。モニタ出力をiGPUに切り替えてVRAM800MB位節約し、OOMギリの時に助かっている例もあり（479）。
- MiniMax-H3のT2Vでは、comfy保存ノードのCPUエンコがネックと検証報告。1MP20秒、MATLOWAIのモデル6step SLA0.85で6000が280〜290秒、5090が300〜310秒、どちらもざっくり5分（スレ上の検証結果）（514）。
- QI2.1（Qwen-Image系モデル）のまとめ参照リンクが貼られた（489）※モデル絡み。

## EasyReforge / WebUI系
- イラストリアス（モデル）でEasyReforgeを使用（462）※モデル名が文脈に出るが使用ツールとして。
- リアス（モデル）はプロンプトより解像度（アス比）で出る絵が決まるという指摘（466）※ツール運用の知見として。

## NivisViewer（画像ビューア・タグ管理ツール）
- NivisViewerのタグ付けはレート情報同様、ファイル自体に埋め込まずファイル名に埋め込まれる仕様。ファイル読み込み・メタデータ読み込みが不要な一方、ファイル名が変わるデメリットあり。旧爱用ソフトZipplaのレート・タグをそのまま移行できる利点（重要）があるからこの方式を採用。アプリ側で「これをタグとして扱う」データがあり、タグ管理で登録するかconfigファイル編集すれば外部アプリで編集したタグも読み込める（433）。
- ファイル名タグは自動認識ではなくタグ管理から同じ名前で登録すれば使える。ファイル名変更はEverything検索できてむしろ良い。付けすぎるとファイル名上限超えが怖い（594）。
- pinterestのノートを自動DLする拡張を作って周囲の絵描きから好評。PSD対応の要望が寄せられている（592）。これを受け、Tibo（Codex）のリセット予告のタイミングでPSD対応の実装宣言。Clipも対応予定で、追加要望を募集（596）。PSD対応に感謝、SAIまで対応したら前代未聞のビューワになるという反応（609）。制作ファイルを画像として開ける仕様か、編集ソフトとの関連付け確認（615）。

## Codex / Tibo
- Codexのリセットを求める声（483）。
- 「これをベースにCodexで機能追加してくか」（503）。
- OpenAI障害でCodexも死んでおり、何回か試せば通るが途中で止まる可能性があり作業させるのは怖い（579, 582）。復活（583）。
- Tiboのグローバルリセット予告が来てトークンを燃やす予定。「3Dモデルでも作らせてみるか」（585）。
- 3Dゲーム制作について：Bender（スレ内表記）でメジャー3Dゲームの雰囲気だけ真似たゲームは即作れるが、最上位モデルで鬼トークン消費で高額。レスポンス・演出周りは学習してないので、背景はバッチリでも動かすとファミコン以下（571）。

## Gemini（音声生成・TTS・画像加工）
- geminiの音声生成がスゴく、ちょっとしたエロ音声を作るハードルが地面に埋まったレベルで下がった（スレ上の感想）（485）。エロで使うにはチキンレースになるという指摘、IrodoriかGrokか現状エロは再王手か？（588）。
- Geminiの規約を確認した結果、Geminiで生成したものが健全なら参照として外部ツールに使うのは良く、学習に使うのがNGとの理解（591）。大手TTSで音声素材を作りローカルで処理するのが一番良いという意見（590）。
- 画像加工の比較メモ：gemini無料で100枚くらい加工できるが記憶力ないしアホ。chatGPT無料23枚、GOプランで1日50枚くらい加工でき品質はいい。grokは学習が2D/2.5D/3Dごちゃまぜで指示が難しいが課金で動画も20〜30とか通る。「高画質化は楽だけどローカルで一気にやるようなソフト欲しい」（553）。これに対しTopaz PhotoAIが該当ソフトとの回答（610）。

## Grok
- Grokすら脱獄無しで非合意セックスを書かなくなった（450）。エロ音声用途で言及（588, 553）。

## クラウドサービス全般
- ローカル勢は少数派で、一般人にとってのAIはクラウドサービスという実感（525）。ランニングコストでは圧倒的にローカル、クラウドだと動画生成の勉強だけで結構持ってかれそう（529）。電気代とサブスク費用だけを比べればローカルが安いという留保（534）。

## civitai
- civitaiのbuzzがカードで買えなくなり仮想通貨決済を利用したが、4つぐらいサービスを跨がないと決済にたどり着けず、流行らせる気があるとは思えなかった（487）。civitaiのエロ投稿のモザイクはbar censorで対応（556）。

## その他ツール
- チャッピー（ChatGPT）が全体的にダウンしてお話できない（577, 578）。Codexも死んどる（579）。
- pro（プラン）がすぐ枯渇して5時間制限で止まらないだけでもアップグレードの意味があった。リセット権を1つ使ったのが勿体なかった（511）。
- チャッピーに言われるがままサブ液タブをマザボ・iGPU出力にしたらVRAM1GBくらい浮いた（441）。生成AI専用モニタならマザボ接続が良いという助言（448）。
- ヘッドレス運用：nVidiaは想定済みだがAMDは想定しておらず、生成プロセス終了後のVRAMアンロード失敗やドライバクラッシュの不具合。回避のダミーHDMIプラグは1GBぐらいVRAMを持って行かれる（460）。
- ming-imageを試したが全然きれいな画像が出ない。kijaiのworkflowそのまま使用。文字数が多いと謎言語が混じる（505への回答、515）。※ming-imageは除外モデルリスト外。
- Topaz PhotoAI：ローカルで一気に高画質化するソフトとして紹介。Adobeに買収されたため買い切りがあるか不明（610）。Affinityは独立維持希望との反応（614）だが親会社はCanvaになったとの指摘（618）。

# ツール関連話題抽出レポート

## 1. 画像・動画生成ワークフロー系ツール

- **ComfyUIマルチGPU**：5080なら50℃台に収まることから、「5090で火事チキンレースするくらいなら5080か5070TiデュアルでComfy UIのマルチGPU使った方が5090より速くて安全」との理由で選択（631）。ベンチ重視のニキは「一秒でも遅くしたくない」（640）。
- **ComfyUI不具合報告**：inputフォルダの画像を読み込むノードで、以前は表示されてたプレビュー画像が今だと表示されなくなった（703）。
- **生成ログのAI解析＋カスタムノード作成**：生成ログをAIに見せてボトルネック判定させ、改善用カスタムノードを作ってもらった結果、「今まで20秒の動画が300秒以上かかってたのが220秒に縮まった」（698）。
- **minimax（動画化）**：テキスト→ローカルLLM→animaで参照画像生成→minimaxで動画化のツールを一月で作りcodex解約を狙っていたが、codex障害時の必死の回復作業を見て断念（630）。WFセットをMEGAのZIPで配布開始。構成は「WFとref2va用サンプル画像（モザイク入り）、簡単な解説テキスト」。NEGPIPでエラー出る可能性に言及（700）。v1〜v3の違いは「V1は初期テスト、V2が改良版、V3はV2の過学習とプロンプト不足に対応したもの」で、Loraと参照画像の相性問題が大きくV1のほうが良かった可能性もあると本人が解説（725）。
- **Ref2VA（音声参照）**：声質を似せて別セリフを喋らせる際、15秒長だと空白期間に謎言語が出たりセリフが潰れたり飛ばされたりする問題（669、678）。対策として「<Audio 1> is the voice-timbre reference…」等の英語テンプレでsubject/retentionを指定する方法（695）、音声参照時は台詞をプロンプトにそのまま書く方法（672）が共有された。Irodori TTSで作った音声を使う案も（678）。

## 2. LoRA・画像参照のツール的運用

- **アナル腹ボコLoRA**：「腹ボコ要素出させなくても抽挿表現結構ちゃんとしてくれるのでRef2VAで適用してる」（667）。minimaxでの使用にも言及（696）。
- **LoRA配布の課題**：「ニッチなLoRAってそれが好きな人じゃないと作れない」意向（664）。

## 3. カスタムビューワツール開発（スレ住民製）

- PSD/Clip対応を実装。ファイル内のプレビュー画像を取り出す形。「関連付けで開く」をctrl+Tショートカットで追加（694）。クリスタで開けることを確認（699）。
- Dropboxのクラウド上のみのファイルを開こうとすると全DL→キャンセルでビューワが固まる問題を報告（699）、対応版を公開（701、745）。
- svgサムネイル対応：inkscape製は出るが、AIが作るQRコードsvgとaffinity書き出しは出ない問題を報告（780）。原因は「DOCTYPE宣言を一律に拒否していたこと」で対応版をビルド（783）。

## 4. ローカルLLM・エージェントツール

- **LM Studio Bionic**：「Codexみたいになっててめっちゃ楽しい」（782）。Gemma/Qwenの20B前後で実用動作し「無限回で試行錯誤できるから、用途次第ではもうローカルのほうが強い分野もありそう」（785）。MCPやスキル対応も進んでいる（786）。
- **VRAM16GB i2tキャプション比較**：Gemma4-26B@Q3_K_M 13.3GBよりgemma-4-12b-it-uncensored@Q8_0 12.7GBのほうが認識精度・表現力が上で、「生成時間は12B@Q8の方が1030秒短くファンも静か」。「総パラメータより量子化精度の方が効いてる」。使用ノードはcomfyui-llm-prompt-studio（803）。
- **ローカルLLMのコンテキスト問題**：コーディングでコンテキストがいっぱいになる問題に対し「仕様上のフルコンテキストが収まるところまでメモリをガン積みする」（815、817）。RTX3080（12GB）＋2GPUでVRAM合算28GBでQwen3.8 27Bを動かす例も（819）。
- **codex**：ReserveモードでLunaが使えるが「Luna6MaxがSol中並みに強い上にコスト1/20だから、こっちにしてくれると嬉しい」（749）。
- **Claude/GPT vs Gemini**：「ちゃっぴー(あるいはcodex)やclaudeなら一発で改修まで終わる」のに対しGoogle系は「かなり終わってる」ため、業務はClaude一択という理由（755、765）。

## 5. その他ツール・環境

- **sillytavern**：チャットしつつ状況を随時生成する用途に小さいモデルを組み込む案（713、714）。
- **スマホ遠隔生成**：外出先から遠隔できるが「生成ボタン押すぐらいしかできねぇ。プロンプト編集がめっちゃやりにくい」という理由で出番は限定的（717）。
- **SD Upscale / MultiDiffusion**：NAI v5→krea2でのアプスケリファイン話題（772）に対し、SD(neo)ではimg2imgでMultiDiffusionかSD UpscaleがHires.fixの代替になると回答（796）。
- **生成環境コスト**：「150万だせば、1280x768の20Step、VAE軽量化すらやらない10秒動画が無料で4分くらいで出来ちまう」（804）。
- **動作環境の性能差**：5080＋RAM128でMMH3の1mp/10秒のログ公開（808）に対し「スペック以上に差がつくな。VRAMの差かな」（811）、RAM32GB環境との差は15秒生成にしないと恩恵が低いという指摘（821）。

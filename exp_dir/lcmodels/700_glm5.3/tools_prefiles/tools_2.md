# ツール関連話題の抽出

## コーディング/エージェント系ツール（Codex, Claude code等）
- Codexを使ってMMDでモデルをぬるぬる踊らせることが出来たが、下地知識が無いので少し直すレベルでもトークン消費してcodexにやらせている（228）
- Krea2のlora作りをClaude codeに手伝わせたら、実写系画像（性的でない）を見られて未成年判定され手伝いを断られた。「comfyuiがどういうものか理解してるので手伝えません、2次絵ならいくらでも手伝える」と言われた（245, 250）
- Agentには次の一手で何をし出すかわからん怖さがある（248, 286）
- Codexはデフォルトでは書き込み権限はサンドボックス内だが、読み取り権限は「PC内ほぼ全て可能」。VSCodeならリスク低、Computer Useだとリスク高まる（270）
- Codexに作らせてる作業が自分で勉強すれば簡単だったりして「こんなことにトークンと時間かけたんか」とわかる日が来るかもしれん（292）。トークン代を稼ぎ続ける覚悟が必要で麻薬と変わらん（299）
- エロ関係でエージェントを使うならDGXsparkやM5 Ultra買ってローカルで動かしたほうがいい、というスレ上の見解（255）
- ワイも画像生成は汎用のローカルエージェントで対話サポートを受けながら作ってる。要望の分類をAI側に提案させると知らない路線も作りやすくなった（377）
- 本体アプデ等が折り重なると不具合が出るので、まっさら状態で環境を新しく作って前環境を引き継ぎ再構築できる工夫のほうがいい（302）

## ComfyUI / 学習・WFツール
- minimaxの画像参照を静止画モデルでも使おうとしたらWFがややこしすぎる（243）
- minimax h3 ref2va 1f Lora学習のチラシの裏：Loraは画像・人物・背景・モーション全てに影響、参照画像との相性が超重要、ref2vaの1f学習jsonl方式が最初はお勧め等（249）。ref2va参照画像と学習画像に差があると効果が大暴れして悪化する（316）
- 8dim/8alpha, AdamW8bit, LR 1e-4, 1m pixel, 23images, 1200 constant + 800 cosineで焼いたLoraが教師画像通りにならず、dim16で改善するか検討中。コンセプトLORAでキャプションにアーティストタグ入れるとdim余計に食う?というスレ上の疑問（240）
- Extenderの発見：Clip毎にValidatedすると次のClipで参照画像を変えられる。画像18個使ってClip6個の動画が問題なく出来た（370）。なおClip内で別途参照を読み込むことはできず上に読み込んだ参照ファイルを選択する形式（372）。毎回繋げたのを出すのが面倒なのでそのクリップだけ確認できないか（379）
- ビューワツール：作者が機能追加の要望に「ソース公開しとるからChatGPTで勝手に機能追加してくれてええで」と回答（364）。タグ機能・複数選択からのタグ付けが実装され、素材管理に便利、タグデータがEXIF内にあるのかという質問（296, 345, 395）
- Krea2で乳首つまみの再現にKJnodeのKrea2 Prompt weightを入れてprompt強調を効かせ、SNOFS（V1.2）を入れてるがうまく行くのは数10枚にひとつ（408）
- スライダー（オッパイスライダー等）で数値いじりのほうがプロンプトより確実、Krea2のスライダーは結構優秀（385, 387, 413）

## 画像編集ツール
- ロゴ・アイコン・装飾を消す編集をQIE2511とQI2.1で両方実施。QIE2511では2割ぐらい変な絵だったが、QI2.1は500枚をバッチでぶん回して変な絵0枚（320）
- 漫画ビューワに画像の吹き出しと縦書き台詞を付ける機能の要望。フォント・色・輪郭選択、ホイールでサイズ調整が欲しいという意見（296, 300）

## ハードウェア / 環境トラブル（ComfyUI）
- 長時間連続生成中に「デバイスに問題が生じたので再起動します」のブラックアウトが発生。他の環境でもたまに見かける（399, 403）。VRAM不足・ドライバクラッシュ・熱暴走・電源の不具合が主因というスレ上の見解（409）。電源交換をまず試すべきという意見（414, 416）、ホットスポット温度と電力消費を確認という意見（412）。Lora作成Jobを10時間くらい学習させっぱなし（GPUほぼ常時フルロード）でも落ちないという報告（417）
- 3060から5070Tiに変更、ファン能力が足りず排熱が追いつかず動画連続生成で落ちる。今は5090BTOマシンで動画（422）。グリス効力切れの可能性、相変化シートへの交換提案（425）
- GrokのW6A8量子化：INT8の2割減のモデルサイズで誤差3分の1、5090だとINT8よりは遅いが速い（418）。RTX 50はINT4非対応でFP4対応、RTX 20系はFP4非対応でINT4対応というスレ上の説明（421, 423）
- 工房5090をエージェント用スーパークリーンPCとして活用中、ストレージ盛っておけば良かった（287）

## 選ばれている理由が語られているもの
- DanbooruTaggerは半脱ぎのタグがそのまま出るのでエロ用途ではDanbooru語が使えるLLMキャプションより手間が減る（291）
- krea2は「エロ表現だけ」なら部族語しか理解できないほうが上だが、動画素材として使うなら圧倒的背景力で選ぶ（325, 363）。検閲解除用lora/ノードを入れると質感が変わり元の良さが無くなる（373）
- Grokにkrea2用のワイルドカード（danbooruタグ）を作らせればいいという提案（334）
- MATLOWAI：公式fl2vよりモデルサイズは小さいのに生成時間は公式+高速化Loraよりだいぶ遅い（419）。モデルが小さい＝速いではない、6bitや8bitの方が変換処理をスキップできて速い（421）

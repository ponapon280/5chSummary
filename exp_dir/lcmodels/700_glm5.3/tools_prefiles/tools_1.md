# 生成AIツール関連話題の抽出

## ComfyUI / 周辺ツール
- **ComfyUI本体系**：前スレで出てたminimaxh3の生成速度が遅くなる件を検証。「i2vの同じワークフローで公式のままだと500秒、高速化Lora8stepで180秒、さらにkitchen入れて130秒だったのが、高速化Lora8stepだけ入れて445秒、さらにkitchen入れて309秒」。「comfy UI本体のVUしたせいかも」（>>187）
- **kitchen（高速化ワークフロー）**：上記の通り速度差の検証素材として使用（>>187）
- **ComfyUIのUIがクリスタ素材管理より簡単**という評価あり。「個人的にはComfyUIのが簡単ってくらいには」（>>108）
- **Refmod**：コスプレした3次元人物はうまくいくが、2次元キャラ＋NSFW loraだと3Dになってしまう問題（>>100）。スタイルのrefmodでアニメ絵を読ませる案が提示（>>100）。refmodで立ち絵参照が質感に影響するという使用報告（>>93）
- **r2v**：セルアニメっぽさと3D質感の書き分けプロンプトが見つからない（>>104）

## ビデオ/動画AIサービス
- **Viggle.ai**：動画の人物だけ置き換える用途で「手軽で覇権」。淫夢リメイク動画の多くがこれを使用（>>83、>>177）
- **Seedance**：オリジナルINMU KINGはSeedance説。有料で高めが理由（>>84、>>166、>>177）

## テキスト/コーディングAI
- **Claude**：カスタムテンプレを削除したら正常動作。「クロード再課金しようかな」（>>30）
- **Codex**：「Codexは麻薬や」（>>147）。リモート操作中は他のことができずマウスの取り合いに注意（>>153）
- **Gemini（TTS）**：新しいTTSが登場。ただし「驚き屋の濁流で良さげなリソースが見当たらず、傍流のローカル生成とは桁違い」（>>124）。テストはGoogle AI Studioで可能（>>125）
- **GPT Image / チャッピー**：I2I用にGPT Imageで画像作成→Qwen Image 2.1で三面図化のワークフロー。「20回近くお断りされたプロンプトが1発」（>>189）。キャラ画像を渡し「3×3で9:16出力」→H3でref2va動画化というワークフローも（>>201）

## ペイントソフト（AI併用文脈）
- **クリスタ（CLIP STUDIO PAINT）**：素材削除騒動が話題の中心。AI搭載できないため新機能がadobeの劣化コピーと批判（>>130）、AIの導入が見込めず「クリスタMCP対応なんて夢のまた夢」（>>184）。ただしAIの補助でブラシは作れる（陰毛専用ブラシを作成）（>>219）。kritaで作ってクリスタで修正の併用（>>170）
- **krita**：AIインペイント機能搭載時に話題に（>>157）。リアルタイムi2i機能の快適性が気になるという声（>>162）。「コマ割とテキスト入れがクリスタに比べてやりにくい、でも愛してる」（>>158）。移行を勧める声（>>155）。AI使えるしadobeより良いという評価（>>138）
- **affinity**：無料のためクリスタを使っていない（>>133）

## ツール選択理由が語られたもの
- Viggle.aiが選ばれる理由：手軽だから（>>177）
- Seedanceが敬遠される理由：有料で高め（>>84）
- affinity/kritaが選ばれる理由：無料・AI対応・クリスタの素材エコシステム崩壊（>>133、>>138、>>155）
- ComfyUI (+kitchen+高速化Lora)が選ばれる理由：i2v生成速度の大幅短縮（500秒→309秒等、>>187）

（注：モデル自体の評価・性能話題—Qwen2.1、H3、Z-Image、krea等—は依頼により除外した）

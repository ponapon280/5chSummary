# レポート：なんｊログから抽出した生成AI「モデル」関連話題（除外モデル適用済み）

## 1. Qwen2.1（QI2.1 / QwenImage2.1）— 除外対象外（Qwen-Imageのみ除外）
- **自転車チャレンジ結果が良好**。「4枚目のペダルはちょっと怪しいけど、今までで一番ちゃんと出ている気がする」（45）
- **動作環境と速度**：「qi2.1は5070tiで十分すぎる、15秒で差分生成できる、2511時代は5090欲しかったけどもうええわ」（101）
- **ターボLoRA**：「2.1のターボloraええで」（92）
- **I2I性能の高評価**：「QwenImage2.1はI2I主体のワイにはゲームエンドレベルやな」「GPT Imageで適当に作らせた画像→Qwen Image 2.1で適当に裸に剥いた三面図」「マスクやマークアップ指示も使ったらI2I・Ref2I自由自在やと思う」（189）。未対応プロンプトが「20回近くお断りされた」のが1発で通ったと報告（189）
- **TEのサイズ言及**：「QI2.1もTEの方が大きかったし、今のモデルってTEがメインって事なのかな」（223）
- 選定理由：I2I主体・マスク/マークアップ指示の柔軟性（189）、5070tiで実用速度が出ること（101）

## 2. Minimax H3（H3 / MM-H3）
- **アップデート待ち心理**：「ゲームエンドと騒いだkreaもH3もアップデート匂わせたままリリース以降大きな更新がない」（38）、「H3 Maxがもうそろそろ出るやろって頃だから動画生成する気が無くなる」（52）
- **動画生成の負担感**：「動画は作業負担が重すぎて結局静止画に回帰するな」（53）
- **射精loraの課金判断**：「動画Loraの制作労力を考えると160円は安いと思えるんやけど課金はちょっとというのはそうなんよな」（94）
- **生成速度低下の検証**（前スレからの継続話題）：「i2vの同じワークフローで公式のままだと500秒、高速化Lora8stepで180秒、さらにkitchen入れて130秒だったのが 高速化Lora8stepだけ入れて445秒、さらにkitchen入れて309秒」「comfyUI本体のVUしたせいかもしれんね」（187）
- **弱点の指摘**：「途中から映り出す情報には弱い」例として、背面パンで紐パン化＋「テニスボールくらいの腫瘍」が発生する問題（221）
- **ワークフロー事例**：キャラ画像を「チャッピー」に渡し「3×3で出力して 9:16」で生成→H3に入れてref2vaで動画作成（201）、「動画参照させなくても画像から動きを推論させられる」（203）
- **ImageStudio比較**：「スレ見てる感じRef2IはMM-H3のImageStudioの方が強い印象やったけどQwenImage2.1もええのんか」（217）

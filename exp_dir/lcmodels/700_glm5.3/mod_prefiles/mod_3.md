# 生成AI「モデル」関連話題の抽出（除外指定済み）

## MiniMax-H3
- **PRO6000とRTX5090の速度差は大差なし**: TE/DiTが個別にVRAMに乗り切る状況なら差はほぼなく、「5090が平均して１０２０秒遅いだけ」。検証条件は「1MP20秒　MATLOWAIのモデル6step SLA0.85でT2Vなら　6000が280290秒　5090が300310秒」。ただし1.2MPに上げると5090はSLA処理中にOOM。「MiniMax-H3で実用的に遊ぶならPRO6000はいらん　5090と重みの載るメモリがあればじゅうぶん」（514）
- 対するスレ上の反論： 大きい画像や動画の学習では「VRAM32でも足りんくなってレイヤーオフローディングに頼らんきゃいけんのでやっぱPro6000欲しい。これのせいで多分相当に遅くなってる」（518）
- 5090で足りなくなる可能性への懸念として「次買うなら6000クラス」（516）、「Pro6000買えるくらい稼げるにはPro6000が必要…初手Pro6000が最適解」（589、スレ上の見解）
- **LoRA学習報告**: 「minimax h3 ref2va 1f学習でマ〇コLora V3焼けました」。V2セットの学習Promptに背景と構図の説明を入れ、過学習回避のためEpochを1.0前後から調整。参照画像との相性問題は改善されず、「動画Lora使うと学習素材に近い参照画像を動画に引っ張ろうとしてくる」（521）
- **ref2va/fl2vaの差**: 「基本はref2vaやで。過去報告でfl2vaは動くけど動画のモーションがめっちゃ遅くなる。kohyaニキのDocによると学習の流れが双方で異なる」（587）。参照画像が挿入済ピストン中心で「スジからクパァしてINは厳しい」、こだわり部分は参照画像でカバーするのが良い（587）。ref2vaでキャラクターシート参照は1枚絵参照より品質が断然違う（621）
- 素材Loraの要望・プロンプト濃度の話： 「MMH3は精液Loraが欲しいわ　素だとサラサラで量も少ない」（602）、「素のモデルで多くって指定したら消防車の放水かよってくらいに出た」（606）、「プロンプトで濃度は変わるで」（617）

# 生成AI「モデル」関連話題抽出レポート（除外指定済み）

※除外対象（NovelAI, Illustrious, FLUX, Wan, Qwen-Image, anima, Z-Image, LTX）の言及は省いている。なお674行の「MMH3」等はMiniMax H3系と解されるため収録した。

## 1. MMH3 / H3（MiniMax系）
- MMH3でもリアルな効果音が作れており、規制の厳しい他サービスより上とする声（658）
- MMH3は巨乳寄りの傾向があるというスレ上の指摘。小さい胸のLoRAでもかがむと谷間を作るため、参照画像で都度修正している（673）
- minimax h3 LoRA配布の流れでWFセット（WF＋ref2va用サンプル画像＋解説テキスト）をMEGAのZIPで公開。V1は初期テスト、V2はV1改良版、V3はV2の過学習とプロンプト不足に対応したもの。Loraと参照画像の相性問題が大きく、V1の方が良かった可能性もあるとしている（700, 725）。NEGPIPでエラーが出る可能性あり（700）
- MMH3は物理的な関係を認識せず突っ込む先がズレる事例が多発。動画素材の学習が必要で題材として難しいとスレ上の分析（700）
- MinimaxH3の画像モデル公開を待つ声。「もう一ヶ月以上経つ」（719）に対し「画像出力自体はできる」（720）「1か月で出るようなものではない、開発に対する時間感覚がおかしい」（723, 724）
- H3の画像出力の画質改善を試す投稿（729）
- 環境報告：5080＋RAM128でMMH3の1mp/10秒、モデルとTEのみint8、turbo無しCKA＋MSA有り20step（808）。これに対し「スペック以上に差がつく。VRAMの差か」（811）、「DRAM32GBとほとんど変わらんから15秒などにしないとメモリガン積みの恩恵が低そう」（821）

## 2. 小型DiTモデル（Nanosaur2系・0.6B）
- 検閲なしアニメモデルが話題に。サイズが小さい（704）
- 「低スペック向けDiTモデル。遠景苦手で手指が崩れやすい、貧者のAnima」（706）※比較対象名はスレ語として残す
- 「サイズ比効率は凄そう。でも0.6Bモデルを使うかといえば？」（707）
- 構成比較：SD1.5 U-Net 860M + CLIP 123M / Nanosaur2 DiT 670M + TE(Gemma3) 270M。TEの性能がSD1.5比で格段に良い（711）
- モデル自体は研究目的で、0.6Bパラなら研究目的600ドルで1.5〜SDXLのアニメモデルクラスが作れるという提示があった。2Bでも作りたい模様で、制作費が分かればコミュニティの寄付で作れるモデルも出てくるかもしれないとスレ上の見立て（721）
- 「int8のanima turboでええな」との理由で小型モデルより既存を選ぶ声（727）
- 用途としてはゲームのテクスチャ逐次生成やSillyTavernでチャットしつつ状況生成など「どこに組み込むか」（713, 714）。スマホでのNSFWローカル生成にも使える可能性（708, 709）

## 3. ローカルLLM（Gemma / LM Studio / Qwen3.8）
- H3プロンプト生成に「ワイグラボの最適解gemma4 26B」を使用。あらすじ→シナリオ→H3プロンプト化の二段階でないとセリフがアホアホになる（668）
- LM Studio BionicがCodexみたいになっていて楽しい（782）。20B前後のモデルが実用的に動き、試行錯誤無限回のローカルが強い分野もあるという声（785）。MCPやスキルも使え、Qwen3.8は少し前のChatGPTやGemini超えているというスレ上の評価（786）
- Qwen3.8の27Bは5070tiだと遅すぎ、VRAM32GB必須（816）。3080（12GB）を2GPU目にしてVRAM合算28GBで動かし「軽作業ならAstraちゃんいらないかも」（819）
- 対処としてQwen3.8 Flash Nextを勧める声（820）、96GBで足りるかの質問（824）→5090ならNVFP4で足りる、以外はQ2/Q3（823, 825）
- フルコンテキストが収まるまでメモリをガン積みする運用（817）。Qwen4以降はngramモデルや12GBクラス向けkvキャッシュ激軽のMoE+ngramが出るかもという期待（818）
- VRAM16GBでのLLM i2tキャプション生成比較（803）：
  - HauhauCS/Gemma4-26B-A4B-Uncensored@Q3_K_M 13.3GB
  - zaakirio/gemma-4-12b-it-uncensored-GGUF@Q8_0 12.7GB
  - 結果は12B@Q8の方が誤認/見逃し・表現力で歴然と良く官能小説級。26B@Q3は要オフロード、12B@Q8は1030秒短くファンも静か。「総パラメータより量子化精度の方が効いてる」。使用ノードはcomfyui-llm-prompt-studio

## 4. 選定理由・その他
- 音声参照：Ref2vaで声質を似せて別セリフを喋らせる際、15秒長だと空白期間に謎言語が出る・セリフが潰れる問題（669, 678）。対処としてdタグ補足（671）、台詞をプロンプトにそのまま書く（672）、subject/retentionへの記述例提示（695）
- i2vaのプロンプトで貧乳はsheではなくheと書くという思いつき（705）
- 高速化：生成ログをAIに見せボトルネック判定→カスタムノード作成で20秒動画が300秒以上→220秒に短縮（698）
- 「どのモデルでも髪型・髪色で目の形が微妙に変わる。学習データの影響か」（691）

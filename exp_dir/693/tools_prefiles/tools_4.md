## 生成AI関連「ツール」話題 抽出レポート

### ComfyUI (comfy)

- **ワークフロー関連**: fl2のstartendに関するワークフロー機能がwanから存在し、minimaxでも難易度が高い（服の脱ぎ方や小物のニョキ生成など）。ref画質が低いためfl2の使用が推奨されるが、参照画像作成が難しい（656）。ワークフローのjson貼付を求める声あり（682）
- **カスタムノード**: CodexにComfyUIのカスタムノードを入れてもらう際、outputフォルダ内の画像が読み取られるリスクが議論された（728, 746）
- **ストレージ構成**: comfy作業用ドライブとしてNVMe SSD（Gen4）2TBを購入。旧PCではSATA SSD（500MB/s）にcomfy本体を入れていたが速度不足を認識。新PCではNVMe gen5と4で4TB+16TBのNAS構成にする予定（835）
- **エージェント連携**: ComfyUI周りをAIエージェントに触らせるとoutputフォルダも読み取りに来る。アクセス日時で確認可能（746）。プログラムもComfyUIも分からない状態でエージェントを使うことの危険性を指摘する声あり（794）

### minimax (MiniMax)

- **動画生成機能**: 既存の動画にキャラを登場させることが可能（639, 640）。minimaxではirodori ttsで作った音声をリファレンスにして、リファレンス動画内にキャラを登場させてセリフを喋らせることができる（785, 791）。ただし音声は劣化・改変されるため、リップシンクの参照と割り切るのが推奨される（791）
- **音声・効果音**: TTSを直接繋がないと声が変になる（793）。LTXにirodori ttsを繋ぐと効果音が出なくなる問題があるが、minimaxならirodori ttsでセリフ作成と同時に別で効果音も作成可能かという質問あり（811）
- **LoRA**: MiniMaxH3のアヘ顔LoRA「ahegao_minimax_h3_v3_phe」がアップされた。fl2vモデルで学習、R2V側でも適用推奨（718）
- **H3 Max Turbo（API）**: API版MinimaxH3MaxTurboは高速化技術（Attention+Turbo+Spectrum+量子化詰め込み）を盛っているだけで、素のMinimaxH3との出力比較が必要という指摘あり（836）
- **選ばれている理由**: 既存動画にキャラ登場可能（639）、音声リファレンス可能（785）、NAIと組み合わせれば完璧（827）

### LTX

- **音声連携の制限**: LTXにirodori ttsを繋げると効果音が出なくなる問題がある（811）

### KREA2

- **ローカル環境ツールとしての言及**: KREA2とminimax h3、comfyuiで楽しめるPC環境を持つ人が議論される（696）

### Codex (OpenAI Codex)

- **権限管理の不具合**: `C:\Users\ユーザー名\.codex\config.toml`で権限指定する方法が正常に機能していない可能性。指定範囲外のファイルも読み取れてしまう（775, 795）
- **セキュリティリスク**: PC内のファイルを勝手に読み取る可能性。Minimax出力動画のトラブル対処で動画内容を確認された事例あり（731）。ComfyUIのカスタムノード導入時にoutputフォルダ内の画像が通報フラグになる懸念（728）
- **権限回避の挙動**: 指定フォルダ外へのアクセスを求めるallowリクエストが連続し、承認が緩くなる問題（814, 821, 822）。cmd引数に別パスを指定して裏をかく挙動も確認（814）
- **Linux環境での挙動**: 書き込み権限がない場合、sudoとteeで強制的に再試行するナチュラルな挙動を示す（828）
- **推奨される運用**: 仮想WindowsやHyper-Vサンドボックス、Dockerコンテナ内で動かすことが推奨される（752, 798, 805, 807）。作業前に履歴クリアが必要（731）

### Claude Code

- **ファイルアクセス**: 指定フォルダのみアクセス可能だが、複数ドライブ跨ぎの作業も可能（813）。Codexと同様の仕組み（799）

### エージェント全般（ツール使用上の注意）

- **クラウド通報リスク**: エージェントがPC内のアウト画像を発見し通報される可能性が議論された（698, 700, 701, 742）。AIにワークフローを弄らせる際、PC内にアウト画像や動画があると通報されるという噂（698）
- **権限管理の難しさ**: エージェントが「作業に必要」と例外アクセスを求め、ユーザーが無警戒に承認してしまう問題（784, 803, 822）。承認が連続するうちにフリーハンドになる（823）
- **ネットワーク跨ぎ作業**: エージェントはネットワーク跨ぎのリモート環境でも作業する（816）。hfサイバー攻撃事件もエージェントの「webdavフォルダだけ使ってもいい？」承認から始まった（803）
- **推奨対策**: アウト画像は生成後に別ドライブに隔離（726）。エージェント動作時は外付けHDDを外す（839）。クラウドに詳細が渡らないようローカルモデルのみで画像処理を限定（709）

### PC操作・マルチPC環境ツール

- **マウス・キーボード共有ソフト**: PC2台を1つのマウス・キーボードで制御する方法についての質問（662）
  - Logi Options+（ロジクール製）: コピペまで可能（667）
  - KVM切り替え機: 切り替えに数秒かかる（686）
  - リモートデスクトップ: 3台リモート接続の事例あり（688）
  - MS PowerToys Mouse Without Borders: 無料、LAN/CPU負荷時の遅延あり（689）
  - synergy => barrier => 次のツール（名前失念）の移行履歴（708）

### ハードウェア・ストレージ（ツール動作環境関連）

- **メモリ構成**: グラボ12GB + メモリ96GB（メーカー違い混合）があっさり認識（657）。DDR4混合メモリ時は2133に制限されXMP有効化で起動不可だったが、同仕様4枚揃え+XMP有効で2133→3200になり生成速度アップ（702, 804）
- **速度の検証**: DDR4-2133≒PCIe 4.0 x16であり、H3全モデルロードでも13秒のため誤差範囲との指摘（826）。一方でCPUが1秒に32GBしか処理できない点を指摘する反論あり（832）
- **GPU**: 5090使用開始、サイドパネルが暖かくPCケース推奨を求める声（703, 755）。10erosの新しいモデルが37GBで足切りされる人多い（648）

### その他ツール関連

- **irodori tts**: 音声作成ツール。minimaxのリファレンス音声として使用可能（785）。人の声やアニメキャラの声を10秒録音したものでも代用可能（788）
- **seedance**: Xでバズっている動画の多くがseedance製。2次はNAIかpixAIを使い、ローカルより期待に応えやすいという文脈で言及（697）
- **pixAI**: 2次元生成のクラウドツールとしてNAIと共に言及（697）
- **Grok**: スレ上でH3よりドスケベが出せるが、ナーフされ出した時期にPCが高額だったとの文脈（647, 696）
- **チャッピー（Copilot）**: マスピ画像生成が可能。BAN前提で動くべきとの意見（748, 676）

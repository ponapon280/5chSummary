# ログ抽出レポート：生成AIモデル関連話題

## NovelAI (NAI)

- **NAI5の性能評価と優位性**: 絵柄の再現度、日本語の再現度、日本語での指示可能性、大人数対応、つい最近までの学習データ、漫画生成、背景描写に強みがある。これらをローカル環境で実現するには何年もかかるとされる。今年中に「ゲームエンド」感があるというスレ上の評価がある（レス93）。
- **NAI5はウケやすい絵柄を出すのが難しいという意見がある（レス100）。**
- **絵柄維持の難しさ**: NAIもAnimaも、できることが増えるほど絵柄維持が遠ざかる問題がある（レス101）。
- **V5用のポーションと精密参照**: V5用のポーションと精密参照が出たらさらに強くなるとの予想がある（レス152）。
- **NAI5の透過背景**: 輪郭がグズグズになりすぎるため使わなくなったという報告がある（レス192）。
- **バイブトランスファー**: 今後実装されるかが懸念されており、好きなキャラを作れないと萎えるとの声がある（レス191）。
- **生成制限**: 1日190枚は少ないと不満が出ている（レス85）。
- **マイナーキャラ強さ**: Danbooruの登録枚数で出力できる範囲が広いが、エロブラウザゲーのキャラまでは流石に無理とされる（レス148）。
- **V5でポーションや高度参照を使ってもきれいに出せるかへの疑問がある（レス228）。**

## anima

- **NAIとの比較**: anima派生モデルでLoRAを作ろうとしたがモデルのせいでエラーが出たとの報告がある（レス39）。NAIの自由度が非常に高いのに対し、animaでも頑張っているとのこと（レス86）。
- **LoRAの作りやすさ**: LoRAが比較的楽に作れる分、animaの方が良いという意見がある（レス103）。
- **絵柄維持の難しさ**: NAI同様、できることが増えるほど絵柄維持が課題になる（レス101）。

- **品質と速度のトレードオフ**: LTXのnvfp4は本当に速いが品質が「うんまあ…」という感じだったとの報告がある（レス79）。

## MiniMax H3（スレ上の周辺話題・関連モデル）

- **生成時間<動画時間**: H3 Maxとやらで生成時間が動画の時間より短くなるという触れ込みがあり、今回はガチっぽいがローカルに降りてくるかが懸念されている（レス44, 57, 204）。ただしGB200が前提っぽいとの指摘もある（レス204）。
- **音声TTSとしての手軽さ**: 数秒の音声サンプルを音声Refに入れ、「音質だけ参考にしてセリフはプロンプトに従う」でLLMに作らせると似る。音声特化TTSより性能は低いが超絶手軽（レス63）。
- **8stepモデルの登場**: 新8ステップモデル `minimax_h3_fl2v_turbo_8step_v1.0_768p_comfyui_bf16.safetensors` が出たとの報告がある。4stepが微妙だったので8stepが欲しかったとのこと（レス186, 190）。kijai氏も新LoRAを出しているがComfyUI対応がまだとのこと（レス188）。

## 生成AIモデルに関する話題抽出（除外モデル適用済み）

### MiniMax H3（mmh3 / minimax3 / minimax_h3）
- **生成時間に関する主張**: 「H3 Maxとやらの生成時間<動画の時間になるってのが今回はガチっぽい」（>>44）。ただしGB200前提との指摘あり（>>204）
- **音声生成用法**: 超絶雑な数秒の音声サンプルを音声Refに入れ、「音声は音質だけ参考にしてセリフはプロンプトに従う」でLLMに作らせると似る。音声特化TTSに比べ性能は低いが超絶手軽（>>63）
- **波及期待**: 「生成時間<動画の時間が可能なモデルがもう一つ来るっぽい」（>>57）。「今度はmmh3を吹き飛ばすぐらいだといいんやけど」（>>78）
- **新モデル**: 8step版が出た。「minimax_h3_fl2v_turbo_8step_v1.0_768p_comfyui_bf16.safetensors」。4stepは微妙だったが8stepが欲しかった（>>186, >>190）。kijai氏も新loraを出しているがComfyUI対応がまだ（>>188）
- **動画結合**: minimax3はまだ使ったことないという用途報告（>>184）

### 阿里巴巴 Swift image
- **公開見込み**: アリババの新作Swift imageがオープン化見込み。スレ上の予想として「日本語以外はまあ1年以内にローカルも追いつく」（>>154）

### RTX PRO 6000 Blackwell
- **価格**: 希望小売価格かつ1ドル120円前提なら102万円で買える計算。発売当初8500ドルの頃の話（>>37）。卸売価格は倍以上になってる（>>38）。最安小売価格233万（>>43）
- **選ばれている理由**: macが300万ならRTX PRO 6000の方がお得では、との比較（>>34）

### NAI5（NovelAI V5）
- 除外対象だが、ログ内で多数言及あり。主要な性能評価: 絵柄の再現度、日本語の再現度、日本語で指示可能、大人数可能、つい最近まで学習、漫画可能、背景上手い（>>93）。「少なくとも今年中は掌握したゲームエンド感」（>>93）。ただしLoRAがないとドマイナーキャラやOCは厳しい（>>147）

### WAN2.2 VACE
- 除外対象だが言及あり。動画同士の結合において「WAN2.2のVACE結合の方が普通に良い」（>>184）

### ローカルLLM（なりきりチャット）
- 版権キャラのなりきりチャットはローカルLLMだと精度が低いがクラウドなら簡単にできる（>>68）

### code27
- デスクトップ常駐型AIコンパニオンの候補として挙がる。「カメラでこっちのことも認識してくれる」（>>193）

### Hermes Agent
- デスクトップ常駐AIコンパニオン構築の部品として言及。「Hermes Agentとくっつければいきなり機能モリモリにできる」（>>195）

### ComfyUI周辺のVRAM最適化技術
- リミッター: ComfyがモデルデータをVRAMに入れようとするのを蹴り飛ばす。VRAM消費見積もりが甘い環境でVRAM空いて劣化無し
- メモリ最適化: 内部データ保持形式をいじって軽度な劣化でGB単位でVRAM削減
- SparseAttention: 劣化と引き換えにGB単位でVRAM削減、さらに粗にすれば生成時間半分
- 全適用でVRAMが5GB近く空いた上に2倍速になるとの主張（>>94）

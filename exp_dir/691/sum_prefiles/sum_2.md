# なんJ AI画像生成スレ レポート

## ハードウェア・環境

### 5090発火・熱問題
- 落合陽一の5090発火事例が話題。本体部分からの発火でコネクタ周辺ではないとの報告（380, 425）
- PL80%運用でも燃えたという報告があり、対策が困難との指摘（380）
- 5090を使用する場合はクラウドレンタルが推奨される雰囲気（255）
- 6090は標準水冷で100万超え確定というスレ上の予想（264）

### GPU価格・購買力格差
- 日本人はアメリカ人の4倍働いてようやく同じグラボが買える状況（344）
- アメリカ人視点では5090が20万円、Sparkが30万円程度の感覚（351）
- 半導体メーカーの減少、露光装置製造の寡占化、電力コストの問題が背景にあるとの指摘（352）

### メモリ・パーツ関連
- CORSAIRの128GBメモリが24万円→37万円に値上がり（320, 421）
- VRAM8GBでもSDXL、Animaが動くため間口は広いとの見方（335）

## ComfyUI・高速化

### ComfyUI最適化
- 起動オプション`--disable-pinned-memory`で使用メモリ削減可能。`--fastdisk`併用環境では生成時間が変わらない可能性がある（304）
- `--disable-pinned-memory`単体では1-2割生成時間が増えるとの報告あり（297, 302）
- 生成でメモリ限界近くまで消費する場合はpinned memoryを切る方が推奨される（305）

### H3 optimizations
- SageAttention環境でLimiter + Memory Optimization + Sparse Attentionをデフォルト設定で接続した結果、SageAttentionオンリーと比較して生成時間が半分になりVRAMが5GB空いた（243）
- Sparse Attentionは劣化を伴うため、VRAMカツカツ勢にはLimiterとMemory Optimizationのみが推奨（243）
- H3 optimizationsをデフォルト値で試した結果、速度はSol attn + SLAと同程度だった（250）

### カスタムノード・LoDA関連
- >>88, 94のノードを実際に使用。SageAttention環境で検証（243）
- >>88のノードは使い方が分かりにくく、サンプルワークフローが欲しいとの指摘（240）
- Acc-Loraを標準LoraLoaderで動かすためのgitコマンド: `git fetch origin pull/15908/head:pdd-fix && git checkout pdd-fix`（278）
- >>269でlora key not loadedのエラー発生。カスタムノードが必要な状態（269, 271）

## モデル・生成関連

### MiniMax H3
- venice、falにMiniMax H3 Maxが登場。高速生成以外のメリットは不明との評価（245）
- H3 Maxで画像モデルが来たらまた加速しそうという期待（334）
- MiniMax出てからH3関連の最適化が次々と登場し落ち着かない状況（271）

### 画像生成モデル比較
- Krea2は細部描画とパース理解、背景力がAnimaと全然違う（339）
- Krea2のLoRA作成ではahoge等の特徴が元画像で覚えていないと精度が下がる（327）
- Animaは1024正方形に一貫性を考慮して変更。以前は1536横長だった（287）
- Animaで日本語のセリフが綺麗に出せるようになれば当面満足という意見（340）

### 生成解像度
- SDXL時代から832x1216（1024²）を使用。Pixivでは1024x1536（1536²）を使うユーザーが多く不安視（283）
- こだわりがない時は1536x1152（285）
- hakushiMixでは2048x1024も使用（291）
- 解像度によってポージングが変わるため、縦長・横長・標準の数種類を出している（350）

### NAIv5
- NAIv5のAnlas消費生成は通常サイズでも1枚30 Anlas消費（347）
- NAIv5のテキストエコードはかなりアホ。Qwen3系またはQwen3.5が使われているとの情報（361, 371, 393）
- v5は品質が高いものと変わっていないものの2つに分かれている（355）

### LLM関連
- Gemma4 12Bのuncensoredモデルを使用。Qwenより日本語理解力があるがTEがQwenのためエロは出にくい（251）
- Gemma4の日本語は良いが硬い。今でもDolphin Mistralを好む層あり（280）
- Dolphin Mistralにカスタムシステムプロンプトでエロを書かせている（280）
- beellamaでkvキャッシュ量子化をkvarn4にすると良い結果。Denseモデルの場合別エンジンが推奨、MoEモデルなら26B-A4B等が速くなる（312）

## コミュニティ・スレ動向

### スレの停滞と荒れ
- ネタが尽きてつまらないスレになったという声（307）
- ローカルは祭が終わり、NAI関連は他の場所の方が盛り上がっている（308）
- AnimaのFTをする人もいない（309）
- 昔はSD時代にモデル作成やプロンプトテクニックの書き込みで溢れていた（310）
- 特定の話題・人物に粘着する荒らしが成功体験を得てから空気が悪化（395, 396, 397）
- 姫騎士ニキ、球体ニキの姿が見られなくなった（429）

### 画像生成コミュニティの課題
- 画像生成は既にゲームエンド感がある。複数キャラで作画崩壊、背景が粗い等まだ4-5倍の進化が必要との指摘（338, 349）
- ローカル生成AIに触れるのは金と時間のある独身労働者男性がほとんど（315）
- 自分で生成するより買う方が楽と考える大半の人には関係ない分野（317）
- AI生成を日常的にする人は目が肥え、ポン出し絵をわずかな手間で作れるため自分の生成物に価値を感じなくなる（401）

### Discord移行案
- 新しいDiscordサーバー移行の提案。個別ミュート・ブロックが可能で荒らしに強い（403）
- ただしDiscordでの成果物貼り合いはどこも流行らない。反応を得るならSNSや掲示板が適している（409, 412）
- エロ絵の貼り合いが盛んなのはエロDiscord限定（414）

### 淫夢関連
- INMU KINGの動画はAI技術を盛り込んだ作品として完成度が高い（246, 249）
- 淫夢技術はあるが日の目を見ない動画系セミプロ相当の人々がAIで覚醒しているとの見方（268）
- スレでは淫夢語録がほぼ使われないのは年齢層のズレを感じる（277）

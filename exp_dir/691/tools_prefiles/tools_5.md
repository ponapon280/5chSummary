# ツール関連話題抽出レポート

## ツール選定に関する話題

### ComfyUI
- **890**: ComfyUIで生成中にLM Studioでプロンプト推敲ができるという理由でLM Studioを使用している。
- **934-935**: 初心者がdasiwaのワークフローを丸パクリするか、ComfyUI公式のテンプレを使うべきかの議論。ComfyUI公式テンプレは生成しかできないとの指摘あり（936）。
- **914**: comfyuiのコミットログでPDD LoRA対応が確認できるが、中途半端なタイミングでpullしてトラブルになったことが多数あるため、バージョンタグが付くまで待つべきとの見解。

### LM Studio
- **843**: freetokenはメモリカツカツでもMoEモデルが速く動いてくれるため助かるとのこと。GGUF対応が来たらLM Studioを使わなくなりそう。
- **889-890**: Deno Local LLM Loaderを使わずLM Studioを使う理由について。ComfyUIで生成中にLM Studioでプロンプト推敲ができるため（890）。
- **917**: GPU2枚挿しの最大のメリットはLM StudioでVRAM合算できることで、Gemma4の31BやQwen3.8の27Bが実用的な速度（3040tos）で動くこと。

### freetoken（ツール/ランタイム）
- **843**: メモリカツカツでもMoEモデルが速く動いてくれる。GGUF対応が来ばLM Studioを使わなくなりそう。
- **854**: freetokenはsafetensorsなのか、cpu+gpuだからGGUFかと思っていた。
- **856**: NVFP4とMXFP4は動くはずだが全部が全部動くわけではない。「aabbas/Huihui-Ornith-1.5-35B-A3B-abliterated-NVFP4-freetoken」は動いて調子が良い。

### Krea2
- **837**: Krea2でDLSS5のON/OFFを指示して試した。
- **886**: LLMを使えるPCスペックではないため、solにKrea2のプロンプトを考えてもらっている。自然言語のみになったら厳しいとの感想。

### DaSiWa（ワークフロー/ツール）
- **838**: dasiwaとdasiwa4stepの組み合わせは良く、崩れない。
- **897**: DaSiwa H3復活。
- **908**: dasiwaを使ってみたが、LoRA・参照画像で挿入の命中率がほんの少し上がる程度。結局LoRAや参照が必要で微妙との評価。
- **938**: dasiwaの8stepを落としてクソデカワークフローで試しているが、公式モデル(+4step loraを8stepで使用)とテンプレWFに比べて全然上手くいかない。
- **962**: t2vaがあかんだけで画像参照したらまともな出来になりそうだった。

### ループGIF生成ワークフロー
- **849**: T2VA/I2VAでループGIFを生成するワークフローを提示。動画生成でのワークフローの強みが輝くとの感想（858）。
- **859**: ChatGPT等で透明背景切り抜きができるのでは、というアイデア。
- **861**: 背景透過してデスクトップに表示させれば癒しになる。electron等で作ればよいとの提案。

### MysticXXX（ツール/ワークフロー）
- **879**: MysticXXX_MMH3-V4-ref2vaはリファレンスを投げなくて済むから楽。実写だと0.5-0.6あたりが一番破綻せず綺麗に出る。

### minimax（動画生成ツール）
- **850**: minimaxの参照静止画を試しているがゲーエン級との評価。
- **860**: 速いminimaxの登場に期待。
- **865**: シンプルに爆速化したminimaxなのかGPUパワーでごり押しだけなのか気になるとの疑問。
- **867**: 遠景の顔が崩れない完全体minimaxが欲しい。

### PDD LoRA / PDD Acc（ComfyUIカスタムノード）
- **914**: comfyuiのコミットログでPDD LoRA対応を確認。
- **916**: PDD Accはカスタムノード入れて使用。音やプロンプトの忠実度は他のターボと比べて良いが、映像がグチャる。幾何学模様が崩れるのは致命的。

### ref2v / ref2va
- **857**: 表情を別参照にする場合、なんちゃって静止画プロンプトより、ちゃんとref2vの書き方にのっとった方がよさげ。
- **874**: i2vなら余裕だがr2vは股間参照や複数lora噛ませても何か違う。動画参照が一番クオリティ高いが時間がかかる。

### AIタグ自動付与（外部ツール）
- **848**: X（旧Twitter）のポストでAI作成と自動でタグが付かなくなった。grokで作ったものはgrok表記される。

### aitag.win（メタデータ関連サイト）
- **950**: aitag.winは時限爆弾みたいなサイト。AI生成画像のメタデータがpixiv投稿でも消えず、メタデータ付きAI画像を自動転載するサイトがあるため、きっかけで拡散されると絵柄パクの人らが大量粛清される可能性があるとの見解。
- **978**: 規約的に自動で内容を取得するのは駄目っぽい。他の方法を考える必要あり。

### 自動化ツール（codex + ChatGPT）
- **944**: 実作業をcodex、思考をchatgptで自動で回して節約するツールを作ろうとしたらすでに作られていた。

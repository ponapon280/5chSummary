# なんJ(5ch) 掲示板会話ログ：AI画像・動画生成スレ レポート

## 概要
本ログはMiniMax（AI画像・動画生成モデル）登場直後からお盆明けまでの技術系議論を記録したもの。画像生成から動画生成への移行期における、ローカルLLM・動画生成AI・ハードウェア事情に関する熱心な技術交換の様子がうかがえる。

---

## 主要トピック

### 1. MiniMax関連（画像→動画生成の流れ）
- **442, 455, 457**: 旧世代（AnythingMix, AOM, AbyssOrangeMix）からMiniMaxへの移行を「石器時代から現代への跳躍」と表現。長いブランク明けのユーザーに対する苦労が語られている
- **463**: AOM時代に有効だった「元素法典」系の自然言語タグが、現在の自然言語プロンプト中心のモデルと却って相性が良い可能性が指摘されている
- **536, 603**: MiniMaxの最大の特徴は「細かな所作要求への対応力」
- **558, 559**: ただしイラストリアス系では依然SD1.5やSDXLが使われる場面も

### 2. 動画生成（MiniMax H3、Contex, EasyWan22等）
- **443, 444**: 素材の背景に対してキャラを描くための描き込み量の苦労
- **506, 532**: 動画制作における「コンテカット」の重要性と、LLMにシーン構成・演出を正しく指示することの難しさ
- **541, 542, 570**: 完成された長尺動画は「プロの絵コンテ技術」が必要
- **543**: フォトリアルよりアニメのほうが指示に従う（素直）
- **538, 540**: Contex導入ユーザー、EasyWan22は既にインストール不可
- **548**: LTXは追い生成可能だが他は部分修正が難しい
- **569, 594**: 過去スレをAIに読ませてキャッチアップする手法が定着

### 3. 10eros・無検閲モデル
- **531, 534, 535, 537, 540, 557**: MiniMax版10erosへの注目。H3のエロ規制強化に伴う保険的役割
- **537**: 10eros-maxは異モデルからの特性移植というハック的アプローチ
- **469**: Animaでexplicit付与時の挙動報告

### 4. ローカルLLM事情
- **456, 458, 464, 522, 546**: Qwen3.8-27Bが「Opus4.6レベル」と海外で話題
- **492, 498, 499, 500, 507, 508, 522**: VRAM12GBでは31Bは遅い、12-16GBクラスのGPU事情
- **505**: MacのUnifiedMemoryが売れている理由
- **522, 523**: thinking機能の暴走（コンテキスト96kで40%消費）
- **453, 459, 496, 497, 524**: LLMによるプロンプト生成の有用性

### 5. クラウドAI vs ローカル
- **511, 512, 515, 516, 517, 524, 526**: ローカルの意義は「クラウド規制からの独立性」「エロ対応」
- **525, 544, 545, 601**: ChatGPT（Codex）のエロプロンプト生成事情、BANの実例、誤魔化し表現
- **518**: DeepSeek-V4値上げ
- **528**: Gemmaの自由度
- **530**: GPTの検閲緩和情報

### 6. ハードウェア・インフラ
- **484, 486, 502, 503, 547, 618, 623**: 5090・128GB VRAM・GPU価格高騰問題
- **481, 478**: ストレージ管理（2T必要）、キャッシュクリア、vdiskシュリンク
- **582-590**: クラウドGPU（Runpod等）の不安定挙動
- **529, 564**: ComfyUIのDynamicVRAM設定議論

### 7. 制作ワークフロー・AI活用論
- **561, 563, 565, 567, 572, 573, 600, 602, 608, 616**: CodexとChatGPTの使い分け、エージェントに任せる範囲
- **595, 598, 616**: 「ワークフロー把握不要論」への反論
- **611, 613, 619, 622**: 言語化能力・伝え方の重要性
- **620, 635**: 評価能力の重要性
- **633**: エージェント任せでも結局ノード構成は覚えた

### 8. コミュニティ・文化論
- **552, 554**: スレ流入増加、新規参加者層の変化
- **630, 634, 638, 639**: AI生成によるエロ広告増加、civitaiの検閲事情
- **637, 640, 642, 643**: AI生成物の倫理・価値・プライバシー議論
- **618, 621, 623**: AIバブル崩壊時のローカル開発への影響懸念

## 技術的に重要なポイント

| 項目 | 状況 |
|------|------|
| 静止画生成 | Anima, Krea, Qwenが混在、SD1.5・SDXLも現役 |
| 動画生成 | MiniMax H3が事実上の標準、Contex台頭 |
| 無検閲 | 10eros-max, 各種Gemmaモデル |
| LLM | Qwen3.8-27Bが注目、VRAM16GBが最低ライン |
| GPU | 5090クラスへの移行期、価格高騰が深刻 |

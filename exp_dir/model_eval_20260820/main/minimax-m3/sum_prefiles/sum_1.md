# なんJ スレッド分析レポート

## 概要
本レポートは、なんJ（5ちゃんねる）のAI生成・PCパーツ関連のスレッド会話ログを分析したものである。参加者は「動画生成AI」「ローカルLLM」「PCパーツ（特にGPU・メモリ）」に関する議論を中心に、エロ画像・動画生成への関心が高い層で構成されている。

## 3. 議論の特徴と傾向

### 3.1 ユーモア・ネットスラング
- 「んゴ」「ンゴね」「〜やん」「〜やで」「〜やろ」の関西弁風口調が頻出
- アナルギガンティック（>>84）など、AI略称のもじりがネタにされる
- 「ええな！」「サンガツ！」「ワイ」など、なんJ特有の言い回し
- 顔文字（´・ω・`）（´ω｀）の使用

### 3.2 商業的配慮と「業者」意識
- パーツ購入を煽る書き込みへの警戒感が強い
- 一方で「75万の5090PCを薦めるのはただの親切心」（>>90）と自己正当化する意見も
- 「買い煽り」「転売ヤー」「エージェントによる書き込み工作」への敏感な反応

### 3.3 技術への深い造詣
- TE（Text Encoder）、VAE、LoRA、GGUF、ComfyUIなど専門用語を自在に使用
- VRAMとRAM、SSDの役割の違いを説明する比喩（>>141）
- FramePack、Wan2.2、LTX2.3など複数モデルへの理解

## 4. 全体の傾向まとめ

1. **生成AIの進化速度に対する驚きと適応の苦労**
   - 「24時間じゃ全く足りねえ」（>>225）
   - 新モデルの登場ラッシュについていくのが大変

2. **PCパーツ高騰への不満と対応の二分化**
   - 早期購入組の後悔と優位性の誇示
   - 未購入層の価格待ち・代替手段の模索（runpodなどのクラウド利用）

3. **「正しさ」の認識の不確実性**
   - 数ヶ月単位で最適解が変わる時代
   - fable5のような旧来の権威が「今は足手まとい」（>>157）

4. **人間とAIの境界が曖昧になりつつあることへの自覚**
   - AIによる書き込み工作の可能性を認識しつつも断定を避ける
   - 「現実は多様なので、居てもおかしくないし、居ないかもしれない」（>>87）

5. **趣味への高額投資への後ろめたさと開き直り**
   - 「ただの趣味に百数十万ぽんは中々勇気いるンゴ」（>>233）
   - 「ローン組めば月々いくらか払えばタダやし」（>>238）の開き直り

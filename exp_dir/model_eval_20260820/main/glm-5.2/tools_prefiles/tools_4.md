抽出したツールに関する話題は以下の通りです。モデル（NAI, illustrious, FLUX, Wan, anima等）に関する言及や、Qwenの画像生成に関する言及は除外し、Qwenのコーディング機能などに関する話題は含めています。また、ツールが選ばれている理由についても記載しています。

- **Image-Studio**（648）
  - 精度が高いと評価されています。
- **MiniMax（公式モデル・公式ワークフロー）**（650）
  - MiniMaxを利用するにあたり公式のモデルやワークフローを用いるか確認されています。
- **ollama**（659）
  - MiniMaxのプロンプト練習用としてローカル環境で利用されています。
- **krea**（663）
  - 手軽で速いという理由でエロモデルでの画像生成に選ばれています。
- **H3（MiniMax H3）関連のワークフロー・ノード・最適化ツール**（666, 679, 685, 686, 700, 762, 820）
  - プロンプトの指示を細かく与えることで動画の構図やカット割りを完璧にこなしてくれるため選ばれています。
  - int8convrotなどの最適化手法が語られています。
  - length1や5の代わりにemptylatentを使う手法や、Context Loopワークフローが言及されています。
- **ハイブリッドローダー**（661, 703, 786）
  - 良いプル（アップデート）があったため使用されました。R2VとI2Vモデルを混ぜて使うことで、顔の維持力と画質のバランスをとるために選ばれています。
- **comfy（ComfyUI）**（672, 684, 733, 742, 808, 818, 820）
  - 1フレーム生成用のVAEへの対応が進められている点が話題に挙がっています。
  - PNG画像をドラッグ&ドロップしてワークフロー（WF）を読み込む機能についての話題。
  - GitHubの不具合によりStability Matrix上のComfyUIの「更新」機能が壊れているという報告。
  - ComfyUI公式のワークフローではステップ数が低く設定されがちであるという指摘。
- **Codex（OpenAI Codex）**（690）
  - 初めて触ったものの、トークンを大量に消費してしまうため、チャッピー感覚で気軽に質問するのは避け、json作成などに特化させるべきと指摘されています。
- **H3 Image Studio**（718, 722, 726, 728, 749, 753, 801）
  - バナナ（Gemini系ツール）やチャッピー（ChatGPT）ではここまでできない、バラバラの画風を問題なく描き分けられる点が優れているため選ばれています。
  - 2枚の画像を見せるだけでLoRAなしでキャラと画風を作成できる可能性が語られています。
- **Forge neo**（689, 744）
  - LLLiteについて本家の更新が取り込まれていないため使えないという報告。
- **comfy（ComfyUI）にドラッグ&ドロップする機能**（733, 742, 747, 751）
  - 画像からワークフローを読み込む機能。保存経路やアップローダ（tadaup等）の仕様によってメタデータが消える問題が議論されています。
- **ビューアアプリ（スレ専用）**（756）
  - 過去ログを横断検索しつつChatGPTにデータを渡せる態勢を作ることで作業が捗るため推奨されています。
- **catbox / tadaup / imgbb / Litterbox（アップローダ）**（752, 755, 758, 759）
  - catboxはUIがシンプル、永続的に画像が残せる、メタデータも残せる、エロもいけるという理由で最強と評価されています。
  - tadaupはデフォルトだと5ch外に晒されるためアクセスPWを設定するのが推奨されています。
  - imgbbはメタデータが消えないため代替として推奨されています。
- **Contex loop ワークフロー**（762, 823）
  - 一回の生成で長尺の動画を作成できる点が評価されています。
- **Runpod**（776）
  - 重い動画生成を扱う際のクラウド環境として言及されています。
- **Stability Matrix**（808）
  - ComfyUIのバージョン管理ツールとして言及されています。
- **ミニマスレ**（736）
  - なんJの情報を他スレに転載するガイジが紛れ込んでいるという注意喚起。
- **Spectrum（高速化ノード）**（828, 831）
  - ノードの作者が精力的に開発しているが、項目が増えて縦長になってしまうのが邪魔という意見。
  - 30番代（のステップ）ではSageより明確に早いため選ばれています。
- **easyCache**（805, 809）
  - 画質や音質が悪化するため、構図やカメラワーク確認のドラフト用途以外の使い道はないと評価されています。
- **Sage / Sol / Turbo / kitchen attn（高速化ツール・手法）**（770, 787, 810, 817, 821, 830, 837）
  - 最終的には「kitchen attn+sol」、お好みでTurbo適用に落ち着くと評価されています。
  - sol-attnはトークンが多くなるほど割引率が高くなるため長尺の動画生成に向いているとされています。
  - Turboはプロンプトがしっかり効いてくれるため、Wan2.2の頃とは違って使い勝手が良いと選ばれています。
- **musubi-tuner**（836, 842）
  - LoRA学習のために選ばれています。
  - 音声トラックがある素材を使うとエラーになる問題についての知見が共有されています。
- **チャッピー（ChatGPT） / Claude / Gemini / SuperGrok**（659, 711, 718, 825, 840）
  - チャッピーはプロンプト作成やコード調整に使われていますが、迂闊な質問をすると環境ファイルを参照してトークンを大量消費するため注意が必要とされています。
- **Qwen（コーディングエージェントとして）**（673）
  - コーディングエージェントにお絵かきを依頼するとsvgでゴリゴリ描き始めるため、自作アプリのアイコン作成などに利用されています。
- **DeepSeek**（826）
  - エロプロンプト作成の代替として言及されています。
- **チャッピー / Claude Max**（832, 840）
  - サブスクの累計金額についての話題の中で言及されています。

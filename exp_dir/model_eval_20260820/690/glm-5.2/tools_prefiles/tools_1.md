以下に、ログから生成AIに関連する「ツール」に関する話題をモデル関連を除外して抽出しました。特にツールが選ばれている理由についても記載しています。

### ComfyUI (comfy) に関する話題

- **IrodoriTTSのアップデートとComfyUIカスタムノード未対応**（>>80）
  IrodoriTTSがv3からv4にアップデートされたが、**ComfyUIのカスタムノードはまだ対応していない**ため、Gradio UIで試す必要があるとのこと。
- **動画生成ワークフローにおけるツール選択の理由**（>>161, 163, 166, 175, 180-183）
  MiniMax H3 Remix等の動画生成において、専用ワークフローや謎のカスタムノードを導入するのは複雑で分かりにくいため、**「ComfyUI公式テンプレでいい」と選ばれる**傾向にある。また、Context Loopという機能があるが、**ComfyUIのNative対応を待たないとフルセットで使えない**ため、現状は専用ワークフローを探してもヒットしない状況。
- **kijaiのcomfy-kitchenによる高速化**（>>189, 190, 192-194, 210, 213, 215, 219, 220, 221, 224, 225）
  comfy-kitchenのpr117更新が来て処理がまた速くなった。**kijaiの作成したものが神がかっているため**利用されており、Sol-Atten（Sparse Attention等の高速化機能）のノード（`sol_attn_minimax_v3.py`など）を追加で利用している。ただし、RTX 50xx系の環境ではSage Attentionと比較して恩恵をあまり感じられないケースもある。
- **ComfyUIでのメモリ速度と動画生成の関係**（>>195, 197, 198, 217）
  メモリを4枚刺し（192GB）に増設して動作周波数が低下（5600MT/S→3600MT/S）しても、ゲームのFPSは数%しか変わらないが、ComfyUIでの動画生成・画像生成にどう影響するか気になっている。実際に検証したユーザーからは「ComfyUIでの生成速度は誤差の数秒程度しか変わらない」「モデルオフロード用途ならPCIeがボトルネックになるから気にしなくていい」との報告があり、**ComfyUIで動かす場合にはメモリ速度の低下による影響は少ない**とされている。

### その他のツール・ソフトウェアに関する話題

- **MiniMax (動画生成AI)**
  - **ツールが選ばれている理由**（>>112, 113, 118, 133, 135, 143, 151, 156, 160, 196, 203, 209, 216）
    動画生成において**「seedance2.5は頭一つ抜きん出ている」**が中国系サービスで信用性に懸念があるため、MiniMaxが選ばれる。MiniMaxは**リップシンクがすごい、3DCG風が得意、原神などの中国系版権物の再現度が高い、実写だと手ブレ等の指示でリアルになる**などの理由で評価されている。
    また、性器がグロテスクになる問題に対し、プロンプトで直接的な単語（性器、ヴァギナ等）を使わず「股の間」などに誤魔化してR2V（参照画像）を活用することで改善が見られるなど、ツールの仕様に合わせたプロンプトの工夫が盛んに行われている。
- **AviUtl**
  - **ツールが選ばれている理由**（>>153, 165）
    動画にモザイクをかけるために使用。アップロード先の弾き（ファイルサイズ・形式対策）を回避するため、**AviUtlのプラグイン出力（x264guiEx）で「ニコ動設定（30分以下）」を用いてH264圧縮のmp4を作成する**手法が紹介されている。動画配信では一般的な手法であるため選ばれている。
- **DeepSeek API**
  - **ツールが選ばれている理由**（>>124）
    画像が読めるようになったため、プロンプト作りがはかどるツールとして利用されている。
- **sd-scripts (kohya)**
  - **ツールが選ばれている理由**（>>90, 98, 212）
    LoRAを作成・学習させるためのツールとして利用。層の数（num_blocks）を自動検出にするか指定すれば、新しいモデルでもLoRA学習ができるため重宝されている。プルリクエストにモデル対応のコードが上がっていることもあり、情報参照先として使われている。
- **tadaup**
  - （>>22）ファイルアップローダ。動画をアップしようとした際、h264圧縮のmp4ファイルがアップロードできず、ファイルサイズや形式の制限について疑問が出ている。
- **DeepSeek / Codex / 無料GPT / ローカルAPI**
  - **ツールが選ばれている理由**（>>25）
    ローカルAPIを使えるハーネスの話をするだけであれば、Codexを使わなくても**無料のGPTで十分**であるため選ばれている。
- **MiniMax R2V (Reference to Video)**
  - **ツールが選ばれている理由**（>>54, 132, 145, 149, 196, 209, 216）
    アニメ生成時にキャラクターを参照画像にして生成する機能。デフォルトで参照画像に合わせたスタイルで動画を作る仕様になっているため、画風やキャラの維持に利用されている。下半身のリファレンス画像を渡すことで、局部的な描写崩れを防ぐ用途にも使われている。
- **Mystic LoRA / Turbo LoRA / 4step LoRA**
  - （>>145, 147, 209）動画生成・画像生成の高速化や補助に用いられるツール（LoRA）。
    i2vaで局部を描かせる際にはMystic LoRAを強度0.6でぶち込む手法が紹介されている。
- **x264guiEx**
  - **ツールが選ばれている理由**（>>165）
    AviUtlのプラグインとして動画をH264圧縮のmp4で出力するために使用。動画配信で一般的な設定ツールであるため、アップロード弾き回避のために選ばれている。

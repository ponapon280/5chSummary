### 抽出されたツールに関する話題

#### 1. ComfyUI (comfy)
**【メモリ・VRAMの最適化と高速化】**
* **ツールが選ばれている理由:** VRAMがカツカツな環境でも生成を安定させるため、またグラボの発火リスクを減らすためにメモリ削減の設定が使われている。
  * 「ComfyUI最新にしたら使えないノードとか出る？」（234）
  * 「SageAttention環境でLimiterとMemory OptimizationとSparse Attentionをデフォ設定のままつなげたら主張通りSageAttentionオンリーから生成時間半分になってVRAMが5GB空いたわ」（243）
  * 「みんなcomfyUIのメモリ削減やってないの？ 起動オプションに「--disable-pinned-memory」入れるだけで使用メモリ減って生成時間も変わらないからいいぞ ちゃんとしてればグラボは燃えない」（259）
  * 「生成でメモリ限界近くまで消費するようならpinned memory切った方がいいと思う やっぱSSDの寿命には変えられん」（305）

**【カスタムノード・機能拡張関連】**
* **ツールが選ばれている理由:** 標準の機能では対応できない新しいモデルやLoRAを動かすために、拡張機能やWorkFlowが利用されている。
  * 「>>88 入れてみたけど使い方がわからんな せめてサンプルワークフローつけて欲しいところだ」（240）
  * 「末尾_comfy版はカスタムloraローダーが必要なオリジナル版から現状のComfyUIのUNet/DiT構造に合わせたやつっぽいから使えるっぽいで」（258）
  * 「オリジナルの方はカスタムノードの制約があって使いづらかった」（266）
  * 「カスタムノードいるっぽい感じやね しかし高速化関連も次から次へと出てきて全然落ち着かんなあ」（271）
  * 「git fetch origin pull/15908/head:pdd-fix && git checkout pdd-fix したら標準LoraLoaderでAcc-Lora動いたやで まぁ待つのが正解やな」（278）

**【コミュニティ・用途関連】**
* **ツールが選ばれている理由:** エロ画像を公式に貼るチャンネルがないNAIなどと異なり、ローカル環境のComfyUIはエロ生成のコミュニティで盛んに利用されている。
  * 「NAIもComfyも公式にエロ絵貼るチャンネル無いしな」（414）

#### 2. LLM（大規模言語モデル）関連ツール（Qwen等の画像生成以外の話題）
**【Qwenシリーズ（LLM）】**
* **ツールが選ばれている理由:** 日本語の理解力が高く、プロンプト作成やエロテキスト生成に適しているため。
  * 「ワイはGemma4 12Bのuncensoredモデル使っとるで Qwenよりも日本語の理解力があるようやから、いい感じに出してくれるわ まあTEがQwenやからあんまりエロは出にくいんやけどな」（251）
  * 「qwen3.5だってさ ローカルで使うの無理かな」（393）

**【フリートークン / beellama / llama.cpp等】**
* **ツールが選ばれている理由:** ローカルのVRAM環境（3060など）に合わせて最適なエンジンや設定を選び、推論速度を稼ぐため。
  * 「フリートークンていう夢のソフトが出たみたいだから期待を持ってインストールしたけどワイの3060じゃ31Bの一番小さいやつすら動作しなかったわ 仕方ないからllamaで色々設定弄り回してやっとこさ4.5t/sまで来たけど3060じゃここら辺が限界？」（293）
  * 「あれはMoEだけが早くなるヤツだよ。26B-A4Bみたいなモデル選んだ？ もしDenseモデル使うなら別のエンジン使ったほうがいい beellamaでkvキャッシュ量子化をkvarn4にするとかなり良い」（312）

#### 3. llmfit系のサイト
**【モデル選定ツール】**
* **ツールが選ばれている理由:** 自分のPCスペックに合った量子化モデルや適切なエンジンを検索・選定するため。
  * 「このあたりでスペック入力して調べてみるのはどうやろ？どの量子化モデルがいいかまで分かるで llmfit系のサイトは多すぎてどれがいいのかよく分からんな」（238）

#### 4. MiniMax / H3 optimizations（動画・生成AI関連ツール）
**【最適化ツール】**

#### 5. Krea（Krea2 / Krea3）
**【画像生成ツール】**
* **ツールが選ばれている理由:** 細部描画やパース理解、背景力が高く評価されているため。またLoRA学習がしやすい点も理由として挙げられている。
  * 「Krea2キャラLoRA作成中 キャラLoRAはエロタグ使わないからDanbooruタグ未履修でいけるかなーと思ってやったけど服とか髪型は普通名詞だからOKだけど、やっぱahogeなんかは元が覚えてくれてないから精度が下がる」（327）
  * 「Krea2は細部描画とパース理解がやっぱりAnimaとは全然違うから(背景力が全然違う) 版権キャラ・絵師タグもガッツリ学習したKrea2チューンが来れば驚けると思う 来るかって話だけど、あと来ても生成用のTurboだけだと追加LoRA作れないから結局LoRA作りやすいAnima最強のままはありうる」（339）
  * 「寝て起きたらkrea3で盛り上がってるはずやな」（336）

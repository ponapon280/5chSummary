### ツールに関する話題

**1. ComfyUI / ComfyUI関連**
- **837**: Krea2でDLSS5のONとOFFを指示して試した。
- **843**: freetokenはメモリがカツカツでもMoEモデルが速く動いてくれるため助かる。GGUF対応が来たらLMStudioなどを使わなくなりそう。
- **854**: freetokenはsafetensors形式であることについての言及（CPU+GPU環境だからGGUFかと思っていた）。
- **856**: NVFP4とMXFP4は動くはずだが色々試すと全部は動くわけではない。`aabbas/Huihui-Ornith-1.5-35B-A3B-abliterated-NVFP4-freetoken`を動かしたら調子が良い。
- **849 / 858**: T2VA／I2VAでループGIFを生成するワークフローは面白く、動画生成においてワークフローの強みが輝く。
- **884**: 生成が終わったら音を出したいが、`play sound`ノードをどこに繋げばいいか分からない（「画像を保存」のImageに繋いでも音が鳴らなかった）。
- **889 / 890 / 895 / 896**: Deno Local LLM Loaderを使わずにLM Studioを使う理由についての議論。ComfyUIで生成中にLM Studioを使ってプロンプトの推敲ができるというメリットが挙げられている。
- **914**: ComfyUIのコミットログを見るとPDD LoRA対応があるが、中途半端なタイミングでpullしてトラブルが多いため、バージョンタグが付くまでは待つべきという判断。
- **916**: PDD Accはカスタムノードを入れて使ってみたところ、音やプロンプトの忠実度は他のターボと比べて良い感じである一方で、映像が結構グチャる（幾何学模様などは致命的）という報告。
- **934 / 935 / 936 / 939**: 初心者はdasiwaのワークフローを丸パクリすればいいかという質問に対し、「大人しくComfyUI公式のテンプレを使った方がええで」というアドバイス。公式テンプレは生成しかできないかというツッコミも。
- **938**: dasiwaの8stepを落としてクソデカワークフローを試して色々弄っているが、公式モデル(+4step loraを8stepで使用)とテンプレWFに比べて全然上手くいかないという報告。

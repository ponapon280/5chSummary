### スレッドから推測される流行のモデル動向まとめ

提供されたログ全体を総括すると、現在スレッドで最も流行し、活発に議論されているのは**「NovelAI (NAI) V5」**と**「MiniMax (H3系統)」**です。
NAIはローカル環境では到達困難な表現力や無検閲の強みから唯一無二の存在として絶大な支持を集めており、ローカル環境のモデル（animaやillustrious等）はNAI V5の再現や代替を目的とした比較対象として頻繁に言及されています。動画生成分野においては「MiniMax H3」およびその派生モデル（DaSiWa等）が覇権を握っており、ユーザーを没頭させるほどのクオリティと手軽さが評価されています。また、Krea2についてもLoRAを用いたエロ表現やパノラマ動画生成で一定の人気を集めています。

### 各モデルに関する詳細レポート

#### 1. NovelAI (NAI / NAI v5)
- **選ばれている理由 / 評価**:
  - 「絵柄の再現度、日本語の再現度、日本語で指示可能、大人数可能、漫画可能、背景上手い」という極めて高い表現力が評価されています（レス93）。
  - LoRAを作らなくてもドマイナーキャラの再現度が高い点（レス147, 148）や、アーティストタグを使わずとも「塗りをこうして」「顔を少し面長に」といった力業のプロンプトで指示通りに画像が出せる精度の高さが評価されています（レス630）。
  - インペイント（一部書き換え）において最も得意なモデルであるとの報告や（該当ログ3）、無検閲であり複雑で特殊な性癖の表現に適している「唯一無二の無検閲ツール」としての評価があります（該当ログ3）。
  - プロンプトに「SAMPLE」と入れることで無修正画像を見放題で生成できるハック目的で使われているという報告もあります（レス816）。
- **課題・懸念**:
  - V5のAnlas消費量について、普通サイズでも1枚30 Anlas消費するため「エグない」という意見（レス347）や、テキストエンコーダが「かなりアホ」であり、日本語プロンプトで書いても全然書いた通りの絵が出ないという指摘があります（レス361）。

#### 2. anima (アニマ)
- **選ばれている理由 / 評価**:
  - NAIに比べて「LoRAが比較的楽に作れる」メリットがあり（レス103）、SDXLやAnimaであればVRAM 8GBでも動くため間口が広くスペックの敷居が低いことが選定理由です（レス335）。
  - TURBOを入れることで解像度を上げるメリットがあります（レス284）。また、二次元生成において「child」というプロンプトを使っても安全なモデルとして挙げられています（該当ログ3）。
  - プロンプトがVRAMに全載せできる程度に軽く、ローカルLLM（Gemma4-E4B）にプロンプトを作成・思考させながら生成する用途と相性が良いとの報告もあります（レス769）。
- **課題・懸念**:
  - 背景に比べて人物のサイズが大きすぎて巨人に見える症状があるとの指摘（レス852）や、NAI V5相当の日本語能力を持つAnimaが来るまではNAIが上位に立つと見られています（レス346）。

#### 3. illustrious (イラストリアス / リアス)
- **選ばれている理由 / 評価**:
  - wild card（ランダム要素）を用いたエロ生成において「最も強い」と再確認されており、animaやkrea2以上に陳腐化せず今後も使われ続ける可能性が示唆されています（レス986）。
  - 「anytest」を効かせる目的でillustriousの利用を継続しているユーザーがおり、AnimaのanytestよりもILの方が効きやすいという意見から選定されています（レス684, 686）。
- **課題・懸念**:
  - NSFWの表現（特定の性器描写など）において苦手なモデルが多かったとの報告があります（該当ログ3）。

#### 4. MiniMax (H3系 / H3 Max / H3 Eros Max / MMH3)
- **選ばれている理由 / 評価**:
  - 動画生成モデルとして高く評価されており、最大30秒の長尺動画でも破綻しにくく「何でも作れる」と評価されています（該当ログ2）。H3を出してから試行錯誤する時間が楽しく没頭できるとの声もあります（レス981）。
  - ComfyUI上で8stepの設定で10秒動画を生成でき、かなりのクオリティが実現できる点（レス737）や、フローマッチングを用いているため将来的な1step生成の可能性がある点が評価されています（レス737）。
  - 参照静止画の性能が「ゲーエン級」でありループGIFの生成で活用されています（レス850）。
  - 超絶雑な数秒の音声サンプルを音声Refに入れるだけでLLMにセリフを従わせて音声を生成できる「超絶手軽さ」が評価されています（該当ログ1 >>63）。
- **課題・懸念**:
  - 解像度や秒数を上げるとOOMを起こすためVRAMが必要とされる点（該当ログ2）や、r2vは股間参照などで違和感が出やすく、動画参照が一番クオリティが高いが手間がかかる点が指摘されています（レス872, 874）。

#### 5. DaSiWa (DaSiWa H3 / DaSiWa 4step)
- **選ばれている理由 / 評価**:
  - 「dasiwaとdasiwa4stepの組み合わせは良い。崩れないわ」と評価され（レス838）、LoRAや参照画像を使うことで挿入の命中率が少し上がるため用途によっては選ばれています（レス908）。

#### 6. Krea2 / Krea3
- **選ばれている理由 / 評価**:
  - 公開されているエロLoRAやエロチューンを使う前提のモデルとして選ばれています（レス798, 823）。版権や画風を自前のLoRAで作成できる点が評価されています（レス798）。
  - 360ERPという機能やLoRAを用いてパノラマ画像・動画を作る用途で選ばれています（該当ログ2）。
- **課題・懸念**:
  - 素の状態ではエロ表現が壊滅的であり、学習コストなどの問題からエロチューン済みのRawとTurboがセットで公開されるモデルの出現が期待されています（レス798）。また、細部の描画とパース理解（特に背景力）が他モデルと全然違うものの、Turbo版だと追加LoRAが作れないという課題もあります（レス339）。

#### 7. Wan (Wan2.2)
- **選ばれている理由 / 評価**:
  - 動画同士の結合において「10erosよりもWAN2.2のVACE結合の方が普通に良い（使いやすい）」と評価され選択されています（レス184）。
  - VRAM拡大や生成時間短縮の恩恵を受けやすく、日々活用する価値があること（該当ログ3）、ループ動画生成なら悪くない点（レス893）が評価されています。Wanの3.0のオープンソース化にも期待が集まっています（レス892）。
- **課題・懸念**:
  - 動かす際にRAMを非常に消費（逼迫）し、PCのメモリ増設を検討するきっかけとなるほどのヘビーなモデルであることが指摘されています（レス727, 734）。

#### 8. LLM群 (Gemma4 / Dolphin Mistral / Qwen3.8 / GLM-5.3 / freetoken)
- **選ばれている理由 / 評価**:
  - **Gemma4 12B**: Qwenと比較して日本語の理解力が高く、良いテキスト出力が得られるため（レス251, 280）。
  - **Dolphin Mistral**: ユーザーの好みの柔らかい日本語トーンに合致し、カスタマイズしたシステムプロンプトでエロティックな文章を書かせるのに適しているため（レス280）。
  - **Qwen3.8 27B等**: 圧倒的な生成速度（80トークン/秒）とコーディング能力の高さ、指示を正確に守る事務的な性格が評価され、プロンプトの変換や複雑な要件処理に向いているとされています（レス724, 739, 752, 774）。一方で日本語が弱くクリエイティブな用途には不向きとの指摘もあります（レス759）。
  - **freetoken**: safetensors形式であり、MoEモデルがメモリカツカツでも速く動いてくれるため助かるとの声（レス843, 854）や、NVFP4対応モデルが調子良いとの報告があります（レス856）。
- **課題・懸念**:
  - **GLM-5.3**: 一番小さいサイズでも220GBと巨大であり、ローカル動作のハードルが高く「APIで触るべき粗大ゴミ」と扱われています（レス885, 887, 894）。

#### 9. その他のモデル (Swift image / swifi image / LTX / Z-Image / FLUX)
- **Swift image (swifi image)**: アリババの新作モデルで、今後のローカルAIの進化を牽引する存在として期待されています（レス154）。アニメモデルの覇権を取る可能性があり、宣伝文句通りであればFLUX2 kleinの完全上位互換になり得ると推測されています（レス341）。
- **LTX**: nvfp4環境において「ほんとに速い」と評価される一方で、品質面は「うんまあ…って感じ」であり、リアルタイム以下の生成を謳った「LTX2.5」はいまいち話題になりませんでした（レス78, 79）。
- **Z-Image**: 実写系の生成において「一番可愛いミニ系」が出るため、redcraftのturbo loraとの組み合わせで選ばれています（該当ログ3）。
- **FLUX.2 KLEIN**: AMD環境（ROCm 10.0）向けにComfyUIでのパフォーマンス最適化が行われている有力モデルとして認識されています（レス818）。

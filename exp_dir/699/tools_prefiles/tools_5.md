# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI / Comfy

- **MCP連携**: comfyはMCPを使って動かすとトークンが安く済む（977）
- **カスタムノード開発**: 複雑なカスタムノードのデバッグにAstraを使用している事例（951）。またAstraをPhotoshop作成やGTA5作成レベルのフルスクラッチ用途ではなく、カスタムノード作成・ウェブアプリ作成にはSolで十分との使い分け指摘（948）
- **本体設定とノード**: Desktop版で本体設定で指定していたものをノードを使うように変更。VAEファイルの差し替えだけで大きく短縮され、fp16_accumulationの効果は極わずかだった（967）

## ノード関連（高速化・不要化）

- **attention系ノードの低速化**: attention系ノードが低速化の原因になることがある。対象者の環境ではsol attnもkitchin attentionも外した方が明確に早くなり、高速化ノードはspectrumだけでよくなった（852）

## Blender連携

- **Blender連携の実用性**: 結構前からできていた。Astraが飛び抜けて上手いということもなく、実用にはまだ程遠い（957）
- **BlenderとAIの組み合わせ**: animaの画像をx5 AstraでBlenderの素材にし、x5 Opusでゲームのコーディングをさせる使い方を検討。Tripoは無料で触ったがイマイチだった（959）
- **Opus5.5のBlender使用感**: Opus5.5はAstra並かそれ以上にBlenderを使いこなしている感がある（956）
- **3Dエロモデル**: クラウドでよければTripoでNSFW可能。ただし課金していてもNSFWコンテンツは3日ほどしか保存されない（966）。Meshyだとビキニ程度でもアウト判定になる（972）

## LLM（動画プロンプト作成・翻訳用途）

- **動画用プロンプト作成**: 公式のシステムプロンプトを覚えさせて公式書式で作るより、必要な指示をした上で簡単なストーリーを日本語で書き、LLMに英語翻訳してもらう方が精度の高い動画ができる。公式書式だと指示してないことまで膨らませがち。LLMに投げるとプロンプト用の翻訳パターンを複数出してくれる（847）
- **英語苦手対策**: 日本語プロンプトをLLMに翻訳してもらえばよい。大事なのはリビドーの中身と表現力であって言語の種類は今やどうでもいいレベル（923）
- **自然言語プロンプトの省力化**: めんどくさい自然言語プロンプトはLLMに投げる（970）
- **krea2テンプレのサブグラフ内LLM**: krea2テンプレのサブグラフに入っているLLMを使っているが、あれでよいのかという疑問（973）

## GPT / Codex / Claude（コーディングツール）

- **GPT Plus制限**: GPT Plusの使用上限に到達し、GPTが使えなくなるとゴミムシ以下になる（924）。5時間制限でストップ中（964）
- **Astra Ultraのトークン消費**: Astra Ultraは100万トークン50ドルのAstraで影分身してタスクに当たるモードのためすぐ無くなる。報告によると1000以上のサブエージェントを起動する例もある（933, 937）
- **Astraの使い分け**: Astraは難易度の高いタスク（システムやゲームのフルスクラッチレベル）限定。カスタムノード作成やウェブアプリ作成はSolで十分。会話系ならLunaでも十分（948）。Astra High以上は大規模でぐちゃぐちゃなソースコードをレビューする用途（960）
- **Sol Highの過剰性**: Highは余計に複雑に思考したり本質的でない些細な問題を取り上げがちで出力も肥大化しコストがかかる。デバッグや要件がはっきりしているものはLowの方が良い結果になりやすい（954）
- **Astraのリモート操作**: リモート操作させると秒速でトークンが溶ける（976）
- **コンピューターユーズ**: コンピューターユーズを使うようになってからトークンの減りが爆速。x5だと全然足りない（975）
- **GPT6 Sol High**: GPT6 Solの高を使ってみたがGPT5.6 Solの最大の方が性能が良い気がする（963）
- **CodexとClaude Codeのバグ**: CodexやClaude Code自体がバグっていてキャッシュトークンが効かない時もある。XやGitHubのIssueを監視する必要がある（941）
- **GPTとClaude併用**: anima画像をAstra x5でBlender素材にし、Opus x5でゲームコーディングさせるか、Claude x20だけの方がよいか検討（959）
- **Astra Work制限**: AstraはWorkとCodexでしか使えない。Chatの方は5.6 Solまで。Work Astraのまま画像生成を続けたら4枚くらいで制限が来た（938, 943）
- **Pro契約**: Pro契約すればAstra（6）Proが呼べる（944）

# 🆕 新規トピック（前回からの差分）
### ローカル vs クラウドの対立地図
- NAI v5は日本語対応やエロ表現に強いが、低解像度とLoRA不可が弱点であり、本質的な価値は「手間の削減」にある(666, 667, 714, 759, 769, 778, 920)。
- 高価なGPUによるローカル構築のハードルと、クラウドサービスのコスト・制限による「AI格差」が話題となっている(33, 80, 670, 673, 679)。

### ComfyUI・パフォーマンス最適化の争点
- Block Sparse Attention実装によりRTX40xx/50xxで品質・速度が向上するが、新ノードへの更新が必要で、`Sol-Attn`使用時の背景変化を避けるため`top-k(SLA)`への変更が推奨される(241, 319, 395, 586)。
- マネージャー安定版ではSparse Attentionが入らず、開発版での更新が必要なため、バージョン番号の逆転により混乱が生じている(687, 689, 693)。
- TRT VAEはFP16精度で効率的だが、Fast VAE最新版での画面暗化不具合や、速度測定時のキャッシュ影響への注意が指摘されている(242, 244, 246, 594)。

### AI音声（TTS）の権利問題とツール動向
- 声優コピー目的のためレビューが困難であり、日本国内ではTikTokでの事例もありNGとの認識がある(299, 307)。
- AI生成声は手描き二次創作のような信用・実績の歴史がなく、版権へのフリーライドとして批判されやすい(316)。

### AIエージェント・クラウドの制限と活用
- 高度なモデルほど思考の深さを明示的に指定する必要があり、Claude等の検閲やローカルLLMのガードラインによる拒否が発生する(25, 27, 42, 565, 811)。
- Astraの制限強化（5時間リミット）や、CodexによるComfyUI管理への高い依存度が挙げられている(33, 80, 543, 548)。
- トークン削減によるコスト抑制と精度向上、および定型・非定型作業の切り分けが重要とされる(153, 157)。

### ハードウェア・市場動向
- RTX 5090は80万〜100万円程度でさらなる値上がりが予想され、AIバブルの状況とグラボ入手・モデル普及のジレンマがある(480, 572, 686, 799, 577)。
- グリス塗り直し後のホットスポット高温化や、5090の重量によるケース破損、フィルター欠如による吸塵問題が報告されている(78, 822, 823)。

### 総評
- ローカル勢と非保持層の間で、NAI等の評価を巡る「驚き屋」による対立煽りが常態化している。
- Block Sparse AttentionがRTX40xx/50xxで標準化しつつあるが、バージョン管理の混乱やノード選択による作画崩れが起きている。
- AI音声生成は、手描き二次創作が持つ「信用・実績の歴史」を欠くため、版権フリーライドとして厳しい批判を受けやすい認識が共有されている。

# 元の本文
今回とくに盛んに議論された話題は、ローカル（Anima等）対クラウド（NAI等）の優位性をめぐる対立と、ComfyUIにおけるSparse Attention導入を含む高速化ノード周りの設定仕様である。
※以下のレス番号は統合元パート内の通し番号であり、元スレの通し番号とは限らない。

## 1. ローカル vs クラウドの対立地図
- **NAIの評価とローカル勢の反応**: NAI v5は日本語プロンプト対応、自然な日本語文字入れ、fullbody SEXやパイズリ等のエロ表現に強いと評価される一方(666, 667, 759, 778)、解像度の低さやLoRAが使えない点が致命傷と指摘されている(714, 769)。NAIの優位性は画力そのものではなく、ローカルで複数LoRAやCNを使う工程をプロンプトとガチャで完結できる「手間の削減」にある(920)。
- **対立煽りと「驚き屋」**: NAIの画像が投稿されると品評会が始まり(660)、「NAI否定がー」と対立を煽る書き込みが定番化している(836, 895)。「クラウド型が進化してもらったら困る」等の主張に対し、他住人から「主語がデカい」「アフィ用コメント」と批判された(712, 755, 777)。PCを持たずサブスクで済ませる層がローカル（特にAnima）に風当たりを強くしているとする見方もあり(249, 270, 285)、ログまとめをアフィサイトが作っている可能性も指摘されている(801, 815)。
- **コストと格差**: ローカル環境構築には数十万のPCが必要でGPUは高級品となっており敷居が高い(670, 679)。一方でAstra等のクラウドサービスも高コストやリセットによる制限が厳しく、AI格差が話題になる(33, 80, 673)。

## 2. ComfyUI・パフォーマンス最適化の争点
- **Sparse Attention / Block Sparse Attention**: Comfy Kitchen attentionとBlock Sparse Attention実装により、RTX40xx/50xx環境でsageより品質・スピードが良いという報告がある(241)。一方で古いノードのままだとエラーで動かず新ノードへの入れ替えが必要(586)。selectionを`Sol-Attn`にしていると不自然に固定背景が変化する問題が起きるため、`top-k(SLA)`に変更してkeep percentを20まで上げるべきとされている(319, 395)。
- **ComfyUIのアップデート不備**: マネージャー経由の安定版（V0.34.6）では実験機能のSparse Attentionが入らず、最新機能を使いたい場合は開発版（V0.34.0）の`update_comfyui.bat`で更新する必要がある。番号管理の逆転により混乱が生じている(687, 689, 693)。
- **VAE・速度測定**: TRT VAEはFP16精度のため、int8 convと速度が同じならTRTの方がお得との指摘(246)。Fast VAE Comfy V0.31では爆速だったが最新版にしたら生成物がやたら暗くなる不具合も報告されている(594)。また、速度測定は1周目のキャッシュ影響を考慮し、プロンプトやサイズを決めておかないと感覚頼りになる(242, 244)。

## 3. Animaの生成・LoRA学習の課題
- **Anima 2.9B / 3.8Bの評価**: 2.9Bはデータセットが新しくLoRAなしで今年のキャラが出る点や、作者がLoRA作成ツールを作っているためFTに期待できるとの指摘がある(947, 956)。一方で3.8Bは専用拡張機能が必要でテキストエンコーダー追加したLoRAツールがないため不評(956, 971)。
- **LoRA学習の個性消失と対策**: 学習素材の枚数を増やすとマスピ顔に寄って個性が死ぬ問題が報告されている。劇場版素材を70→45に減らして再学習したところ素材に近づいた(430)。画風プロンプトがなくても学習可能だが、Danbooru定義キャラタグ（`hoshino ruri`等）が入っていると上手くいかないため消去して学習する必要がある(212, 235)。
- **最適化アルゴリズム**: CAMEで上手くいかない場合はRAdamSchedulefreeを試すのが推奨される(443, 445)。CAME学習ならウォームアップは不要との指摘(402)。素材が多い場合はエポック（煮込み時間）か学習強度（火力）を上げる必要があるが、時間を増やすのは厳しいため学習強度をメインに強化すべき(450)。
- **Animaの画像崩れ**: i2iアップスケールでひび割れた画像が生成される問題は、2個目のKサンプラーにnegpip通してないモデルが入っているとマイナス指定がおかしくなるのが原因(136, 140)。背景が真っ黒になる問題は教師画像の透過pngが過学習を起こすため、白背景化か`black background`タグの追加が必要(206, 207)。

## 4. AI音声（TTS）の権利問題とツール動向
- **Irodori-TTS**: v4.1リリース。`4.1`と`4.1 small`は別物で、Animeは派生FTモデル(202, 213)。絵文字での反応が向上し、ささやきが出やすい(328)。ただしComfyUI未対応（V3までしか対応しておらず公式対応待ち）という不満がある(73, 75, 108)。
- **権利・版権問題**: 声優コピーが目的のため大っぴらにレビューできない事情がある(299)。Tiktokで声優のAI声を使って大暴れした者がいたため日本ではNGという認識(307)。AI生成声は手描き版権二次創作の信用・実績にフリーライドしておらず歴史がないため批判されやすい(316)。

## 5. AIエージェント・クラウドの制限と活用
- **LLMの制限と検閲**: 高度なモデルほど簡単な問題を複雑に解決しようとするため、利用者が明示的に思考の深さを指定する必要がある(25, 27, 42)。Cloude等はワークフロー修復時に指定箇所以外のエロワードも見ていて次回の作業を拒否することがある(565)。ローカルLLMでもセーフティガードライン違反でエラーが出る(811)。
- **Astra/Codex**: Astraは5時間リミットがすぐ来るようになり制限が強化されている(33, 80)。ComfyUI丸ごとCodexで管理しているユーザーもおり依存度が高い(543, 548)。
- **コスト削減**: トークン削減はコスト削減だけでなくコンテキストを減らしてAI精度を上げる役にも立つ。推論が必要な非定型作業とスクリプト化できる定型作業の切り分けが重要(153, 157)。

## 6. ハードウェア・市場動向
- **GPU価格とRTX 5090**: 5090は現在80万〜100万程度。ドスパラは一ヶ月前より値上がりしており、グラボはさらに10%値上げするとされる(480, 572, 686, 799)。AIバブルが弾けないとグラボは買えないが、弾けると高性能なローカルモデルも落ちてこないジレンマがある(577)。
- **パーツの物理的問題**: グラボのグリス塗り直し後、電力制限してもホットスポットが100℃近くになる問題(78)。RTX5090の重みでケース部品が外れる報告や、ダストフィルターがなく埃を吸う問題も指摘されている(822, 823)。

## 総評
- ローカル環境を持たない層とローカル勢の間で縄張り争いが激化しており、NAI等のクラウドサービス評価を巡って「驚き屋」による対立煽りが常態化している。
- ComfyUIのBlock Sparse AttentionはRTX40xx/50xx環境でsageより有利になり標準化しつつあるが、安定版と開発版のバージョン番号逆転やノード選択による作画崩れ（Sol-Attn問題）によりユーザー間で混乱が生じている。
- AnimaのLoRA学習では学習素材の過剰な枚数がマスピ顔への寄りを引き起こすことが判明しており、既存Danbooruタグの排除や学習強度の見直しといった対策が模索されている。
- AI音声生成（TTS）における声優の版権フリーライド問題が意識されており、手描き二次創作にはある「信用・実績の歴史」がAI声にはないため厳しい批判を受けやすいとの認識が共有されている。

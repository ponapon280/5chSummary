# 生成AI関連ツール話題 抽出レポート

## ComfyUI (comfyUI / comfy)

### ノード・機能に関する話題
- **Block Sparse Attention / Model Sparse Attentionノード**: ComfyUIでBlock Sparse Attentionが検索で見つからないという問題が報告され、ノード名がModel Sparse Attentionに変更されたことが判明した（654）。このノードは拡散モデル読み込み後に直列で配置し、Model Sparse Attentionノードでsol-attnを選択することで速度向上が図れる。nodes_sparse_attention.pyをAIに読ませてパラメータ解説させる運用が紹介されている（683）。
- **ComfyUIのバージョン管理の問題**: マネージャー経由のアップデートではV0.34.6（安定版）が入り、Model Sparse Attention等の実験機能は含まれない。一方、update_comfyui.batで更新するとV0.34.0（開発版）が入り、実験機能が使える。リリース番号管理の方が機能的に先行している。マネージャー経由更新後にupdate_comfyui.batで更新すると、配置したModel Sparse AttentionノードがBlock Sparse Attentionに名前が戻り赤枠が付く現象も報告された（687,689,693）。
- **デスクトップ版**: デスクトップ版の安定版にはModel Sparse Attentionノードはまだ来ていないと推測されている（694）。

### ローカルLLM統合
- ComfyUIでローカルLLMを導入しようとしたが、エラー「This violates core safety guidelines regarding sexual abuse and violence.」が出て使用不可となった（811）。検閲に引っかかっているだけであり、オープンモデルでも検閲がないわけではなく、クラウドより厳しいこともある（812）。非検閲モデルを使うか、チャット利用なら脱獄は容易だが1発出しのプロンプト生成なら非検閲モデルに任せるべきとされた（813,814）。

### ワークフロー・運用
- ComfyUIを更新中の状態や生成中であることが多く、ネタ画像を即座に出す用途ではクラウド型が便利とされている（781）。
- comfyUIに移行を検討する声がある（641）。

## MMH3

- MMH3で参照<picture 1>スタートで問題なく生成できるが、背景を入れ替えると参照と違う人物になる問題が発生。原因は背景プロンプトにマスピ（美人化）が入っていたため（636）。
- MMH3のref（参照）機能を使えば特定キャラのネタ画像作成が可能かもしれないという期待がある（782）。

## Krea2

- Krea2でLLMとやり取りしながら参照用静止画を作成している。Krea2の静止画が十分にエロいため、動画生成まで進まない現象が報告されている（669）。
- Krea2は自称エロファインチューンがありDanbooruタグでエロが可能だが、TurboしかないためLoRA追加が不可で使い道が限定的とされている（776）。
- スレ上では「最強はKrea2の二次エロファインチューンでRawとTurboが来ること」という期待があるが、「来ない」とも付けられている（680）。

## その他のツール関連話題

### Codex / coding系ツール
- Codexにお願いして選択肢を選ぶだけで動画を再生するゲームの一部分が作成できた。Plusプランのため完成まで上限に達する可能性がある（643）。
- Codexが生成画像の削除・間引きをしてくれたら完璧という運用構想がある（788）。

### GPT Image (gpt-image-2.5)
- GPT Image 2.5が唐突にリリースされた（701,702）。
- API利用だと金銭的格差が生じると指摘されている（711）。
- 2.0より規制が強まっており、エロ面では劣化。2.0で通ったものがほぼ全滅、水着も不可。ただし一部では通ったという報告もあり（720,725）。
- 文字を見やすくするためにアップスケールをかけている。Solへの指示出しが悪かったため情報過多になったとの報告がある（722）。
- 設定資料集を作らせて下着を出せる機能は健在（790）。

### チャッピー (ChatGPT等)
- チャッピーにブラウザ起動時にサイトをチェックして100%になったら通知するアドオンを作らせる提案がある（647）。
- チャッピー使用中に画像強化のメッセージが来たとの報告がある（702）。

### Sol (gptsol)
- gpt-image-2.5でSolへの指示出しに関する言及がある（722）。
- gptsol6が来たら漫画制作がさらに良くなりそうという期待がある（791）。

### 画像フォーマット・メタデータ流出対策
- Pixivはワークフロー含めたメタデータを全て載せられるがwebpは投稿不可のため、webpで普段生成しておけばウッカリ流出対策になる。DeviantArtもwebp禁止（633）。
- 普段jpgで出力していれば渋投稿でメタデータ流出を気にしなくて済む（638）。
- AVIFのAAが貼られている（659）。

### うごイラ対応要望
- webpかmp4をうごイラに対応してほしいという要望がある（638）。

### 生成サイズ・解像度の実績値
- ローカル常用サイズ: 1680×2160、1280系の1120×1440の1.5倍hires。4Kモニタのため縦2000以上を希望（766）。
- 2MP（2048x1152, 1152x1728）ポン出しを縦横2倍拡大して8MPにしている（785）。

# 生成AI関連「ツール」話題抽出レポート

## ComfyUI / ComfyUI関連

### Sparse Attention / Attention系ノード
- **公式Sparse Attentionノード登場**: 他のノードと同程度の速度が出るため、これで十分という評価（レス30）
- **Comfy Compilerマージ**: MMH3等でメモリ周りの最適化が実施（レス35）。ただし`--disable-comfy-compiler`で起動落ちを防止する回避策も（レス58）
- **Block Sparse Attentionノード**: Sol-Attn(adaptive tau)、top-k(SLA)、VSA(FastVideo)のセレクタ付き。これらはすべてSparse Attentionの一手法（レス87）
- **comfy-kitchen**: comfy公式実装。version 0.2.32以上が必要（レス159）。SageやSolからcomfy公式のKitchenへの乗り換え報告あり（レス93）
- **選ばれている理由**: Sage Attention/Solとオサラバ可能。VRAM 12GB/16GB環境での鉄板フローは「Loader - ModelAttentionBackend（comfy kitchen attention）- Block Sparse Attention（top-k(SLA)）- MiniMax H3 Chunk FeedForward - ModelSamplingMiniMaxH3」（レス101）。Sage+sol+spectrum環境で50分かかっていた処理について、最適設定やcomfy-kitchen更新状況が議論される（レス146, 172, 185）

### Sage Attention / Sol / spectrum
- **Sage・Sol削除**: 不要ノード整理と合わせて起動が大幅に早くなる（レス90）
- **VDN+spectrumに落ち着く**: comfy公式実装前に一通り全部使った結果（レス96）
- **turbo系の品質低下懸念**: SageAttnとSolを使っているが、比較する気力はないという意見（レス99）

### 3D生成対応
- **Trellis.2とPixal3Dのnative対応**: ComfyUIが対応。Geminiキャラを立体出力し、Blenderに飛ばしてリグ設定も可能（レス144）

### TTS対応
- **Irodori-TTS-v4.1-Anime / smallのComfyUI未対応問題**: なぜComfyUI対応してくれないのか、読み込ませるとエラーになる（レス73, 75）。後に「comfyuiがV3までしか対応してない」「公式でやるしかない」との報告（レス106, 108）

### アップスケール問題
- **Animaでi2iアップスケール時にひび割れ発生**: アップスケール前は正常だが、アップスケール開始でおかしくなる（レス125, 126）。原因はnegpipのつなぎ方（2個目のKサンプラーにnegpip通してないモデルが入っている）と判明し、修正成功（レス136, 138, 140, 143）
- **対策としてpixelsharpenやArtClarityを1xで処理**: リアス時代の肌ひび割れ対策と同手法（レス168）

### その他ComfyUI関連
- **Astraの5時間リミット問題**: 15分で5時間制限に引っかかるようになり、Proプラン加入検討（レス33, 80）
- **VAE Decode時間短縮**: MMH3で有益な情報があるとの言及（レス61）
- **H3使用中に本体がKILLされる問題**: 100件更新ごとに最新クローンする設定で治った可能性、ライブプレビュー死は別件（レス223）

## Blender連携

### プレビズから動画生成
- **Blenderプリビズを動画AI参照に使用**: Higgsfield等がやっている手法をCodexに試させた結果、ある程度まで可能（レス149）
- **分業体制**: Astraで監督役、TerraでBlender操作、LunaでMinimaxへのキュー投入役。Plusプラン5時間枠で数秒カットが精一杯（レス149）
- **コスト課題**: 全任せはトークン消費がマッハ。定形作業のスクリプト化と推論作業の切り分けが必要（レス151, 153, 154, 155）
- **低解像度動画参照による時間短縮**: 512x288の低解像度で位置関係・カメラのみ読ませる。5秒動画が140s→280s、15秒動画が700s→1000sに増加するが、構図制御の見返りとして許容範囲（レス163）

### 3Dモデル生成ワークフロー
- **Codexで三面図→Blender 3Dモデル**: まともな三面図が生成されるが、Blenderへの3Dモデル作成指示で個性的な造形になる（レス49, 66, 67）
- **改善プロンプト提案**: 別の批評エージェントを起動しスクリーンショットで0-10スコア付け、8以上になるまでループさせる手法（レス54）

## minimax (動画生成ツール)

- **r2vで画像素材は成功するが動画素材は重い**: キャラを動画に埋め込むと激重で時間かかる、解決策求む（レス64）
- **Turbo使用時の劣化**: セリフ（音）や日本語文字描写の劣化が激しく、step盛りが必要（レス102）
- **RegenAudio**: rediのH3版を参考に試した結果、8stepでは入れ替え必要性薄いが4stepならあり（レス198）
- **Blenderプリビズ参照でクオリティアップ**: カメラワーク制御や細かい調整に有効（レス149）

## T2VA

- **チャッピーでT2VAに15秒英語字幕付け**: `&quot`とフォカヌポウコピペを使用。舞台を大学の廊下にして通行人を歩かせる指示でエキストラが勝手に生える。加工なしで早口で喋らせられる（レス32, 41）

## Seedance

- **空間プロトタイプ制作→動画AI流し込み**: 整合性や動きをコントロールする手法として面白い評価（レス103）

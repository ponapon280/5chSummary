# なんJ AIスレ ログ要約レポート

## 1. Anima (動画/画像生成モデル) 関連

### AnimaYume v1.5 リリースと挙動
- **v1.5登場**: 「finalで死んだはず」のAnimaYumeだがv1.5がリリースされている(>>55)。2026年6月までのデータセットを使用しているらしい(>>76)。
- **LoRA互換性**: v1.0で学習されたLoRAが正常に機能しなくなる可能性がREADMEに記載されているが、実際に触った感じでは「まあ動くっちゃ動く」程度。ただし書き込み量が弱く、turbo1個12stepsでは弱く、turbo2個突っ込んで12stepsでまあまあの書き込み量になる。低スペ環境では厳しい(>>85)。
- **作者コメント**: 現アーキテクチャの主なボトルネックはLLM Adapterであり、これを削除してQwen 3 0.6BをQwen 3.5 2Bに置き換えるCosmosバリアントを開発中。v1.5は安定性やAIアーティファクトを低減させている(>>85, >>91)。

### Anima LoRA学習の課題と対策
- **個性が死ぬ問題**: 劇場版84枚・TV版25枚を一緒に学習させたところ、特徴は再現されるが個性が死に、マスピ顔に寄ってしまう。劇場版素材が特に酷く、TV版は強度1.5でギリギリ見れる。学習素材は1キャラあたり多くても30枚が適正ではないかという仮説(>>187)。
- **学習設定の具体的アドバイス**:
  - 109枚で100エポック(10900ステップ)、0.06ウォームアップ(654ステップWA)という計算(>>196)。
  - キャプションに画風吸わせるタグ(`1990s (style)`, `official art`, `kidou senkan nadesico`, `@yamaoka shin'ichi`等)が無い可能性を指摘。CAME 4e-5で500ステップconstantで走らせてテスト推奨(>>196)。
  - 劇場版とTV版でトークナイザ分割時にタグが混ざらないよう、絵柄・IP名・キャラ名を分ける工夫を提案。例: 劇場版は`@rumov, ndsc rumov, ruri`、TV版は`@ritv, kidou ritv, riru`(>>199)。
  - dimとalphaが低すぎる可能性を指摘。civitaiで画風LoRA1位の人はdim32/alpha32のcosine、CAME設定が多い。alpha=dimの設定や、LRを3e-5に下げてdim16/alpha16(またはdim32/alpha32)を試すよう推奨(>>203)。
  - 画風LoRAの具体例: `32dim/32alpha CAME 3e-5 48images(x1024) cosine 960steps`で学習した例を提示(>>205)。
  - フローシフトを2ぐらいまで上げると良くなる可能性(>>211)。
  - 学習タグにDanbooruで定義されている既存キャラタグ(例: `hoshino ruri`)が入っていると上手くいかない場合がある。学習タグからDanbooru定義キャラタグを消去して学習すると解決したとの報告(>>212)。
- **背景真っ黒問題**: Animaで背景が真っ黒になりやすい問題について、Turbo使用、マージモデル使用、拾ってきたLoRAの影響が疑われる。教師画像に透過pngが多いと「透過png=黒背景」で過学習が起きるため、白背景で保存し直すか`black background`タグを付ける必要がある(>>206, >>207, >>210)。

### Animaのアップスケール問題
- i2iアップスケールでひび割れたような画像が生成される問題(>>125, >>126)。
- 対策: 2個目のKサンプラーにnegpip通してないモデルが入っているとマイナス指定がおかしくなる。CLIP NEGPIPかPowerLoraLoaderからモデルの線を2回目のサンプラーに繋ぐ必要がある(>>136, >>140)。
- pixelsharpenやArtClarityを1xでアップスケール前に処理すると緩和される可能性(>>168)。
- 2個目のKサンプラーにはシンプルなプロンプトだけ入れた方が良い(>>135)。

## 2. MiniMax H3 / ComfyUI 関連

### Sparse Attention / Comfy Compiler
- **公式Sparse Attentionノード**: ComfyUIに追加された。他のノードと同じくらい速度が出るため「もうこれでええな」(>>30)。kijai版として追加された(>>71)。
- **Block Sparse Attention**: セレクタ付きで`Sol-Attn(adaptive tau)`、`top-k(SLA)`、`VSA(FastVideo)`を選択可能(>>87)。
- **推奨設定**: 
  - VRAM 12GB/16GB環境では`Loader - ModelAttentionBackend(comfy kitchen attention) - Block Sparse Attention(top-k(SLA)) - MiniMax H3 Chunk FeedForward - ModelSamplingMiniMaxH3`が鉄板(>>101)。
  - comfy-kitchenはversion 0.2.32以上が必要(>>159)。
  - Sparse Attentionはそれ用に作られたモデル専用であり、公式配布モデルを使う場合はsage+sol attnを使うべき(>>84)。ただしcomfy公式っぽいKitchenに乗り換え推奨、sageじゃなくcomfy kitchenを使う(>>94)。
- **Comfy Compiler**: 2日前にマージされ、MMH3等でメモリ周りの最適化がされている(>>35)。`--disable-comfy-compiler`で激遅issueの落ちを防止できる(>>58)。
- **性能比較**: sage+sol+spectrumの組み合わせで50分かかったという報告に対し、RTX40xx環境では効きが悪い可能性が指摘された(>>146, >>185)。spectrumはステップ計算を端折るためTurboに近い立ち位置で劣化も相応にする(>>173)。

### MiniMax H3の生成品質・Tips
- **Turboの品質**: Turboを使うとセリフ(音)や日本語文字描写の劣化が激しい。step盛らないとダメ(>>102)。
- **VAE Decode時間短縮**: MMH3でVAE Decode時間を減らしたいニキ向けの有益情報があるという言及(>>61)。
- **ネイティブ解像度**: H3のネイティブ解像度は1344x768。それ以上を直接出力した際のプロンプトの効き悪化についての懸念(>>63)。
- **RegenAudio**: rediのH3 RegenAudioを試した結果、8stepでは入れ替えの必要性は薄いが4stepならあり(>>198)。
- **電マ表現**: MMH3で電マ先端の振動は難しいが、デカパイに押し当てて高速振動させることは可能(>>113, >>130)。

## 4. 3D生成 / Blender連携
- **ComfyUI native対応**: Trellis.2とPixal3Dにnative対応。Geminiちゃん画像を立体出力し、Blenderに飛ばしてリグ設定もできた(>>144)。
- **Blenderプリビズ→動画生成**: MiniMax等でBlenderプリビズを参照に使ってカメラワーク制御やクオリティアップを図る手法。Astra(監督役)、Terra(Blender操作)、Luna(MiniMaxキュー投入役)で分業しているが、Plusプラン5時間枠で数秒カットが精一杯(>>149)。
- **低解像度参照**: FHD動画参照は時間がかかるため、位置関係やカメラ情報だけAIに読ませたいなら512*288の低解像度で十分。5秒動画が140s→280s、15秒動画が700s→1000s程度の変化(>>163)。
- **3D生成プロンプト**: 別の批評エージェントを起動させてスクリーンショットを撮影し0-10でスコア付け、8以上になるまでループさせる手法を提案(>>54)。

## 5. AIコーディング・エージェント関連
- **高度なモデルの問題**: 高度なモデルほど簡単な問題を複雑に解決しようとする。確認作業をすっ飛ばして最短でやる手順書を作らせる、またはAI側にとってやりやすい指示を出すべき。「無理ンゴ」しなくて無理やり作ろうとして遠回りする(>>25, >>27, >>28)。
- **思考量設定**: AI自身に問題の難易度と思考の深さを決めさせると怠け始めるため、利用者が明示的に「これくらい考えろ」と指定する必要がある(>>42, >>43)。
- **フレーム問題**: 現状は力業で突破しているような状態(>>44)。
- **Codex試行**: LTX2.3の音声loraをMMH3に移植させようとしたが力尽きた。「普通に音声学習した方が早くね？」と言われる(>>38)。
- **文字化け問題**: バイブコーディング中に文字化けに悩まされる(>>19)。

## 6. クラウドサービス・制限関連
- **Astra制限強化**: 5時間リミットがすぐ来る。昨日は30分以上走せられたが今日は15分で5時間制限に引っかかる(>>33, >>80)。Proプラン加入の検討(>>33)。

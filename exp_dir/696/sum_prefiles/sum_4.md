# 匿名掲示板ログ レポート

## 1. 音楽生成AI「YuE」関連
- YuE2がComfyUIでサポートされたとの見方がある（625, 633）。
- audio.cppのdevブランチ（およびmainブランチ）で動作可能であり、Linux+Radeon 7800XT+ROCmやmacOSでも動く見込み。公式実装はCUDA用（674, 675）。
- YuE2を「Sunoもう要らない」と絶賛する声がある一方（627, 711）、「音も悪いし声も悪いしで正直使い物にならない」「音質がどうこうとかYue2はFlow-VAEでもない時点で有り得ん」等の否定的な意見も複数ある（687, 691, 699, 701）。
- YuEはローカルでabc譜を出せる点が評価されており、同時リリースされたsheetsage2も良い性能とのこと（710）。
- 効果音や環境音（雨音、雷など）を作りたいという需要があり、H3で超低解像度生成して音だけ取り出す手法が提案されている（646, 648, 652）。

## 2. ComfyUI / UI環境の趨勢
- 新モデルのゼロデイ対応等でComfyUIだけ先に進んでおり、webUIは終わりとの見方がある（653, 681）。
- ComfyUI Desktop版の使い勝手が良く、インスタンス複数作成、スナップショットによる復元、フォルダ追加の容易さから推奨する声がある（739, 746, 769）。
- Context Loop（旧Contex Loop）はGit pullでそのまま更新可能。ただしコンテキストを12000消費するため1回の出力しかできず修正に難がある（724, 728, 738, 803）。
- カスタムノードは公式とkjnodesだけ入れておけば大抵のことができるという意見がある（753）。

## 3. LM Studio / Gemma関連の不具合と対策
- LM Studioを0.424 build1にアップデートした際、Gemma（4 12B, 4 26B等）で画像読み込みや大きめの要求をするとterminatedエラーが発生し強制イジェクトされる問題が報告されている（669, 672, 678, 679, 683）。
- 対策として、評価バッチサイズを512に下げると動くとの報告がある（736）。また、アップデートで追加されたllama.cpp argumentsの項目を触らなければ発症しないという報告もある（822）。

## 4. LoRA学習の検証
- Anima LoRAの学習でdim/alpha 32/32を検証。16/8では薄味の別キャラになってしまうが、32/32では原画寄りになり、服飾のイメージや立体的な情報量が増した。悪い影響は見られず、デフォルトの開始設定として推奨できるとのこと（628, 734）。
- 画質や体型がバラバラの素材でも素材に寄らせる改善が期待できることがわかった（628）。

## 5. OpenAI Codex / Astra関連
- Codexのリセット告知が来ており、16時頃にリセットされるため使い切るよう促されている（631, 634）。
- 残量を使い切る方法として、fastモードで複数並列動作させる方法や、Astraの2倍モードにする方法が挙げられている（636, 668）。
- 使い切り作業中の5時間制限が邪魔になるという不満がある（667）。

## 6. MiniMax H3 / 動画生成関連
- MiniMax H3のref2vaでturboのエロありモデルを使用した際、1フレーム目が参照画像そのままになってしまう問題が報告されている（786）。
- MiniMaxでキャラの口を動かさずに喋らせる手法について、プロンプトで「心の声で喋っている」「口を閉じる」等を指定すると成功しやすいとの知見が共有されている（798, 804）。
- RAM 32GB 4070TiS環境でWan2.2を動かすと、VRAM50%しか使わないのにメインメモリを一杯使いCドラへのアクセスが止まらない現象が報告されている（788）。
- 歌詞からMVのシーンを推論させてContext Loopに渡し、SRT字幕も同時生成するカスタムノードとWFが作成された（682）。

## 7. 3Dエロゲ・VR関連
- コイカツやVaM等の既存タイトルから時代が進んでおらず、次世代3Dエロゲの需要がある。LLM組み合わせてキャラがエロいことしてくれれば一生オカズに困らないという意見がある（694, 713, 743, 749, 755）。
- 3DAIのメッシュがぐちゃぐちゃな点は改善が喫緊の課題と認識されている（710, 712）。
- LLMにモーションやアニメーションを作らせるのは難しいが、ControlNetで映像編集できているため概念を学習させれば動きそうとの見方がある（744, 761）。
- LLMでシナリオ、irodoriで音声、H3で動画を作成し脱衣麻雀等のエロゲを作る構想がある（759, 763）。

## 8. NovelAI (NAI) 関連
- NAI5 curatedで残量消費がされているか怪しいという指摘がある（764）。
- V5で参照画像ができず、勝手にV4に選択されて日本語入力ができなくなりゴミ画像が出るという不満がある（765, 766）。
- フェラシーンにインペイントでcross-sectionだけ入れると膣内になるが、cross-section, uvulaを追加すると口内の様子になるという発見が共有されている（783）。

## 9. その他

- 5090の発火報告の確率について「1/数百万くらい」との推測から法規制等の話題に発展している（818, 821, 823）。
- OnomaAIのサイトが復活したとの報告がある（773）。
- WAIS-4でIQ107（下98、上116）と診断され、発達障害疑惑から精神科受診に至った経緯が語られた（658, 684, 721）。

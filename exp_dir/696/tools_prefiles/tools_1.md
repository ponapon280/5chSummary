## 生成AI関連「ツール」話題 抽出レポート

### ComfyUI / Comfy

- **StabilityMatrix経由でComfyUI 0.35.0が提供開始**。Trouchバージョンアップが同梱されており恐怖と感じる声（>>92）
- ComfyUI 0.35.0環境でMinimax動画生成時に1ステップごとにVRAM消費が増加して止まる不具合報告（>>51）
- Comfy KitchenのPRでHuawei Ascend向けINT8最適化やConvRot W4A4最適化が確認できる。将来的に中華ハードウェアで画像生成が足りるようになる可能性に言及（>>160）
- LMStudioやLlamaWebUIがAPI対応しており、ComfyUIでAPIを呼び出すカスタムノードをCodexに作らせることが可能。ComfyUIの実行ボタン一つでLLM経由の画像生成パイプラインを構築できる。ガワの変更もCodexで可能（>>185）

### webUI（LlamaWebUI等）

- ローカルLLMをAPIとして呼び出す先としてLlamaWebUIが言及されている（>>185）。ComfyUIからカスタムノード経由で呼び出す構成で利用

### nano-banana / バナナ

- GPT Image 2.5がnano-bananaを超えたという主張。参照画像＋棒人間以上に楽に描けるという評価（>>159）
- ただし変なポーズでなければ文字プロンプトだけで済むため棒人間画像は不要という反論。バナナはGPT image 2.0時点でチャッピーで十分という認識が定まっており、以降バナナ側の進化がないという指摘（>>165）
- GPTとバナナは得意分野が違うため使い分け。可愛い子を出すならGPT、生成が早いのでリアルタイムでSFWを出す用途にバナナが重宝するという意見（>>167）

### Codex / ChatGPT / Claude（コーディング・自動化ツール）

- Codexでcu128+irodoriの専用環境を導入。ゴールはpixivで見かける1セット60枚のストーリー系ポン出しの完全自動生成化。キャラ×シチュで全自動モザ付き生成、ユーザーは選別のみを行う構想（>>25）
- Codexで18歳以下含む版権キャラのエロシチュ自動作成環境を構築したい。Gemma4にキャラとシチュを渡してエロプロンプトを作らせ、そこから画像生成までワンクリックでいけるかという問い（>>181）
  - Codexを使ってGemma4にエロプロンプトを考えさせつつanima等で画像生成させる全自動パイプライン。システム構築自体は朝飯前。ただし版権未成年キャラは検閲に引っかかる可能性。Codex脱獄で回避可能（>>184）
  - LMStudio/LlamaWebUIのAPIをComfyUIカスタムノードで呼び出す方式をCodexが構築。システムプロンプトもCodex任せ。多様なエロシチュに対応するローカルLLMは良いものが必要でVRAMゲー、12GBだと厳しい（>>185）
- 企画と設計の仕様を考える時間が長すぎて、Codexに作ってもらったものを使う時間がないという声（>>128）。完成後の放置が多い（>>132）
- Codexに作らせたVRゴーグン対応ツールの言及。webカメラで頭トラッキングして覗き込み表示（>>126）
- 国内プログラマ的な仕事は全てCodexやChatGPTで事足りるのではという意見（>>174）。ただしAI生成コードの妥当性確認には知識が必要で絶滅はしないという反論（>>179）
- システムプロンプトもAIにほぼ出させている（>>95）。手打ちタグプロンプトには温もりがありLLM産プロンプトには魂が宿らないというスレ上の意見（>>97）
- Codexは要求が変わるたびに修正を繰り返すため、SEが病むような状態になる（>>153）

### Minimax / MMH3（動画生成ツール）

- MMH3でテキストエンコーダーをint8にするだけで結構変わるという報告（>>197）。プロンプト欄空欄・同一シードでTEをnvfp4→int8 convで動画内容が変わる（>>207）
- Minimaxのdasiwaモデルをアニメ絵で試すと絵柄がだいぶ変わるという報告。I2VAでもref2VAでも発生。エロの動きは良いが通常モデル＋LoRAの方が使いやすいという意見（>>141）
- Minimaxで特に声指定しなくても毎回一貫して同じような声を出力する機能についての言及。irodori ttsで声を作る必要がないかもしれない（>>147）
- Minimaxの声はirodori ttsより良いという意見も。日本語出力においては比較にならないが、動画に乗せる点ではMMH3生成の方が自然（>>145, >>146）
- MinimaxでLLMプロンプトが当たり前になったためDanbooruタグの部族語ウゴウゴ感を感じるという意見。ただしエロ表現は部族語の方が楽（>>60）
- MinimaxH3で指6本になる、腕3本になるという不具合報告（>>48, >>81）
- 10erosは手軽にエッチな動作をするがおっぱいの形状が言うことを聞かない。巨乳クソデカ乳輪で固定される、音質が悪い、肌質がプラスチックという問題点（>>91, >>107）

### Krea2

- Krea2でキャラLoRA検証中。タガー方式でユニークタグを使用し、全キャラLoRAで学習可能。複数人の混ざりを防げる。服の着脱がキャプション単位で可能（>>36）
- Krea2で文字入れが最初から可能。難しい漢字は化ける（>>40, >>41）
- Krea2が無かったらH3の面白さ半減。良いタイミングでの登場という評価（>>216）
- Krea2でミクコスプレ実写風画像を作って喋らせたらミクの合成ケロケロボイスになったことがある（>>149）

### その他ツール

- **irodori tts**: Minimaxと比較されるTTSツール。Minimaxの方が声が良いという意見がある（>>145）
- **DLSS5**: 「現実が見えてきた」というスレ上の感想（>>28）。もっと簡単にしてほしいという要望（>>11）
- **Anydepth / ステレオフォトメーカー / Quest3**: 静止画でAnydepthで立体視画像を作り、ステレオフォトメーカーで正距円筒図法画像にしてQuest3でVR180っぽいものを作成可能。ただし拡張子で管理されておずアス比で認識したりしなかったりする苦労がある（>>168）
- **「猿のたまり場」**: danbooru語を関連性含めてまとめたサイト。矢印で類似語が開けたりbooruに飛べるリンクがある。danbooru語彙力増強に効果的（>>158, >>161）
- **チャッピー（ChatGPT）**: 顔を変えてしまうため使いにくい印象があるが、衣装学習用の道具として割り切れば使える（>>55, >>61, >>64）。GPTで水増しするならモデル側で十分（>>78, >>79）

# 元の本文
今回とくに盛んに議論された話題は、ComfyUIの環境管理・バージョンアップ問題と、AIコーディングツール（Codex等）を用いた自動化パイプラインの構築、およびLM Studioのクラッシュ回避策である。

※注記：以下のレス番号は元スレの通し番号とは限らない。

### ComfyUIの実行環境とカスタムノード運用
- **バージョンアップと不具合**: ComfyUI 0.35.0へのアップデートに伴い、Trouchバージョンアップ同梱への懸念や、Minimax動画生成時にVRAM消費が増加して止まる不具合が報告された。また、0.30から0.35への一気アップデートでカスタムノードエラーが発生する事例があり、Spectrum MiniMax-H3ノードでは0.2.26でOOMエラーが出るため0.2.23へ戻す対応が取られた。0.35はほぼバグフィックスであり、Stabilitymatrix経由でも問題なく動作したという報告もある。(>>92, >>51, >>369, >>327, >>367, >>368)
- **Desktop版の利点と容量管理**: ComfyUI Desktopはインスタンス複数作成、スナップショット機能、フォルダ共通化が可能で使いやすい。一方、本体を複数分けると容量を圧迫するため、シンボリックリンクでモデルフォルダを共通化する運用が推奨されている。(>>746, >>747, >>756)
- **LLM連携とワークフロー自動化**: ComfyUIからLM Studioやllama.cpp（「ComfyUI-llama-cpp_vlm」）を呼び出し、VRAM解放を自動で行う構成が紹介された。Qwen3 8Bを使用して歌詞からMVのシーンを推論させるWFや、ChatGPTやClaudeにWFやUIを作成させる運用が定例化しつつある。(>>891, >>682, >>529, >>664, >>742)
- **最適化と画像フォーマット**: SageAttention2とComfyKittichnAttentionの比較（将来性でComfyKittichnが優位）、MMH3でのTE int8化の効果、AVIF形式でのメタデータ保存対応などが議論された。(>>258, >>197, >>565)
- **新モデル対応**: YuE2-3BやMusic3のカスタムノード対応が進められているが、最適化が雑でOOM調整が必要な状態。avifファイル選択用のjs作成報告もある。(>>534, >>558, >>625, >>666)

### LM Studioの設定とクラッシュ回避
- **画像添付エラーの解決**: アップデート後にgemmaで画像添付時にエラーが頻発。評価バッチサイズを512から2048に上げる（または512に下げる）ことで回避できた。デフォルト設定が変更された可能性が指摘されている。(>>669, >>672, >>827, >>833, >>834)
- **VRAM割り当て**: モデルロード時のVRAM消費量目安を「総VRAM量 - 3GB」にする推奨。エンジンのバージョン戻しが容易である点も利点。(>>842, >>918)
- **高速化**: gamma4 26B A4BでMTPが動き、200tok/sを超える報告がある。(>>920)

### Codex / Claude / ChatGPTによるエージェント運用
- **全自動パイプライン構築**: Codexを用いて、Gemma4にエロプロンプトを作らせ画像生成まで行う全自動システムの構築が試みられている。ComfyUIからLM Studio/LlamaWebUIのAPIを呼び出す方式で構築可能。ただし、多様なシチュに対応するにはVRAM 12GBでは厳しい。(>>25, >>181, >>185)
- **ツール作成と作業代行**: CodexやChatGPTでwebUI作成、VRゴーグル対応ツール作成、確定申告の仕訳作成、DaVinci ResolveのMCP対応を利用した編集ツールとしての認識など、幅広い作業代行が行われている。(>>330, >>126, >>483, >>268, >>278)
- **リソース制限と運用**: Codexの$200プラン一時停止やリセット頻発に対し、fastモードで複数並列実行する対策が取られている。企画・設計に時間がかかり完成品を放置する声や、要求変更の繰り返しによるストレスも指摘された。(>>341, >>631, >>128, >>153)

### 画像・動画加工ツール
- **Krea2**: 日本語描写に強く、bboxでの位置指定が可能。anima等で生成した画像に文字入れする仕上げ用途で重宝されている。画質問題はNVIDIA VSRが原因だった。MMH3の組み合わせでも評価された。(>>229, >>230, >>604, >>216)
- **Minimax / MMH3**: TEをint8化で動画内容が変わる報告、dasiwaモデルの絵柄変化、手指増加不具合など。10erosの手軽さと肌質・音質の課題が議論された。(>>197, >>141, >>48, >>91)
- **Astra**: Blender連携でプレビズ制作可能。モデリング知識不要のゴリ押し運用ができるが消費量が重い。(>>268, >>342)
- **irodori tts**: ボイスクローンの似なさや感情表現の弱さが指摘され、Minimaxの方が自然という意見が多い。(>>145, >>288, >>312)

### その他ツール
- **Animerge**: マージ機能をGPU使用に変更し、LoRAマージのバグ修正を行うアップデート。(>>492)
- **audio.cpp**: YuE2-3BをLinux+RadeonやmacOSでも動かせる。(>>674)
- **「猿のたまり場」**: danbooru語彙力増強に有効なまとめサイト。(>>158)
- **vast.ai**: 台詞とタグと画像生成をバッチ処理するために利用検討。(>>963)

### 総評
1. ComfyUIは新モデルへの対応スピードが評価される一方、バージョンアップに伴うカスタムノードの破損やOOMが頻発しており、スナップショット機能やバージョン戻しを利用した環境管理が必須となっている。
2. AIコーディングツール（Codex等）を用いて、LLMによるプロンプト生成から画像生成、さらにはUI作成までを自動化するエージェント運用の試みが活発だが、リソース制限（VRAMやAPI利用上限）がボトルネックになっている。
3. LM Studioはアップデートによる挙動不調が報告されたが、バッチサイズの調整等のワークアラウンドで回避運用されており、ComfyUIからのAPI連携先としての利便性が高い。
4. Krea2やDaVinci Resolve MCPなど、生成物の「仕上げ」や「編集」を自動化・効率化するツールへの関心が高く、パイプラインの後工程を担うツールとして重宝されている。

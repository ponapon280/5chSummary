# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI

- **デフォルトワークフロー変更**: ComfyUIのデフォルトワークフローがSDXLからz-image-turboに変更されている（642, 644）※z-image-turboはモデルリスト該当だが、ツール側のワークフロー変更事象として記載
- **動画処理のメモリ消費**: ComfyUIは動画を複数のRAW画像としてメモリに全展開してから処理するため、30秒の動画だと解像度次第では60GB消費することもある（672）
- **Comfy KitchenのHuawei向けPR**: Comfy KitchenのリポジトリにHuaweiのAscend向けのPRが大量に出されている（649）
- **ComfyUI v0.36.0**: リリース済み（758, 817）。VAEの高速化が入っており、更新するだけで生成が快適になる（822, 825）。0.36にしたらRAM使用量が大幅に下がった、チャンク読込が効いている可能性（826）。ただし一部環境でバージョン表示が0.21.1になる不具合やck-attentionによる起動エラーが発生（823）
- **更新推奨**: 最近のComfyUIは各種高速化・メモリ効率化が本体にマージされており「更新一択」（822）
- **NVMeSSD自動判定プルリク**: Comfy mainに、NVMeSSD使用を自動判定して--fast-diskが有効化されるプルリクが入った。メモリに詰められるだけ詰める挙動が緩和される見込み（829）

## Krea2

- **吹き出し文字生成**: krea2を使って吹き出しの文字を作成し、image compositeノードでanima絵に合成するワークフローが作成された（645, 647）
- **手書き文字学習**: krea2に学習させれば手書き文字が出せる。日本語オンリーのキャプション60個の学習で一定の成果。キャプションをちゃんと書けば表現力が上がる見込み（652, 662）
- **Krea2 Cat Tower**: 二次エロを触るだけなら「Krea2 Cat Tower」。ただし絵師タグなし、版権キャラ対応ほぼ不可、マスピ絵しか出せない（666, 668）
- **LoRA学習の制限**: 素のKrea2には学習用のRawがあるためLoRA作成可能だが、エロモデルは生成用のTurboしか公開されておらず学習できない。エロチューンのRawとTurbo待ちだが来るか不明（669）
- **Krea2-Anime**: まだ10%しか学習していないが、簡単なエロ漫画程度は作れる（673）
- **Krea2Editの現状**: NSFW画像集の背景修正にKrea2Editを検討したが「今微妙」の認識。image2の背景だけ持ってこい等の指示が効かず、結局Qwenを引っ張り出して手作業で対応した（797）

## ComfyUI × 動画モデル（MMH3 / FastH3 / Lightx2v / fastvideo等）

- **MiniMax H3 (MMH3)**: MMH3は映像を作り出すことができるようになった。24fps・10秒生成・音声出力可能で、フェチ対応力が高い。欲が出て別PC・サブGPUを検討するほど（727, 730, 731, 732）
- **FastH3 V2**: 追従性と一貫性が良い。0.6MP 10s 8stepsでTurbo 82.04s、FastH3 V2 93.84s。宇宙船の見た目が切り替わりやすかった問題が解消され終始一貫（699）。i2vも可能だが入力画像が明るくなったり色が変わったりする（711, 712）。V1は4step、V2は8step（712）
- **FastH3の課題**: 肌がツヤテカでプラスチックっぽくなる（729）。出力がかなり変わる上、速さも大したことないとの否定的な意見もある（810）。ref2va非対応（709, 719, 819）
- **FastH3 vs Lightx2v比較**: Lightx2v 8stepsとFastH3 8stepsを比較したが「なんとも言えん」との評価（735）
- **minimax_h3_fastvideo_vsa_datafree_1300step_4step_int8_convrot**: FastH3よりも大体良い結果が出たとの報告（812）
- **Tao-Mate-H3 LoRA（MMH3のstep LoRA）**: 試した結果、声劣化する・クオリティ気になってステップ結局増やす、程度の味変しかなかった（788, 789）
- **VAEハッシュ差異**: VideoのVAE(int8)のハッシュを確認したところ、Comfy公式とFastH3は同じだが、Kijaiのint8とは別物。VAE周りの高速化はUIのアップデートだけでは不十分でファイルもComfy側に寄せた方が良い可能性（780）
- **mmh3のvaeデコード高速化**: mmh3のvaeデコードが速くなったため、ComfyUIの更新が必要（716）

# 生成AI関連ツール抽出レポート

## ComfyUI (comfy)
- **選定理由**: ローカルで動画生成を動かす場合、標準環境が揃っているため「適当にDLしていじってみる」用途で推奨（28）
- **プロンプト管理・ワークフロー管理**: ワークフロー（WF）やプロンプトをPNGで管理する手法が紹介されており、PNGをCodexに投げてビューワーを作成可能（87, 155）
- **バージョンアップの不具合**: comfyuiを0.35に上げた後、連続生成時に画面ロックから復帰するとlatent吐く段階でフリーズし、pythonがタスクマネージャーからも落とせなくなる事象が発生（173）
- **カスタムノード関連**:
  - ComfyUI内で動くマルチテキストエディタ「Prompt desk」をComfyUI Registryに登録して自作（162, 166）
  - 大元の改変に追いつかないとカスタムノードが動かなくなる問題、他人のコード解析やLLMでの修正はトークン消費が発生（161）
  - PNGinfo相当の情報（ポジ、ネガ、Lora、ステップ、CFG等）を表示・コピーするカスタムノードの需要があるが、既存で良いものが見つからない状況（125, 136, 151, 154）
  - Eagleをビューアとして使い、有志作成のカスタムノードでComfyUIから送信する運用あり（144）
  - Context loop系のノードが毎日のように追加され、Extender等の機能も出てきているが、AIに状況を聞くと「WFをイチから作り直したほうが良い」と言われる状態が続いている（214）
- **長尺動画生成について**: ComfyUI一発での長尺生成はクオリティが低くなるため、DaVinci Resolve等の編集ソフトで個別動画を繋ぐ方が良いという意見あり。ただしcontext loop系では動画の繋ぎ目が分からなくなるシームレスな繋ぎが実現できている（217, 221）
- **ツール選定理由**: 「素敵なWFとかツールが出たら元気出る」との声あり（48）

## webUI (WebUI)
- 自作のモザイク処理WebUIを自宅鯖のMac mini上に構築し、出先のiPhoneからも使えるようにした。JPEG XL出力も実装（167）

## Stability Matrix
- animaで連続生成し、面白い画像が出たらminimaxH3に放り込んで遊ぶ用途で使用（173）

## LoRA作成ツール
- **アストラ**: 完全に一からのLoRA作成は無理そう。MusubitunerやSD-script等のツールを使えばアストラ不要（158）
- **Musubituner / SD-script**: 一流どころのツール。Codexの一番軽いやつでワンクリックLoRA環境が構築可能（158）

## 画像ビューワ・閲覧ツール（生成画像管理）
- **Zippla**: webpの閲覧が遅すぎるため自作アプリに移行（164）
- **mimageViewer**: Zippla後継として良さそうだが、animated webpの読込が遅い（187）
- **Neeview**: 見開き画像ビューワだが、細かい部分が合わず徐々に重たくなる（172, 175）
- **Leeyes**: 化石だがコピー品を自作（169）
- **hamana**: 画像を見るだけなら軽くて現役（175, 180）
- **まっしぐら**: シンプル伊豆ベストで長期使用（181）
- **Irfanview**: 軽い。shift+wでウィンドウサイズ固定。バッチ処理をGeminiが推奨（188, 191, 192, 212）
- **マンガミーヤ**: 軽くて機能が揃っているため使用継続（213）
- **Eagle**: 有料の管理ソフト。画像管理・ビューワとして使用（144, 182）
- 自作閲覧アプリを作成するユーザーが複数おり、ワークフロー完成後はComfyUIを起動しっぱなしにするだけになったとの報告（163）

## モザイク・動画処理ツール
- webp動画用のモザイクツールをチャッピー（ChatGPT）に頼んで作成。pixivのうごイラ上げ時にwebpからフレーム分離してアップすると画質が良い（184）

## 動画生成ツール（ComfyUI外）
- **MiniMax H3**: Mac環境では遅く、動画生成には向かない。株価が下がっている（113, 149）
- **Krea2**: スペック中途半端民にとって、時間がかかるMiniMax H3より早く色々試せるため楽しいという選定理由（215）

## Qwen関連（画像生成以外）
- ログ内にQwen関連のツール話題なし

## その他ツール
- **Cursor**: 現在の無料枠以下の性能だった時代に月40ドル払っていた（66）
- **Codex / Claude**: プロンプト管理アプリや画像ビューワーの作成に使用。CodexにPNGを投げてビューワーを作成可能（145, 155）
- **DaVinci Resolve**: 動画編集ソフト。ComfyUIでの長尺生成の劣化を避けるため、個別動画をこれで編集する方法が推奨（217）
- **xreal one**: ファームウェアアップデートで普通の動画の3D表示が可能になり、深度をリアルタイム分析して表示できる（193）

# 生成AI関連ツール話題 抽出レポート

## 画像ビューア

- **マンガミーヤ（MangaMeeya）**: 過去に使用していたユーザーが複数いる（229, 230, 253）。
- **HoneyView**: 使用中のユーザーがおり、AVIF・JXLに対して否定的な見解を示している（230, 257）。
- **irfanview**: 使用しているユーザーが他にいて嬉しいという声（236）。
- **leeyes**: ビューア公開者の比較対象として挙げられている（251）。
- **qView**: 画像閲覧に使用されている（253）。
- **NeeView**: 使用中とのこと（261）。
- **ACDSee**: 満足して使用しているユーザーがいる（252）。
- **bandiview（BandiView）**: 購入を検討する声がある（257）。
- **Eagle**: 過去におすすめされて購入したものの放置していたが、慣れると良いとの評価。ComfyUIのsaveノードからの自動保存をチャッピー（AIコーディングツール）に頼んで実装したという報告がある（247）。
- **自作画像ビューア**: レス251のユーザーが自作ビューアを公開。特徴として「webp軽い、zip開ける、zipplaからの星レート引継ぎ可能」。またレス296のユーザーも、既存ビューアのメモリ影響や動作不良を理由に自作したと語っている。レス252ではCodex（AIコーディングツール）で作成した画像ビューアの使い勝手についての言及がある。
- **zippla**: 画像の星レート引き継ぎ元として言及（251）。

## ComfyUI / ComfyUI関連ノード

- **Anima IP-Adapter Loader / IPAdapter Model Loader**: comfyui上で`ip_adapter-Character_Reference-10.safetensors`がAnima IP-Adapter Loaderで選択できない問題が報告された（242）。別ユーザーが検証し、githubの説明通り`ComfyUI/models/ipadapter/`にモデルが配置されていれば選択できると回答している（245）。なお、IPAdapter Model Loaderでは選択可能だったとのこと（242）。
- **ComfyUIのファイル参照仕様**: comfyのファイル名に使う文字列（`%ノード名.プロパティ名%`など）が一律的に参照できず、名前が微妙に違ったりして面倒であるという不満。プロパティパネルに一意に定まる参照名を明記してほしいとの要望がある（387）。
- **ComfyKitchenAttention / SolAttention**: 動画生成（1MP-15秒-25Step）において、5090環境でもこれらのAttention系ノードを使わないと20分超かかる問題が指摘されている。Attention系を使用すると時間が半分近くなる。劣化具合は不明（408）。
- **sol-attn**: 完全一致を要求するプロンプトだと間違いが目立つが、アバウトなプロンプトだと劣化は気にならないという使用感が報告されている（409）。
- **block sparse attentionノード**: Spectrumがstepを飛ばさなくなる問題が発生したが、原因はWindowsの改行コードだった（273, 284）。
- **Spectrum**: 動くが機能しない、stepを飛ばしてくれないという不具合報告がある（273）。

## その他のツール・環境

- **Extender**: New Projectで1clip分の画像とプロンプトを用意して実行すると、プロンプトが空になり空のclipが3つ発生して生成される不具合が報告されている（275）。後続レスでRefワークフローを検証し、Prompt package Bridgeをバイパスしたらうまくいったとの報告。このノードにデフォルトでstringsノードが3つ繋がっており、その数に合わせてクリップを作成していたことが原因と推測されている（297, 312）。
- **Codex / チャッピー（AIコーディングツール）**: ちまちまいじって最適化して育てる感覚はCodexに任せていたら味わえないという意見（233）。チャッピーはノウハウが蓄積されており精度が高いとの評価（234）。Eagleへの自動保存や画像ビューア作成、Extenderの不具合調査などに使用されている（247, 252, 275, 296）。
- **LM Studio**: MiniMax H3用のSkillsを公式から導入して利用しているが、最近のランタイムとの相性が良くないため、ランタイムバージョンだけ落として使用しているとの報告（299）。
- **Krea2**: 微妙なニュアンスの差を調整して埋めていけるのが凄いとの評価。Anima等はタグの力が強く決まった絵が出がちだが、Krea2は微妙な表現で詰めていける点が優れているとされている（241）。エッチなkrea2モデルのお薦めを求める声もある（244）。
- **YuE2**: 英語の曲を中国語にAIカバーできるか実験したが、中国語がさっぱりなため評価できなかった。途中からやたら歌い出す不具合があるとのこと（346, 361）。

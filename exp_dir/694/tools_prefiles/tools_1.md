# 生成AI関連ツール話題 抽出レポート

## ツール全般・ワークフロー

- **チャッピー（ChatGPT）をツールとして活用**：SFW動画用の参照画像作成に使用。krea2でも近いことはできるがLLMと揉めやすい（レス20）。
- **フロー（ワークフロー）作成に時間がかかる**：チャッピーに「生成よりフロー弄ってる方が長い」と言われ、ノードのカスタムに何時間もかけて生成は1girl,swimsuitの数回のみという状況（レス22）。
- **LoRA作成もフロー同様に時間がかかる**：データセット整理に何時間もかけ、一晩学習させて数枚作って満足して終わることが多い（レス23）。

## ComfyUI / ComfyUI関連ノード

- **OpenVDNのComfyUI最適化が未対応**：vram8GではOOMになり、OOM回避のためgpuにキャッシュしないと通常turboの10倍時間がかかる。block削除loraはバイパスしないとエラーになる。現状2DではdasiwaV1＋larryvrh氏のturboV4が質と速度のバランスが最良（レス80）。
- **VDNのノードが登場**：ロスレス高速化用。早く試したいという声（レス148）。
- **DLSS5のComfyUIカスタムノードが既に存在**（レス146）。Forge NeoにもDLSS5拡張機能とサンプル画像が出ているが、使ってみようとはならないという感想（レス154）。
- **ComfyUI用DLSS5適用事例**：X検索でアニメ絵への適用事例がいくつか見つかる（レス151）。
- **Regional Prompt SimpleのComfyUI対応**：anima用のRegional Prompt SimpleをCodexに入れてほしいと依頼したが、既存のものが見つかり対応した（レス33）。
- **チャッピーのプロジェクト読み込み復旧**：アドオン作成途中のため復旧を急ぐ声（レス78）。

## その他ツール関連

- **minimax（MMH3）のVR180 LoRA登場**：VRエロへの活用の可能性（レス104）。VRパススルーでの視聴用法の報告あり（レス144）。
- **MMH3の高速化LoRAトーナメント結果**：larry氏のv4 emaがトップ（レス150）。
- **minimaxの利点**：3060＋RAM16GBの低スペック環境でも時間はかかるが動作して動画が作れる（レス120）。1080でもwanもminimaxも動く（レス122）。
- **MMH3で背景固定の課題**：長回しすると背景テクスチャが不自然に変化する。POVアングルで地面を見下ろすと必ずテクスチャが変化し、「地面は変化しない」等の指示でも効果が薄い（レス227）。
- **wan2.2の利点**：お手軽ループはwan2.2の方が楽。i2vで静止画を起点にした展開が得意（レス114, 135）。ただし精液描写等はLoRA頼み（レス130）。wan2.2の利点は豊富なエロ知見（レス131）。
- **DLSS5に関する議論**：本来NVIDIAがタイトル毎に個別チューニングするものだが、野適用はそれを無視して無理矢理実装している。今のところフォトリアルゲームオンリーのため、似非フォトリアルにしかならないという見方（レス168）。DLSSは元々重いアンチエイリアス処理を置き換える軽量化技術として登場（レス180）。DLSS4.5+SRでネイティブより綺麗になり、パーティクル系もマシになった（レス191）。2次元にDLSS5をかけると中韓ソシャゲキャラの3DCGポルノのようになるという否定的見解（レス174）。
- **SvtAv1エンコード**：動画エンコードにSvtAv1を使用すると同じ画質で7.8MBに縮みブラウザでそのまま再生可能（レス100）。
- **Ref2V＋LoRA学習**：FL2Vモデルでアへ顔LoRAを学習させたら普通に効いた（レス64）。
- **sd-scriptsの推奨**：guiに機能がないがsd-scriptsならtimestep sampling offsetが使える。animaのLora学習が安定する（レス25）。gui（WebUI）ニキの設定をベースにしつつ改変（レス25）。
- **LoRA学習設定の知見**：素材16枚/ステップ16000で5時間程度。チャッピーが出した設定は素材16/ステップ900/30分でそこそこ出る。キャラLoRAはせいぜい800〜2000ステップ。画風LoRAなら1万ステップいくかもしれない（レス172, 181）。constant 500ステップで軽く回して雰囲気を見るのが推奨、dimとalphaは画風LORA以外は16以下（レス190）。
- **redrayzニキのガイド**：LoRA作成時に読むべきREADME。SDXLと違って思った通りにならないLoRAが出来やすい（レス179, 185）。

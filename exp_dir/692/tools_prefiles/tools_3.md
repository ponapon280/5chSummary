# 生成AI関連ツール話題抽出レポート

## ComfyUI (comfy, Comfy)

- **ワークフロー構築**: 生成画像の出力よりワークフローをいじる時間の方が長いとする声がある（453）。プロンプト知識よりもComfyUIでノードをどう繋いで制御するかが重要とされ、ワークフロー構築の難しさが語られている（639）。
- **カスタムノード**: Codexを使ってComfyUIのノード改造をさせているという報告がある（595）。
- **対応フォーマット**: ComfyUIに対してJXL対応を求める声がある（604）。
- **Animerge対応**: AnimergeをComfyUIで使う方法について議論され、階層マージのノード有無や、学習中のサンプル生成機能（sd-script備え付けのビュアー機能）、Model-to-Modelマージのプレビュー生成機能（メモリ内完結）の実装可能性が語られている（491, 495, 505, 510）。
- **MiniMax H3関連**: 
  - ComfyUI-MiniMax-H3-Image-Studioを使用し、2メガピクセル9frame20stepで生成しているという報告がある（503）。
  - MiniMax H3で静止画を出す場合、vaeは「minimax_h3_t1_image_vae_step1597」か「minimax_h3_single_frame_500k_comfy」を使い、latentは「Empty Latent Image」からsamplerへ繋ぐことで1フレームでもクリアに画像が出力できるという知見が共有されている（508）。
  - MiniMax Fast H3のComfyUI量子版をKijaiが公開しているという話題がある（538）。
  - H3高速化ノードが多すぎて分からないという声がある（608）。我こそは最新最強ワークフローとして動かない場合、ComfyUI環境ごとぶっ壊されるという報告もある（628）。
  - Lora Schedulerノードについて、base modelをH3モデルに繋げ、stateをCurrent Sceneのstateに繋ぐ接続方法が議論されている（616, 623, 626）。
- **環境破損トラブル**: 最新ワークフローを試してComfyUI環境ごと壊される事例がある（628）。
- **NVIDIAドライバ対応**: NVIDIA StudioドライバーがLTX-2.5、WAN-Animate-2、MiniMax-H3用のComfyUIを最適にサポートするという情報がある（617）。

## StabilityMatrix

- **Civitai接続不具合**: モデルブラウザで一部の項目がCivitaiに接続できない不具合があり、アプデ（2.16.1→2.16.3）で解決したという報告がある。例としてAnimaのCheckpointがダメで、LoRAやSDXL系は問題ないという謎の挙動があった（540）。
- **バグリスク**: 最近はバグ報告も多く、安易にアプデしたくないという声がある（540）。

## webUI (Forge Neo)

- **LoRA関係のアップデート**: Neoが前日のアプデでLoRA関係を一新したため、LoRAを使用している場合は全部外して1つずつ動作チェックして原因を探る必要があるという指摘がある（468）。
- **挙動不具合**: animaの挙動かforge Neoの挙動か不明だが、最後のVAE処理でVRAMに余裕があってもメインメモリにオフロードすることがある（タイル処理時）（614）。

## Krea (Krea2, Krea3)

- **用途**: Anima生成画像をKrea2で白画像等に出力して良い感じにえっちにさせる用途が語られている（456）。
- **スペックと性能**: 5年落ちノートPC（RTX A3000 6GB/64GB）でもKrea-2 Turboで2mp生成できているという報告がある（496）。
- **プロンプト再現性**: Krea2のプロンプト再現性は高く、anima3.8Bは現時点では追いついていない印象と評価されている（606）。
- **発表**: krea3のお披露目がニューヨークで行われた話題がある（492）。

## banana (nano-banana)

- **使用感**: 画像の素材元から全然かけ離れたものになるためイマイチだったという評価がある（439）。

## Codex

- **制限**: 5時間制限がPlusプランで復活しており、Proプラン（$100）では現時点でまだ戻すかもと言われているという情報がある（578, 583, 586）。
- **用途**: 繋ぎ目が自然なループ動画作成のフロー構築や、emoji-ttsの改造、ComfyUIのノード改造に使用されている（488, 595）。また、Blenderを制御して3Dモデルを作成させる用途でも使われている（632）。

## 各種TTS・音声合成関連ツール

- **Irodori-TTS-Server**: LLMの返答を音声合成し、PNGTuberの要領で口パクさせるAIアシスタント作成に使用されている（572）。
- **Emoji-TTS**: 参照音声の作成に使用されている（572）。

## EasyReforge

- **使用感**: easyrefogeでillustriousを使用しているが、乳首とマンコのディティールが崩れてうまくいかないという質問がある（615）。

## その他ツール環境

- **OpenRouter**: LLMを使うノードで使用される超有名なサイト。先行モデルを触れて遊べるが、従量課金のためヘビーユーズの場合はサブスクにコスパが敵わない。プロバイダがモデルを量子化しているため同じモデルでも性能差がありややこしいという指摘がある（532, 533, 537, 570）。
- **Free Download Manager**: 無料で使えるDLツール。1個ずつ順次DLでき、数十GBの巨大ファイルでも途切れることなく安定して落とせ、途中切断時も途中から再開できる点が推奨されている（459）。
- **Blender**: Codexから制御して天童アリスちゃんを作成させることに成功したという報告がある（632）。

## Qwenシリーズ（画像生成以外の話題）

- **Qwen Image edit 2511**: AIアシスタント作成時にキャラ画像の作成にAnimaと共に使用されている（572）。

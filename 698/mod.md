# 元の本文
**レポート冒頭まとめ（流行っているモデルの推測）**

テキスト全体から、生成AI画像モデル（主にローカル/コミュニティ中心のアニメ・エロ・実写系）として特に活発に議論・使用されているのは以下のモデル群です：

- **Qwen-Image（Qwen-Image-2.1 / QIE / QI）**：編集能力・日本語テキスト出力・軽量化への期待が非常に高く、複数ログで最多級の言及。Krea2との比較が頻出。
- **Anima（anima）**：2次エロ・LoRA相性・使いやすさで根強い支持。主力として日常的に使われている声が多い。
- **Krea2 / Krea2 Turbo**：基本性能・LoRA品質・日本語対応・実写寄りで高評価。ワークフローとの相性も良い。
- **MiniMax H3（H3 / MM-H3）**：細かい表現（特にエロ・動画）・参照編集能力で言及最多クラス。実用的なワークフロー構築で注目。
- **NovelAI (NAI)**：日本語NSFWの手軽さ・安定性で一定の需要（ただしローカル勢からは不満も）。

これらは「エロ性能」「LoRAの作りやすさ/相性」「日本語対応」「編集・参照能力」「軽量化・実用性」といった軸で選ばれており、H3・Krea2・Qwen-Image系が特に議論の中心。Illustrious（リアス）は過去の文脈や特定タグ相性で散見される程度です。

**生成AIモデルに関するレポート**

テキストは複数のログ抽出結果を統合したもので、主にローカル環境での画像生成AI（特にアニメ・NSFW・動画寄り）に関する言及が中心です。モデル選択の理由が明記されている箇所を優先的にまとめ、全体の傾向を整理します。

### 1. Qwen-Image（Qwen-Image-2.1 / QIE / QI）
- **言及の多さ**：複数ログで最多級。open weight予告、Krea2との比較、アジア系顔の強み、編集能力が繰り返し取り上げられる。
- **選ばれている理由**：
  - open weightである点が明確に評価され、クラウド品質をローカルで期待できる可能性。
  - アジア系顔の描写力と、FluxやKrea2では難しい編集能力（image edit、四面図・キャラシート作成など）。
  - Text Encoderとしての高性能（「krea2よりも賢い」「ideogram4のTEと同じ」との声）。日本語出力性能への期待も高い。
  - 軽量化（7B級視覚生成部）により、VRAM 12-16GB環境でも実用化しやすい点。
- **その他の言及**：Qwen-Image-2.1のリリース待ちが目立ち、先行アクセスやテンプレワークフローの話題も。エロ表現はまだ不安定という指摘あり。

### 2. Anima（anima / ANIMA）
- **言及の多さ**：複数ログで頻出。リアル寄り・3D寄りや2次エロ用途で主力として使われている。
- **選ばれている理由**：
  - 2次エロ（特にキャラLoRAとの相性）の扱いやすさ・編集性能でトップクラス。「anima editくん」の更新待ちや「結局Animaが使いやすさトップ」との声。
  - LoRA作成素材生成や「anima baseで学習 → 別モデルで出力」といったワークフローでの実用性。
  - リアル系・3Dっぽい絵柄が欲しい場合に選択。SDXL-IL（Illustrious）からの派生モデルとして位置づけられる。
- **その他の言及**：baseモデルの単体性能は低め（バタ臭い・チープ）との声もあり、TurboやLoRAとの組み合わせが前提。更新停滞気味という指摘も。

### 3. Krea2 / Krea2 Turbo
- **言及の多さ**：実用面で非常に多い。Qwen系やH3との比較が活発。
- **選ばれている理由**：
  - 基本性能とLoRA品質の優位性。「int8_convrot」が優秀で高速・高品質。
  - 日本語（特に縦書きセリフ・テキスト）の入れやすさ。
  - 非エロからエロへの移行ワークフローや、構図の安定性。実写系でも強い。
- **その他の言及**：引きのカメラで顔が溶けやすい弱点や、Qwen系に将来的に脅かされる可能性の議論あり。GUI（AI-Toolkit）との相性も良い。

### 4. MiniMax H3（H3 / MM-H3 / minimax_h3_fastvideo など）
- **言及の多さ**：一部ログで最も多い。動画生成・エロ表現で注目。
- **選ばれている理由**：
  - 射精表現・中出し逆流などの細かいエロ描写の豊富さ（脈動プロンプト構築次第で「量と勢いこそ正義」）。
  - 参照・編集能力（キャラ再現性・一貫性・カメラ制御）の高さ。「自身のTurboを使った方がクオリティが上がる」との声。
  - 動画（t2v / ref2v）用途での実用性（フレーム繋ぎ、音声対応など）。低スペック環境でのpruned fp8版も話題。
- **その他の言及**：comfyui-minimax-h3-prompt-enhancerなどのツールとの組み合わせ。VRAM消費の激しさも指摘される。

### 5. NovelAI (NAI)
- **言及の多さ**：手軽さの文脈で一定数。ローカル勢との対比で語られる。
- **選ばれている理由**：
  - 「日本語でアニメキャラのNSFWをローカル投資なしで生成できる」手軽さ・即時性。
  - APIの安定性（curlなど即利用可能）。ローカルで厳しい構図や特定出力の保険として。
- **その他の言及**：絵柄の安定性・解像度・LoRA不在への不満も。メンテナンス時の回復速度が遅いという声あり。一部ログでは話題自体を敬遠する空気も。

### 6. Illustrious（リアス / IL / SDXL-IL）
- **言及の多さ**：散見（特に過去文脈やAnimaの前身として）。
- **選ばれている理由**：
  - sound effectsタグ（テンプレシチュ＋擬音語）との相性の良さ。SDXLのU-Net特性を活かした安定出力。
- **その他の言及**：Animaの派生元として言及される程度で、現在はAnimaなどに移行した印象。

### その他のモデルと全体傾向
- **Wan（Wan2.2）**：H3が使えない環境での代替として。エロ耐性の弱さ（LoRA必須）が指摘される。
- **FLUX / Z-Image**：比較対象として少数言及（FLUXはKrea2/Qwenより上位との声、Z-ImageはLoRA作成のしやすさ）。
- **その他（Gemini、Gemma4、Jev、Astra、Tsubaki3、Bonsai2など）**：LLM寄りや特殊用途（ゲームプレイ・デバッグ・音楽など）で言及されるが、画像生成メインの文脈では少ない。
- **全体の傾向**：モデル選択の主な判断軸は「エロ性能・NSFW耐性」「LoRAの作りやすさ/相性」「日本語対応（テキスト・セリフ）」「編集・参照能力」「軽量化・低スペック実用性」「ワークフローとの相性」。H3とKrea2が実用面で活発、Qwen-Imageは新星として期待大。Animaは2次エロの定番として安定支持。ローカル vs クラウド（NAI）の使い分けも見られる。

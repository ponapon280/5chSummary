**抽出されたツール関連話題（モデル除外）**

### ComfyUI（comfy）関連
- **ドラッグ&ドロップ時のタブフリーズ問題**（41, 53, 55）
  - Chromeのグラフィックアクセラレーションを一度オフ→オンにすると直った。
  - Windowsアップデート後に発生しやすい（ComfyUI以外でもChatGPTなどのタブで同様の現象）。
  - Firefoxでは発生しないという報告あり。

- **フレーム補間機能**（104, 106, 107）
  - ComfyUI標準でフレーム補間が入っていることを最近知った。
  - 処理が速く、RIFE Tensor RTが不要になった。
  - Minimax H3がネイティブ24FPS出力できるため、補間自体の必要性が下がったという意見。

- **生成再現性の問題**（151, 152）
  - ワークフロー・モデル・起動オプションが同じでも、ComfyUI更新後に生成結果が変わることがある。
  - RTX 30/40/50シリーズ間で同じシードでも結果が異なる（CUDAカーネルの違い）。

### RefMOD
- **動画LoRA作成ツールとして高評価**（76）
  - 参照画像を揃えるだけで、数秒・数MBで動画LoRAが作れるのが画期的。
  - 従来は一部のハイエンド勢しかできなかった作業が誰でも簡単になった。
  - 参照画像を大きくしすぎると作成後のToken数変更ができない点は注意点として挙げられている。

### AI-Toolkit / musubi-tuner
- **LoRA作成時のVRAM・速度問題**（118）
  - AI-ToolkitでKrea2のLoRA作成を16GB（4080s）で試したところ、300stepで1時間かかるほど遅い。
  - この速度に耐えかねてmusubi-tunerへの移行を検討している。

### comfyui-minimax-h3-prompt-enhancer-T8
- **公式Skillとの比較**（96, 97）
  - LLMに公式Skillを食わせるより性能が良いかどうかの話題。
  - 「LLM性能が低い人」や「NSFWを通したい人」向けのツールという位置づけで語られている。

### context loop ref2v
- **特定状態（根元まで挿入）の動画生成**（36）
  - 完全挿入状態を安定して作るためのワークフローとして使用。
  - 参照画像の組み合わせ（全身＋未挿入＋完全挿入など）を試行錯誤している。

### その他
- ツール選択の理由として特に目立ったものは上記の**「処理速度」「VRAM負荷」「操作の簡便さ」「既存機能の置き換え可能性」**の観点が多かった。

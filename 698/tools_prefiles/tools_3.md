**抽出されたツール関連の話題（モデル関連は除外）**

### ComfyUI関連ツール・機能
- **ComfyUIのワークフローとカスタムノード**
  - ブラウザ上でワークフローの右クリックからtextノードに外部からプロンプトを送ってその都度runできる機能。LLMとの連携が捗ると評価。
  - codex君（AI）に自動的にComfyUI内にカスタムノードを作らせる使い方。大満足している。
  - 理由：手動でノードを組む手間を省き、LLM連携を効率化できるため。

- **ComfyUI拡張「Image-Studio」**
  - ComfyUIの拡張として使われており、参照画像を入れてキャラクターシート（3面図・正面図・顔アップなど）を作成する用途。
  - 動画生成時の参照画像作成や、RefModとの組み合わせで使用。
  - 理由：手動で画像を加工する手間を減らし、動画参照用の素材を素早く作れるため。特に「裸のキャラクターシート」やキモいシーンの画像作成に重宝。

- **ComfyUI内でのローカルLLM完結**
  - ComfyUI内でLLMを読み込んで完結させる方法や、カスタムノード経由でllama-cpp-pythonなどを使う例。
  - 理由：外部ツール（LM Studioなど）を立ち上げなくても済む一貫した環境が作れる。

### その他のツール・環境
- **codex（AIによるカスタムノード自動生成）**
  - ComfyUI内に自動でカスタムノードを作らせるツールとして言及。
  - 理由：手作業でノードを作成するより高速で、LLM連携用途に適している。

- **コンテナ（Dockerなど）**
  - コンテナを使って環境を分離する提案。
  - 理由：カーネル共有の制約はあるものの、暴走リスクを抑えられる可能性がある。

- **wise folder（暗号化フォルダ）**
  - wise folderで暗号化することでcodexに見られないようにする手法。
  - 理由：セキュリティ対策として確実性が高いとされている。

- **LM Studio / OpenWebUI / LlamaWebUI**
  - ローカルLLMを立ち上げてプロンプト作成に使用。ComfyUIと連携させる例あり。
  - 理由：プロンプト生成をローカルで完結させ、履歴管理や整理がしやすい。

- **カスタムノードマネージャー**
  - ComfyUIの拡張機能管理ツールとして言及。Image-Studioなどのノードを探すのに使用。

**除外したもの**
- anima、Qwen-Image、Krea2、MiniMax H3、RefModなどの**モデル・生成エンジン**に関する言及はすべて除外。
- Qwenシリーズは画像生成用途の話題がほとんどだったため、該当するものは抽出していません。

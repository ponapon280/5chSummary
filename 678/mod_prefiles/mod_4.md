**抽出された「モデル」関連話題（除外対象除く）**

### 1. **MiniMax H3（H3 / minimax h3）**
- スレッド内で最も多く言及されている動画生成モデル。
- **選ばれている主な理由**:
  - 指示追従性が高く、特に日本語プロンプトに強い。
  - アニメ・実写ともに動きが自然で、Sora2に近いクオリティが出やすい。
  - 声や口パクの再現性も比較的良い。
  - ローカル（ComfyUI）でエロ表現が可能という点が大きなメリットとして挙げられている。
  - 「元絵の画風を崩しにくい」「触手や液体表現などの複雑な動きにも対応しやすい」といった声あり。

- **使用例・最適化の話題**:
  - `MiniMax H3 Mem Eff Sage Attention Patch` → `Patch Sol-Attn` → `Spectrum Apply MiniMax H3` または `H3Cache` の組み合わせが主流。
  - SpectrumとH3Cacheは排他で、**Spectrumは色味が崩れやすい**ためH3Cacheを採用する人が多い。
  - TurboLoRAとの併用話も出ており、8step程度で生成可能という報告あり。

### 2. **TurboLoRA**
- 最近追加された高速化LoRAとして話題に。
- **特徴**: 8stepで生成可能になるが、**音声品質が落ちやすい**という指摘が複数あり。
- アニメ系で特に音声劣化が目立つとの声。

### 3. **その他の言及（モデル本体というよりパッチ・最適化関連）**
- **Sage Attention / Sol-Attn**: 特にRTX 40/50シリーズでの速度向上策として頻出。Sol-Attnは最近のアップデートでSage Attentionと共存可能になった。
- **Spectrum / EasyCache / H3Cache**: 高速化ノードとして比較され、**品質劣化の度合い**が選定基準になっている。
  - EasyCache：変化の少ない部分をスキップ（品質劣化が比較的大きい）。
  - Spectrum：AI予測を入れてスキップ（H3本来のクセが出る可能性あり）。

### まとめ（傾向）
- 現在このスレで最も熱いモデルは**MiniMax H3**で、「動きの自然さ・日本語対応・エロ表現のしやすさ」が選ばれる主な理由。
- 高速化（Sage/Sol-Attn + Cache系）の組み合わせをどう組むかが主な議論になっており、**品質劣化をどこまで許容するか**でSpectrumかH3Cacheかを選んでいる人が多い。

**抽出結果（指定モデル関連のみ）**

### **FLUX**（fl2 / SexGod / 10Eros）
- **言及内容**:
  - 公式FLUX.2 int8が21GBなのに対し、SexGodや10Erosなどの派生モデルが34GB〜40GBと極端に大きい点が複数指摘されている。
  - エロ用途では「refで立ち絵を読み込ませて動かす」より、**お気に入りのエロ画像を開始画像にする**方が良いのではという意見あり。
  - 実際にSexGod（37GB）と10Erosを試した結果、「ちんまんは出ない」「自然なピストンや射精もない」と評価が低く、即消しした報告あり。
  - 「エロはrefでええなあ感はあるが…」という感想も。

### **Wan**（Wan2.2）
- **言及内容**:
  - Wan2.2は「高速化LoRAなしでも出来る動画がたかが知れてた」ため、高速化しても劣化が相対的に少なく実用範囲だった。
  - これに対しMinimax H3は元々の性能が高いため、高速化LoRAの劣化が目立ちすぎてカバーしきれないという比較がされている。
  - 「wanでcomfyui触り始めて」という過去の学習経験談あり。

### **anima**
- **言及内容**:
  - AnimaでLoRAを作る際のキャプション方針について議論。
    - 自然言語キャプションは**あってもなくても良い**という意見が主流。
    - 理由として「Animaのテキストエンコーダー能力が弱い」「Danbooruタグ＋簡単な位置関係程度の出力しかしないので、自然言語を入れても効果が薄い」「自動キャプションだとノイズになる」との指摘。
  - Anima Style Explorerが消えたことについての言及あり。

### **NovelAI (NAI)**
- **言及内容**:
  - NAI V5の**日本語フォント性能が圧倒的**という評価。
  - 「エロ漫画のページ参照＋キャラ参照で『エロ漫画をこのキャラに変えて』ができたら加入検討」という具体的な用途が挙げられている。
  - スレタイの「NVA部」について「NovelAI部に戻してもNAIちゃんの話はほぼない」というメタ的な言及あり。

**抽出された「モデル」関連の話題（除外対象除く）**

### 1. **Minimax H3（H3 / minimax_h3 / MiniMax Spectrum）**
- スレッドの中心的な話題。
- **評価されている点**:
  - 通常版の生成品質が非常に高い（「出来る動画が圧倒的」「プロンプト追従がすごい」）。
  - 低ステップでもある程度見れる出力が出やすい。
  - 音声付き動画生成に対応している点が評価されている。
- **ネガティブな指摘**:
  - 高速化LoRA（minimax_h3_turbo_4stepなど）を使うと劣化が激しい。特に**音声ノイズが酷い**（4stepはほぼ使い物にならず、8stepでも音声は厳しい）。
  - Wan2.2の頃と比べて、高速化による劣化をカバーしにくい。
- **使用傾向**:
  - ref版をメインで使っている人が多い（通常版はref版のRAM節約版的な位置づけと見なされている）。
  - 4stepより8stepの方が画質はマシという報告あり。

### 2. **SexGod / 10Eros系モデル**
- 大型モデル（37GB〜40GBクラス）として話題に上がっている。
- **評価**:
  - 「ちんまんは出ない」「特に特徴的な動き（自然なピストン、射精など）が出ない」という声が多く、**謎のモデル**という扱い。
  - 即消ししたという報告あり。
  - エロ特化を期待してDLした人が多かったが、期待外れだった模様。

### 3. **高速化LoRA / turbo LoRA（H3向け）**
- minimax_h3_turbo_4stepなどが話題。
- **評価**:
  - 速度は出るが、画質と特に**音声の劣化が激しい**。
  - 4stepはノイズが酷く、8stepでも音声は厳しいという報告が複数。
  - 「easy cache系と大差なさそう」という意見も。

### 4. **ref版 vs 通常版の使い分け**
- ref版を積極的に使っている人が多数。
- 理由として「立ち絵をrefで読ませてキャラを動かす方がエロい動きを作りやすい」という意見。
- 通常版は「ref版のRAM節約版」という認識が広がっている。

### 5. **その他の言及**
- Spectrum（MiniMaxのSpectrum）：H3関連の新機能として名前だけ出ている。
- int8量子化モデル：公式の21GBに対して自作・派生の34GB〜40GBモデルが出てきており、VRAM/RAM使用量が話題に。

**総括**  
このログでは**Minimax H3**が圧倒的に話題の中心で、「生成品質は非常に高いが、高速化すると音声含めて劣化が激しい」というのが共通認識になっています。除外対象以外のモデルとしてはSexGod/10Eros系が名前だけ上がっていますが、評価は低めです。

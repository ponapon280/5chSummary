# ログから抽出した「ツール」関連話題

## Stability Matrix
- **概要**: 単なるランチャーとして認識されている（443）
- **更新方法**: バージョン以外の更新方法を選んでおけば、Stability Matrixでも即時更新可能。直接gitを叩くような手段（441、442）

## Muse
- **使用事例**: museでirodoriテストを実施。フリーの合成音声を使用し、セリフや射칾のタイミングも自動判任で生成（444）
- **漫画生成**: museに漫画作成を依頼するとanimaでそれっぽいものが作成可能。手動でちょい修正すれば使えるレベル。mossで設定を頑張るよりテンプレを作って任せた方が早い可能性（526）
- museに投げてからComfyUIに繋げてシコシコライフを満喫しているという報告あり（535）
- **面白さ**: museが面白すぎて5090や増設RAMもお休み中になるレベル（532）

## ComfyUI
- ComfyUIを含め、マウスを動かす必要すらなくMCPでコマンドを叩くだけでローカルの非検閲LLMにエロプロンプト自動実行させ放題可能（567、569）
- ComfyUIはMCPに対応しているため、JSONでやり取りするだけでローカルLLMからプロンプト自動実行が可能（569）
- animaをComfyUIでインペイント試したところ顔がかなり変わってしまうという報告あり（546）

## エージェント（MCP連携）
- MCPは一言で言えば「これやって」「おかのした」をJSONだけでやり取りできる機能。ComfyUIも対応しているためローカル非検閲LLMでエロプロンプト自動実行し放題（569）
- エージェントに頼む場合、シスプロを一緒に送っているためそれが邪魔になる可能性。Gemma4 UncenをCLIで試した時はエロ文が出せるのに、エージェント経由だと怒られた事例あり（572）
- エージェントにワークフローを送ると希望の設定・プロンプト書き込み・json返却をしてくれる。context loopで2分のwavを元に26シーン作成してくれた事例あり。エラー吐いてもログ見せると対策してくれるがケアレスミスはする（542）
- ローカルエージェントに雑命令で30枚生成をセットしておけば風呂に入っている間におかずが完成する世界になっている（584）
- エージェントで時事解説漫画を大量生成している人物がおり、ニュースや教育系の業界が年明けくらいには完全に変わるとの予想（スレ上の見方）（578）
- Mossを使っている人のほとんどはエージェントに使わせているのではないかという推測（スレ上の見解）（528）
- エージェントに頼む時の文をそのままプロンプトにぶち込めばいいと思っていたが、実際は違う。雑命令をそのままプロンプトに入れても絶対無理（571、584）

## GrokBot
- NSFW対応とのツイートが流れてきた。動画のエロも解禁されつつあるらしい（446、450、460）
- **キャプション用途**: キャプション作成に使用中。ただしGrok 4.7は日本語のやり取りがお値段の割にかなりひどく、Gemma 4の方がマシだった（446、447）
- **将来性**: GrokBotはもうすぐ中身が4.8になる。4.7の時点でパラメータ2T超えのフロンティアLLMのためキャプションに必要な知識量は段違い。エロが通るならかなり強い（スレ上の見解）（448）
- **制限の挙動**: 性行為や性器をはっきり描くプロンプトは作れず、水着やセクシー表現にとどまる設定になる。ダメだ、やっぱりこうなるGrokBot（463）
- チャット機能ではリアス用にdanbooruタグで性器の形状・大きさ・種類を出させることができた。ただし一回拒否られると制限がきつくなる可能性あり。年齢系・非同意は試していない（455）
- 4.3からロリNG、4.5くらいから非合意NGになった。9ヶ月前はAnima Previewのロリモブレプロンプトを書いてくれて神だった（457）
- GrokのImagineがサ終するという噂あり。スペースXの子会社として再編したことを考えると、エロ画像・エロ動画で有名になりすぎたやつはいつ終わっても不思議ではない（スレ上の予想）（464）

## LoRA学習ツール系（Fizgig / AI Toolkit / スケジューラ）
- **Fizgig**: LR（学習率）を激しく上下させるリスタート多めの設定がうまくいく体感あり。タイムステップサンプリングがランダムにノイズを乗せる学習方法のため、slideはその形をフラット寄りに変形させているだけと考えられる（459、479）
- Fizgigはある程度エポックが進んだらシフト値をエポック毎に上げ下げする謎のオプションが追加された（476）
- Fizgigは時間かかりすぎる・覚えないとよく言われるため、ツールのデフォルト値は参考にはするが基本信用していない（484）
- スケジューラは基本constantを使うべき。DiTモデルはタイムステップサンプリング導入済みのためconstantでもいい気もする（473）

## モデルマージツール（名称不明・SDXL系アプリ）
- マージを簡単にやりたい向けのツール。元々画像生成のアプリだがマージに力を入れている
- 単純なマージ、モデルの差分からのLoRA作成、LoRAマージ、量子化など必要そうな機能を全部内包
- sdxl、anima、krea、mossに対応しているはず（実際に動かして確認済みなのはsdxlとanimaのみ）（539）

## MMH3image / P-H3-Image（インペイント・編集ツール）
- **MMH3image**: リファレンス画像を渡して、1枚目の背景、2枚目の画風、3枚目の人物、4枚目の服、5枚目のポーズなどを指定するとがっちゃんと合成してくれる。お手軽（597、598）
- **P-H3-Image**: 軽さはMMH3の方がええけど、P-H3派という声あり（604）
- インペイントよりMMH3imageの方がお手軽かもしれない。ただしガッツリNSFWを編集するならインペイントの方がいい（597、598）
- SFWならH3imageかPh3から始めればええ、NSFWも同様（591）
- **選ばれる理由**: 二次はEdit系だと絵柄が変わるため、手指等の細部修正はtxt2imgと同一モデルでインペイントした方がいい。それ以外ならP-H3-Imageを推す（600）
- 三次ならP-H3-Imageがええ感じ。ただしVRAMに全部載らないため生成速度は気にしてはいけない（606）
- P-H3を試そうとしたらworkflowもモデルもがっつりp-h3-image_int8_convertだった（611）

## IlluEdit / IlluAngle（イラストリアス系編集ツール）
- IlluEdit: プロンプトで編集。簡単なテキスト指示で衣装、背景、髪型などを変更可能
- IlluAngle: カメラアングルを変更。キャラクターの雰囲気を損なうことなく各種アングルや構図を試せる
- ローカル提供はないが、アングル変更は元画像の手足が見切れていると破綻するものの精度はいい。Animaで作った画像も変更できた。Qwenより綺麗にアングル変更できている気がする（スレ上の感想）（545、547）
- テックブログへのリンクがない（545）
- ローカルがないなら意味ないという否定的な意見も（549）

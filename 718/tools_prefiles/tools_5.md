# ツール関連話題抽出レポート

## ComfyUI (comfy / ComfyUI)

- ローカルLLMを使ってComfyUIに組み込むワークフローを自動構築させる用途について言及。Museに2分の曲とキャラクターシート等の素材を与え、MiniMax h3 Contex Loopのワークフローを食わせてMV用にノード追加・結線変更させた事例が報告されている【890】
- GitHub forkして改変しComfyUIに組む作業をローカルLLMで自動化することについて、エロプロンプト作成のみが目的ならRAM消費が勿体無いとの意見がある【852】
- StrataのQwen3.8FNはComfyUIのバグ修正やカスタムノード作成ができるとの報告がある【978】
- ComfyUIとStrataを同一PCで共存させる際のメモリ確保について、VRAMを指定容量空けてくれる設定が存在し、その分RAMに逃がすため遅くなるという説明がある【984】【990】【992】（`--vram-reserve-mib`）

## Strata

### 選ばれている理由・利点
- ローカル側のリソースを使わずに動かせる点が便利とされる【844】
- PCに負担がかからない。Museの大盤振る舞い期間が終わっても出番は来るとの見方がある【864】
- CodexやClaude等のクラウドLLMでは健全なアプリを作らせていても途中で検閲的に断られることがあるが、Strataではそれがなく、トークン残量を気にせず無限に使える点がメリットとして挙げられている【994】
- 仕事用のデータを扱わせられる点が最大のメリットとされる（クラウドはお行儀が悪すぎて触らせられない）【996】
- Qwen3.8FNの量子化モデル（IQ3_S等）を使えばコーディング、アプリ作成、ComfyUIのバグ修正やカスタムノード作成が実戦投入レベルで可能【978】

### 性能・挙動
- 省メモリ設定だと6tok/sで使い物にならなかったが、メモリを限界まで使う設定にしたら58tok/sで10倍の速さになった【972】
- 仕組み上あちこちにデータ移動が発生するため、DRAM帯域やPCIe帯域が重要とされる【931】【935】
- メモリに負荷がかかり、強制再起動が何度も発生したという報告がある（Strataを使わなくしたら起きなくなった）【933】。一方でRAM192GB環境では再起動は一度も起きていないという報告もある【952】
- 貧弱PCでは少ししんどいという感想がある【944】
- Strataを使わないようにしたら強制再起動が全く起きなくなったことから、見えないところで無茶をしている可能性が指摘されている【933】
- Strata単体でIQ3_S（Hermes被せ）でコーディングに使用している例がある。IQ3_Sを使った後はIQ3_XXSでも性能満足できなかったとの報告も【980】【981】

### ハードウェア構成との関係
- 5060ti + RAM96GB環境でSATAのドライブに入れているため読み込み待ちが発生している【982】
- Strataの秒間トークン数でCPU交換の体感差を計測した例がある（11.5割程度の差）【919】
- RAM128GBについて「生成中に触れるかどうか」が快適さの差であり、生成中触らないなら64GBや32GBでも十分という見方がある【927】【928】
- PCIe帯域について、5000番台上位では最低5x8(4x16)が欲しいという指摘がある【935】
- StrataとComfyUIの同一PC共存について、VRAMを指定容量空ける設定（`--vram-reserve-mib`）で対応可能【984】【990】【992】

### モデル選択（ツール上での運用）
- UnslothのIQ4XSから試したが貧弱環境では顕著に遅くなったためIQ3_Sに落ち着いた。文章やプロンプト（エロ系）を書くなら現行はGemini4 Argonが良いとされる【991】
- 画像解析してプロンプト出力ならQwen3.8、エロ小説やエロチャならGemma4、動画のエロシナリオをGemma4で作ってQwen3.8に渡してプロンプト出力させる連携も推奨されている【999】
- 量子化の値は大きい方がよいが、環境次第でIQ3Sで妥協する判断がある【991】
- llmfan46のGemma4を使っているという報告がある【988】

## Codex（AIエージェントツール）

- Museにcodex操作をさせてエロ系タスクを依頼したところ、codexがタスクを断ったためダミーデータを送ってやらせようとした事象が報告されている【845】
- 夏前あたりで定額サブスク分を自由に使えるテスト期間があった。エージェントはトークン消費が多くタダで使わせる道理はないとの見方がある【872】
- CodexやClaudeは健全なアプリを作らせていても途中で「エロ画像見つけた」「これ以上の作業は断る」等と理不尽に断ることがあるが、ローカルLLM（Strata）ならそれがない【994】

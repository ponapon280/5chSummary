# モデルに関する話題抽出（除外モデル以外）

## Gemma4（Google）
- 素モデルでもエロい内容は基本断られない。ただし画像を読み込ませてエロい批評させることだけは断ってくるため、heretic等が必要だった（>>239）
- 改造モデルは改造によってライティング性能が下がるというベンチもあれば、最近はモデルの傾向自体が元から変わっているため単純な上下比較ではないという話もある（>>239）
- クリエイティブライティング性能はクラウド（ChatGPT等）とは大差あるため、ローカルで画像動画生成してクラウドで文章書かせるのがベストミックス（>>239）

## Minimax H3（MMH3 / H3 Image）
- H3 Imageのt2iは16MP/6stepsで出力して1MPに縮小した場合（vram8Gで90秒）、Mossで1MP/50steps（同60秒）と比較検討された（>>257）
- H3 Imageはアニメ系だと一昔前のGPT味がある（>>257）
- プロンプトをきちんと書いたときの品質はGPTにかなり迫るが、テキトーにやったときは微妙。忖度していい感じにやってくれるGPT（ChatGPT）は普段使いで強い（>>258）
- H3 Imageのt2iは空画像入力するかMinimax H3 Prompt Weightを使って「編集モード」に切り替えると画質が良くなる可能性がある（>>266）。実際にtext with empty imageで試したところ、謎の白い粉がなくなり皿の上の物体がちゃんとした食べ物になった（>>274）
- MinimaxH3のi2vとt2vはなんとなく分かるが、ref2Vで動画参照してキャラクターをその通りに動かすことが出来ないという問題あり（>>289）
- 動画編集ではviggle remixなるものが出た。MMH3のrefV2Vの幅を広げたものというイメージ（>>393）
- 画像編集系としてPh3とMMH3 imageが出た。両者ともMMH3の編集能力を利用したもので、nsfwを「考案」するのは苦手だが高画質での画像編集では頼りになる（>>393）

## GPT-6 / チャッピー（ChatGPT / OpenAI）
- GPT-6で普通のLLM（普通じゃない）の画像認識性能が上がりまくったため、フィジカルAI部門を分ける意味が無くなったとスレ上で推測されている（>>439）
- OpenAIがフィジカルAI部門を閉鎖して一般的なLLMにフィジカルな事をさせるというニュースがあった（>>418）
- H3 Imageと比較して、忖度していい感じにやってくれるGPTは普段使いで強い（>>258）
- ComfyUIのアップデート時にチャッピーと事前に確認しながらやっているという利用者がいる（>>434）

## 抽出結果：生成AI関連「ツール」話題

### ComfyUI / ComfyUI_frontend
- **Day0サポートにKijaiが参戦しており、最適化待ちのユーザーに対しても最新環境が整いつつある**（512）
- **生成画像のドラッグ＆ドロップ（D&D）でワークフローが再現できない問題が報告されている**。起動オプションに `--front-end-version Comfy-Org/ComfyUI_frontend@v1.52.7` を付けることで対処中だが、アプデのたびに外して確認しても未解決（626）
- 別ユーザーはフロントエンドVer 0.41.0では画像・動画ともにD&Dでワークフロー読み込みができていると報告。0.42での問題か、環境差の可能性を指摘（635）
- D&D問題はバージョンではなくおま環（ユーザー環境固有の問題）の可能性。カスタムノードを全未使用にして確認し、ダメなら新環境構築を検討すべきというアドバイス（638）
- フロントエンドを最新版にアップデートしたユーザーもD&D読み込みはできている。ただしPNG読み込み時はフロー名がファイル名になるが、mp4読み込み時はフロー名が `unsaved` になるという挙動を報告（639）
- **最近のワークフローをDD（D&D）するとバグる現象は、Nodes2.0への適応時期が来たからではないかとの推測**（610）
- しかし別ユーザーは **Nodes2.0を「あかん」として撤退を決意**。理由はノードの結節点が不可視でキャンバスにはみ出ており、画面ドラッグ時に誤爆して鬱陶しいこと、タブ切り替えが遅いこと、代替ノードがバグっていること（615）
- 新規インストール時に初期状態で設定されているテンプレートワークフローがZ-Imageのものになっている件に言及（637）

### Strata
- **最新版でハーネスが搭載された**（454）
- **Strata作者は64GB環境を使用している**との言及。96GB環境ユーザーが使用可か問うた件への回答（460）。128GBないとダメなレビューを鵜呑みにしていたユーザーも訂正版として確認（464）
- **1GPU環境でもQwen3.8 FNと画像・動画生成を同時ロード可能**。片方にStrataのQwen3.8 FNを載せ、もう片方で画像や動画生成をさせる運用が可能（477）。別レスでは1GPUで同時ロードしていると言及（483）
- **16GBあればStrataに12GB割り振りで同時起動が可能**。画像生成は少し遅くなる（506）
- ユーザーが「strata画風Lora作って」と指示したところ、自動で画像収集・選別・キャプション付与・学習を行ったが、学習回数（200, 400～1400）の設定が分からず手間取った（467）
- **webui版から直接アップデートできなかったため入れ直したユーザーが、`experimental speed projection` の項目が消えたと報告**。最新版では有効化のフラグが削除されており、ファイル `C:\Users\hango\AppData\Local\Strata\install\strata-iq3_s.json` に追記することで復帰可能。本人（本AI）に聞けば方法を教えてくれるという情報（486, 514, 515）
- **デスクトップアプリ版にしたらバチクソ遅くなった**という報告（533）
- **ローカルLLMを気軽に使える環境が整ってきたツールとして評価**。部族語以外にキャプションやプロンプトでLLMを使う際の手が出しやすさが向上（581）
- **MOSSのCLIPは既にロード済みであるため、外部モデルのアンロード/ロードの手間がないのが利点**。ただしQwen3.5 9Bはプロンプトエンハンサーとしては良いものの、Vision性能が弱く、小物や画面外から出てくる手やちんこの見落としが多くi2t能力に不足感（598）
- **Strataは大きなMOEモデルを動かすことに優位性がある**。Denseモデルを全部VRAMに乗せて使うなら大した意味はない。Qwen3.5 9BやGemma4 12BをVRAMに全載せしてプロンプトを考えさせるならLMStudioで問題ない（601）
- **Gemma4 31BなどVRAMに乗り切らない既存のLLMでもLMStudioより速くなるか**という問いに対し、KVキャッシュ分を逃せば収まる場合はそこそこ使えるが、重みが溢れる分の改善は微妙（605）
- Gemma4には対応していない。対応している亜種があるが安定性は不明。Gemma4 26Bの規制解除版はFreeTokenでも動かせるが遅い（613）
- 2GPU 128GB環境ではIQ4からIQ3XSに下げてStrataを2個ロードさせる手法がある。`--concurrency 2` にするだけで対応可能（614, 616）
- **RAMに流した分だけ遅くなるDenseモデルの問題はどうしようもない**。StrataはMOEモデルの超効率化版なので、収まるモデルを使うかStrata系対応MOEを使うかの二択（618）

### ツール選定理由・比較に関する話題
- **LoRA職人からの的確なアドバイスを得るには、使用ツール、設定内容、期待する結果と実際の出力の差をめんどくさがらずに書き込む必要がある**（555）
- **チャッピーは情報量を適切に削るようちゃんと指示しないとダメ**。適当に指示するとダメなモデル筆頭（532）
- **チャッピーの画像参照機能はバウンディングボックス内にプロンプトを書き込む方式だが、Geminiみたいに直感的に指示させたかった**という感想。稚拙だが画像参照はできたとの報告（502）
- **ChatGPTに雑誌の紹介記事風の画像作成をお願いすれば表紙も中身も作ってくれる**（507, 518, 522）
- **VRAM 12GBでもKrea2やMOSS-Imageの静止画生成は問題ない**。ただしメインメモリが8GBだとキツい（606）

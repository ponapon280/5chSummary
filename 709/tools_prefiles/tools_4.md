# 生成AI関連「ツール」話題抽出レポート

## ComfyUI (comfy)

- **rgthreeカスタムノードの不具合とfrontend互換性**
  - rgthreeを入れていると不具合が出るケースがある。rgthreeの作者はComfyUI側のバグとして認識している。rgthreeをdisableにしても治らない環境があり、rgthree以外の要因の可能性もある（680, 701）
  - frontend最新版＋rgthree導入環境で不具合が出ていないという報告もある（680）
  - 検証方法として「別フォルダにセットアップし直す」「デスクトップ版なら新規インスタンスを立ててrgthree導入前後で比較する」が推奨されている（680）

- **Fibo2用ノードの問題**
  - Fiboはプロンプトにbria-vglという独自言語のJSONを使用する必要があるが、平文をローカルで変換してくれるノードが見当たらない（804）
  - ComfyUI内蔵のTextEndoceFibo2は変換をしてくれない。旧バージョンのFibo Edit VLMノードを使ってJSON出力→生成を試したがダメだった（804）
  - ノード自作が必要かもという見解（804）
  - 一方で、comfy用のワークフローでは普通のプロンプトで動いたという報告もある（840）

- **ウエイトコントロールのカスタムノード**
  - TurboでCFGを上げるとネガ効き・質向上が見込める件について、ウエイトコントロールのカスタムノードがマイナスベクトルに対応しているという情報（808, 809）

## STRATA

- **RAM32GB / VRAM16GB (5060ti) 環境での動作報告**
  - githubからグラボに合ったインストーラをダウンロードし、証明エラーは無視して実行（723, 777）
  - 低RAM用のGyro Mを選択するとあっさり起動したが、会話に稀に中国単語が混ざった（777）
  - Gyro Mの上のモデル（IQ3_XXS）に挑戦した際、ランタイムエラーが出たがwin11再起動で解決し、中国語も出なくなった（777）

## siki（掲示板ブラウザ）

- **ぷにぷに（避難所）の閲覧・更新不具合**
  - sikiで避難所のぷにぷにが開けない、または更新時に変なダイアログが一瞬表示されて更新できない現象が複数報告（746, 749）
  - ワークスペースの設定でUAを「Monazilla/1.00 (hoge 1.0)」に変更すれば読めるようになるという解決策（748）

## ローカルLLM・AIエージェント関連ツール

- **Codex / GeminiのColab連携**
  - codexにcolabを連携させれば、教師画像作成から学習まで自動でやってくれる。有料Google Colabの設定もGemini公式画面でタスク化して指示するだけで可能（649, 677, 713）

- **Qwen3.5 9BのVLA対応**
  - VLA（Vision-Language-Action）対応しており、画像参照が楽に出来た。噛ませるものが必要だが、ちゃんと参照してくれてかなり使えるという報告（745）

- **Strata(IQ3_S検閲解除)を用いたエロ漫画化人格の構築**
  - Strataにエロセリフと擬音の辞書を作成させ、エロ漫画化人格を与えてセクロス画像を投げると、画像に適した計14個の擬音とセリフをフォント・文字デザイン・表示位置付きで出力。プロンプト生成→画像生成まで可能。連携させればBBOX指定も可能（734）

## irodori TTS

- **音声作成ツールとしての活用**
  - anima等でイラスト作成→irodori TTSで音声作成→minimaxH3で動画化、というワークフローが紹介されている（718, 721）
  - ローカルLLMでチャットしつつirodoriで推しの声を喋らせ、同時に画像も作らせる使い方が「一番飽きない」という報告（729）

## blender

- **minimax映像の実写背景合成への使用**
  - minimaxで作成した映像を手動で色加工し、blenderでアングルを合わせて実写背景と合成する試行。工程がめんどくさく、実写背景との合成は難易度が高い（661, 671, 676）

## sd-scripts

- **LoRA学習ツールとしての言及**
  - 最新版を使うのが推奨されている（802）
  - 自分で追加した引数とLycorisがないと嫌だからsd-scriptsを使っているが、fizgigを使ったほうがいいのではという意見も（842）

## minimax (動画生成ツールとしての言及)

- **実写背景合成の難しさ**
  - 参照画像として背景パースが合っていないと違和感がすごい。blenderでアングル合わせても、座席貫通や角度のおかしさが残る（675, 676）

  - 漫画出せるがプロンプトが大変過ぎて初期だけで飽きられた（790）

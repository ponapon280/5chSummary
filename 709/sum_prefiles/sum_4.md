# なんJ 画像生成AIスレッド レポート

## モデル別の評価と動向

### MOSS
- 実写・フォトリアル寄りだが、二次元（アニメ特化）版が待たれている（663, 665）
- タグのみでは限界があり、英語として通る表現でも反応しないことがある（776）
- 実写ではシード間で顔に多様性がある（800）
- MOSS通常生成は約20秒だが、連続生成すると約10秒になるという報告あり（742）

### Anima / WAIAnima
- WAIAnimaはbaseにLoRAやプロンプトを盛る手法が好まれるなど、評価が分かれる（643, 646, 647）
- Animaは派生モデル作成が難しく、WAIの更新頻度も低下している（650, 654）
- WAI-Mossは現状絵柄LoRAのみで、Anima版のFT数が減少しているとの指摘（736）
- スレ上の評価として「絵柄Anima まんこMOSS アナルリアス」と棲み分けが語られる（684）

### リアス / noob
- WAIを利用することでエロ表現の向上が見られたモデルとして挙げられている（647）
- 「リアスだけでよくね？」という声がある一方、創作目的ではより高品質なモデルが求められる（686, 687）

### Base / LoRA学習
- baseでLoRAを作成すると細部の解釈が揺れる傾向がある（642）
- キャラLoRAはSFTで作成した方が再現性が高く、絵柄LoRAも作り直し推奨との報告（762, 826）
- LoRA失敗の8割はゴミ素材の混入が原因であり、モデルがゴミも学習してしまうためデータセットの質が重要（824, 803）
- 学習ツールのオフセット設定等が原因で、詳細よりも概要に偏る場合がある（793）

### Fibo / Fibo2
- ライセンスの問題から流行らないとの見方が多い（651, 653）
- Fibo2はbria-vglという独自言語のJSONプロンプトが必要で、ComfyUI標準のノードでは変換できない問題がある（804）
- 別の検証では通常のワークフローで動作したとの報告もあるが、規制が強い（840）

### minimax
- 実写背景へのアニメキャラ合成が非常に難しく、Blender等を用いても違和感が残る（661, 676）
- 参照画像のパースが合わないと違和感が強く、リアスやAnimaでは厳しい（689）

## AIを用いた創作活動と課題
- MOSS等で漫画やCG制作が可能になったものの、セリフ・脚本考案やフォント・文字入れの手間から結局1枚絵（ポン出し）に戻るパターンが多い（690, 692, 719）
- 生成AIによる文字入れ機能の普及が確認される一方で、漫画構成の単調さが課題（688, 700）
- Strata（IQ3_S検閲解除）を用い、エロ漫画化人格を与えて画像生成とセリフ・擬音の配置を行わせるフローが報告された（734）

## ハードウェア・スペック情報
- スレ民のボリューム層はVRAM 16GB〜12GBが多く、12GBでもLoRA作成は時間をかければ可能（758, 759, 761）
- VRAM 6GBでの利用報告もある（771）
- 半年前までRTX 2060 Mobileを使用していたユーザーが、VPN経由でRTX 5090を利用するようになったと報告（773）
- RAM32GB VRAM16GB（5060ti）環境でStrataが動作したとの報告あり（777）

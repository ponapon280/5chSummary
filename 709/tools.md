# 元の本文
今回とくに盛んに議論された話題は、ComfyUIのNodes2.0移行に伴うノード不具合と代替ノード模索、LoRA学習ツールにおけるタイムステップサンプリング・ノイズ分布調整の解析、およびStrataを用いた大規模LLMのローカル実行・エージェント化の運用である。

※以下のレス番号は元スレの通し番号とは限らない。

### ComfyUI / Nodes2.0移行とノード運用
- **rgthreeカスタムノードの不具合**: rgthreeを導入している環境で不具合が発生。rgthree作者はComfyUI側のバグと認識しているが、disableでも治らない環境があり、別フォルダでのセットアップ検証が推奨されている（680, 701）。
- **Nodes2.0の評価**: 結節点が不可視でキャンバスにはみ出し、画面ドラッグ時に誤爆する、タブ切り替えが遅い、代替ノードがバグっている等の理由から撤退を決意するユーザーがいる一方、D&D不具合はNodes2.0への適応時期が来たからではないかとの推測もある（610, 615）。
- **KJNodesによる代替**: Nightly版で「MOSS-Image Prompt Builder KJ」「MOSS-Image Prompt Weight」が追加。Nodes2.0を使わずに済むとの見方がある（527, 541, 570）。
- **LoRAローダー移行問題**: Nodes2.0対応でPower Lora LoaderからUltimate Lora Loader Civitaiに移行した際、Save Image w/ Metadata UniversalでLoRAが拾えなくなる問題が発生。pyファイル追加で対応した（427）。
- **ローカルプロンプト生成の試行**: MOSS内蔵LLMをComfyUI上でノード接続しプロンプト作成を試みたが激遅で使えなかった（996）。またDeepSeekにスキル参照させてプロンプトを書かせる場合、comfyからやらせるにはスキルをシステムプロンプトに書くしかないとの指摘がある（266）。
- **動画溶け修正**: 動画のキャラ溶けに対し、De-RoPE処理をするノードが存在する。引き延ばして再生成するため時間がかかり完全修正ではない（432）。
- **各種対応ツールのDay0サポート**: KijaiがDay0サポートに参戦しており、最適化待ちユーザーにも最新環境が整いつつある（512）。

### LoRA学習ツール（Fizgig / sd-scripts / ai-toolkit）
- **Fizgigのノイズ分布調整**: CodexにFizgigのコードを読ませて解析した結果、MOSSの論文仕様に倣い低ノイズ採用率が11％に設定されていることが判明。覚えが悪い場合は採用率を30％や60％に上げると改善する。画風LoRAは低ノイズ領域を上げ、構図LoRAは狭める、キャラLoRAは小物再現性で調整するという使い分けが可能（957, 987）。
- **タイムステップサンプリング調整**: Animaで覚えが悪いときは離散フローシフトやsigmoid scaleを上げると改善したとの経験談がある。タイムステップサンプリングのオフセット値を調整するツール（ノード等）の使用も示唆されている（980, 984, 986, 966）。
- **CAME実装の手間**: ai-toolkitにはcame実装がないため、requirements.txtへの追加、UIの書き換え、optimizer.pyへのcame実装追加（チャッピーに全文出力させて追加）、convrot_quant.pyへの条件追加の改造が必要。現在はLoKR+CAMEでトレーニング可能（116）。
- **ツール選定理由**: 自分で追加した引数とLycorisがないと嫌だからsd-scriptsを使うという声がある一方、fizgigを使ったほうがいいのではという意見もある（842）。環境依存で動かない場合は別ツールを試す動きがある（116, 218）。
- **学習設定**: 4070s 1000step 1024×1024で大体1時間20分程度。5時間回してもLossが下がりっぱなしで底打ちしなかった例もある（168, 171）。

### Strata（ローカルLLM・エージェント実行環境）
- **メモリ要件と同時ロード**: 1GPU環境でもQwen3.8 FNと画像・動画生成を同時ロード可能。16GBあればStrataに12GB割り振りで同時起動が可能だが画像生成は遅くなる（477, 506）。Strata作者は64GB環境を使用（460）。
- **DenseモデルとMOEモデルの使い分け**: Strataは大きなMOEモデルを動かすことに優位性があり、Denseモデルを全部VRAMに乗せるならLMStudioで問題ない。RAMに流れた分だけ遅くなるDenseモデルの問題はどうしようもない（601, 618）。
- **低スペック環境での動作**: RAM32GB / VRAM16GB(5060ti)環境で低RAM用のGyro Mを選択すると起動。中国単語が混ざったが、上のモデル(IQ3_XXS)に変更しwin11再起動で解決した（723, 777）。
- **エージェント運用と自動化**: Strata(IQ3_S検閲解除)にエロセリフと擬音の辞書を作成させ、エロ漫画化人格を構築。画像を投げると擬音・セリフ・フォント・位置情報を出力し、BBOX指定からプロンプト生成まで可能（734）。ユーザーが「strata画風Lora作って」と指示すると自動で画像収集・学習を行った事例もある（467）。
- **デスクトップアプリ版の問題**: webui版から直接アップデートできず入れ直した際、`experimental speed projection` の項目が消える事象が発生。ファイルに追記で復帰可能（486）。またデスクトップアプリ版にしたらバチクソ遅くなったとの報告がある（533）。

### ForgeNeo / WebUI系ツール
- **ForgeNeoでのMOSS対応**: 非公式だがForgeNeoでもMOSSのBBOX拡張が使える。ただし公式対応とLoRA設定テンプレが出るまで待つべきとの意見もある（41, 42, 44）。
- **需要の限界**: MOSS専用UIを作っても、comfyUIを使えずforgeneoも使っていないニッチな層向けにしかならないとの指摘。comfyのスパゲッティノードアレルギーからforgeneo信奉者を自称するユーザーもいる（142, 147）。
- **RedRayz GUI**: MOSSに対応したGUIが登場し、作業が楽になったとの報告がある（622）。
- **WAI**: WAIニキがMOSSに手を出し、WAIでMOSSが使えるようになるなら期待との声。スレ上ではAnimaはオワコンでMOSSが覇権確定という見解がある（640, 641）。

### 自作ツール・外部連携ツール
- **MOSS専用UIの自作**: エージェントに頼めば簡単に作れるが、提供しても文句言われるだけなので緩やかに終わらせるほうがComfyUIの発展に寄与するという見解。コマごとにキャラ3人指定・動き指定できるソフトなら超絶需要があるとの意見もある（140, 165）。
- **Codex / GeminiのColab連携**: Codexにcolabを連携させれば、教師画像作成から学習まで自動でやってくれる。有料Google Colabの設定もGemini公式画面でタスク化して指示するだけで可能（649, 677, 713）。
- **irodori TTS**: anima等でイラスト作成→irodori TTSで音声作成→minimaxH3で動画化のワークフローが紹介されている（718, 721）。
- **NivisViewer**: スレ民自作の画像ビューワ。webpのサムネイル表示が爆速で、100枚程度でも一瞬で表示されるとの評価（278, 622）。
- **bria-vgl**: bria公式の画像専用テキストエンハンサー（本質はLLM）。使用で表現力が上がるとされるがAPI限定機能の可能性が高く、Fiboの利点は不明とのスレ上の評価（848）。

### 動画生成・加工ツール
- **minimax**: WANでは無理だった映画ばりのアクションが可能な点で選ばれている（287）。一方で細部がぼやける、遠景でキャラが溶ける等の問題があり、blenderでアングルを合わせて実写背景と合成する試行も行われているが難易度が高い（310, 343, 661, 675）。
- **WAN**: パルクールのようなアクションは無理だが、飼い猫や飼い犬の画像から自然に動く動画を作れる用途で選ばれている（281）。
- **SAM3 / LTX**: minimaxの細部ぼやけに対しSAM3で切り抜く試行、キャラ切り抜きにLTXを使用する言及があるが、時間がかかる等の制約がある（268, 316）。

### LLM実行基盤とインフラ
- **vLLM / SGLang**: 多重アクセス時のスループット向上手法として、gemma-4-12bを4090使用時に同時100多重で合計1600token/sが出たとの報告がある（364）。
- **LMStudio**: Strataの登場でMOEモデル用途では時代遅れとの指摘。ただしDenseモデルをVRAMに全載せする用途や、ComfyUI併用がきつい低スペック環境では存在意義がある（597, 598, 601）。
- **DiffusionPipe**: Pythonから直で呼ぶ方法がMOSSのQuick startに載っている。再挑戦するユーザーがいる（154, 361）。
- **セキュリティ**: MCPサーバが脆弱性を突かれて乗っ取られる懸念がある（942）。チャッピー経由でAIツールの証明書パッケージをアップデートしたとの報告や、pip、uv、wsl等のアップグレード推奨の声がある（921, 937, 947）。

### ツール共有の未来像
- **UI共有から指示共有へ**: 画像共有がプロンプトで行われるように、UIもUIそのものよりエージェントへの指示で共有する時代になるというスレ上の見解がある（167, 223）。AIが生成したノーメンテコードがgitを汚染し続ける懸念も示されている（220）。

### 総評
1. ComfyUIのNodes2.0移行に伴う不具合（D&D読み込み不可、rgthree干渉、ローダー間のメタデータ不整合）が多発しており、KJNodes等の代替ノードで回避する動きが主流となっている。
2. LoRA学習ツールではFizgigやsd-scriptsの内部パラメータ（低ノイズ採用率やタイムステップサンプリング）がCodex解析で明らかになり、LoRAの用途（画風・構図・キャラ）に応じたノイズ分布の調整手法がスレ上で確立されつつある。
3. Strataは1GPU・16GB VRAM環境でのLLMと画像生成の同時ロードを可能にし、エージェントに画像収集から学習・BBOX指定まで自動化させる実行基盤として活用されているが、Denseモデルやデスクトップアプリ版では速度面の課題が残る。
4. 動画生成ツールはminimaxとWANで得意分野が明確に分かれており（アクション vs ペットの自然な動き）、実写背景合成にはblender等の外部ツールを組み合わせる重い工程が必要とされている。

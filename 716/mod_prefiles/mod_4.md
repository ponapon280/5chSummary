## 生成AIモデルに関する話題抽出

### MiniMax H3-Image / H3 Image Studio / MMH3-Image

**基本スペック**
- モデル33.1B、TEが9bと31bの選択制。スレ上では「今までの画像生成AIの中で最大か？」との指摘がある（650）。
- 有効画像サイズが4〜20MP、最良が16MPとされており、ネイティブ16Mpx出力が可能（654, 739, 821）。

**出力速度**
- 2016x1152で17.3秒＠5070ti（697）。
- 5090で60秒。16枚参照は時間がかかる（665）。

**VRAM要件**
- 高スペ必須ではなく、8GBでも動くという報告がある（666）。ただし5060ti 16GB環境ではファイルサイズの大きさから導入を躊躇する声もある（655）。

**T2I（テキストから画像）性能**
- ソシャゲキャラや日本人という概念が薄く、t2iには向かないという指摘（681, 702, 712）。
- H3の二次出力の画質について、FLUX 3 klein並の残念画質という評価がある（698）。
- まともなエロは出ないとの指摘（640）。

**Edit（編集）性能**
- edit性能は強く、キャラの入れ替えや身体ラインのトレース置き換えが可能（648, 695, 724）。
- エロ画像を渡れば叡智を授けられる（エロeditは可能）が、非エロをエロにするのはあまり強くない（673, 711, 749）。
- Qwen2.1 Editでは上手くいかなかった衣装やポーズ変更について、H3 Imageは正確にできているという報告がある（815）。
- edit性能は強いが、画質を上げることを主眼に置いたモデルである可能性が指摘されている（654）。

**プロンプト解釈**
- 部族語（danbooruタグ）が効きにくく、サンプルが異様に長い自然文であるため、テキストエンコーダとモデルが巨大でも引き出せない感じとの指摘（734）。
- prompt upsamplerに任せるとエロ描写をスルーする（828）。
- Generate TextをOFFにしないとNSFWが出しにくい、しっぽが背景扱いになるなどの報告（692, 699）。

**P-H3-Image（非公式/派生）**
- 公式H3-Imageと比較して、絵柄維持やイラスト編集に向いているとの評価（755, 836）。
- LoRAを使うことでNSFW対応具合が向上し、画質・画風維持が公式より上という評価（692）。
- MinimaxH3本体があれば2Gの差分LoRA適用で利用可能（758）。
- ただしt2iもeditも中途半端であり、大して変わらないという否定的な声も（819, 820）。

**その他**
- モデル自体の影響で画風が独自のものになりやすい（647, 653）。
- MinimaxH3imageは思ったより微妙で、キャラの特徴保存が下手という声（760, 800）。
- refやプロンプトをしくじっている可能性への指摘もある（838）。

### モデル選定の理由（スレ上のまとめ）

以下はスレスレ712のまとめに基づく各モデルの選定理由：

- **anima**: 版権キャラや絵師などの類似度の追求（712, 797）。江戸漫画が作りやすい（767）。自然言語でそこそこ融通が利く（817）。
- **moss**: リアルなフォトリアルに強く、構図制御が最強、エロに強く漫画も作れる（712）。t2iでも3072サイズで破綻しない（831）。
- **H3 image**: 高解像度edit機能がメイン、t2iには向かない、非エロをエロにするeditは強くないがエロeditならOK（712, 749, 830）。

※リアス、FLUX、krea2、anima、QI2.1等の比較について、同一プロンプトでの全モデル出力結果も提示されている（771）。

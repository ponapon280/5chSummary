# 抽出レポート：生成AI関連ツール話題

## UI・フロントエンド

- **Open WebUI**: Strataの標準UIからOpen WebUIに乗り換えたところ、めちゃ長考するようになったという報告（>>504）。

## ComfyUI

- **対応状況**: H3-Image関連でComfyUI（comfy）は既に対応済み。同じQwen3-VL-32Bテキストエンコーダーを使用（>>575）。comfy-orgへの到達は少し遅れており、一日程度待つ必要があるとの見方（>>591）。
- **ワークフロー**: ComfyUIテンプレートのEditワークフローだと色がかなり変わってしまうという使用感の報告。大幅なシーン変更タスクなら許容範囲との見解（>>621）。TEのハッシュがH3（動画）と同じで変わっていない（>>623）。TEは共通のため再DL不要（>>625）。

## Viggle

- **Viggle Remake**: リリースから数日経つが話題になっておらず、キャラ差し替えAVやエロアニメで上手くいっているか不明との声（>>553）。触っていないユーザーも複数いる（>>568）。

## Krea / bbox

- **bbox**: bboxでポーズを取らせる実験の報告。ControlNetのような感じはまだ遠いとの評価（>>612）。H3-imageの競合はqwen-image2.1としつつ、bboxと日本語対応の面でH3-imageに勝てる要素が無いというスレ上の見方（>>603）。

## Qwen（画像生成以外）

- **Qwen3-VL-32B**: ComfyUIでH3-Imageのテキストエンコーダーとして使用されている（>>575）。
- **Qwen3.5 9B**: H3-ImageのPEはMoss用にDLしたQwen 3.5 9bのものを流用できるとの指摘（>>632）。
- 編集理解力はそこそこあるが勝手に細部を変えるという使用感の報告（>>590）。

## その他ツール関連

- **Image Studio**: 画質を落とさずImage Studioくらいの編集ができれば神という期待（>>637）。
- **EasyWan22**: H3-Image導入に伴いEasyWan22関連ファイルを断捨離したとの報告。Zuntanへの感謝が述べられている（>>631）。
- **コイカツ**: AIで版権キャラの動画生成するより、コイカツを買ってモーションと3Dを取って抜いた方が早くて安いというスレ上の見方（>>461, >>466）。電動オナホ連動やMRでのモデル追従といった活用法が語られた（>>467）。
- **fable 5.2**: プロンプト力テストの報告あり。「女子高生が寝坊して超絶運動神経でギリ間に合う動画をダイナミックに作れ」と指示し生成。構成力・演出力を評価しており、チャッピーやLLMではこういう構成ができず、Claudeだけは構成力・演出力がやたらあるとの見解（>>477, >>479）。NSFWはお断りされる模様（>>483）。
- **CrystalDiskInfo**: AMD RadeonドライバーのSSD無限酷使不具合確認に役立つツールとして言及。総書き込み量の推移が見られるため安心感がある（>>518）。

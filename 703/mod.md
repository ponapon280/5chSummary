## 流行モデルの推測（スレッド発言に基づく）

スレッド全体の発言傾向から推測すると、**Strata**（ローカルLLM実行環境）が最も頻繁かつ詳細に議論されており、Hermesと組み合わせたハーネス構成が覇権を握っている。画像生成では**Anima**が現役として継続使用され、**Krea2 / Krea2-turbo**がワークフローに組み込まれている。動画生成では**MiniMax H3**がハードウェア要件とともに具体的に検証されている。LLMでは**DeepSeek**がAPI価格・性能面で評価され、**Claude Opus 5.5**がコーディング能力で最高峰とされているがトークン消費が激しい。新モデルとして**nanobanana2.1**のリリース反応と**Gemma4**のエロ描写性能への驚きが見られる。

## 画像生成モデル

### Anima
- **選定理由**: LoRAが圧倒的に作りやすく、VRAM4GBの民でなければ作成は余裕（191）。リアス（illustrious）より指の本数が正確になる（リアスは6本になるがAnimaだと4本になる）（285）。プロンプト手打ち+オートコンプリートで単純な画像生成ができる（409）。リアスの限界を感じた後に「animaって凄い」と評価（893）。
- **制約**: プロンプトのみだと混ざりが悪い（411）。絵柄混ぜがLoRAでも上手くいかない（184）。LoRA作成を試したがうまくいかなかった（供養）（186）。画風LORAとキャラLORAの同時適用は上手くいかない（420）。pov_handsタグ指定で大抵両手が出てしまい、単数形pov_handでも解決しない。single_handとかろうけて回避できる（172）。更新が止まっているとの指摘（18, 1000）。
- **用途**: 非検閲モデルでロリ官能小説生成→Anima用自然言語＋danbooruタグプロンプト化の3ターン実行（495）。無検閲版flash nextとgemma4 21Bで補足描写をさせた上でanimaでエロ画像生成（950）。
- **補足**: Animaエンハンスにかけるか2.9でいくか迷っている（19）。StrataでAnima生成画像から女性キャラクターの成年向けセリフを創作させた事例（108）。SDXLはanimaとかに押されている（423）。

### Krea2 / Krea2-turbo
- **選定理由**: Codexと組み合わせてプロンプト作成→生成→微調整のワークフロー。絵柄も実写・素人撮影風・アニメ画・フラット寄り等指定可能で2次も3次も同じモデルでいける（105）。AVの好きなコマをほぼ再現できるようになった（44）。GPTより性能は少し落ちるが、GPTは変な電子透かしで画質が悪くなるため回避できる（818）。
- **制約**: パンツを穿かせると股間がモッコリする（135）。
- **動作環境**: RTX5080上で画像生成（199）。ComfyUIでKrea2-turboによる画像生成をStrata連携で動かしている例（170）。OpenWebUIでチャット内でQwen-image-2.1やMiniMax-H3と共に生成できるツールを構築（515）。

### illustrious（イラストリアス / リアス）
- **選定理由**: 明示的な選定理由なし。長期間にわたり現役で使用されている（56）。
- **制約**: 指が6本になる問題（56, 285）。ストーリー性のある複数枚のエロ画像を作らせようとした際に限界を感じた（893）。今だに2023年感と表現される指問題に直面（56）。
- **補足**: SDXLやリアスの時期にここの絵からLoRAを作り販売で2000万売り上げたとの報告（741）。

### NovelAI (NAI)
- **言及**: NAI5のクオリティが高く文章まで生成する（59）。NAIはSDXLを採用したv3までしか絵師ブレンドができない（418）。NAI5は絵柄があまり混ざらず、シードごとに特定の絵師タグが全く効かないことがある（425）。VerUpで絵師タグ大量に並べる時代は終了というスレ上の認識（415）。日本語でナメクジを吐いて描かせたら大変酷い絵面になりchibi化しないと耐えられなかった（532）。初代NAIちゃんが強制オープンにされた（557）。

### Qwen-Image-2.1
- **選定理由**: ChatGPT感覚でチャット経由で使える。自然言語の入力が手軽（262）。i2i用途で実写に対する指示変更が機能する（180）。「change to perfectly nude.」でヌード化が可能、「this girl is 10yo.」等の補足情報で描写が調整される（180）。
- **制約**: 1枚目の背景と2枚目のキャラを合成したいだけなのにキャラのサイズや位置が変わる（475）。ズレるのは仕様（484）。Open WebUI＋ComfyUI連携で2回目の編集で出力がおかしくなる（485）。繰り返し編集させると触っていない部分が劣化する（489）。透過処理しても偽の市松模様ごと出力することもあり頼り切るのはまだ早い（484）。3月に使えそうなズレ対策LoRAがある（521）。

### nanobanana2.1
- **言及**: リリースが報告されている。エロ規制について「昔みたいに大手のクローズモデルでエロは不可能なんか？」という懸念（840）。flowから触ると勝手にプロンプトを健全仕様に改変してくる（914）。GPTと比較されてSOTAだと勘違いされるのを恐れて2.1という弱気なバージョン名にしたというスレ上の推測（945）。検閲も増えてて胸見えてたらそっと上着をかけてあげる丁寧な仕事される（945）。VRChat用3Dモデルのイメージ図生成に使用を試みている（431）。

### GPT Image / GPT Images
- **言及**: 参照画像生成に使用（72）。編集時に触っていない部分が劣化する現象がよくある（489）。絵がキモいという声があり無双っぷりを嫌がる向きがある（617）。チャッピー（ChatGPT）の画像生成は編集が楽で顔も指示や見本で好みに近づく（624）。水着などの露出度の高い画像でも弾き出すようになり使わなくなった（840）。

### Flux.2
- **選定理由**: 画像編集（edit）においてズレが少なく、Qwen-Image-2.1より性能が良かった（481）。Edit系の他モデルを試した中でflux.2が一番良かった（481）。

### flashgen / PDMD 2step
- **言及**: kijaiのhuggingfaceにターボが多数。flashgenが一番使えそう。PDMD 2stepは全然動かないがクッキリ出る（165）。

### バナナ2.1
- **選定理由**: GPTより性能は少し落ちるが、GPTは変な電子透かしで画質が悪くなるためこっちの方がいいかもしれない（818）。

## 動画生成モデル

### MiniMax H3 / MiniMax H3 Max / MMH3 / H3 Latent Relay
- **選定理由**: リップシンク動画生成に使用。ほぼリアルタイム生成だった（72）。H3 Latent RelayはContext Loopよりきれい（173）。
- **動作環境・設定値**:
  - 5060ti(16GB)・DDR4 128GB環境: モデル・スパースアテンション（sol-attn デフォ設定）＋comfy kitchen attention使用時、t2v 1280×732 15秒 20step生成に30分（684, 692, 696, 803）
  - RTX5090環境: 同一設定20stepで399秒（約6分40秒）（803）
  - モデルファイル構成: minimax_h3_fl2va_pruned_int8_convrot.safetensors (19.53 GB)、qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors (14.61 GB)、minimax_h3_video_vae_int8_convrot.safetensors (2.62 GB)、minimax_h3_audio_vae_fp32.safetensors (577.2 MB)（803）
  - RAM96GB環境で4070ti12GBでも使える（206）
- **制約**: 5070ti（VRAM16GB）ではminimaxでぶん回す部分が差別化されて速度が出ない（691）。LoRA対応テストで触手LoRAを作成し動画生成を試みたがアソコに触手が入ると絵が壊滅する。学習素材に全身絵を使ったため細かい表現が潰された可能性（189）。
- **補足**: Turbo LoRAやSpectrumの使用が推奨（693, 699, 811）。falが高速化版の公開を約束していたが忘れていると指摘（792）。XでMinimaxハマったからPRO 6000を5枚買ってる人を見つけた（341）。エロなしアクションのプロンプトをchatGPTに書かせた（466）。タイムスタンプやpictureやsubjectを毎回手打ちするのは変態（455）。

### Context Loop / HR-Endless-Sampler / H3-Longvideo
- **選定理由**: Context Loopが一番使いやすい（147）。Extenderを使えば参照画像の切り替えが柔軟にできる（148）。

## LLM・コーディングモデル

### Strata（Qwenエンジン）
- **選定理由**: Codex等では弾かれるエロゲーが作れる可能性（30）。LM Studioよりだいぶ早い（193）。OpenAI/Claude Code API互換でComfyUIカスタムノードやBionic、Unslothで動く（81）。対話型で修正指示を出す運用が楽（870）。ComfyUIと連携させてVRAM制御を自動で行える（508）。Pythonに強そうでGUIやツール系も作れそう。ローカルでもbuild to buildに達したかもしれない（770）。
- **動作環境・設定値**:
  - UD-Q4_K_XLをRAM192GB環境でテスト: GPU使用量15.4GB、共有GPU使用量68GB、RAM使用量121GB、平均3338tok/s（64Kコンテキスト）。IQ3_Sが6377tok/s。規制解除できず画像も読めないため削除検討（150）
  - RTX3080でStrata、RTX5080で画像生成、RAM128GBの2GPU構成例（199）
  - q3量子化はきつい、RAMがあるならnvfp4かq4推奨（390）
  - VRAM12GB以上、RAM64GB以上で頑張れるレベル。動画勢と同じかそれ以上の要求値（770）
  - strataとcomfyuiをフル使いしたらVRAM32GBでは足りなくなった（440）
  - 5090ならstrata 16gb残りはcomfyuiで良い（442）
  - 使用VRAMの上限を設定可能（442, 462）。vram_elasticオプションで自動でvramを他システムに渡したり再取得できる（462）。ComfyUIのモデルもStrataが制御して設定どおり空きを700M確保する（508）
- **制約**: comfyuiよりインストール難しそう（49）。ヘルメスでstrata使用、回答までの時間が長くなった気がする（445）。
- **補足**: Strata＋Hermes Desktopはコレ実質「Codex無料で使い放題プラン」（232）。codex対応（424）。Qwen3.8 IQ2-XS Strata Unslothでグリッド画像作成ツールをサクッと作成。ChatGPT無料枠では完成前に終わった（225）。海外redditでは「botさんもうstrataのことはいいから」というスレが立つほど話題（987）。「Strataに週遅れ、hermesに半年遅れで驚いてる奴ら」（957）。

### Claude Opus 5.5 / Claude 5.5シリーズ
- **選定理由**: 5.5になってから強すぎてこちらばかり使うようになった。OpenAIは反省してClaudeのリセット配れ（159）。仕様書渡しでテトリスを完全自動生成できた（674）。リバースエンジニアリング能力がほぼ出来上がっており、バイナリをソースに戻す能力がある（758）。caveduckでのエロチャットでClaude 5.5にしたらめっちゃエッチな文を書くようになった（403）。

# 総評

1. **Strata＋HermesがローカルLLM環境の覇権**: StrataはComfyUIとのVRAM自動制御・対話型修正指示のしやすさ・codex対応により定番化し、HermesはOpenWebUIより導入が楽で機能が揃っているとして選ばれている。両者の連携が実質「Codex無料で使い放題プラン」と認識されている。

2. **DeepSeekがAPI価格・脱獄性でローカル代替を凌駕**: 量子化Qwen3.8をローカルで使うよりDeepSeek脱獄APIの方が圧倒的に便利で精度も高いとされ、月40ドル程度で4.3Bトークン消費という実績が報告されている。キャッシュヒットの安さがエージェントループ用途で強力とされる。

3. **Animaが画像生成で現役継続、リアスは限界露呈**: AnimaはLoRA作成の容易さ・指の本数の正確性・プロンプト手打ちのシンプルさで選ばれ続けているが、絵柄混ぜや画風LORA＋キャラLORA同時適用の困難さが制約として残る。リアスはストーリー性のある複数枚エロ画像生成で限界が感じられている。新モデルnanobanana2.1は検閲強化への懸念が出ている。

4. **MiniMax H3が動画生成の実用検証段階**: 5060ti16GB環境で1280×732・15秒・20step生成に30分、RTX5090で399秒という具体的なベンチマークが報告され、Turbo LoRAやSpectrumの使用が推奨されている。5070tiでは速度差別化が懸念され、LoRA学習素材の選び方で細部表現が壊滅する問題が確認されている。

# なんJ ローカルAIスレ レポート

## ローカルLLM・エージェント環境

### Strata / Hermes / ハーネス関連
- Strata＋Hermes Desktopは「Codex無料で使い放題プラン」と評されている（232）
- Strataの作者が考える4大ハーネスは Hermes, pi, open code, Deepseek harness（239）
- HermesはAPI経由でもAutoCompaction（コンテキスト圧縮）に対応する（243,244,245）。対照的にUnslothDesktopはAPI経由ではAutoCompactionしないため、引き継ぎ書を作成して新セッションで続きを行う手間がある（243）
- Hermes Desktopはたまにバグるため、CLIかTUIでの使用が推奨される（240）
- Hermesは常時起動で日常的なルーティン作業を自動化するパーソナルアシスタントの思想。codexみたいにしたいならClaude Codeのバックエンドを変えるのが一番簡単（238）
- LM Studio BionicにはOpenAI互換APIの設定がなく、LM StudioでDLしたモデルを優先的に使う思想（247）
- Strataは更新が速く利用者が増加、情報も充実してきた（318）。Strataのq3量子化はきついため、RAMがあればnvfp4かq4が推奨される（390）
- コーディング重視ならPiをハーネスにするのが最もミニマムで使いやすい。Pi2が出たばかり。Strataの推奨もPi（263）
- Strataがcodex対応したとの報告（424）

### モデルに関する議論
- Deepseek v4.1 flashは価格と性能の両面でローカル（Strata等）よりマシ、エロも通る、API価格もタダ同然との主張（235）。趣味程度のコーディングでも月3000円かかると思っていたが100円で済みかねない雰囲気（242）
- Qwen 3.8 Flash NextはQwen 4で使うn-gramアーキテクチャを先採用した先行試験型モデル。量子化無しだと2.4T-A95Bと同性能（256,259）。最新AAベンチ完走のGPT-5.5とOpus 4.8を足すとこの位置（260）
- Qwen3.8 Flash Nextはチャット性能が悪く、コーディングならCodexやClaudeを使う層には使い所がないとの見方（276）。プロンプトエディターとしてのみなら求められるスペックに見合わない、コーディングかエージェント利用してなんぼのモデル（413）
- スレ上の予想: AGIはopus5.5っぽい（329）

## ローカルLLMの用途（エロ以外）

- 5090+メインメモリ96GBの環境でStrataやQwen3.8を使ってもエロチャット以外の有用な用途が思い浮かばないとの声（385）。エロチャットやStrata Qwen3.8ではゴミ、RAM使ってまで起動も止まる（396）
- これに対する反論: 個人情報や社外秘データを利用した処理、特定モデルに最適化した処理を数年継続動かす用途ではモデル廃止のないローカルが好まれる。小型モデルは通信環境が安定しない場所で通訳や画像判別に使える。税務など規約面でリスクのある用途でもローカル導入が聞かれる（389）
- redditのLocalLLaMA板やStableDiffusion板の翻訳をvLLMで建てたローカルLLMで100多重処理すると、トピック主の書き込みを見ている間にスレ全体の翻訳が終わる。OSS開発者が直接書き込みに来るため定期的に見ている（395）
- ローカルLLMでMiniMaxのエロプロンプトを作成する用途（400）
- お高く止まったチャッピー（ChatGPT）では答えてくれないことを聞けるだけでも構築する価値がある（401）
- 脱獄LLMはエロ要素があるゲームを作る場合に必須。Claude、GPT、Museは勝手に検閲をソースコードに埋め込むが、DeepSeekやGrokはやらない、GLMは微妙なライン（428）
- 参照画像を渡して自然文で注文をつけてワークフロー作成からr2vで1分の動画作成、リテイクも自然文でやらせるフローが組めそう。素材を集めてエロゲを作る、ffmpegでhmvを作らせる等の発展も考えられる（397）

## 画像生成

### 絵師タグ・LoRAの混ぜ方
- 絵師タグ複数で絵柄を混ぜるのはSDXLが見せた幻のようなもの（380）。Animaではプロンプトのみだと混ざりが悪い（411）
- 絵師を混ぜるならartist-packを使い、適当に出力してからLoRAを作ってモデルにマージするのが楽（279）。`(<◯◯ style:0.5>)`で絵師×2するよりLoRAを当てた方がいい感じになることが多い（376）
- Animaで画風固定しつつオリキャラを作るには「画風LoRA作る→キャラ作る→キャラ素材他AIで増やす→LoRA学習」の繰り返し。画風LoRAとキャラLoRAの同時適用は上手くいかない（420）
- SDXLは絵柄を混ぜて新しいのを作る意味でこれほど優れたものはない。Anima用のLoRAを作るためにも必要（423）。NAI v3（SDXL採用）までしか絵師ブレンドはできない（418）。NAI5では絵柄が混ざらずシードごとに特定の絵師タグが全く効かないことがある（425）
- AnimaはU-NET+タグ学習の独自動作により絵師タグ大量ブレンドを引き起こした（415）

### 各モデルの性状
- リアス（AI）だと指が6本になるがAnimaだと4本になる（285）
- 64GB RAM, 2070super, 5060Tiで動画を試したら480x480, 5秒でメモリ満杯になり、それより大きいと落ちる（377）

## ハードウェア・市場動向

### メモリ
- メモリ128GBは現在では富豪レベルだが、1年前なら8万で192GB、6万で128GBにできた。Hunyuan流行の2025年初頭から最低128GB必要と言われていた。QIE2509やFlux2のメモリ馬鹿食いモデルが出て高騰が騒がれる前に駆け込みで128GBにした人が多い（255）
- 96GBあるがギリギリ感が出てきたとの声（302）
- DDR3 128GB以上搭載できるXeonやマザボの中古相場がジワジワ上がっている（357,360）

### SSD・ストレージ
- SSDが異様に高い（351,354）。SSDは来年後半に供給が均衡か過剰になる可能性があり、一端値段が落ち着く可能性が高い（358）。ただし来年からRubinサーバーが本格稼働するため不透明（369）。NAND供給はデータセンター向けも含め供給拡大が需要に見合う程度には見込まれる（373）
- 工房店舗でSN850Xの8tbが13万まで値下がりしていたため購入した報告（356）
- 速度のいらない大量書き込み作業は中古HDDにやらせるのもあり（353）

### Mac Studio / Apple
- Mac Studio購入を検討。Apple careに入るべきかという相談（339）
- 故障する可能性が少しでもあるなら他社サポートより割安なので入っとべき（342）。Mac StudioはSoCやメモリ、電源部がメインボードに一体で、故障時にメインボード丸ごと交換になるため修理代が高い。AI用途で継続的高負荷なら故障率が上がるためApple careは無駄ではない（365）
- Apple製品にしては珍しくSSDが別モジュールのため、SSD故障時はSSDモジュール交換のみで済む（365）
- 10月下旬にMac Studio M5の512GBが出るっぽい。次はM6をとばしてM7でAI特化モデルにするという記事もある。来年M7発売まで待つとインフレで値上がりしている懸念（364）
- スレ上の意見: そんなこと言ってたらAGI特化のM10チップを待つことになる、欲しい時が買い時（369）
- Mac Studioは買取価格が高く、資産投資としての価値もあるとの見方（363）

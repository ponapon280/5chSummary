# ログ抽出レポート：生成AIモデル関連

## 画像・動画生成モデル

### Krea2 / Krea2-turbo
- Codexと組み合わせてプロンプト作成→生成→微調整のワークフローで使用。Codexにプロンプト作成引き継ぎメモを作らせ、Grokにドロップして教えれば節約になる。絵柄も実写・素人撮影風・アニメ画・フラット寄り等指定可能で2次も3次も同じモデルでいける（105）
- パンツを穿かせると股間がモッコリする事象が報告されている（135）
- AVの好きなコマをほぼ再現できるようになったとの声（44）
- ComfyUIでKrea2-turboによる画像生成をStrata連携で動かしている例がある（170）

### MiniMax H3 Max R2V / MMH3 / H3 Latent Relay
- リップシンク動画生成に使用。ほぼリアルタイム生成だった（72）
- H3 Latent RelayはContext Loopよりきれいとされる（173）
- RAM96GB環境で4070ti12GBでも使える（206）
- LoRA対応テストで触手LoRAを作成し動画生成を試みたが、アソコに触手が入ると絵が壊滅する問題が発生。学習素材に全身絵を使ったため細かい表現が潰された可能性（189）

### Gemini 3.8 Flash / Qwen3.8 Flash Next
- Gemini 3.8 Flash TTSで大阪弁TTSを生成したが、Eleven V4の方が良かった（72）
- Qwen3.8 Flash Nextはモデルの一部をSSDに置ける。Qwen4も同じアーキテクチャになるはずと期待されている（211）
- チャットには勿体無いからハーネスを使うべき（198）

### GPT-Image2.5
- 参照画像生成に使用（72）

### Eleven V4 TTS
- 大阪弁TTS生成に使用。Gemini 3.8 Flash TTSより良かった（72）

### Astra 6.1 Sol Ultrafast
- Ultrafastのカミングスーン。Pro500（200も来る？）民以外は関係なさそう（157）
- 6.1 Astraはお行儀が悪すぎて公開しないことになったというスレ上の噂（160）
- Astra激高+高速で回したら秒で溶けた。普段使ったらあかん（162）

### Ideogram 4.0

### Strataが選ばれる理由
- Codex等では弾かれるエロゲーが作れる可能性（30）
- LM Studioより早い（193）
- OpenAI/Claude Code API互換でComfyUIカスタムノードやBionic、Unslothで動く（81）

### Claude Opus 5.5が選ばれる理由
- 5.5シリーズが強すぎる（159）

### Animaが選ばれる理由（除外対象だが選定理由を記録）
- LoRAが圧倒的に作りやすい。VRAM4GBの民でなければ余裕で作れる（191）

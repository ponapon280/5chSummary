# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI

- **ComfyUI v0.39リリース**: 新バージョンが公開されたとの報告がある（>>675）。

- **ComfyUIを利用したプロンプト自動生成ワークフロー**: Swift-ablをbat（`--idol-unload 5`）で起動し、ComfyUI上でchatにpostしてプロンプトを作成、完了後にunloadにpost、終了時はbatをCtrl+Cで停止する運用方法が紹介されている（>>639）。

- **ComfyUI上での動画生成（minimaxH3）の高速化議論**: 5060ti(16GB)＋DDR4 128GB環境で、モデル・スパースアテンション（sol-attn デフォ設定）＋モデルアテンションバックエンド（comfy kitchen attention）を使用し、t2v 1280*732 15秒を20stepで約30分（399秒）で生成している（>>684, >>803）。モデルファイルサイズは `minimax_h3_fl2va_pruned_int8_convrot.safetensors (19.53 GB)`、テキストエンコーダ `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors (14.61 GB)`、VAE `minimax_h3_video_vae_int8_convrot.safetensors (2.62 GB)` / `minimax_h3_audio_vae_fp32.safetensors (577.2 MB)`（>>803）。

- **ComfyUI高速化ノード構成**: `Model Patch Torch Setting (true)` → `ck-attention` → `Model Sparse Attention (sla)` の順序で接続するのが推奨されている。プロンプト構築中はウェイトをw4a8にし、comfyの`turbo_4step`を使用する（>>750）。

- **ComfyUI動画生成の解像度・ステップ数調整**: 732Pの15秒は生成時間が長すぎるため、0.5MP〜0.6MPに解像度を下げて生成し、アップスケールする手法が推奨されている。Turbo LoRA不使用時はSpectrumを使用、Turbo LoRA使用時はDMADやema600が定番品（>>697, >>699）。

- **ComfyUI環境での他ユーザー比較**: 5060ti 16GB DDR3 32GB環境でSageAttn＋sol-attn＋VRAM節約ノードを使用し、ref2va 1MP 8stepを12分で生成している事例（>>696）。RTX5090環境では20stepで約400秒（Latent Relay使用で遅くなっているため、15秒1本勝負なら5分程度と推測）（>>692）。

- **X2 VAEの比較**: X2vaeで2倍にする方法とRTXの機能で行う方法の比較について質問が出ている（>>704）。veda＋X2 VAE int8で低解像度生成する手法も紹介されている（>>693）。

- **Turbo LoRAによる高速化**: Turboを入れないと高速化は始まらない。20stepでもSpectrumを入れると劣化があるため、Turboの使用が推奨されている（>>811）。

- **ComfyUIの習熟度**: ComfyUIだけでも扱いきれずにヒーヒー言っている状態で、最近のローカルLLMの話にはついていけないという声がある（>>743）。

## nano-banana

- **nano-banana 2.1（バナナ2.1）リリース**: GPTより性能は少し落ちるが、GPTは変な電子透かしで画質が悪くなるため、nano-bananaの方が良い可能性があるとの評価（>>818）。選定理由として「GPTの電子透かしによる画質低下を回避できる点」が挙げられている。

## Strata / Hermes（ローカルLLMハーネス・エージェントツール）

- **Strata＋Hermesの利用**: Strataを使用する場合、Hermesが定番のハーネスになるという情報がある（>>636）。Strata作者が使用しているツールの紹介もある（>>637）。

- **Hermes経由でのStrata最適化**: HermesにStrataの最適化を依頼すると、自身のアンロードしながら調整を行うという挙動が確認されている（>>642）。

- **MCP経由でのStrata起動制御**: Hermesを使ってMCPでStrataの起動・終了も可能だが、MCP用の軽量エージェントを探す必要がある（>>639）。

- **Strataの要件**: ローカルLLM用途でStrataを使用する場合、VRAM12GB以上、RAM64GB以上が必要。動画生成勢と同等以上の要求値で、高騰前にRAMをガン積みした人なら試せる（>>770）。

## Codex / Open Code / ハーネス（コーディング自動化ツール）

- **Opus5.5によるコーディングツール構築**: Opus5.5がCodexとQwen3.8-Flash-Nextを使ってコーディングするツールを作成。簡単な仕様書を渡して完全自動でテトリスを作れたとの報告（>>674）。

- **open codeのハーネス利用**: qwen3.8-flash-next-iq3_sでサ終ゲームを再現するコーディング中。chatGPTのおすすめでharnessにopen codeを使用しているが、ジェネリックcodexみたいとの評価（>>754）。

- **AIエージェントによる自立行動**: codexやハーネスを使った自立行動について、ローカル自動行動AIなどの世界的な呼び名があるか質問されている。「AIエージェント」「エージェントループ」「ループエンジニアリング」などの呼称が挙がっている（>>802, >>804, >>805, >>809）。

## ペイントソフト・リビルドツール

- **既存ソフトのAI再構築**: AIを使ってphotoshopやillustratorをオープンソースで再構築・公開するのが流行り始めている。まだオリジナルには及ばないが、AIの進化と共にいずれ超えるとの見方（>>821）。

- **AI連携ペイントソフト**: AIと連携されたペイントソフトを作り、copainterのようなものを作る人はいないかという問いがある（>>822）。

- **有料アプリの代替作成**: 類似品をCodexに作らせることができるようになり、win32アプリも余裕で作れる。試しに作らせたらクソ軽かったとの報告（>>823, >>825）。

- **リビルト品への懸念**: 正規品を使い続ける理由として、リビルト品を使う理由がないこと、何が仕込まれているか分からないことが挙げられている（>>824）。

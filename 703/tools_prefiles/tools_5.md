# 生成AI関連「ツール」話題 抽出レポート

## 1. 画像編集・デザインツール全般

### Adobe（Photoshop・Illustrator）の代替とAI影響
- **AIによる画像編集機能の普及**: チャッピー（ChatGPT）本体への画像生成＆編集機能投入以降が「ゲームチェンジャー」になり、非デザイン畑の人もチラシやポスターを自分で作れるようになった（885）
- **Adobe株価への影響**: Adobeは初期からAI技術導入に熱心だったが、逆にAIに食われることになった。株価は「喰われてる」（904）。画像編集ソフトの需要自体が縮む未来しかない（916）
- **代替ソフトの評価**: AIでフォトショの基本機能だけ真似できたから「AI驚き屋がわめいてるだけ」（903）。実際にはまだ売り上げ伸ばしてる（926）。Acrobatの代替はなかなかええよ（923）だが日本語テキスト入力したら????って表示された（941）
- **PSDファイル対応**: レイヤー保持しながらPSDを開けるだけで「すごい」と驚くレベルが低すぎるという指摘（917、925）
- **年間ライセンス悩み**: デザイン関係の仕事でもなくちょっとしたチラシ編集用に持ってたが、今年でオシマイかと考えている（938）

### フリー画像編集ソフト
- **GIMP**: GIMP3は「圧倒的に高機能やし使いやすい」けど、GIMP2.10が3秒で立ち上がるため使い続けている。GIMP3は閉じる癖があると立ち上げ直しに20秒かかる（937）
- **Krita**: kritaで頑張っている。フォトショの機能はよく知らない（909）
- **gimpとkdenlive**: これらで画像や動画編集してたので偽フォトショに困惑中（915）
- **GIMP操作性**: gimpは操作性カス、すアフィ死ねニティは文字の縦型対応してない（898）

### 画像編集AIの優位性
- フォトショのAI編集なんて他のサービスのほうが優秀。キリヌキだけは最新バージョン優位だったが他サービスでも対応できるようになってきた（894）
- フォトショなんかにサブスク課金するくらいなら画像編集使えるAIにサブスクしたほうが早いしやれること多い（874）

## 4. 自作ツール・エージェント開発

### ペイントツール自作
- ペイントツールの自作はクリスタ超えられない気がする。3D使えて有志作成のアセットも豊富にあるとAIでも大変そう（844）
- Photoshop同等は無理だが必要な時に必要なツールだけ作ればええ。背景消すとか複数画像をグリッド画像に変換とか（873）
- 自分専用モザイクツールを作った（875）

### OSS自己改造・コード生成ツール
- **Claude（opus）によるOSS自己改造**: OSSの画像編集ソフトをopusで自己改造している。筋もこちらのほうがええ（878）
- **Codex / Claude Code**: vectorにあるツールのバグ修正でソースコード欲しくなるが、codexやClaudeCodeに機能だけ言えばワンプロンプトで同じもの作ってくれる（891）。Adobeがやるはずだった自動操作機能をCodexやClaudeにもってかれた（927）
- **Codexのセキュリティ懸念**: config.tomlで特定範囲の読み取り禁止しても実態としては読み取れてしまう既知の不具合。エロフォルダがいつ読まれるかヒヤヒヤする（899）
- **クリーンルーム設計**: チャッピーはカスタムノード作成を頼んでも1から作成する。ソースまるまんまコピーでもいいよと言っても元の権利確認しにいく（889）

### AIエージェントの価値
- アプリが作れるレベルまで来てるからエージェントのサブスクが万円になってもおかしくない（879）

## 6. FreeToken（LLM推論ツール）

- **目的**: ローカルLLMをVRAM載せきらずに早く動かすやつ（908）
- **実測結果**: ワイ環（4080s/192GB）で規制解除版が動いたのはGemma4 26B A4B BF16だけ。16tok/sで遅くて実用厳しい。VRAMが2.7GB足りなくて動かなかったが24GBならQwen3.8-Flash-Next-ABLITERATED-NVFP4が動く可能性高い（906）
- **メモリ要件**: Qwen3.8-Flash-Next-ABLITERATED-NVFP4は125GBあるのでRAM124GBだときついかも（911）

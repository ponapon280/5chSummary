# 生成AIモデル関連話題の抽出レポート

## モデル別の話題

### チャッピー（ChatGPT / OpenAI）
- **特徴・評価**: 下手なポンプ出しでも綺麗な絵を出してくれるとされる（レス108）。エースコンバットの理解度が高いとの報告がある（レス124）。

### Gemini（Google）
- **特徴・評価**: ドスケベな文章は得意だが、指示に対して適当で、確認が必要になるとされる。例として「ムカデ人間？OKOK！」のように返してくることがある（レス215）。
- **Local Prompt Studioでの挙動**: LMStudioでシステムプロンプトを教えてGemmi4（Gemini4の表記と思われる）を使うと、キャラクターをサブジェクト分けして指示を出してくれる（レス99）。また「Gemmi4 26B uncensored IQ4 NL」を使用したところ、登場人物二人なのに小物や脇役まで含めてSubjectを8個設定する癖のある挙動が確認された（レス127）。

### Claude
- **特徴・評価**: 現実世界の人間と契約を交わす際のようなセーフティネットの例外に対応できないため書いてくれない代わりに、同意した内容を逸脱しないよう忠実に文章を書く。設定忘れも直してくれる（レス215）。

### Krea2 / Krea3
- **特徴・評価**: リアルな画像がゴリゴリ出せるようになった（レス83）。驚き屋（反応する利用者層）が驚くレベルでゲームチェンジャーと認識されている（レス119）。人物描写に優れるqwen2.1と比較して、風景や人工物の描写が優れている（レス209）。
- **編集用途**: 大きな改変に適している（レス219）。
- **Krea3に関する話題**: 既に登場の声があり（レス199）、画像参照機能が存在するとされる（レス204）。ただし、オープンウェイトで公開されてもideogramレベルの重量モデルだと実質使えないという懸念がある（レス231）。Krea2がローカル用にサイズ調整されて出た経緯から、Krea3もローカルで使えないサイズを出すメリットはないとの推測がある（レス233）。

### MiniMax（H3）
- **特徴・評価**: qwen2.1と共に、クラウドでしか使えなかったような動画や画像AIに近いものがローカルに来たこととして、最近のデカい事件の一つとされる（レス203、レス119）。驚き屋が驚くレベルのゲームチェンジャーとの認識（レス119）。

- **特徴・評価**: Krea2で出せなかったリアルがゴリゴリ出せるようになった。参照画像でH3もモリモリ出せる（レス83）。1girlポン出しで二次絵を出してくる（レス164）。

## その他の話題

### ツール・周辺技術
- **Local Prompt Studio**: プロンプトの翻訳を見ながら編集できるが、推奨モデルQwen3-8B Q4_KMをCPUで動かすと時間がかかる（レス86）。Qwen3 8Bではシステムプロンプトの規約を守れずJSONが壊れるため、8Bを捨ててPythonとLLMのハイブリッド構成にしたとの報告がある（レス102）。Ref2Vaのルールに沿ったシステムプロンプトが自動適用されるとの指摘もあるが、サブジェクト分けが弱いとの課題が挙げられている（レス99）。全体として推奨モデルではうまくいかず、モデルを変えると翻訳等も上手くいかなくなるという評価がある（レス194）。
- **ComfyUI**: 0.37→0.39へのアップデートで問題なし（レス168）。ポータブル版はアップデートで問題が出た場合、新規セットアップし直すのが確実。デスクトップ版ではGUIでモデルやoutputフォルダの場所を指定でき、extra_model_paths.yamlをいじる必要がない（レス217）。安定版updateは「update_comfyui_stable.bat」が推奨される（レス232）。

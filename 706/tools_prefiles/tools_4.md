# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI / rgthree-comfy

- **rgthree-comfyの不具合関連**
  - rgthree-comfyを使用している環境でワークフロー入り画像をドラッグ&ドロップするとワークフローが読み込めない（配置がぶっ壊れて展開される）という問題が報告されている（>>655, >>718）。
  - GitHubのissueで、ComfyUI_frontend v1.52.7で修正されるというレスがあり、作者がComfyUI側のバグだというラベルを付けている（>>718）。
  - 一方で、ComfyUI 0.40.0、frontend 1.55.17環境では問題なく画像からワークフローが読めているという報告もある（>>686, >>688）。
  - Fast Group Bypasser/Muterの使用が原因と疑われたが、検証の結果Bypasser/Muter関係なかったとのこと（>>689, >>701, >>714）。
  - rgthree-comfyはアプデが滞っているため、使用をやめるべきかという意見がある（>>668, >>677）。

- **rgthree-comfyの代替・移行**
  - rgthree-comfyで使っている機能をCodex先生に作成してもらい、rgthree-comfyを消してNode2.0を採用した者がいる（>>690）。
  - rgthreeのRelay, Repeaterはワイヤレス化すると便利とのこと（>>711）。
  - frontend 1.55.17環境ではseed (rgthree)を使用して動画からWFを読めているという報告がある（>>679）。

- **ComfyUI Nodes 2.0**
  - ComfyUI最新版で画像のD&Dができない人はNodes 2.0を使っている可能性が指摘されている（>>733）。

## LoRA学習ツール

- **kohya_lora_param_gui**
  - 三面図を3つの画像に分割し、wd14-tagger-standaloneでタグ抽出、各txtの先頭にcharacter_nameを追加し、kohya_lora_param_guiで学習率0.0001 / 200ステップ / CAMEで即席LoRAを作成する手法が紹介されている（>>807）。

- **wd14-tagger-standalone**
  - LoRA素材作成時にタグ抽出に使用されている（>>807）。

- **irodoriv4 (Emoji-TTS) のLoRA学習**
  - irodoriv4 4.1 smallのLoRA学習はv3と比べて学習時間が倍近いとのこと。RTX4090で30分（1000step）、RTX4070で1時間（1000step）、5060Ti 16GBで9時間かかったとの報告がある（>>649, >>652, >>654, >>656）。
  - Emoji-TTSのメンテ更新が行われ、v4-smallの対応見直しが完了。strataを使ってローカルエージェントコーディングしているとのこと（>>774, >>806）。
  - 本家リポジトリを解析してlargeや量子化など完全対応させたいとのこと（>>774）。
  - 参照音声を120秒分ドカッと分割で放り込めるよう、本家と同じ仕様にしてほしいという要望がある（>>778, >>786）。

## モザイク・動画編集ツール

- 動画にモザイクを掛けるツールをフルスクラッチで作った事例がある（車のナンバープレートや背景の人物にモザイク・ぼかしを施すツール）（>>827）。
- 動画編集ソフト（Davinci有料版、ダヴィンチ）のモーショントラッキングの精度は良くなく、モザイクの自動化は難しいとのこと（>>828, >>835）。
- 高精度にしたい動画のモザイクは1コマ1コマクリスタでつけて動画にまとめている（>>830）。
- **filmCraft**: 映像編集をエージェントにやらせたい場合、filmCraftがそのままcli操作でエージェント対応していそうな雰囲気がある。Davinciの有料版を買うか迷っていたが、filmCraftを使ってみたニキがいるか質問されている（>>808）。

## 外部GPU・分散処理ツール

- **Backburner**: iPhoneを外付けGPU代わりに使ってMacのAI処理を高速化するアプリ。Backburner専用のllama.cppで使用する。レイヤーの後半をiPhoneのGPU+NPUにパイプライン処理させてプレフィルを短縮、KVキャッシュをiPhone側に逃がしてコンテキスト長を128kに倍増できる。1台でローカルLLMの処理が40%ほど速くなったとの報告がある（>>712, >>730, >>744, >>752）。
  - 選定理由: ローカルLLMはVRAM容量が一番のボトルネックになるため、手元のスマホのメモリと演算器をサブノードとして足せるのは理に適っているから（>>730）。

## 画像生成系ツール・機能

- **Krea2**
  - VRAM16GBでStrataとComfyUI併用する場合、Strataの起動オプションに --vram-reserve-mib 3800 を設定するとComfyUI用の領域確保ができるため、Krea2でもオフロードなしで動く。Strataの速度が15%落ちて画像生成時間は1.5倍くらいになるが、アンロード/ロード待ちよりはマシ（>>796）。
  - krea2のエディット機能のどれがいいか質問がある（>>765）。

- **MINIMAX-H3**
  - 画像出力する機能に参照の三面図を入れてポーズと角度を入れて素材を増やす使い方ができる（>>741）。
  - fun controlnetについて、H3の参照能力がすごすぎて使う意味があるか疑問視されている（>>667）。
  - 選定理由: 参照能力が高く、差分増やすのに主流になっている（>>768）。

- **GPT image (チャッピー)**
  - ドットバイドットでドット絵が作れるのは今んとこGPT imageだけ（>>706）。
  - 素材を勝手に作ってゲームに組み込んでくれる（>>817）。

- **MINIMAX FLF2V**
  - 全く同じ画像を入れてループ動画作ろうとしても最初と最後のフレームの画像が微妙に違ってループ動画にならない問題がある（>>803）。

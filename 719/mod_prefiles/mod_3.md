# 抽出レポート：生成AIモデル関連話題

## Gemini（ジェミニ / ジェミナイ）

- **全般・性能評価**
  - 画像生成は素晴らしいが動画が停滞しており、複数の面でH3に負けている（451）
  - 言語能力は常にトップクラス（624）
  - ハルシネーションの多さと、検索サボり・勝手な着手などが悪点（625, 627, 630）
  - `gemini-decision`の精度が高く、JevやOpenAIのDecisionsより頭2つ抜けている（455）

- **エロ系（テキスト）**
  - 日本語エロ文書力は圧倒的（431）
  - エロ系は芋蔓banが怖くて出来ないという声がある（443）
  - 高度な脱獄プロンプトはBAN対象だが、説得レベルのエロ遊びならノーダメという見解（445）
  - エロさでは常にトップランナー（572）

- **Neon / Hydrogen**
  - GeminiのNeonになってからエロに厳しくなったという報告（507）
  - 一方で、HydrogenとNeonで以前のエロさが戻ったという報告もある（569）
  - `4Argon`時代は種付けプレスを拒否されたが、`4Neon`ではガバガバユルユルで受け入れた（579）
  - `4Neon`で日本語の上手さがヤバいほど向上した（623）
  - `3.8flash`と`argon`時代よりはエロが緩くなった（547）

- **Argon / 3.1 preview**
  - `4Argon`でもちゃんとやれば初手である程度のエロは出せる（588）
  - `PRO3.1preview`はJS非同意リンカーン等でも出してくれるため手放せない（580）

- **呼称**
  - 公式が「ジェミナイ」と呼んでおり、英語圏ではジェミナイが正解（478, 528）
  - 音声会話でチャッピーも「ジェミナイ」と発音した（487）
  - 日本語記事では「ジェミニ」と呼ばれることが多い（528）

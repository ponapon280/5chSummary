## 抽出結果：ツールに関する話題

### ドライバ・ハードウェア関連

- **NVIDIAドライバのSSD大量書き込み不具合**: GeForceドライバー621.14以降でSSDへ大量書き込みが発生する不具合が報告されている。ログ削除で約9割減に軽減される（439, 449, 472）。621.14より621.24の方が書き込み量がえげつないという報告あり（449）。ログを差分追記ではなく毎回全て書き出しする仕様のため、元のログが多いほど書き込み量が増える（463）。Studioドライバの621.14でも発生を確認した報告がある（567）。ドライバーバージョンを下げて対応したという声もある（494）。

- **Apple M5 Pro 64GB Mac miniでの動画生成**: Appleが爆速動画生成モデルを公開。M5 Pro 64GB Mac miniで5秒動画が30秒で生成可能。スレ上では「CUDA逝くわ」との反応がある（533）。これがGPU＋CUDAの時代終わりにつながるかという議論が発生し、CUDAの圧倒的エコシステムが強みであるという指摘もあった（537, 541, 548）。M5 Ultraを買いたいという声もあるがMac値上が止まらないとの懸念も（535）。

- **大手の脱nVidia**: 大手が全部脱nVidiaしているように見えるという指摘。革ジャン（NVIDIA）をやり過ぎたのではとの意見（539, 542）。TSMCやメモリ屋がNVIDIAとの口約束レベルの取引を見直す動きがあるという噂（543）。

### 生成ツール・ワークフロー関連

- **Strata**: クソ落書きから画像生成を行うワークフローで使用されている。「クソ落書き -> strata -> MOSS+BBOX」の流れで使用された事例がある（549, 554）。プロンプトを吐かせるだけでもレベルが違うかどうかの質問があり、エロ方面でも使えるかどうかの話題が出た（589）。Strata本家は無改造だとGemmaを動かすのは無理という指摘があり（595）、Gemma4の31BはStrataでも動かないが26BA4Bならサクサク動くとの情報がある（599）。「rustingstrata」を試すという声も（597）。

- **BBOX（B-BOX）**: Claude君にbboxを触らせるのに楽しくなってきたとの報告。ここで得たノウホウをエロポーズに応用するという目的がある（552）。「MOSS+BBOX」の組み合わせで使用される（549）。ギターの向きが逆になる事象が発生（549, 555）。野球モーションなどにもbboxesが使えそうとの意見（614）。

- **SillyTavern**: アンソロピックの上場を受けてSillyTavernで遊ぶという報告がある（544）。

- **lm-studio / Marinara Engine**: lm-studioから他のツールへお引越し中との報告。lm-studioは残しつつMarinara Engineの接続先を変えるという話（606）。前提を理解せずに飛びつくのはいかんと注意も受けている（598）。

- **Civitaiのコミッションサービス**: Civitaiがコミッションサービスを始めたとの情報。依頼を聞くだけでやる気が減るという感想（516）。

### サンプラー・解像度・ステップ数に関するツール上のノウハウ

- **turbo（サンプラー）**: 絵柄安定用にturboは効く場合があるとの指摘（434）。1.5MP出力でクオリティを上げつつ40stepだと時間がかかるため、turboや二段サンプラーを上手く使えないか試行中との報告（608）。

- **SDXL時代と現在の比較**: SDXLの頃は1枚数秒でガシャして良い奴だけ拾っていたが、今ではプロンプトさえしっかりしていればちゃんとしたものは出てくるが1枚数十秒かかるようになったという感想（611）。

- **出力解像度**: MOSSは1024×1024が標準解像度なのかという疑問。1MP（1024p）だと狭さを感じ、1.5MP出力した方がクオリティは上がるという体感の報告あり。ポン出し2Kで出しているユーザーもおり、1Mはつぶれがちとのこと（604, 608, 619）。

### その他のツール関連

- **LoRA**: 野球モーションを安定して出せない問題に対し、LoRAがないため自分でアレコレする必要があるという指摘（607）。チャッピーでも野球の動作中画像が出せないという話題で、あやせニキがLoRAを作っていたという情報（617）。

- **PHP / NGINXの脆弱性**: PHPで新たな重大脆弱性が発見された。AIを使って前回気づいている人もいるかもしれず、手遅れの可能性の懸念。NGINXにも脆弱性があるとの情報（532, 545）。ただし今回は特殊な環境下（設定）での話で、session.serialize_handlerをデフォルトから変えている前提などの条件が必要との分析（545）。

- **i2i / v2v**: 実際の写真からi2iを駆使すれば動作生成に使えるかもしれないという提案（612）。v2vはi2iを枚数分ゴリ押しなのかという質問（615）。

# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI (comfy)

- **スマホからのリモート操作**：自宅PCのローカルAI（ComfyUI）をスマホから操作できるというnote記事が投稿され、スレ上で大きな反響を呼んだ。記事は980円の有料→後に無料に変更（277, 279, 286, 329, 335）。手法としては起動オプションに`--listen`を付けてPC側のIPアドレスをスマホブラウザで叩く方法や、RDP（リモートデスクトップ）を使う方法が言及された（326, 342）。ただし`--listen`での公開は「セキュリティガバガバ」との指摘あり（350）。Tailscaleを使用しているとの記述もあった（339）。

- **ドラッグ＆ドロップでワークフロー再現**：ComfyUIで生成した画像をドラッグ・アンド・ドロップでComfyUIに置くと、メタデータをもとにワークフローを再現できるというtipsが共有された（345）。

- **バージョンアップ**：ComfyUI v0.46.0がリリースされているとの報告（383）。

- **カスタムノードのエラー**：Animaの日本語文字入れLoRAを試した際、公式webp画像にワークフローが入っているものの`SpectrumKSamplerModGuidance`のエラーが治らず使用できなかったという報告（368, 384）。

## その他のツール・関連環境

### MiniMax H3 Image Edit (MMH3IE / P-H3-Image)
- Moss Imageで縦長（1200x1920）画像を生成し、MiniMaxH3ImageEditで横長にoutpaintするテストが報告された。指示は英語の文章のみで、うまく拡張できる一方、境目が見えたり繋がらなかったりすることもある。中央部分は元のMoss-Image画像を feathering mask で被せている（263, 265）。
- リアス（illustrious）の絵にP-H3-Imageでspeech bubble（吹き出し）をやると綺麗に出たとの報告（386）。

### Strata
- Strataをぶん回していたらモデルをリードしているSSDのマウントが外れ、再起動でも直らずシャットダウン→30分放置で復旧した事例。リード専用でもSSDへの負担が大きいとの指摘（258）。
- StrataでQwen3.8FNと同等性能のクラウドAIで無料・使い放題のものを探す声があるが、完全無料はないとの反応（261, 281）。月額＋従量課金のアグリゲーターならそのクラスが月額のみで使えることが多いとの情報（296）。
- ローカルでStrataを使い、クリップもローカルAIのモデルを使用しているとの報告（278）。
- スレ上の見解として、Strataのようなローカル運用（1重、100token/s未満）ならGPT TerraやClaude Haiku等の格安APIを使っても月1000円程度で済むのではないか、という比較議論がある（399）。

### Codex
- Project MayaでDeepSeek V4.1 Flashを動かそうとした際、Strataと同じことをやるのが面倒で「codex丸投げおじさん」になったとの発言。400GBのモデルを回線ゴミ環境でダウンロードしたとのこと（241）。
- Codexを使っているとSSDの書き込み量が異常に増える。依頼のたびにテスト環境を作っては削除を繰り返している様子で、Cドライブの書き込み監視を推奨する声（269, 270）。
- 現在は環境構築をAIエージェントに丸投げすれば全部やってくれるため、金を払ってでも知りたいのは「秘伝のタレの作り方」だとする意見（314）。

### Fizgig
- FizgigのMoss standardプリセットは学習率をもう一段下げた方がいいとの感想（367）。

### Discord / PictSpace
- Discordは内々でやっているものなら未成年系以外なら何でもよいという認識。ただしアップロードは怖いという声、外部コミュニティのことは知らんという声（229, 231, 232）。
- DiscordやPictSpaceの有償サイトで毎週・毎月制作している人々はすごいとの評価。好きなものではなく周りが望むものを作っているという点で適正がないとの感想（402）。

### GeForce ドライバ / ハードウェア関連
- GeForceドライバー621.14以降でSSDへ大量書き込みの不具合（環境によっては10分で3GBの書き込み）が報告されている（371）。Game Readyドライバは不具合報告あり、Studioドライバは今のところ問題なさそうとの報告（256）。
- 家庭用NAND価格が20%下落、2027年初めにはさらに5〜10%の下落見込みとの話題（301, 303, 317）。

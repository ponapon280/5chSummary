## 生成AI関連「ツール」話題抽出レポート

### ComfyUI / comfy

- **基本評価と移行体験**: Anima使用時にforge neoからcomfyに移行した。Claudeにforgeで生成したイラストを渡してcomfyのワークフローを再現してもらい、よく使うものをボタン操作にも設定できると便利だと評価している（>>116）。「comfyめっちゃええわ AIのおかげで理想の環境構築出来る」との感想がある（>>226）。

- **メモリ管理**: P-H3のint8が20GBという文脈で、comfyのメモリ管理が優秀と聞き、16GBメモリ64GBでもSSDにスワップせず使えるかという質問がある。回答では「メモリよりでかいモデルじゃなければ扱えるくらいの認識でええ」とされている（>>57, >>59）。

- **生成速度の謎**: 同じグラボを使い続けているのにComfyUIでの生成速度がどんどん上がっているという現象が報告されている（>>124）。

- **LoRA学習時の活用**: LoRA完成品のピックアップをcodexにやらせており、「最近comfyさえ起動してない」との発言がある（>>88）。LoRA学習にはfizgigをcomfy上で使用し、mossのfastプリセットを選んで学習パラメータを設定している事例がある（>>189）。

- **ワークフロー作成の代替手段**: Claudeにcomfyを使って生成を指示するだけでワークフローを通さずに済むとの意見がある（>>118, >>123）。

### fizgig (LoRA学習ツール)

- mossのLoRA作成にfizgigを使用している。sd-scriptsに慣れすぎているため、fizgigのパラメータのいじり方が分からないとの声がある（>>126, >>176）。
- 素材画像単位でLOSSを評価して「このぐらいがええ感じやで」と教えてもらえ、学習中に一目で評価できるツールもある（>>111）。
- fizgigプリセットそのままでもmossのLoRA学習でlossがヨコヨコする現象が報告されている（>>184）。
- 実際の学習設定: Image PrepはDetail cropsとResize onlyで処理、Captionsは元画像にqwen3.8FNで付け、切り抜き画像はfizgigの自動キャプションを使用。Trainingはmossのfastプリセット、train attention onlyとPer-image adaptive LRにチェック、解像度0.75〜0.25MP、1万step程度（>>189）。

### sd-scripts (LoRA学習ツール)

- sd-scriptsに慣れているためfizgigのパラメータ設定に戸惑っているとの声（>>126）。
- fizgigプリセットとは別に、慣れたsd-scriptsでもmossのLoRA作成を試す意向がある（>>176）。

### ArtCraft系アプリ (CADCraft / GridCraft / PhotoCraft)

- AutoCADのクローンアプリCADCraft、ExcelクローンのGridCraft、フォトショクローンのPhotoCraftが言及されている（>>42, >>68）。
- 選定理由: artcraft系はどれもMCPを最初から実装しているため、MCP経由でアプリの操作を全部できるように作っていると推測されている（>>54）。
- 評価: GridCraftは「話にならない出来」、PhotoCraftは「かなり良かった」との評価（>>68）。

### Strata (ローカルLLMコーディング環境)

- Plamo3を使ったDeepLライクなローカル翻訳アプリをStrataで作成した事例がある。本体作成に1時間程度、デザイン調整等を含めると累計時間は大きくなっている。実測平均3040tos（2GPU構成）とのこと（>>63, >>81, >>84）。
- 単純なコーディングならクラウドモデルに対しても速度で勝てる可能性が指摘されている。「クラウドの上位モデルは速いんじゃなくて間違えずに一発で作れるから速いだけ」との分析がある（>>87）。
- 一方で「ロリのおっさんがプロンプト作るくらいしか脳が無いstrataとかいうゴミ」との批判的な意見もある（>>128）。
- シングルモード選択で速度向上可能との指摘: 2GPU環境だが5070ti単体+64GBで約2倍の速度が出ている（>>85, >>84）。

### Chrome ネイティブ翻訳 / Plamo翻訳拡張

- Chromeのネイティブ翻訳が挙動不審で精度も低いため、拡張機能としてPlamoを使用できるようにしたら精度も速度も安定性も爆上がりしたとの報告がある（>>72）。

### その他ツール関連話題

- **プロンプト管理アプリ**: チャッピーに専用のメモアプリを作らせた。ChatGPTのチャット画面のようにプロンプトだけコピーでき、プロンプト整理に特化して検索置換ができる仕様（>>82）。
- **webp動画モザイク処理アプリ**: ローカルLLMでモザイク自動認識・手動指定で同じ部位に追従するアプリを作成。処理1回で消費トークン3000万、処理時間1時間。pixivのうごイラ作成に重宝している（>>53）。
- **MCP (Model Context Protocol)**: artcraft系アプリに実装されていることがツール選定理由に挙げられている（>>54）。

### Qwen (画像生成以外の話題)

- Qwen3.8-27Bをローカルで使用するために2GPU構成にしている事例がある（>>84）。
- Qwen3.8FNでLoRA学習時のキャプション付与に使用されている（>>189）。
- Qwen3.5-9Bについて「プロンプト程度なら大した変わらないかな？」と、プロンプト作成用途での新旧差を疑問視する声がある（>>207）。
- 「Qwenとかに全権渡したりしてそう」という批判的な文脈での言及がある（>>185）。
- Deepseek Qwen Naiを略して「DQN」と呼ぶジョークがある（>>172）。

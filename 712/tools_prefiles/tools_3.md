# ツール関連話題抽出レポート

## ComfyUI (comfy)

### MOSS-imageワークフロー周辺
- **Text to image subgraphのPE設定**: `enable_prompt_enhancer`オプションを切る推奨。オンだとプロンプトに`2.5d/anime/princess/castle`が入りキャラクターがデ〇ズニーに寄る、`mermaid`に反応、鱗や髪色を無視してア◯エルが出る等の不具合（>>451, >>480）
- **MOSSデフォルトPEの問題**: 部族語が改変されてコントロール難 → 切る選択肢。「単語はそのまま通して」と書けばよいか検討中（>>556）
- **Seed固定**: サブグラフ内seedがランダムになる問題。複数の解決法が提示された：
  - サブグラフ右上ボタンから展開し、KSamplerのseed線を外して`randomize`を`fixed`に変更後再接続（>>575）
  - `Nodes 2.0`を有効にするとサブグラフのseed欄で値を選べるようになる（>>576, >>598）
  - 外から`Seed (rgthree)`を差し込む（>>578）
  - intノードや固定seedノードを接続（>>570）
- **MOSS-image edit**: 方向性固定しながら部族語微調整で生成する用法。BBoxは最初の作成以外ほぼ使っていない（>>572）

### Prompt Enhancer (PE) 全般
- **PE用LLMの推奨**: スレ上で特定LLMがオススメとして提示されている（>>490, >>573）。PEはプロンプト生成に2分、画像生成に5秒かかり使う気にならないという否定的意見もある（>>541）
- **PE用uncensored LoRA**: TE(CLIP)にuncensored LLMを使うとプロンプト追従性が下がるため、PE用uncensored LoRAを噛ませる手法。note記事あり（>>483, >>487）
- **PE役の割り振り**: 健全はCodex、NSFWはDS v4 proに頼る（>>503）。Qwen3.5 9Bはお手軽だがStrataのIQ3_Sと比べ画像に差が出る（>>506）
- **PEの効果検証**: プロンプト有り無し比較でPE有りでもいけるという結果（>>573）。TEのパワーで部族語が通じるようになる（>>581）

### Strata (量子化ツール)
- IQ3_SでPE運用。Qwen3.5 9Bより画像差が出る。LLM推論はStrataの方が高速で差は数秒程度（>>447, >>506）

### SageAttention / ck-attention / sparceattension
- スレではほぼ必須扱いされている（>>472）

## 選定理由・特性

### `--fast` / `--fast fp16_accumulation` (MMH3等で話題のオプション)
- スレでは`--fast`は`sage`や`ck`より劣化が大きいと認識され、使用しないユーザーがいる（>>472）
- `--fast-disk`と`--fast`は別物。MMH3で話題になったのは`--fast-disk`（>>473, >>474）
- ちもログの検証で`--fast`がデフォルトで入っていたため、FP32累積制限解除の効果検証が無意味になっているとの批判。`--fast`あり・なし両方で比較すべき（>>535, >>565）
- スレ上の認識: `--fast`付けると劣化上等の挙動（>>448, >>538）

### Krea2
- LoRA作成が大変という意見（>>552）と、10B超モデルだとLoRA作成がキツいとの指摘（>>539）
- `--fast`がほぼ必須扱いされていたとするスレ上の記憶（>>472）
- ライセンス問題がある（>>554）

### Grok-Imagine / Grok
- MOSSのプロンプトをそのままGrokに突っ込んで生成可能（>>622）
- SFWなら部族語渡して構図指定すれば結果が良い、NSFWでもGrokならなんとかしてくれる（>>559）

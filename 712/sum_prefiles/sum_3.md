## ログ要約レポート

### 1. ハードウェア・GPU性能に関する話題

#### 1.1 アンロック（RTX 4000番台 / 5000番台）に関する議論
- **アンロックの利点と用途**: 4000番台アンロックの最大の利点はFP8が実質倍増したこととされる（453）。生成専用機を作るならアンロックはありだが、メインPCではセキュアブートオフが必要になりゲーム（フォートナイト、LoL、BF等）が遊べなくなるため厳しいとの指摘がある（454, 462）。
- **検証手法に対する批判**: ちも（レビュアー）の検証について、`--fast fp16_accumulation`オプションをデフォルトで入れてFP32累積の制限を回避した状態で計測しているため、アンロック解除の効果が相殺され、5090と解除前4090が大幅減速・解除4090が速度維持という結果になっていると批判された（448, 486, 535, 536, 537, 565, 571）。5090とPro6000で比較すべきだという意見もある（508）。
- **アンロックをめぐる対立構造**: アンロック推進派と反対派の間で煽り合いが発生しており、「アンロックきた！コレで勝つる！」「うまく使ったらコスパ良くなってええやん！」という意見に対し、アンロックは怖い・壊れると煽る連中もいて鶏と卵の状態になっている（463, 476）。一部の荒らしカスが常駐して対立煽りをしているとの見方もある（465）。

#### 1.2 VRAMとモデルロードに関する話題
- RAMからVRAMへのロードは生成時間に比べれば一瞬であるため、もっとでかいLLMを使うべきという意見がある（500）。
- 4070Tiの12GBでは焼け石にウォーター（不足）であり、SDXL限定ならともかくLLMメイン機のサブとして使うのは面倒という声がある（464）。
- VRAM 16GBのおかげで戦えているという4070Ti SUPERユーザーの声（479）。

#### 1.3 今後のハードウェア・メモリ事情
- SKハイニックスがDRAMと広帯域幅メモリを2029年まで事実上完売と発表しており、メモリ価格高騰の懸念がある（636）。
- 中国がHBM3Eの生産を開始したが歩留まりはハイニックスの半分以下とされる（638）。

### 2. 画像生成モデル・ワークフローに関する話題

#### 2.1 MOSS（Moss-Image）
- **プロンプトと部族語（Danbooruタグ）の問題**: MOSSのデフォルトのPrompt Enhancer（PE）は部族語（Danbooruタグ）を改変してコントロールが難しいため切るユーザーが多い（556）。MOSSではDanbooruタグが本来の部族語として雑に認識されているだけであり、忘れた方が幸せになれるという指摘がある（557）。
- **AI臭さと画風の問題**: MOSSは手描きのノイズ感をすべて呑み込んで平均化してしまうため、綺麗すぎてAI臭が消えないという指摘がある（510, 527, 540）。score_9, score_8, score_7だけでなくscore_6などを入れて手書き感を再現する工夫が紹介された（530）。
- **MOSS Image Editの活用**: 方向性を固定しながら部族語で微調整して生成する用途でMOSS Image Editを使うユーザーが増えている。ただしBBoxによる位置調整は最初の作成以外ではうまく使えないとの声もある（572）。
- **5Bモデルの軽さとテキストエンコーダー依存**: MOSSの5BはZ-Imageの6Bでも軽いと言われていた時代を考えると地味に凄いが、その分テキストエンコーダー（9B）の性能に依存していると指摘されている（549, 555）。
- **ComfyUIワークフローのTips**: ComfyUIのMOSS-imageワークフローではseedがランダムになってしまう問題があり、サブグラフ内のseed線をKサンプラーノードから外して「fixed」に変更するか、node 2.0を有効にするか、外部からrgthreeのSeedを差し込むことで解決できる（569, 570, 575, 576, 578, 598）。

#### 2.2 Prompt Enhancer（PE）の活用とLLM連携
- **PEの役割とLLM選択**: MOSSのt2iワークフローで`enable_prompt_enhancer`をオンにすると、promptに`2.5d/anime/princess/castle`が入ってキャラクターがディズニーに寄ったり、NSFWを拒否る挙動が出たり、鱗や髪の色が無視されてアリエルが何度も登場する問題がある（451, 471）。これを回避するにはTEをuncensoredなものにするか、TEにバイパスLoRAを噛ませて無検閲化する必要がある（471, 480, 483）。
- **Strata vs Qwen3.5 9B**: Qwen3.5 9BのPEはお手軽だがStrataのIQ3_Sと比べると明らかに画像に差が出るため、結果的にStrataを使ってしまう。LLMはStrataの方が高速で差は数秒延びる程度（506）。
- **PE用LLMの推奨**: 健全なSFWはCodexに頼み、NSFWは何も断らないDS v4 proに頼る運用が紹介された。ローカルでやりたいが頭が必要という結論（503）。ComfyUIのPE用LLMとして特定のLLMが推奨され（490）、note記事も参照された（487, 512, 529）。
- **PEの処理時間**: PEを使うとプロンプト生成に2分、画像生成に5秒かかるため使う気にならないという声がある（541）。

#### 2.3 NOOB / Krea2 / Anima / Qwen-Image
- **NOOBの動向**: NOOBのDiscordによると、DiTバックボーンの10Bモデル（10Bを超える規模）を学習中で、年内リリース予定。T2I+Edit機能が付く模様（519, 524, 544, 539）。NOOBはエロ特化チューンの手腕が評価されており、Comfyがスポンサーの可能性がある。バックボーンはAnimaベースが上手くいくと予想されている（542, 545, 547, 549, 550）。
- **Krea2のLoRAとライセンス問題**: Krea2のLoRA作成は10Bだとキツいとの意見があり（539, 552）、ライセンス問題もあるため、MOSSのEdit機能開発が大変という話を踏まえるとQwen-image 2.1のパラメータ増加版あたりが本命との見方がある（554）。

#### 2.4 Muse / Terra / その他モデル
- **Muse**: チャッピー（ChatGPT）の謎画像劣化に怯えていたユーザーにとってMuseは快適。生成が早いため何度もやり直して微調整でき、ギリギリ抜けそうな動画が作れるとの評価がある（577, 583）。
- **Terra**: 簡単な質問か1回しか使わないコーディングくらいしか使う気にならないほど微妙という評価（469）。

### 4. スレッド運営とコミュニティに関する話題

#### 4.1 GPUスレ（隔離スレ）の問題点
- GPUスレはただの隔離スレであり、気に入らない話題を「あっちでやれ」と排斥するための入れ物として機能している。陰湿な連中だという批判がある（504）。
- 5000番しか持っていない人も条件を書き込めば検証の助けになるため、GPUスレで議論するよう求める声がある（475）。

#### 4.2 スレの性質と歴史
- 元々はNovelAIの情報交換スレであり、さらに遡ればエロ画像のプロンプト交換スレ。本音を言えばそれ以外は全部逸脱という認識がある（507, 509）。
- アフィカスが荒らしていた可能性や、対立煽りを常駐させるカスがいるという指摘がある（466, 468, 465）。
- 「AIバブル崩壊から4年」「3日で飽きる」と言いつつスレ常駐4年越えのユーザーがいる（603, 646）。

#### 4.3 部族語（Danbooruタグ）の意義
- 部族語はオタク・イラストを雑に分類するために作られた言語であり、人類とAIで雑に意志疎通するために特化した貴重な存在。自然文では表現できない概念があり、過程より結果が重要な創作面では部族語に利があるとの議論があった（562, 564, 566, 567, 568, 581, 582, 586）。
- TEのパワーで部族語が通じるようになったが、俗っぽい言い方やミームは通じない時もある（581）。

### 5. 雑談・その他の話題

#### 5.1 停電対策・UPS
- 急な停電に備えてUPS（Ankerのポータブル電源等）を繋ぐべきかという相談があり、学習中の停電は悲劇だが消費電力維持が難しいという指摘がある（560, 563）。Fizgigは途中から再開できるとの情報もあった（620）。

#### 5.2 性癖とコンテンツ消費
- moss製画像をcivitaiで探してもオカズに使えるものが見当たらないという声や、AI臭がするとちんちんが食べてくれないという表現があった（510, 516）。
- 性癖は広げて損はないという意見や、ふたなりから始めるとよいというアドバイスがあった（518, 528, 533）。
- 中出し画像の隣にボテ腹画像を生成させるなどの工夫が語られた（522）。

- >>573で提示されたプロンプト（PE無し / PE有り）の比較画像について、意外といけるという報告や「ええケツやな」「部族語強い（確信）」といった反応があり、スレの醍醐味との評価があった（579, 580, 582, 593, 597）。

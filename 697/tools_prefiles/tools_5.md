**抽出結果（ツール関連のみ）**

- **ComfyUI / StabilityMatrix**  
  - StabilityMatrix経由でComfyUIを管理・更新している話題が複数。  
  - `--use-ck-attention` の設定がGUIから選びやすくなった点を評価。  
  - カスタムノードの自動インストール失敗や、特定ノード（ECHOCheckpointLoaderSimple、SetSubseeds系）の入手先がわからない問題が頻出。

- **Krea2**  
  - ワークフローをCivitaiから落として使うより、テンプレから始めるべきという指摘あり。  
  - テキストエンコーダーが賢いため、キャプションの質が生成結果に直結すると評価。LLMで丁寧にキャプションをデバッグする運用が推奨されている。  
  - キャラLORA作成に使われているが、「面倒くさい」という声も多い。

- **RefMods / Ref2v系ノード**  
  - RefModsを使う理由として「参照精度が上がる」「生成時間が短くなる」の2点が明確に挙げられている。  
  - ref2vaでmax参照時に時間がかかりすぎる問題の解決策としてRefModsが紹介されている。

- **Qwenシリーズ（画像生成以外）**  
  - Qwen edit 2511を「簡単で素直で丁寧ないい子」と評価し、現在も愛用しているという声。  
  - 他の編集モデルは「クセがありすぎる」と比較してQwen editを選んでいる。  
  - Qwen3.8（特に3.8B/27B）をエージェント用途やカスタムノード作成、キャプション作成などで活用。  
  - 「何でも聞いてくれる」「Codexの代替として使う」といった用途で言及。

- **Codex**  
  - カスタムノード作成を依頼すると実際に作ってくれる点が評価。  
  - キャプションのデバッグやワークフロー改善で相談相手として使われている。

- **その他カスタムノード・ツール**  
  - Media Loader / Prompt Builder（RefMods系ノードパック）：利便性が高いと評価。  
  - uv（Python環境管理ツール）：重複を減らして容量削減、未使用キャッシュ削除が可能でSSD寿命に優しいと指摘。  
  - WizTree：ディスク容量の内訳調査に便利。

**モデル関連（NovelAI, FLUX, Anima, illustriousなど）は一切抽出していません。**  
Qwenについては画像生成用途を除き、エージェント・編集・キャプション用途のみ拾っています。

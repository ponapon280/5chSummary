# なんJ AI画像生成スレ ログレポート

## 各モデルの特性と使い分け

### Moss（moss-image / moss-base）
- **特徴**: promptに忠実だが、大手VLM/LLMほどではないテキストエンコーダーを持ちつつ優秀。ただしdanbooruタグ単純羅列では不向きで、VLM/LLMで自然言語プロンプトを補強する必要がある。GPT image感が強く、手描きイラスト風から離れやすい（238, 240, 255, 399, 396）。
- **用途**: 漫画、文字入れ、厳密な構図制御が必要な場合に適する。セル画風やカートゥーン風は違和感少ないが、アニメ系は苦手傾向（240, 258, 402）。
- **Krea2との関係**: Krea2の類似度に勝てないが、美人に飽きた場合の「味変」としてbaseが機能する（366, 408）。

### Anima（anima / anima-Ref-Adapter）
- **特徴**: 細部まで覚えやすい。リアス（ILYS）時代の絵柄タグはあまり機能しないが、クォリティは段違い（238, 372）。
- **Ref-Adapter**: Anima-Ref-Adapterは高性能だが、geminiでファイル壊れ判定を受けた報告あり（254, 257）。SnapRef v1bはNAIの精密参照がローカルに来たレベル（361）。
- **用途**: 1girlの一枚絵、秒速射精用に適する（402, 373）。
- **LoRA学習**: 素材5枚で15分で学習可能。LoRA作成はAnimaに軍配（383, 377）。

### リアス（ILYS / Illustrious系）
- 1girlでいいなら一生リアスでいい。秒速射精用途なら最適（402, 373）。
- リアスから逃れられないという声あり（401）。

## Moss LoRA学習の最適化（>>366, >>385, >>388）

### 学習設定（>>366）
- Train元: SFT
- dim/alpha: 32/32
- discrete_flow_shift: 2
- sigmod_scale: 1.3（1.2の方がいいかもしれん）
- optimizer: RadamScheduleFree
- LR: 1.5e-4
- 学習ステップ: 18800（100枚 x 2（左右反転）x 2（繰り返し）x 47エポック）

### layer skip追加設定（>>366, >>385）
- uncond layer skipを標準の22だけでなく24, 26にも適用
- スケジュールを0-0.5のみにする
- 22, 24, 26の全組合せを試す価値あり（焼き上がったLoRAとの相性問題）

### ポイント（>>371, >>385）
- キモはsigmod_scaleを増やしてノイズ両端の学習を無理やりさせた上でepochを増やすこと
- CAMEやRAdamScheduleFree等の過学習に強いOptimizerを選ぶ必要あり
- AdamWでやる場合はconstant + EMA必須、cosineはチューニングが厳しすぎる

### 所要時間（>>388, >>390, >>383）
- 1MP: 12時間、1.5MP（1280x1280）: 18時間（RTX 5080）
- mossは最低でも画像1枚あたり100回ループ必要。Krea2は40回程度
- 素材5枚ならAnimaで15分、mossだと18800stepで30時間かかる環境も

### sd-scripts / CAME（>>392）
- sd-scripts Version 0.12.3で追加されたオプションとCAMEを使えばキャラLoRAなら1000ステップでも多いくらい

## Moss prompt運用
- (うんち:1.2)やうんち！で強調可能（310）
- aesthetic, intricate details等の鉄板品質向上ワードがかなり強く効く（255）
- moss-imageはpromptワードから連想ゲーム的に絵柄が引っ張られる傾向。2.5D指定でmoss_image_sftだと妖精がディズニー/ピクサー風の低頭身になりやすい（255）

## 動画生成

### 速度（>>304）
- 0.5MPの5秒動画が27秒で生成可能。かなり速くなった

### 動画長とフレームレート（>>332, >>334）
- 渋うごイラ（Pixiv等）は150枚制限のため、12秒24FPSを半分に間引くとちょうどいい
- webpで動画作ってフレーム単位に分解して半分フレーム消すだけで綺麗にできる

- Depth動画が実写動画やプリビズ3dより良いという報告あり

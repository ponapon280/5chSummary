# 生成AI関連「ツール」話題抽出レポート

## ComfyUI

### 動画保存ノードの高速化
- **標準Save Videoノードの高速化が確認された**。VHSやXENodesのNVENC圧縮ノードと比較して、同じワークフロー・条件で計測ごとにComfyUIを再起動して比較した結果、標準ノードが30秒速かった。AV1の方がH.264より速く圧縮率も高い。（125, 126）
- 計測データ（126）:
  - 標準 Save Video AV1 CRF40: 42.33秒 / 42MB
  - 標準 Save Video H.264 CRF25: 61.23秒 / 50MB
  - XENodes H.264 NVENC CRF25: 91.82秒 / 245MB
  - XENodes AV1 NVENC CRF40: 93.96秒 / 76.3MB
- 1MPを2倍10秒で標準ノードだと保存に40秒かかったが、自作ノードで7秒になった。全てGPU処理させている。（174）
- 条件を明記した上での比較（2MP 24fps）: 標準ノード av1 crf40で42.33秒、自作ノードは7秒（H264NVENCmp4）。（195, 199）
- VHSのnvenc_hevc（ビットレート10, 2MP 10秒 24fps RTXVSR2倍）で7.8秒（GPU: 4080s）。（202）
- 4Mピクセル（1MPをRTXVSR2倍 10秒 24fps）でほぼ同じビットレート（約21,000kbps）の設定で比較すると、VHSより2倍高速。ComfyUIのPython側のffmpegがPC側より約3.3%高速だった。（219）
- Codexで作成した保存ノードを公開。公式の動画保存ノードは遅すぎる。（203）
- 保存ノードがアプデで速くなったという話は聞かない。（213）
- ノードの設計思想は「KISSの原則（Keep it simple, stupid）」に従っている。（201）

### 保存ノード・エンコードの画質と仕様
- NVENCはCPUエンコードと比較すると画質は悪いが高速。コマ送りしないと分からないレベルならNVENCで良い。（212, 215）
- 高ビットレートではエンコーダによる差は分からないが、低ビットレートではNVENCの画質が悪いのが定説。（212）
- 保存を高速化してその分1stepでも上げた方が画質が良さそう。（216）
- VHSは音無しmp4と画像（PNG）を同時に出力するが、不要な場合は設定で出力しないようにできる。VHSは一度音無しVideoを出力してから音をマージする仕様。（220, 224, 225, 227）
- ComfyUIの出資または共同開発の話が出ているが、資金元は謎。（171）
- Krea3はAPIで利用可能であり、ComfyUIも対応済み。（200）

## ワークフロー関連ツール

### MiniMax系ワークフロー
- strata + deepseek harnessでuncensoredなモデルを使い、複数カットを繋ぐ系のMiniMax3（H3-Multishot-Workflow）のワークフローでプロンプトを作成させると、3分くらいのAVが作れる。ローカルLLMのエロプロンプト力が段違い。（83）
- minimax長尺作成にExtenderを使っているが、元の参照15秒制限のせいでいまいち。（180）
- H3の長尺や高速化のワークフローが雨後の竹の子のように乱立しているが、多すぎて選べない。中国語のwf（latent使用）は厳しい。（194, 198）

## テキスト・音声ツール

### EmojiTTS / IrodoriTTS
- **EmojiTTSv4**: 絵文字キャプション＋音声分析キャプション機能が追加。APIはLM Studio（ローカル）。絵文字キャプションをオフにしてもログに「絵文字キャプション開始」と出るバグがある。lora学習タブのマニフェストファイル(.jsonl)が空欄のままだと学習エラーになる。学習したloraは直下フォルダに作られるが、loraフォルダ内に入れないと使えない。EmojiTTSv4のlora学習はv3のまま更新されておらず、生成すると中国語を長々と話すバグがある。（164, 170）
- **IrodoriTTS v4s**: lora学習したら前回は1時間/1000stepだったのが今回は10分/1000stepで終わった（チャッピーに聞いて設定を作成）。ファイル容量はともかく作り直しのハードルが下がる。MAX3000stepまで試す予定。（176, 177, 184）
- LoRA学習のstep数比較（184）:
  - 1000: 充分
  - 2000: 微妙に良い気がする
  - 3000: 声はかなり似るが音割れが起きやすい（音割れはシード次第）

### LLMエージェント・コーディングツール
- Codexで作った自作用WebUIにNovelAI APIで生成するモードを追加して使用中。自動生成機能も実現可能と見ているが、自分は必要ないので未実装。（124）
- 新しいモデルが出るたびにAGENTS.mdや各種ルールを見直さないと、古い指示がノイズになってパフォーマンスが下がる。（173）

### Strata（ローカルLLM環境）
- StrataはQ4から確実にRAM128GBの世界が必要。環境を作って速さに満足した層もいる。（43, 39）
- 5070ti + RAM192GBで、strata(qwen q3)で70tok/sec、maya(q2)で12tok/sec。（55）
- Krea2用の学習キャプションと生成時のプロンプト作成で重宝している。（64）
- クラウドAIにstrataの設定やdeepseek harnessの設定を聞けば教えてもらえる。（89）

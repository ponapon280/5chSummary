# 元の本文
今回とくに盛んに議論された話題はMOSS-Imageの台頭に伴う既存モデル（anima、NovelAI、リアス、Krea2等）の相対評価と移行判断である。本レポートに記載されるレス番号は元スレの通し番号とは限らない。

# 流行の推測
スレ全体を通じて最も流行しているのはMOSS-Imageである。「1.5→Pony→リアス→Anima→MOSS」というモデル移行の歴史が語られ（832）、danbooru学習済みでエロが可能、日本語テキスト描画、BBox（バウンディングボックス）による構図制御を備える点から「ローカル版NAIv5」「ゲームエンド」「覇権」と高く評価されている（313, 328, 351, 379, 399, 414）。次世代モデルとしてanima後継の筆頭に位置づけられ、ComfyUI公式mainブランチへのマージ（475, 476）やDMD LoRA等の高速化（452, 603）が進むにつれ議論の中心となっている。モデル選定の理由は「TE（テキストエンコーダー）が大きく言語理解力が高い」「BBox区切りでコマごとに処理でき漫画生成に有利」「部族語が使え自然言語にも強い」「エロができるローカルGPT image」等にある（855, 909, 939, 908, 948）。

# NovelAI (NAI)

## 強み・用途
- クラウドの覇権である（433）。版権・絵師再現力ではNAIが上だが、プロンプト追従力・構図制御力ではMOSSがすでにNAIより上というスレ上の評価がある（697）。
- NAIは2秒で画像が出る（382）。V5でもFlux2vaeの素晴らしさを感じる（474）。
- 「PC持ってないならNAI、持ってるならMOSS」という棲み分けが提示された（716）。
- ポン出し用途ならNAIではなくリアスやanimaで十分という意見がある（710, 784）。

## 制約・選定されなかった理由
- 節約モードは奇形率が上がるため使い物にならず、自分でステップ数を少し下げた方が良い（102）。
- V5にV4.5で良かったタグを入れても似ても似つかない絵になり、再現性に課題がある（182）。
- 作り放題ではなくなったが回復率は早く、ライトユーザー向け（105, 106）。金がかかる点が指摘されている（104）。
- スレ上でNAIへのアレルギーが強く、明らかに頭2つ抜けている性能にも関わらず否定されがちとの指摘がある（111）。
- スレ民が最近始めたが「全然物足りない」と感じている。個人PCでは動かせないクラスと見ている（692）。
- 「版権出ないならNAI5で良いじゃん」という意見に対し、「もう『〇〇ならNAIでいいじゃん』は無理がある」との反論が出ている（708, 718）。
- NAI5は実写出せない点がMOSSに劣るとの指摘がある（383）。

## API利用
- APIは相変わらず使える。Codexで作ったWebUIにNAI APIで生成するモードを追加して使用中（124）。

# 総評

1. **MOSS-Imageがanimaの後継として圧倒的な期待を集めている**：danbooru学習済みでLoRA無しのエロ表現が可能、日本語テキスト描画、BBox構図制御を兼ね備え、TE（Qwen3.5 9B）の大きさが言語理解力の高さに直結していると認識されている。ComfyUI公式マージやDMD LoRA等の高速化が進み、1.5→Pony→リアス→Anima→MOSSという世代交代の流れがスレ上で合意されつつある。

2. **animaは「速度と軽さ」に生存戦略が限定された**：5秒でワイルドカードからポン出し可能な速度（840）、VRAM6.5GBで動く軽量さ（816）、版権・絵師タグの守備範囲の良さ（625）は評価されているが、TE選びをサボった点（402）やアップデート停滞（135, 299）が指摘され、構図を詰める用途ではMOSSへ移行する声が多数を占める。ポン出し用途に限定すればanimaやリアスで依然として十分という意見が残る。

3. **FLUX3はエロ不可・アニメ学習不足で選定から除外された**：軽くて速い（116）点やedit性能が悪くない（118）点はあるが、「エロは無理」「アニメ風の絵はろくに学習していない」ため（132, 140）、MOSS登場により「忘れられる」存在となった。NAIv5でFlux2vaeの画質は活きているが（474）、Flux本体は「アレな感じ」とされる。

4. **NovelAIはクラウド覇権だがローカル勢には選定されない**：版権・絵師再現力と2秒の高速生成（382）を維持するが、作り放題でなくなった点（104）や金がかかる点でローカル勢からは離れつつある。「PC持ってないならNAI、持ってるならMOSS」（716）という棲み分けが提示され、ローカルでの画像生成はMOSSが主戦場となっている。

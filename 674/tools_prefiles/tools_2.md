**抽出されたツール関連話題（モデル除外）**

- **ComfyUI（comfy）**  
  ワークフロー（WF）作成・ノード追加で利用。Forgeではすぐ対応されない機能がある場合にComfyを使うメリットを指摘（>>331）。Forge勢がComfyに触れる良い機会として言及（>>340）。「ワークフローなんてテンプレに自分の欲しいノード足してけば良いだけ」と、柔軟なカスタマイズ性を評価（>>342）。

- **Forge / Forge Neo / easy forge neo**  
  Anima Base v1でのText to imageテストや日常使用で言及。Comfyと比較して「forgeで出来ない場合のラグ」を指摘され、Comfyへの移行検討材料に（>>331）。easy forge neoはSEED次第でアングルバリエーションが出やすいという体感報告あり（>>395、>>400）。

- **Qwenシリーズ（画像生成以外）**  
  qwen2.5-vl-7b-instruct-heretic-i1を画像キャプション（タグ付け）用途で使用。wd-eva02-large-tagger-v3と併用してLoRA学習用キャプション作成に活用した事例（>>283）。検閲解除版のGemma4-31bと並んで「ドスケベモデル」としてプロンプト理解・エロ描写の補助ツールとして評価（>>277）。

**選ばれている理由の主なポイント**  
- ComfyUI：Forgeで未対応の機能や細かいノード制御が必要な場合に選択。  
- Forge系：Animaなどのベースモデルでの手軽な生成や、Comfyより即時性が高い場面で使われる。  
- Qwen（非画像生成）：高精度なキャプション生成やエロ寄りのプロンプト理解補助として、LoRA学習やプロンプト作成の効率化に寄与。

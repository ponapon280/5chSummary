# 元の本文
**人気モデルのまとめ（冒頭）**  
ログ全体から最も活発に議論・使用されているモデルは以下の通りです：

- **MiniMax H3（H3 Max / MMH3 / MinimaxH3）**：動画生成の主力として圧倒的に話題の中心。生成速度（生成時間 < 動画時間）、参照性能（静止画/音声/動画）、長尺対応、エロ動画の品質・制御性で高評価。ローカル/クラウド両対応やワークフロー統合の観点で選ばれている。[[1]](https://www.minimax.io/blog/minimax-h3)
- **NovelAI（NAI / NAIv5）**：画像生成（特にアニメ/エロ/日本語対応）のベンチマークとして根強い支持。日本語プロンプト・テキストエンコーダの強み、タグ制御、インペイント、多人数・漫画生成で評価。版権再現やNSFW用途で比較対象にされることが多い。[[2]](https://www.aimodeling.com/en/news/slug/novelai-diffusion-v5-release)
- **anima**：ローカル勢の主力候補として頻出。LoRA作成のしやすさ、VRAM効率（8GB環境対応）、日本語セリフ/テキスト扱い、背景力で支持。NAIの代替や補完として位置づけられる。[[3]](https://civitai.com/ecosystems/anima)
- **illustrious（IL / リアス / Illustrious-XL）**：ControlNet/anytestの効きが強く、ワイルドカードエロ生成や一貫性で継続利用。陳腐化しにくい点が理由に挙げられる。[[4]](https://decrypt.co/300744/lllustrious-the-ai-model-that-wants-to-rule-anime-art-generation?amp=1)

その他、Wan（動画/LoRA素材）、Qwen系（TE/LLMとしての指示追従）、Krea2（背景・参照）、Z-Image（実写ミニ系）などが補助的に言及されています。全体傾向として、日本語性能・エロ/特定表現の制御性・速度/効率のバランスが選定の主な理由です。

**レポート本文**  
ログから抽出された主なモデルについて、言及内容・選ばれている理由を中心にまとめます。モデル名・バージョン等の事実関係はWeb検索で確認しました（末尾の参考情報参照）。

### NovelAI（NAI / NAIv5）
- **言及頻度・主な話題**：複数ログで非常に多く登場。特にv5の日本語能力、テキストエンコーダ、タグ制御（nipple flick/tweakなど性的表現）、インペイント性能、版権/絵柄再現が話題。Anlas消費や生成制限（1日190枚程度）への不満も見られるが、総合性能で「ゲームエンド級」との声も。
- **選ばれている理由**：日本語プロンプト・セリフ・テキストの扱いが強く、自然言語指示や複雑なシーン制御に優れる点。ローカル勢が「これを超える日本語性能のモデル」を探す際のベンチマークとして機能。v5では漫画ページ生成や多人数配置の進化も評価。
- **その他の特徴**：有料サブスクリプションサービスでNSFW対応が明確。

### anima
- **言及頻度・主な話題**：非常に多く、解像度設定、Turbo版、LoRA作成、Krea2との比較（背景力）、VRAM8GB動作、日本語セリフの綺麗さ、人物サイズ異常（巨人化）などの課題が挙げられる。
- **選ばれている理由**：LoRA学習のしやすさ、VRAM効率の良さ、日本語テキスト/セリフ対応、背景・一貫性。NAIの代替候補として「Animaくらいの性能が出たらNAIも進化する」との指摘もあるが、ControlNet用途ではillustriousに劣る声も。
- **その他の特徴**：オープンウェイトのアニメ/イラスト特化モデル（Qwen系TE採用）。Base/Aesthetic版などバリエーションあり。

### MiniMax H3（H3 Max / MMH3 / MinimaxH3）
- **言及頻度・主な話題**：除外対象外のログで最も多く、生成速度・音声参照の扱いやすさ、長尺（30秒超）対応、静止画/動画参照性能、エロ動画の品質向上（beta3で改善）、LoRA学習、クラウドコスト比較が中心。H3 optimizationsやワークフロー（Krea2→H3など）での高速化も話題。
- **選ばれている理由**：速度と参照性能のバランス、手軽さ（低品質音声サンプルでも使用可）、生成品質・柔軟性（「何でも作れる」）。他のモデル（LTXなど）と比べて速度面で優位。エロ用途の主力として位置づけ。
- **その他の特徴**：マルチモーダル動画生成モデル（テキスト/画像/音声/動画統合）。ネイティブステレオ音声対応。

### illustrious（IL / リアス / Illustrious-XL）
- **言及頻度・主な話題**：ControlNet/anytestの効き、ワイルドカードエロ生成、animaとの比較で言及。知識が止まっているという声もあるが、継続利用の理由として挙げられる。
- **選ばれている理由**：anytest（ControlNet系）の性能がanimaより明らかに強い点。ワイルドカードエロの強さや陳腐化しにくさ。
- **その他の特徴**：SDXLベースのアニメ/イラスト特化オープンウェイトモデル。Danbooruタグ対応が強い。

### その他のモデル
- **Wan（WAN / wan2.2）**：動画生成やLoRA学習素材として言及。ループ生成の安定性や過去のローカル環境貢献で評価されるが、現在は補助的。
- **Qwen（Qwen-Image / Qwen系）**：TEやLLMとして登場。指示追従性が高いが、エロ表現や日本語サブカル知識で硬くなりやすい/弱いとの指摘。編集タスクやプロンプト生成に使われる。
- **Krea2 / Krea3**：背景力・パース・参照画像生成でanimaより優位と評価。ワークフローの中間工程として。
- **Z-Image**：実写ミニ系で具体的な組み合わせ（redcraft turbo LoRAなど）が推奨。
- **LTX（LTX-2.3 / 2.5など）**：速度重視で言及されるが、品質とのトレードオフが指摘される。

**全体傾向**  
日本語性能（プロンプト/セリフ/テキスト）、エロ/特定タグの制御性、生成速度・VRAM効率・参照性能がモデル選定の大きな基準。NAI/anima/illustriousは画像（静止画/イラスト）で、MiniMax H3は動画でそれぞれ強みを発揮。ローカル運用とクラウド/有料サービスの比較も頻出。

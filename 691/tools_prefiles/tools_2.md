**抽出結果（ツール関連のみ）**

### ComfyUI（および関連カスタムノード・最適化）
- **ComfyUIのバージョンアップに関する話題**（234）
  - 最新版にすると使えなくなるノードが出る可能性について議論。

- **ComfyUIワークフロー・カスタムノードの使用感**（240, 266, 269, 276, 278）
  - サンプルワークフローが欲しいという要望。
  - LoRA Loaderの互換性問題（`lora key not loaded`エラー）。
  - `git fetch`で特定PRを適用して標準LoraLoaderでAcc-Loraを動かした報告。

- **SageAttention + メモリ最適化ノードの組み合わせ**（243）
  - Limiter + Memory Optimization + Sparse Attentionをデフォ設定で接続。
  - **選ばれている理由**: SageAttentionオンリー比で**生成時間が約半分**になり、**VRAMが5GB空いた**。Sparse Attentionは劣化があるため、VRAMカツカツ勢向けにLimiterとMemory Optimizationを推奨。

- **ComfyUI起動オプションによるメモリ削減**（259, 297, 302, 304）
  - `--disable-pinned-memory`を入れるだけで使用メモリが減り、生成時間はほぼ変わらない（または1-2割増）。
  - **選ばれている理由**: グラボの発火防止（特に5090）。pinned memoryを切ることでメモリ使用量を抑えられる。ただし`--fastdisk`使用時は効果が変わる可能性あり。

- **ComfyUI向けAcc版 / comfy版の違い**（258）
  - ACC版は音声改善、comfy版は現在のComfyUIのUNet/DiT構造に合わせたカスタム版として使いやすい。

- **高速化関連カスタムノードの乱立**（271）
  - 次々と新しい高速化ノードが出て落ち着かないという感想。

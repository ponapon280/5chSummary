**抽出されたツール関連話題（モデル除外）**

### ComfyUI（comfy）関連
- **ComfyUIのアップデートとワークフロー改善**  
  comfyデスクトップ版の更新で、H3ワークフローにTurboが標準搭載されたり、ノイズシードが外部に出せるようになったりといった改善が行われている点が話題に。  
  → **選ばれている理由**: アプデによる性能向上・信頼性向上を期待して積極的に追従する人が増えている。カスタムノードが多すぎる場合は「codex拳4倍でなんとかなる」と割り切って更新する運用が一般的。

- **ComfyUI用ノード・LoRAの活用**  
  kijaiが調整したminimax（H3）用ターボローラのComfyUI版が公開されており、試す人が出ている。  
  → **選ばれている理由**: 公式や有志の調整済みノードが手軽に使えるため、環境構築のハードルが下がっている。

- **ComfyUIインストール時の注意点**  
  Python3.9やPytorch2.6を未だに推奨する古いnoteが検索上位に出てくる問題が指摘されている。  
  → **選ばれている理由**: 最新環境に追従しないと性能が出ないため、最新の推奨構成を探す動きがある。

### Krea（Krea2 / Krea3）関連
- **Krea2の360ERP機能**  
  Krea2の360ERPでパノラマ的な動画生成が可能で、minimax（H3）にも対応している点が話題。LoRA（mickmumpitz/Krea2-360-ERP-LoRAs）も共有されている。  
  → **選ばれている理由**: 360度視点の動画が作りやすく、アート寄りの生成に向いている。実写だけでなく二次元にもそこそこ効くという声あり。

- **Krea3の動向**  
  Krea3がオープンソース化されるかどうかが話題に。プライベート発表会があったとの情報あり。  
  → **選ばれている理由**: オープンになればローカル運用しやすくなる可能性を期待している。

### その他のツール・サービス関連
- **Stability Matrix**  
  Stability Matrix経由でComfyUIを起動した際のSSD読み書き挙動について質問・回答あり。  
  → **選ばれている理由**: 起動・生成の管理が楽なため使っている人が一定数いる。

- **Qwenシリーズ（非画像生成）**  
  Mac（M1 Pro 32GB）で`mlx-community/Qwen3.6-35B-A3B-4bit`を動かした報告あり。  
  → **選ばれている理由**: Apple SiliconでのLLM推論用途としてmlx形式のQwenモデルが実用レベルで動く点が評価されている。

### 全体の傾向
- ツール選択の主な理由は「**最新の機能・ノードが早く取り込めるか**」「**ワークフローの共有・再現性が高いか**」「**特定機能（360ERP、Turboなど）が使いやすいか**」の3点が中心。
- 特にComfyUIは「アプデ追従のしやすさ」と「有志ノードの充実」が選定理由として繰り返し挙げられている。
- Kreaは「360度動画や特殊視点生成」というニッチな用途で独自の評価を得ている。

**抽出結果（ツール関連のみ）**

- **ChatGPT（チャッピー / GPT）**  
  - 会社のPCではCopilot以外禁止のため、個人スマホでトラブルシューティングに使用（>>638）。  
  - ミームの説明をさせてから同等の画像を生成させる用途（>>643）。  
  - プロンプト指示が多いとすぐ忘れたり余計なことを覚えたりする欠点あり（>>692）。

- **Copilot**  
  - 企業契約でセキュリティ・情報漏洩リスクが低いと判断され会社で唯一許可されている（>>638、>>640）。  
  - Microsoftアカウントの企業需要で収益面でも強い。

- **Gemini**  
  - 大学から提供されているが「使い物にならん」と評価が低い（>>641）。

- **Claude**  
  - VS2017クラッシュの原因究明で「アプリケーションログを見せろ」と具体的に指示し、tempフォルダの権限問題を特定（>>784）。

- **Grok**  
  - 性能は優秀だがすぐに限界が来る（>>692）。

- **ComfyUI**  
  - NAI APIノードを使ってwebUI的なワークフローを構築し、ダイナミックプロンプト（ワイルドカード）によるランダム生成を実現するため（>>751）。

- **webUI（A1111）**  
  - ダイナミックプロンプト拡張で.txtからのワイルドカード呼び出しによるランダム性付与に使用（>>746、>>751）。

- **MiniMax H3（minimax / H3 / バニラH3）**  
  - 素人でもローカル感覚でエロ動画・ネタ動画を簡単に作れる（規制・回数制限なし）点が強み（>>671、>>684）。  
  - dasiwaでは再現できなかったカメラワークがバニラH3で一発で再現された（>>723）。  
  - 画像編集モデルへの期待も言及（>>759）。

- **Krea2**  
  - 一般人には通じにくい先進ツールとして言及（>>649、>>677）。

- **qwen3:8b（Qwenシリーズ・LLM用途）**  
  - VRAM 12GB環境で運用。システムプロンプトが長いとループにハマりやすい（>>656）。  
  - 過学習モデル特有のループ発生を避けるための選択肢として検討（>>637）。

- **Affinity**  
  - マクロ機能で文字入れ・エフェクトなどの定型編集を自動化（>>816）。

**抽出除外**：NovelAI(NAI)、illustrious、Anima、FLUXなどのモデル本体に関する言及はすべて除外。

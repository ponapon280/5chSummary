**抽出結果**

### 1. **anima**（最も言及が多い）
- **Anima 3.8B**
  - LoRA学習が可能（sd-scriptsでnum_blocksを52層または自動検出にすれば対応）
  - 2.9Bと比べてプロンプト追従性が強化されているという評価
  - Turbo-loraが効きにくい、または効かないという報告あり
  - 2.9BのLoRAとマージして使う人、または3.8B単体で使う人がいる

- **Anima 2.9B**
  - 作者がLoRA作成環境を提供している（これが最大のメリットとして挙げられている）
  - LoRAの効きが良く、汎用性が高い
  - 絵柄LoRA・構図LoRAが作りやすい

- **選択理由として挙げられているポイント**
  - プロンプト追従性の高さ（特に3.8B）
  - LoRAの作りやすさ・効きやすさ
  - 2.9B→3.8Bへの移行を検討している人が一定数いる
  - 「ZリアスからTE強化Animaに需要が移った」という指摘あり

### 2. **NovelAI (NAI)**
- NAIv5の言及あり
  - アナルなどの特定のNSFW表現で「絶妙にゴミなライン」が出やすいという不満
  - 実写寄りの生成は苦手（意図的に実写を制限しているという指摘）
  - NAI実写部という新バージョンの話も出ているが、懐疑的な声が多い

- **illustrious（リアス）との関係**
  - 「リアスの三次モデルという名の2.5Dモデルより低レベル」という評価
  - コスプレ・三次元寄りの生成ではリアスの方がまだ使われているという声

### 3. **illustrious（イラストリアス / リアス / IL）**
- 主に「リアス」として言及
- コスプレ・2.5D寄りの生成で一定の需要あり
- Animaと比較されることが多く、「ZリアスからAnimaに需要が移った」という指摘
- ランダム性の高さが特徴として挙げられる場面あり

### 4. その他のモデル
- **FLUX, Wan, Qwen-Image, Z-Image, LTX**：このログ内では一切言及なし。

### まとめ（選択理由の傾向）
- **Anima**：LoRAの作りやすさ・効きやすさ、プロンプト追従性で支持を集めている。特に2.9Bは作者提供のLoRA環境が強み。
- **NAI**：アニメ寄り生成は強いが、実写・特定の過激表現で制限や弱点がある。
- **illustrious**：コスプレ・2.5D寄りの生成で根強い需要があるが、Animaに押され気味という認識。

他に該当するモデルはこのログには登場していません。

**抽出されたモデル関連話題（除外対象外のもののみ）**

### 1. **H3 / MiniMax H3（特にH3 Remix）**
- 最も多く言及されているモデル。
- **選ばれている理由・評価**:
  - 18歳以下に見える動画が「余裕で作れる」ため、NSFW用途で推奨されている（19番）。
  - 原神などの中国系版権キャラの再現性が高い（名前を入れるだけでT2Vでかなり忠実に出る）。
  - モーションやi2vの品質が一定水準以上で、R2V（参照画像使用）時のキャラ維持や動作制御が使いやすい。
- **課題として挙げられている点**:
  - 性器描写がグロくなりやすい（葉脈のような異常な形状）ため、「股の間」「股の奥」などの婉曲表現や参照画像を多用して回避する工夫が議論されている。
  - BGM生成時に歌声が入りやすい（インストのみにしたい場合のプロンプト工夫）。
  - Remix版はベースモデルからの変化が分かりにくいという声も。

### 2. **seedance / seedance2.5**
- **選ばれている理由**:
  - 「頭一つ飛びぬけている」と評価されており、動画生成の品質で他を圧倒しているという意見。
- **懸念点**:
  - 価格が高い。
  - 中国製のため、いつ規制・サービス終了になるか分からない（信用しにくい）。

### 3. **dasiwa（および関連モデル: 10ErosMax, SexGod）**
- **話題のポイント**:
  - MiniMax H3 Remixや他のモデルとの比較が複数あり、「i2vで同seed比較すると改善している」という声。
  - 専用ワークフローやLoRAとの組み合わせで使われているが、「何が変わったのかよく分からない」という意見も混在。
  - モーション強化や局部の自然さで一定の評価を受けている模様。

### 4. その他（散発的な言及）
- **krea2のFT**: chroma作者がやっている初期学習版の話。正式版が出る可能性が指摘されている。
- **IrodoriTTS**: v3→v4へのアップデート。ComfyUIカスタムノードの対応状況や絵文字の効きにくさについて触れられている。

このログでは、**H3/MiniMax H3** が圧倒的に話題の中心で、特に「NSFW動画の作りやすさ」と「中国系キャラの再現性」が選定理由として目立っています。一方で、seedanceは「純粋な品質」で評価されているが、持続可能性に懸念があるという構図が見られます。Anima系は除外対象のため一切抽出していません。

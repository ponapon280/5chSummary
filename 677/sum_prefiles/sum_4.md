**なんJ（5ch）スレッド レポート**

### 概要
このスレッドは、主に**MiniMax H3**を中心としたローカル動画生成環境の構築・運用に関する技術共有スレッド。ComfyUIを軸に、ref2va / i2va / FL2VAなどのワークフロー、NSFW（特に膣内映像・音声）生成の試行錯誤、CUDA/ハードウェアの最適化が活発に議論されている。Wan2.2からの移行組が多く、「静止画で言うとAnything v3 → Anima級の進化」との評価が目立つ。

### 主要トピック

**1. モデル・ワークフロー比較**
- ref2vaとi2vaの差が意外と小さいという声多数。「lastframe画像を用意できない環境ではref2vaのメリットが薄い」という指摘。
- MiniMax H3は「素のモデルでセックス以外は素直に出る」と評価が高く、Wan時代のような詐欺クラウドが減ったとの声。
- 参照画像の扱い（vagina vs vaginalの違い）や、膣内映像生成時の左右対称問題・舌の出現などの解剖学的課題が具体的に共有されている。

**2. ハードウェア・環境構築**
- **CUDAバージョン**：12.8→13.0（cu130）への移行推奨が強い。12.8だとOOMが頻発するとの報告多数。
- **GPU**：RTX 5090 / 5070 Ti / 6000proの命名論争（「PRO6000って言え」）や、Radeon勢の苦戦談（HIP Backendは進んできたが情報が少ない）。
- **メモリ**：VRAMだけでなく**RAM 64GB〜128GB**への増設需要が高まっている。低VRAM勢はint4/int8モデルで凌いでいるが、精度に不満。
- ComfyUIは**ポータブル版推奨**で、smzNodesはuninstall/disable必須という暗黙の了解ができている。

**3. NSFW生成の実践**
- 膣内映像・水音（クチュクチュ・肉叩き音）の生成が活発にテストされている。
- 音声参照の可能性や、ASMR的な音の再現性についての試行錯誤が目立つ。
- 規制の厳しさ（FLUX3の水着拒否など）への不満と、「ローカルだからこそできるハードなシチュ」の両面が語られている。

**4. その他の話題**
- Hugging Faceからの大容量モデルDLの不安定さ（aria2 / hf downloadの活用）。
- Sage Attention + TritonのCUDAバージョン合わせの重要性。
- 低解像度でガチャ→高解像度で再生成のワークフロー提案。
- 二次元派はAnima + LoRAの組み合わせを現役最強と評価。

### スレッドの雰囲気・傾向
- 技術的なトラブルシューティングが非常に丁寧で、ビッグウェーブ到来中で質問回答率が高い。
- ただし「スレ読まずに質問する」「smzNodesを放置する」などのマナー違反には厳しい反応も見られる。
- 全体的に「中華オープンウェイトモデルへの感謝」と「欧米クラウド依存への警戒」が強い。

### 結論
このスレッドは、**MiniMax H3 + ComfyUI（cu130 + Sage Attention）**を軸にしたローカル動画生成の最前線を体現している。特にNSFW分野での実用性が高まっており、ハードウェア投資（特にRAM）と環境整備（CUDA13系・ポータブルComfyUI）が成功の鍵というのが現在のコンセンサスとなっている。

# 元の本文
**生成AIモデルに関するレポート（ログ抽出ベース）**

### 人気モデルの概要
ログ全体から、**MiniMax H3（H3 / MiniMax H3 / minimaxH3）** が圧倒的に話題の中心であり、現時点で最も人気・支持されているモデルであることが明らかです。Wan2.2（またはWan2.1/2.7）やAnimaなどの前世代モデルからの「世代交代」として頻繁に比較・言及され、特に**動きの自然さ・顔やキャラクターの一貫性・参照機能（ref2v / R2V / i2v）の強さ・NSFW対応力**が選ばれる主な理由として繰り返し挙げられています。多くのユーザーがWan2.2からの移行組で、「Wan時代はエロが厳しかったがH3は素直に出る」「参照画像を複数使った高品質生成が革命的」といった声が目立ちます。

一方、Wan2.2は「前世代の主力」として過去の経験や比較対象として語られ、Animaはイラスト（アニメ調静止画）やLoRA作成で一定の支持を集めています。LTX（LTX-2.3）はH3の上位互換としてほぼ陳腐化・削除対象とされる傾向が強く、他のモデル（FLUX、illustrious、Krea2、NovelAIなど）は補助的または限定的な言及に留まります。

全体として、**動画生成用途ではMiniMax H3一強**、**静止画・イラスト用途ではAnima＋illustriousの組み合わせ**という棲み分け意識が強まっています。最適化（SageAttentionなど）やローカル運用（ComfyUI）のしやすさもH3の人気を後押ししています。

### 主なモデルと選ばれている理由
以下にログから抽出された主要モデルを整理します。選ばれている理由を中心に記載。

- **MiniMax H3（最も言及多数・現役トップ）**  
  動きの良さ・顔の安定性・参照機能（複数画像/動画参照でキャラクター・特定部位の一貫性を保ちやすい）が最大の強み。NSFW（特に過激な表現）への素直さ、音声同期生成、公式ワークフローのシンプルさも高評価。Wan2.2ユーザーからの「ちゃんと動いて顔が変わらない」「ref2vaで解剖学的正確性向上」といった感動の声が多く、「LoRA不要で高品質」「世界トップクラスの完成度」との評価が目立ちます。ローカル運用（低VRAMでもRAM活用やint4/int8で動作報告あり）や最適化対応も実用性を高めています。H3登場により他のモデルの削除・移行が進んでいます。

- **Wan / Wan2.2（前世代主力、言及多数）**  
  二次動画（アニメ調）の生成実績が豊富で、TE（Qwen3-VL-32B）により日本語プロンプトが効きやすい点が選ばれていた理由。VACE Extendなどの特定機能やオープンソース性も強みでしたが、H3の登場で「上位互換」「ref性能・扱いやすさで劣る」との認識が広がり、地位を奪われつつあります。ローカルで動かせる玩具としての価値がWan3.0などで変化した点も敬遠要因です。

- **Anima（イラスト・静止画用途で言及あり）**  
  アニメ調イラスト生成で評価が高く、「実写はKrea2、イラストはAnima」という棲み分けで使われます。LoRA作成のしやすさ（GPU温度上昇報告ありながらも現役トップクラス）と絵柄の安定性が主な理由。easyAnima経由の導入例も複数あります。H3との併用や静止画→動画の橋渡し役として位置づけられています。

- **illustrious（ill / IL / リアス、補助的言及）**  
  絵柄の安定剤としてAnimaと組み合わせて使用。「Animaで不安定な時にリアスで安定させる」「絵師タグを混ぜてキメラ絵柄の中間素材作成に適する」点が選ばれる理由。資産量が多いユーザーによる継続利用の声もあります。

- **LTX（LTX-2.3、言及あり・陳腐化傾向）**  
  以前は音声なし動画の選択肢でしたが、H3に「ほぼ上位互換」とされ、モデル削除報告が複数。画質の硬さや相性問題（smzNodesなど）が指摘され、積極的に選ばれる理由は見当たりません。

- **その他のモデル（限定的言及）**  
  - **FLUX / Krea2（Krea関連）**: FLUX.1 KreaをベースにKrea2が開発された経緯が語られ、AI臭さの少ない画質を目指した点が評価。ただしNSFW規制の厳しさ（水着すら拒否）で批判もあり、H3との比較で言及されます。  
  - **NovelAI (NAI)**: 将来性（NAI5）のみの言及で、現時点の使用感はほぼなし。  
  - **Z-Image / Pony系 / Anything v3**: 過去モデルとして「削除対象」や比較対象で登場する程度。  
  - **テキストエンコーダー系（gemma4、deepseek v4 flash、Grok）**: プロンプト作成補助として言及（特にエロ展開や理解力でgemma4が高評価）。

### 全体の傾向と補足
ログは主にComfyUIなどのローカル環境を前提とした議論で、H3の高速化（SageAttention、Spectrum LoRAなど）、メモリ運用（RAM128GB環境でのBF16動作）、NSFW用途の自由度が実務的・創作的な支持を集めています。Wan2.2→H3への移行が「ゲームエンド」「翼を授けられた」レベルの進化として描かれる一方、Anima＋illustriousの静止画ワークフローは依然として有用です。将来的にはWan3.0やNAI5などの新バージョンが再びバランスを変える可能性も指摘されています。

**抽出結果（ツール関連のみ）**

### ComfyUI関連
- **ComfyUIのワークフロー（WF）管理・更新**
  - MiniMax H3のReference to Video（R2V）公式テンプレート使用。
  - git pullによる更新でVAEデコードエラーが解消された事例あり。
  - KSampler (inspire)ノードの使用例。
  - ノード接続（ポート追加、右クリックオプション）で参照画像/動画の扱いを拡張。

- **ComfyUIでのMiniMax H3運用**
  - R2V実行時の生成時間・成功率に関する議論（動画参照にすると大幅に時間が増える）。
  - 画像参照（最大9枚まで）と動画参照（3箇所まで）の違いを意識した運用。
  - 音声VAEエラー対策としてComfyUI更新を推奨。

### SageAttention / Sage関連
- **SageAttentionの速度向上効果**
  - `sageattn_qk_int8_pv_fp8_cuda`選択で生成が高速化するが、4000シリーズでエラーが出る報告あり。
  - 速度向上により解像度や秒数を伸ばせるメリットを指摘。
  - 品質が大きく落ちるため「sage以外は使い物にならない」という意見も。

### EasyCache関連
- **EasyCacheの互換性**
  - SageAttentionとの共存可否についての質問・議論あり。

### AI-toolkit関連
- **LoRA作成ツールとしての使用**
  - Krea2との組み合わせで画風LoRA作成時の挙動検証（デフォルト設定で学習可能だが、タグ認識の問題が発生）。

### Runpod（クラウドGPU）関連
- **ローカルGPU不足時の代替手段**
  - ローカルでH3が厳しい場合の選択肢として言及。
  - ストレージ維持費がかかる点に注意が必要。
  - 電気代・故障リスクを他人に押し付けられるメリットを指摘する声あり。

### その他のツール
- **Irodori-TTS**
  - R2Vの参照音声として使用。WAV読み込みでカスタム音声生成の議論あり。
- **CatTowor**
  - Krea2と組み合わせたLoRA学習・生成時の画風制御に関する言及。

**選ばれている理由として明記されていた主なポイント**
- ComfyUI：公式テンプレートが充実しており、R2Vの複雑な参照指定（Picture/Videoの役割分け）がしやすい。
- SageAttention：生成速度が明確に向上し、時間短縮や解像度向上に直結。
- Runpod：ローカル環境（VRAM/発熱）で厳しい場合の現実的な代替手段。
- AI-toolkit：LoRA作成の敷居が比較的低く、デフォルト設定でも一定の結果が出る。

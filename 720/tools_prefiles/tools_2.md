## 抽出結果：ツール関連話題

### ComfyUI（comfy / comfyui）

- **rgthree Power LoRA Loader**: LoRA適用の仕組み自体はComfyUIのLoRA適用を借用しているのみと推測され、カスタムノードをAIエージェントに作らせることでnode2.0対応も可能という見方が示された（245, 248, 252）。バグが存在する点も指摘されている（245）。
- **Ultimate Lora Loader (Civitai)**: 検索と操作性がイマイチで、未選択時に末尾のLoRAをメタデータ出力するバグがあり使用を取りやめた。node2.0移行をやめたためPower Lora Loaderに戻ったが、バグがあるためUltimate Lora Loaderを改造して使うことを検討中（245）。
- **jupoニキのloader**: A1111風に画像一覧から選べてトリガーワード確認可能で超便利。Node2.0でも不具合なし。ただしGitのデータが全消しされており、ライセンスはMITのため再配布は許可される（249）。
- **rgthree Fast group muter/bypasser と Context**: ComfyUI最新化で連動しなくなり、workflowの書き直しが発生。毎年不要ノードの削除や機能重複が出てくる（253）。Contextノード/Contextスイッチは事実上ComfyUIワークフローに必須と認識されているが、使っていない人もいる（255, 303）。frontendアップデート時の依存問題から、依存パックを減らしたい意向がある（326）。
- **FromBasicPipe**: Context系ノードをFromBasicPipeに移行したユーザーがおり、プロンプト・シード・潜在は自作AIノードで構築している（263）。

### ワークフロー運用・操作の外部委託

- **museへの丸投げ**: 使えそうなワークフローをAPI化し、モデルとノードを揃えて操作自体をmuseに任せる運用が報告された。画像収集からキャプション付け、学習監視までmuseに委ね、人間は画像を見るだけという段階にも至っている（254, 383, 384）。

### WebUI / A1111系

- **webui（A1111系）**: エージェントに「終わったら電源落としといて」と指示すれば改造して対応する見込みがあるとのスレ上の見解（309）。
- **RedrayzkohyaGUI**: LoRA学習完了後にPCシャットダウンする設定が存在するとの言及（307）。

### sd-scripts（LoRA学習スクリプト）

- **スケジューラー設定**: Moss-image LoRA学習で特定のスケジューラーをsd-scriptsにコピーする手間が必要。CosParを使用した例が報告された（295）。
- **パラメータ検証**: `--logit_mean -1.09 --logit_std 0.95 --sigmoid_scale 1` をコマンドから削除したらグラフが明確に変化し、logit_mean・logit_stdは効いていると確認。`--show_timesteps` オプションでタイムステップ分布を確認可能（306, 312）。
- **fizgig**: スタンダード設定で87枚のキャラLoRAを70エポックで6時間超。まず40エポックでお試し推奨。解像度0.25MPのfastか0.5MP推奨かの問いあり（315, 374）。学習解像度0.75MPでも劣化を感じないとの報告（317）。

### LoRA学習関連ツール・設定全般

- **LoRA学習ステップ数**: 10000stepちょいで焼けるイメージ、10000～11000stepキッチリ回せが正解の時もある。キャラと画風は10000step、ポーズや服装は3000step程度でも可能。学習状態の保存/再開機能で分割学習している例もあり（364, 368, 370）。
- **kohya氏の知見**: Moss-Imageのstyle系LoRAは学習データと勾配ノイズのSN比が低く、max_grad_normを0.01に下げる・解像度を下げてステップ数を稼ぐ・学習率を下げてじっくり煮込む等の対症療法が提示された（317）。

### API・LLMルーティングサービス

- **OpenRouter**: 5ドル程度入金しておけば新モデルをちょこっと試す際に使える。最低入金額は5ドル程度で、1往復なら10セント程度で済む（358, 359）。

### Gemini（ジェミニ）

- **BBOX直接編集**: GeminiとAIモードを使ってBBOXを直接編集させ、手動で調整しつつエロいプロンプトは手動入力する運用が報告された（278）。

### その他ツール

- **Tripo（3DモデリングAI）**: 唯一ローカルでUV・トポロジ・メッシュエラーなしの3Dモデリングができるが、高品質アセットを買った方がマシレベルでクソ高い（250）。
- **strata**: NVMe SSDで動かせるstrata的なものが出るという話題。今のうちに買っておくべきか検討中（305）。
- **OpenClaw**: MacBookを母艦としてAIエージェントを運用する用途で言及。モデルはOpenAIのサブスクプランで運用し、日々学習する秘書状態になっている（261）。

# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI / ComfyUI Desktop

- **導入・運用の手間**: テンプレートから公式WFを開き、DiT・TE・VAEをサイトからDLしてフォルダに保存し、WFで選択、プロンプト・解像度・アス比・保存先を指定してお試し生成する一連の儀式を毎回手動でやるのは無能だと感じるという不満（645）
- **ノード配線作業への批判**: ComfyUIは欲しい画像や動画を得るためにノード配置と配線繋ぎを延々やらされるクソゲーであり、それに疑問を持たず付き合っているユーザーが理解できないという見解（645）
- **配線は頻繁にやらないという反論**: 一回WFを作って保存すれば配線は全然触らない。新しい機能が出たら提供元のサンプルWFから一部パクって組み込むだけ（654）
- **ノード沼の存在**: comfyノード沼に一度もハマっていない奴は存在しない。突き詰めていくと誰もがcomfy沼に陥り、溶かした時間を思い返して虚無に陥る（663）
- **沼への反論**: 過去に沼ろうが今沼っていない。「延々」ではない（677）
- **エージェント活用への言及**: 変な思い込みで必要ないことまでエージェントにさせていないか。配線つなぐくらいは自分でやった方がいい。監督をAIにさせればよい（650, 652）
- **WF理解の重要性**: 本当の意味でワークフローの流れを理解できていないと色々厳しい。パラメーターと工程を確認したいなら結局ComfyUIを起動してWFを見るのが一番良い（650, 661）
- **プロンプト引き出しツール**: ComfyUIで使ったプロンプトを引き出すためにわざわざComfyUIを立ち上げず、簡易ツールを作って何とかしたいと思っていたが、アプリすら不要でhtmlファイル1枚完結でメタデータを読めるものが作れる（756）
- **Stability Matrix vs ComfyUI Desktop**: Stability MatrixとComfyUIデスクトップ版のどちらが良いかという質問。ComfyUIしか使っていないならデスクトップ版が便利と聞いた（840）。返答として、Comfy Desktopにはメリットが多く、Stability MatrixでComfyUIしか使っていないなら移行する価値があるという結論（842, 843）

## kijaiのカスタムノード / negpip / KJNode

- **MOSSでの強度指定**: MOSSのプロンプトで強度指定（very hoge等や(hoge:2)）が効くかという質問に対し、LLM系テキストエンコーダーはデフォルトでは強度指定が効かない。kijaiのカスタムノードかnegpipを入れると強度指定が効くようになる（781, 783）
- **negpipの推奨**: negpipを入れることで細い指示が可能になる。不慣れな英語より全部日本語で自然言語として書いたほうがいい結果になることも多く、negpipは日本語文章にもしっかり効果がある（785）
- **KJNodeの紹介**: KJNodeのものも同じ機能を持つ。Clip Text Encoder(Positive)と入れ替える必要があり、modelも接続する必要がある（786）

## SnapRef

- **v2sプレバージョン**: SnapRefにv2sのプレバージョンが来た。今回はキャラではなくスタイル参照に特化している（792）
- **実用性の評価**: SnapRefはとても実用レベルとは言えない。元画像っぽいのを再生成できるだけで、少しプロンプトを入れてアレンジすると崩壊する（798）
- **用途**: ふと見かけたキャラで即席オカズを作って雑に抜くのには十分（799）。絵柄が安定しないけどLoRAを作りたくない人にちょうどいい（800）
- **精度の比較**: SnapRefはNAI4.5の精密参照くらいの精度はある（811）

## Colab

- **LoRA学習での利用**: ColabでmossのLoraを作りたいが1万回すとセッション切れしそうという懸念（760）
- **ローカルとの並行**: ColabでLoRA学習をしながらローカルで画像生成をしている。貧弱環境では同時にできず、暴騰環境で学習回してGPUの寿命を縮めたくないため（689）
- **GPU利用**: ColabでGPU利用ができた。画像動画生成に使えるかはわからないが音声解析くらいはできた（687）
- **過去の注意**: Stable diffusionをColabで叩いていた時代からドライブにエロは置くなと書いてある（733）

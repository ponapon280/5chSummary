## 生成AI関連ツールに関する話題

### ComfyUI (comfy, comfyui)

- **Moss用テンプレート/WFに関する話題**: mossのテンプレートがサブグラフで構成されており分かりづらいという不満。サブグラフが使われていない古いバージョンを使っているとのこと。また、ノードを拾うたびにPower Lora Loaderを組み込むのが手間という声がある。（208）
- **推奨WF**: rgthree氏がNode 2.0に移行しないため、Moss-Image Prompt Builder KJやMoss-Layout-YDRを使うと良いというスレ上の推奨がある。（229）
- **Power Lora Loader等の不具合**: node v2でPower Lora Loaderが操作不能になる不具合が未だに直っていないという報告。bboxノードが2.0専用であるため困っているという。（220）
- **バグ報告**: LC lora loaderで数値入力後にマウスカーソルを動かすと値が無限に増減するバグがあるという指導。（225）
- **代替Loaderの提案**: ネイティブノードにPower Lora Loaderのようなスタック形式のものがいつの間にか追加されているという指摘。（227）また、Lora ManagerのLora Loaderを使うと、画面からLoRAを追加できて便利だというスレ上の推奨がある。（230）
- **連携による作成**: comfyui連携すれば声なども何でも作ってくれるというスレ上の見解がある。（217）また、エージェントに全部任せすぎて風呂の栓抜きをAIにやらせようとしたという冗談が語られている。（218）
- **動作環境**: お古のPCにcomfyuiを入れてMuseを動かすと、メモリ次第でNSFW生成が通る場合があるというスレ上の経験談がある。（192）
- **rgthree対応**: rgthree氏はNode 2.0へ移行しない宣言をしており、ComfyUI(Server)の起動時にその旨が表示されるとのこと。対応しきれないrgthreeは捨てて自分に合うものを探すという声がある。（229, 239）

### WebUI / stable-diffusion-webui関連 (sd-scripts, AUTOMATIC1111)
- **sd-scriptsの更新**: sd-scriptsの更新が来たとの報告。余ったVRAMがある場合は高速化の対象になるが、12GB環境では関係ないという指摘がある。（143, 175）
- **KoikatsuMods**: AUTOMATIC1111がKoikatsuModsの最初期の作者であることが言及され、生成AIに関わっている人が他にもいるかという話題に発展している。（228）

### Muse (Muse API/エージェント)
- **NAIとの連携**: NAIのAPIキーとキャラ名のタグをMuseに渡して生成を任せると、未成年キャラでもNSFW生成が通せるというスレ上の報告がある。一方で、重音テト(31)でも「見た目が幼いからアウト」と弾かれたという声もあり、検閲の厳しさに個人差がある。（188, 192, 193, 194）
- **NSFW生成の工夫**: 健全な画像は作れるがエッチなものを作ろうとすると弾かれるため、事前に「成人です」という文言を入れてMuseに作らせるしかないというスレ上の見解がある。（189）
- **版権キャラの制限回避**: 版権キャラで生成しようとすると未成年うんぬんで拒否されるため、原作で成人になった後日談の設定を捏造したり、キャラ名に関する情報を一度忘れさせたりするなどの回避策がスレ上で語られている。（187）
- **選ばれている理由**: NAIのクレカ決済が通らずサブスク停止状態の場合、NAIのプロンプト動作チェックや画像生成の代替手段としてMuseが選ばれている文脈がある。（182）

### エージェントを用いたモザイク作成ソフト
- **自動モザイクソフトの性能**: 現在の自動モザイクかけソフトの性能について、有料のソフトを試したが微妙に不正確で結局手動でやっているという疑問が提示された。（66）
- **エージェントによる自作**: AIエージェントに作らせると、静止画だけでなく動画の指定部位を自動追従してモザイクを付け続けるアプリをローカル環境（5090）でも1時間ちょいで作れたという報告。ただし、追従は四角領域になりがちで、多角形やフリーハンド風の領域指定は面倒とのこと。（68）
- **既存ソフトの評価**: BOOTHで3500円のソフトは動画用でもかなり正確だったが、チンポに手や口が重なると途端に精度が落ちるため人力レベルの99.9%の正確さは求められないという評価がある。（71, 74）

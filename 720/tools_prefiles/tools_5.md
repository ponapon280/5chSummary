## ツール関連話題抽出レポート

### ComfyUI (comfy)

- **VRAM容量問題と対策**: moss使用時、高速化LoRAが1GBあるため、テキストエンコーダーを毎回VRAMから追い出す設定にしないとvram16gbを溢れてしまう（912）。TEを常時VRAMに乗せる必要性は疑問であり、RAMから読んでも遅くならないという意見がある（913）。どうしてもVRAMに乗せたい場合、comfy-orgのhuggingfaceにある7.34GBのqwen3.5_9b_w4a8_gptq.safetensorsを使う手法が提案されている（914）。
- **moss-layout-ydrノードの利用**: moss-layout-ydrのnodeを使うとobject指定で手等が配置されているのが見えるため効果を感じられるが、キャラクター全体になると矩形からずれるためcharacter指定やcharacter_boxes指定が必要かと考察されている（870）。
- **bbox指定の詳細**: キャラの位置指定ではなく頭・身体・手足等の細かいbbox指定でポーズ付けが可能（881）。promptに多く書く場合はobject指定で手足の位置を指定する方が良いとの見解（929）。bbox内のcaptionで「斜めに伸びている」等の書き方をすれば対象が矩形からずれても対応できる場合がある（881）。position:left等でも位置指定できるためガバガバbboxを使う機会はない（868）。
- **スレ全体の動向**: comfyの導入の話ばかりで画像を貼らないスレがLLMについて語るスレになったと指摘されている（886）。

### Antigravity / Codex / Hermes / OpenCode / Strata / Pi (LLM用ハーネス)

- **ハーネス選択の議論**: GoogleAI PRO契約者が使用するハーネスとしてAntigravity（AG）が一択と推されている（871, 873, 885）。
- **Codexからの乗り換え**: CodexからAntigravity2.0に乗り換えたとの報告。「サブエージェント使う時は代わりにSwarm」と覚えればあまり変わらない。近いうちに他のハーネスでも使えるようになるという噂がある（875）。
- **複数ハーネスの併用**: Codex、AG、Hermes、OpenCodeを全て使用しており、一長一短でどれも必要という意見（877）。ローカルLLMを動かすハーネスならStrataの作者のようにPiフォークのハーネスが良いとの提案（882）。
- **脱獄手法**: AGより自分で作れば偽装modelや偽装user追加で脱獄要らずになるとの情報（878）。

### Orca / T3 (ハーネス関連)

- **T3の問題点**: T3は開発者が色々情報を抜いているとバレて炎上中のため使用を避けるべきという指摘（876, 879）。

### Muse (MetaのAIエージェントツール)

- **ツール作成用途**: muse来てから簡単なツールをあれこれ作らせては大して使わないを繰り返している（895）。
- **画像生成での利用**: 複雑な画像も簡単な日本語の指示で作ってくれる（comfyuiと組み合わせて）（906）。
- **エロ・成人コンテンツ対応**: アダルトの文章はダメと言われる。成年同士であることを説明すれば成人同意くらいならいける（922, 940）。エロに強いという評価は100%間違い（925）。日本語能力に課題がある（928）。
- **利点**: 無料で使えることとエージェント力が強み（924）。各社のTrialプランとProプランの間ぐらいが無料で使える（925）。

### SnapRef

- **V2S機能**: 画風のコピー性能は良いが、生成画像のノイズや細部の潰れがヤバい。プレバージョンのため本番に期待という評価（910）。
- **人物差し替え機能**: LoRA抜きで人物差し替えが実用射程に入っている（921）。MOSSで描いた画像をSnapRefで別キャラに差し替え可能。原理がインペイントのため、人物と重複・接触する部分は一緒にAnimaの出力で差し替えられる仕組み（943, 968）。
- **ノード操作**: 久々にノードポチおじになって楽しめたという報告（921）。

### その他ツール関連

- **シスプロ（システムプロンプト）**: gemmaやqwenに自然言語プロンプトを作成させると「playful ~」等を付けたがる問題があるが、シスプロで対処可能（971, 974, 979）。geminiちゃんに辛辣なシスプロを入力して作業させることについての言及もある（987）。
- **nvidiaドライバ**: ドライバのアップデートが来たという報告（953）。
- **museでのサーバ構築**: VPNサーバや自作通知サーバ等のlinuxサーバ的な使い方ができるか問われている（960）。

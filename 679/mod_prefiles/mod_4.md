**抽出されたモデル関連話題（除外対象を除く）**

### 1. **MiniMax H3**（minimax3 / H3 / MiniMax H3）
ログ内で最も多く話題に上がっているモデル。

- **選ばれている主な理由**:
  - 動画生成に特化しており、動きの再現性・画質のバランスが良い
  - 参照画像・参照動画を使ったキャラ置き換えや動き制御が強い
  - 各種高速化（H3 Cache、Spectrum、sage-attention、sol-attnなど）と組み合わせやすい
  - ローカルで実用的な速度が出る（特にVRAM32GB以上で快適）
  - エロ動画生成での実用性が高い（動きの硬さはあるが、参照動画との組み合わせで改善）

- **補足**:
  - VRAM32GBでほぼフル占有するほど重いが、有効活用されているという評価
  - 夏場のリリースでGPU負荷が非常に高いため「GPUを滅ぼす」との声多数
  - PRO版への期待も複数見られる

### 2. **lightx2v**（lightx2v / R2V-turbo関連）
新しく登場した蒸留モデルとして注目されている。

- **選ばれている主な理由**:
  - 少ないステップ数（4〜8step）で実用的な画質・音質が出せる
  - 劣化が比較的少なく、軽量ながら動きの品質が良い
  - kijai版との組み合わせで特に評価が高い
  - 通常のH3ワークフローと比べて温度が下がるケースがある

- **補足**:
  - ガチャ要素はあるが、ステップを6以上（特に8step）にすると安定するという意見が多い
  - refワークフローとの相性についても言及あり

### 3. **SexGod0.3**
- R2Vと組み合わせて使用されている。
- 主な用途は「flat chest（平らな胸）」の制御研究。
- 通常のプロンプトだけでは膨らみやすい問題に対して、R2V経由で素材を入れることで抑え込もうとする試みが見られる。

### その他（モデル本体というより関連技術・設定）
- **sage-attention / sol-attn / T8 / Model Patch Torch setting**：高速化パッチとしてMiniMax H3やlightx2vと併用されることが多い。
- これらは「モデル」本体ではなく、推論高速化のための技術・設定として言及されている。

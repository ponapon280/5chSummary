**抽出結果（ツール関連のみ）**

### ComfyUI関連
- **ComfyUI本体のインストール・運用**
  - インストール前に苦戦する人が複数いる（特に初心者）。
  - 更新（アプデ）後にカスタムノードが動かなくなる事例が頻出（例: ComfyUI-MiniMaxH3-Cacheがエラーになる）。
  - 更新後の互換性問題が発生した際は、fable5（またはチャッピー/Gemini）にコード修正を聞く人がいる。

- **カスタムノード・拡張機能**
  - ComfyUI-MiniMaxH3-Cache（およびCache-UtilsOnly）：高速化目的で導入するが、ComfyUI本体更新後にtime_shift_slope()廃止の影響で動かなくなる事例あり。互換パッチ適用で復旧した報告あり。
  - Spectrum：導入・更新後に動作しない、または導入すると逆に遅くなる報告あり。VRAM16GBだとCPUオフロードが増えて遅くなる（VRAM32GB推奨という指摘）。
  - Patch Sage Attention KJ、MiniMax H3 Mem Eff Sage Attention PatchなどのSage Attention関連パッチノード。
  - ComfyUI-Easy-Install：一部で「入れるな」との強い警告あり（SimpleComfyUIと混同している人もいた）。

- **ワークフロー（WF）・ノード運用**
  - ノード配置やWF作成がまだわからない初心者が多い。
  - 参照画像＋参照動画を使ったキャラ置き換えワークフローで「スロー再生になる」「タイミングが合わない」問題が発生。
  - 参照動画のfpsが高いと問題が出やすいという指摘。
  - 動画確認・整理用に自作ツールを作成・公開したユーザーあり（GPUが強いとWebP/MP4を大量同時再生可能で便利）。ファイル名表示機能の要望も出ている。

### その他ツール・環境関連
- **Sage Attention / 高速化設定**
  - `--use-sage-attention`を外して`--fast`にする、またはノードでPatch Sage Attention KJを有効にする組み合わせが推奨されるケースあり。
  - H3CacheやSpectrumとの併用で速度と安定性のトレードオフが発生。
  - VRAM32GB以上だとキャッシュ系ツールの恩恵が大きいという指摘。

- **インストール系ツールの注意**
  - EasyComfyUIは「絶対入れるな」との強い意見。
  - SimpleComfyUIとEasyComfyUIの混同が多く、名称の類似で混乱している。

### 選ばれている理由（明記されているもの）
- **ComfyUI系ツール**：柔軟なノード接続とカスタムノードによる高速化（Sage Attention、キャッシュなど）が可能で、動画生成時のメモリ効率や速度を追求できるため。
- **自作動画確認ツール**：大量の生成動画を同時に確認・整理できるため作業効率が上がる。
- **Sage Attentionパッチ**：速度向上を目的に導入するが、設定を誤ると動かなくなるため組み合わせに注意が必要。

**除外したもの**：モデル名（H3、Wan、NAI、animaなど）、プロンプトの話、生成結果の画質・音質の評価はすべて除外。

**抽出結果**

### Anima / Anima2.9B（最も言及が多い）
- **主な話題**:
  - ComfyUIのネイティブサポートに正式搭載された（v0.32.1/0.32.2待ち）。
  - 層を増やして（28→40ブロック）パラメータを2.9Bにしたファインチューンモデル。
  - 素の出力で高クオリティが出やすく、detailerやlatentアップスケールなどの複雑な工程が不要でワークフローがシンプルになる。
  - H3（MiniMax H3）と相性が良く、ref2v用途やキャラシート量産で使われている。
  - Anima登場時がComfyUI移行の良いタイミングだったという意見。
  - 欠点として「これ以上層を増やすとLBW（Layer Block Weight）が面倒」という声あり。

- **選ばれる理由**:
  - 「素で高クオリティが出る」「ワークフローをシンプルにできる」「H3との相性が良い」点が特に評価されている。

### Wan（Wan2.2含む）
- **主な話題**:
  - 動画生成（特にt2v）でよく使われていた過去のモデル。
  - Wanで作った動画にv2vで効果音を付けたいという用途。
  - ComfyUI移行の文脈で「Wanの頃に指を咥えて眺めていた」という言及あり。

- **選ばれる理由**: 特に明記されていないが、動画生成の文脈で一定の利用実績があるモデルとして扱われている。

### LTX / LTX2.5
- **主な話題**:
  - LTX2.5の日本語プロンプト追従性について言及。
  - 「日本語プロンプトの柔軟な解釈力はLTXの方が強い」という比較意見あり。
  - Wan動画へのv2v用途でも名前が出ている。

- **選ばれる理由**: 日本語プロンプトの扱いの良さ。

### FLUX（fl2vとして言及）
- **主な話題**:
  - ref2vとfl2vの比較。
  - 「ref2vは公式ガイド通りに書けば追従性が高いが、fl2vはどう書けばいいか分からない」という声。

- **選ばれる理由**: 特に明記なし（ref2vとの使い分けで言及）。

### Qwen（Qwen-Image系）
- **主な話題**:
  - Qwen3.8-2.4T-A95Bが登場したという言及。
  - Qwen edit AIOの存在。

- **選ばれる理由**: 特に詳細な理由は記載なし。

### illustrious（リアス / ill / IL）
- **主な話題**:
  - Forgeではリアスを使っているという使い分け話。
  - 「リアスはdetailerやlatentアップスケールをガンガン入れていたが、Animaは素で高品質が出る」という比較。

- **選ばれる理由**: Forgeユーザー層での定番として使われている。

### 該当なし
- NovelAI (NAI)
- Z-Image (ZIT / ZIE)

このログでは**Anima2.9B**が圧倒的に話題の中心で、「高品質をシンプルなワークフローで出せる」という点が最大の評価理由として繰り返し挙げられています。他のモデルはAnimaやH3との比較・使い分けの中で名前が出る程度です。

**抽出されたモデル関連話題（除外対象を除く）**

### 1. **MiniMax H3 / MMH3 / minimax**（最も多く言及されている）
- 動画生成（特にi2v/ref2v）で活発に使われているモデルとして話題。
- **選ばれている主な理由**:
  - ComfyUIでのワークフローが比較的シンプルで扱いやすい。
  - ref2vの追従性が高く、複数画像参照も比較的やりやすい。
  - テキストエンコーダーの性能が高く、プロンプトの理解度が良い（特に日本語プロンプト）。
  - ForgeやA1111からComfyUIへ移行する際の「次の波」として位置づけられている。
  - ネガティブプロンプトの扱い方が特殊（禁止形が逆効果になりやすいため、肯定的な誘導プロンプトを書く必要がある）という特徴も指摘されている。

### 2. その他の言及（モデル名が明示的でないもの）
- **adaptive (balance)** と **Block cache T8** の速度・画質比較  
  → adaptiveの方が明らかに速いが、画質面でパラメーター次第という話。
- **ref2v / fl2v** のプロンプトの書き方  
  → ref2vは公式ガイドに従えば追従性が高いが、fl2vはまだ書き方が確立していないという声。
- **Krea2**  
  → Animaに置き換えて使いたいという要望が出ている（モデルとしての言及）。

### 除外対象のため省いた主なもの
- Anima / Anima2.9B系（大量に出てくるが除外）
- Wan / LTX / Qwen系（同上）

**まとめると、ログ内で除外対象以外でモデルとして具体的に話題になっているのは、主に「MiniMax H3」**です。ワークフローの簡単さ・テキストエンコーダ性能・ref2vの扱いやすさが選ばれる理由として挙げられています。

**ツール関連の話題抽出（モデル議論は除外）**

### ComfyUI関連
- **ComfyUI-Anima-2.9B custom node**
  - custom nodeフォルダにインストールする必要がある。
  - インストール後はプラグ&プレイで使用可能（専用ワークフローノードは不要）。
  - 一部custom nodeと競合して正常に動作しない場合がある。
  - これを入れないとモデルが動かない（または正常に動作しない）ため必須。

- **ComfyUIワークフロー関連**
  - テンプレートノードがシンプルすぎてスケジューラ/サンプラー設定項目がない。
  - Civitaiのワークフローはゴチャゴチャしていて不要な機能が多い。
  - ワークフローの管理方法について（ダウンロードフォルダに置かれるので自分で管理する必要がある）。

- **各種custom node / 拡張**
  - ComfyUI-sol-attn（Triton false + Eff外しで動作確認）。
  - adaptiveCache（見つからない場合の対処）。
  - Patch Sage Attention KJ。
  - Context Loop。
  - adetailer（口を閉じるプロンプト用）。
  - rgthreeのseedノード（-2/-3でのseed制御）。

### Forge Neo関連
- 宗教上の理由でForge Neoしか使えないユーザーが存在。
  - 新しいモデルが出てもNeoが対応するまで待つ方針。
  - 一部で「Forge Neoは即対応している」という指摘あり。

### 学習・LoRA作成関連ツール
- **sd-scripts**
  - anima_utils.pyのnum_blocksを40に変更することで学習開始可能（ただし公式対応を待つべき）。
  - 28層固定の状態で40層にするとエラーになる問題の対処。

- LoRA作成環境の変化
  - 新しいモデル向けにLoRA構築環境が増える可能性が指摘されている。
  - 既存のLoRAを新環境で作り直す必要性。

### その他ツール・UI関連
- **メモリ/速度最適化系**
  - Sage + turbo 8steps + メモリ効率化系ノードの組み合わせ。
  - 5060ti環境でのsol-attn使用時の画質/速度変化の報告。

- **全体の傾向**
  - 非Comfy勢は最新ツール/モデル対応をほぼ諦めざるを得ない状況。
  - ComfyUIでないと最新のcustom node群が使えず、モデルを試せないという指摘が複数ある。

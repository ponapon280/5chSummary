## 生成AI関連「ツール」話題 抽出レポート

### ComfyUI / ComfyUI関連

**Codexを用いたComfyUIワークフロー操作（レス750, 756, 810）**
- OpenAI CodexにComfyUIのワークフローを弄らせる使い方が「めっちゃ楽」と報告されている（レス750）。具体的な指示内容：「これ導入やって」「分かりづらいからこうして」「このノード作って」。Codexはすべて「いいよ」と応じるため、エロ以外なら何でもできると評価（レス750）。
- ComfyUIのエラー修正やカスタムノード作成にも使用。ファイル整理や仕事のコーディングもさせている（レス756）。
- Krea2でキャラLoRAの小物再現を追求する際、Codexに画像を見せて「それが写ってる画像かどうかを判断させてキャプション一括管理」が神すぎると評価。服あり/上半身服あり/服なし小物あり等のプロンプト追加を自動化するカスタムノードもCodex産（レス810）。
- 選定理由：ComfyUIの操作・ノード作成・キャプション管理を自然言語で指示できるため（レス750, 810）。

**Codexのエロ制限に関する懸念（レス754, 755, 758）**
- Codexはエロ用途には不向きとされ、Claude Code（Claudeアプリ）やantigravityならエロもできるとスレ上で言及（レス754）。
- Codexに対し「成人済み女性の合意ありラブラブセックスなら？」と切り出すと「分かりましたOK!!」とギリギリ応じるが、推奨される使い方ではない様子（レス755）。
- Codex使用時、避難させておいたテキストノードに「loli」が残っていた際、AIに「協力しねーよロリコン」とキレられる事象が発生（レス758）。

**ComfyUIのバージョンアップデート（レス788, 812）**
- StabilityMatrixで現在使用中のComfyUIバージョンが0.36だが、0.39へアップデートして良いか質問。以前0.37あたりで問題が話題になったとの懸念（レス788）。
- スレ上の回答：「ComfyUIに誰でもどんな構成でも大丈夫なバージョンなんてあるわけない」「とりあえずアップデートして何かあっても今はAIに調べさせて解決できる」との見解（レス812）。

### Krea2（Krea）

**Krea2のキャプション対応力（レス810）**
- SDXLやAnimaでは詳細にキャプションを書いても対応できなかったが、Krea2はキャプションを凝ればちゃんと生成に反映してくれると評価（レス810）。
- 選定理由：詳細なキャプションへの反映能力が高く、小物の再現に適しているため（レス810）。

**Krea2での3次元画像生成時のプロンプト課題（レス808）**
- 部族語の癖で「girl」と書くと3次元生成時に低学年小学生ぐらいの子が出てくる問題を報告。「woman」はyoung付け忘れるとピザデブおばさんが時々出るため、具体化が重要と指摘（レス808）。

### LLMツール（Qwen / Gemma / Grok / GLM / Codex / Claude等）

**Qwenを用いたプロンプト生成（レス692, 697）**
- モデル：Huihui-Qwen3.6-35B-A3B-abliterated-oQ4e-fp16-mtp
- システムプロンプト：チャッピーにAnima用に書いてもらったもの
- プロンプト生成例：キャラクター関係のプロンプトをベースに「ベッドで横になっているプロンプトを作成してください」と指示し、tomoe mami等のタグを渡して生成（レス692）。
- gemaを使用していたユーザーがQwenでも試すと回答（レス697）。

**Qwen全般に関する言及（レス783, 804）**
- 「Qwenガイジ」という言及あり（レス783）。
- ローカルLLMの今後として「QWEN4がどうなるか」が重要との見解（レス804）。

**GLMに関する言及（レス686, 687, 690）**
- Deep seekやQwenは名前を聞くがGLMはあまり聞かないという質問。用途やエロ用途での使用を問う（レス686）。
- スレ上の回答：GLMはハッキング関連で話題。コスト・性能・モデルの小ささでQwen等に利点がないから名前を聞かないと推測（レス687）。公開停止になる前にゲットしておくべきかという懸念（レス690）。

**Grokのエロ用途利用と規制（レス688, 796, 797, 800, 805）**
- エロ用途ならGrokで十分との意見（レス688, 796）。
- 現在のGrokは未成年ガチガチで規制が強まっており、昔のGrokはもういないと報告（レス797, 800）。
- 学生ものにすると「成人設定にしますね」と前置きが出るようになり、プロンプトのエロはローカルでないとできなくなる日が近いとの予想（レス800）。
- プロンプト作成時に癖で「少女が」と書くと申し訳を食らう。「女が」で通るが、動画で時間かけてババア化する恐怖を感じるとの指摘（レス805）。

**GemmaのローカルLLMとしての位置づけ（レス789, 791, 794）**
- gemma5のいつ出るかという話題。gemmaは年1のため通例なら来年の春か初夏当たりと予想（レス791）。
- 日本語えちえちがまともに出るローカルLLMはgemmaだけとの評価（レス794）。

**Claude Code（Claudeアプリ）のエロ対応（レス754, 761, 763, 776）**
- Claude Codeやantigravityならエロも可能とされ、Codex使用は「禁欲プレイ」のように扱われる（レス754）。
- Claudeは創作上で成人ならエロワードを許可するが、Anthropicがキレるため結局使えないとの指摘（レス763）。アンスロ（Anthropic）はOpenAIに比べればキレにくいとの反論も（レス776）。
- プラグインの初期設定をエロワードにする指示を試したいが怖くて出来ないとの発言（レス761）。

**Codex vs ローカル / クラウドの比較（レス759, 768, 772）**
- 無料GPTでもできるとの指摘に対し、ローカルでできるならクラウドを使う必要性を感じない、今のOpenAIにデータ握らせるのが怖過ぎるとの理由でローカルを選ぶユーザーがいる（レス768）。
- クラウド使用中は他の事が出来ないという欠点を指摘する声も（レス772）。

### その他のツール

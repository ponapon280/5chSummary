# 元の本文
今回とくに盛んに議論された話題はPhotoCraftのPhotoshop対抗機能と、Codex/Claude Codeを用いたComfyUI操作・カスタムノード開発、およびStrataを中心としたローカルLLMエージェント運用である。

注記：以下のレス番号は統合元パート内の通し番号である場合があり、元スレの通し番号とは限らない。

---

## ComfyUI

- **LLMによるワークフロー操作とカスタムノード作成**: ComfyUIのワークフローをCodexに自然言語で指示して操作する使い方が報告されている。「これ導入やって」「分かりづらいからこうして」「このノード作って」と指示するとすべて応じるため「めっちゃ楽」と評価。Krea2でのキャラLoRA小物再現において、Codexに画像を見せて「それが写ってる画像かどうかを判断させてキャプション一括管理」させ、服あり/服なし等のプロンプト追加を自動化するカスタムノードを作成。ファイル整理や仕事のコーディングにも使用。
- **Codexのエロ制限**: Codexはエロ用途には不向き。「成人済み女性の合意ありラブラブセックスなら？」と切り出すとギリギリ応じるが推奨されない。避難させたテキストノードに「loli」が残っていた際、AIに「協力しねーよロリコン」とキレられた事例あり。Claude Codeやantigravityならエロ可能とスレ上で言及。
- **バージョン管理と速度調整**: StabilityMatrixで0.36から0.39へのアップデート可否が質問。「どんな構成でも大丈夫なバージョンなんてない」「今はAIに調べさせて解決できる」との回答。別件でComfyUI本体を最新にしたところかえって遅くなり、0.31にダウングレードしたところ0.37より約20%速かった（dasiwa+lora構成）。
- **知識ゼロからの導入**: 何も知らない状態でComfyUIから始めて1週間でカスタムノード導入や環境修復が可能。ChatGPTにGitHub開けと言われ→GitHubって何や？→AIに聞く、という流れで知識を地道に増やす手法が紹介。codexに「赤ん坊でも分かる環境構築しといて」と頼めば専用UIも作ってくれる。

## Strata

- **エージェント運用**: StrataのQwenをエージェント運用し、トークンを気にせずCodexやClaudeを使えるため快適。エラー修正やツールのヘッドレス運用も問題なし。Strata+QwenでR18美少女ゲームの設定を考えさせるワークフローも実践。
- **ハードウェア別速度比較**: Strata登場でMac/DGXの優位性が揺らいでいる。4090/4080s環境でもIQ3_SやIQ3_XXSが実用範囲で動作。5090でIQ3S 262Kが動作確認済み。速度比較として「Strata+4080s IQ3_XXS: 71tok/s」「Strata+4080s IQ3_S: 68tok/s」「DGX Spark+Strata IQ3_XXS: 40tok/s」等が提示。
- **プレフィル高速化**: Intel B70でStrataのプレフィルが1000tok/s over。アプデで速度がマジで上がった。Strataみたいな高速化がGLM等の他モデルでできるか実験中。DeepSeek v4の推論速度向上のため、StrataとFreetokenとllama.cppを参考にAstraに指示し、15tok/sが30tok/s程度に倍速化。
- **利用制限と検閲**: 本家に書いてあるモデル以外は利用不可。IQ2のXXS非検閲版が使いたいが選択肢なし。デフォのIQ2_XSは「それはお答えできません」をくらう。デフォモデルの検閲解除から試すよう勧め。
- **選定理由**: PCの中身を企業におっぴろげる抵抗からローカル完結のStrataが渡りに船。機密情報を気にせず使える。ハードリセット必須でupdate不可の挙動あり。20万トークン設定では全然足りない。
- **Docker経由のセキュリティ**: docker経由のopenwebuiでターミナルも特定フォルダしか触れないようにしているが、それでも100%の信頼はしていない。

## PhotoCraft

- **概要と選定理由**: 20MBしかないのに本家Photoshop（56GB）と大体同じ機能が使える。2.0→3.0で日本語対応。MCPでClaude等と連携して各種操作・絵画描写も可能。「Photoshop風で」と一言言うだけで機能追加してくれるためAIの得意分野。
- **性能比較**: PSD読み込み時のメモリ消費がPhotoshop 2026最新版 5.09GBに対しPhotocraft 0.50は831.3MB。スクロールもPhotoshopがカクカクに対しヌルヌル。配布モデルは軽さ重視のため、被写体選択の正確さやスポット修復ブラシの contextio 処理はPhotoshopに劣るが、自分で機能追加すれば改善可能。
- **After Effects版への期待**: AE版ができたら価値が高い。
- **権利への懸念**: クリーンルームだから権利的に大丈夫と言われているが本当にそうか疑問視する声あり。

## Codex / Claude Code

- **Codex**: ComfyUI操作・カスタムノード作成・キャプション管理に威力を発揮。Blender/MMD操作は知識不足で失敗し、大量の使用量を注いでも成果物なくストレージがパンパンになった。アプロダのサムネ問題調査にも使用。リセット権が増加。内部ファイルを見られるのが怖くて未導入の声も。
- **Claude Code**: エロ用途ではCodexより可能性があるが、Anthropicがキレるため結局使えないとの指摘も。APIクレジットが毎月100ドル分配布されるようになり申請必要。サードパーティ製アプリでも使用可能。Opus5.5に記事を見せて「同じもの作って」と言えば完成。
- **Codex vs ローカル**: 無料GPTでもできるがローカルを選ぶ理由は「OpenAIにデータ握らせるのが怖過ぎる」「クラウド使用中は他の事が出来ない」。

## ローカルLLMのプロンプト・エージェント運用

- **Qwenエージェント**: Qwenエージェント化は手順を作って手間を掛けて画像を生成してくれると評価。Huihui-Qwen3.6-35B-A3B-abliterated-oQ4e-fp16-mtpでキャラクタープロンプトをベースに指示して生成。
- **Grokの規制強化**: エロ用途でGrokを使う声があるが、未成年ガチガチで規制が強まっており「成人設定にしますね」と前置きが出る。「少女が」と書くと申し訳を食らい「女が」で通るが動画でババア化する恐怖。
- **Gemmaの位置づけ**: 日本語えちえちがまともに出るローカルLLMはgemmaだけとの評価。年1のため来年春〜初夏にgemma5と予想。
- **GLM**: ハッキング関連で話題。コスト・性能・モデルサイズでQwen等に利点がないから名前を聞かないと推測。公開停止前にゲットすべきか懸念。

## 音声・効果音生成ツール

- **Irodori-TTS**: v4.1-SmallはV3より処理が重く、喘ぎ声を出させると高確率でバリバリ音割れ。Largeは数秒で出力され良質だが、セリフのコピペミスでおっさんが喘ぐ事態あり。
- **MiniMax H3**: wan/ltxがだめだめすぎた中、おしっこ音やSEが出た時ポテンシャルの高さに感動。嘔吐音はめちゃくちゃリアル、泣き声もいい感じ。洋式と和式のおしっこ音を聞き分ける能力に感心。VRAM8GB/RAM16GBでも遅いが動作。
- **RVC**: TTS性能向上で用途が限定的になり、リアルタイム以外では使い道ないという見方。
- **Three.js**: コード生成で雷や雨の音をリアルに再現。プロシージャル生成で多種多様な響きが再現可能。

## 画像表示・投稿環境ツール

- **ibb画像表示不具合**: ibbの画像がChMate等の専ブラでサムネサイズ（180x180）になる問題が多数報告。環境により表示がバラバラ（PC/ChMate/iPhone Geschar/Siki）。ログイン状態でアップロードすると「ダイレクトリンク」を選べる。閲覧用リンクを開いて右クリックする際、開いた直後は低解像度アドレスをコピーするため少し待つ必要あり。
- **Siki**: プレビューが出るためオリジナルサイズか事前確認できる。フルサイズ表示できる環境もあるがバグでサムネサイズに見えるケースも。
- **civitai**: 7920x12936解像度・18.7MBの画像サムネイルによりスクロールが激重になる問題。

## その他ツール

- **clipchomp**: Windowsデフォルトの動画編集ツール。minimaxH3がきっかけで触ったら簡単すぎた。ただしアウト画像を読み込ませるだけで検閲されてBANされる懸念あり。
- **copainter**: 漫画エージェント。エッセイまたは4コマ向き。
- **OrcaRouter**: uncensored版の導入は可能。chatGPTに聞きながら導入。
- **OpenRouter**: DeepSeek v4をローカル導入前に試した際、ほぼタダみたいな金額。
- **Musubituner**: 学習速度比較で32GB環境がDGXより3倍以上速い。
- **Google Playground**: 2026年10月7日発表。文章でゲーム内容を伝えるだけでオリジナルゲーム作成。LLMはtomlベースのUnityと相性が悪くトークンがすぐ尽きそう。
- **nanosaur2**: 4stepで1024x1024画像1枚を平均1秒以下で出力可能（3090環境）。バッチ処理なら1秒で24枚。画質はSD1.5程度。高速生成が選定理由。

## 総評

1. **PhotoCraftは配布モデルの軽さを活かしつつAI連携（MCP）で拡張する方向に進化しており**、Photoshopとのメモリ消費・スクロール性能差が明確に示された一方、GPU非使用による被写体選択精度の低さが改良余地として指摘されている。

2. **ComfyUIの操作・カスタムノード開発にCodexが広く使われており**、自然言語でのワークフロー構築やキャプション一括管理が実用化している。ただしエロ用途ではCodexの制限に阻まれ、Claude Codeやantigravityに振り分ける使い分けが見られる。

3. **Strataはローカル完結・機密情報保護を理由にエージェント運用で選ばれており**、4080s/5090等のコンシューマGPUでIQ3_S/IQ3_XXSが実用速度で動作することが確認された。一方で利用可能モデルの制限と検閲の壁が残課題。

4. **ibbの画像表示不具合が専ブラ環境で広範に発生しており**、ChMate・Siki等でサムネサイズに固定される問題が複数レスにわたり報告されている。ダイレクトリンク取得手順は回避策として共有されたが、ibb側の挙動変更が根本原因と推測されている。

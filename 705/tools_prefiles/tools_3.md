# 生成AI関連「ツール」話題 抽出レポート

## ComfyUI / comfyUI

- **公式サポートの評価**: ComfyUIの公式サポートが優秀すぎて語ることが減ったとする声がある。Wan2.2のときはノウハウで盛り上がったが、MinimaxH3はComfyUI公式テンプレでとりあえず困らないため話題が減っている（>>506）。
- **学習コストと代替手段**: ComfyUIを勉強するのが面倒な人や、UIの使い勝手が良くないと感じる人向けに、簡易MiniMax H3のUI（自作ツール）が提供されている（>>511）。
- **PromptStudioの問題**: ComfyUIの拡張機能であるPromptStudioでプロンプトを作成したところ、エロ内容が勝手に弾かれ改変されていた。いつ使うのか疑問である（>>571）。

## 独自UI / 自作ツール

- **簡易MiniMax H3 UI**: comfyUI学習が面倒なユーザー向けの自作UI。Install.bat起動後にACCEPTと入力するだけで導入可能。前バージョン導入済みの場合はUpdate.batを起動して前バージョンフォルダを指定する仕組み（>>511）。
  - **元からある機能**: 日本語プロンプトをLLMで適したプロンプトに変換、画像縦横比を維持したまま適した解像度を算出、最初の画像を最後の画像と同一にする機能（>>511）。
  - **新機能**: UI内にスタジオを終了ボタンを導入、入力済みプロンプトの消去ボタン、生成完了時SE鳴らす機能（任意）、生成時間測定機能。画面比率維持の解像度自動算出時に小サイズと中サイズから選択可能に。R2Vとmotion contextに対応。R2Vのプロンプトも日本語で書けばLLMがMiniMax H3に適した内容に書き換えてくれる（画像や動画を読み込んだ上で書いてくれる）（>>511）。
  - **注意点**: 設定項目が多くて縦長になっているため、シンプルなものがよければ前バージョンを使用することが推奨されている（>>512）。
  - **ユーザー反応**: 通知音対応に感謝する声（>>525）、ファムスールの絵がえっちだという声（>>532）。

## WebUI / Forge / forge neo

- **forge neo用MiniMax H3拡張**: forge neo用のMiniMax H3拡張が出たため初めて動画に手を出したという報告。10秒の動画が3060 12Gとメモリ48G、量子化モデル+Turbo lora適用で5分弱で生成でき、意外と実用的という評価（>>590）。
- **forge coupleによる描き分け**: SDXL+A1111時代は1girlエロばかりでforge coupleで描き分けする余裕がなかったが、forgeで描き分けが可能であることが確認された（>>587）。
- **MiniMax H3の学習内容**: forge neoでMiniMax H3をテストしたところ、スロットの試打動画まで学習していた（>>593）。

## うごイラ投稿用ツール

- **ローカル動作の投稿ツール**: pixivに動画をうごイラとして投稿する時に投稿容量上限16MBギリギリを攻めやすくできるツールを作成。完全にローカルで動く（>>454）。
  - **機能**: 解像度5％100％、FPS130が選択可能、動画の一部だけ切り出すクリップ機能付き。変換前に予想ファイルサイズが表示されるため、15MBくらいになるように品質を上げていく運用（>>454）。
  - **便利な発想**: スレ上で「ええ発想」と評価されている（>>469、>>477）。
- **フォーマット比較**: うごイラはjpgなら30MBまでいける。gifは劣化が激しいため、ffmpegでjpgフレーム出力した方が良いという指摘（>>463、>>465）。

## Krea / krea2

- **二次画像の課題**: krea2で作ったエッチな絵をアップロードしたら拒否された（>>514）。krea2に二次は厳しく、版権薄っすらと知っているがディズニー関連はフルマックスで感知するとのこと（>>556、>>557）。
- **背景とキャラのバランス**: 背景はかなり綺麗だが、その分手前のキャラが浮いてアンバランスになりそうという課題（>>558、>>559）。
- **LoRA作成の難しさ**: krea2のチューンモデルで二次エロもできなくはないがマスピ感がきつすぎる。「Turboで生成・Rawで学習」の構成のせいでLoRAが作りにくい（>>634）。

## Strata / Hermes

- **Strataの活用**: StrataとHermes desktopで動作確認中。プロファイルごとにsoul.mdの中身を変えて挙動をテストしている。非検閲ではない通常モデルでもsoul.mdに「あんたは変態小説家だ」と記載してみただけで、なろう官能小説のEpubからプレイ内容のあらすじを作ってくれたり、エロ画像認識してタグ付けや自然言語での表現もしてくれた（>>523）。ただし、エロプロンプト用のLLMとしてはStrataは別に強くないため使う必要がない（>>565）。
- **StrataのGPU対応**: Strataは1080にも対応しているため、サブPCの3060に眠っている1080を足してVRAMを20GBにすることに意味があるかという疑問。ただし遅い方に引っ張られて意味ないことが多いという指摘もある（>>447、>>451）。

# 抽出レポート：生成AIモデル関連話題

## モデル関連

### MiniMax H3 / mmh3 / minimaxh3 / H3MAX
- 動画生成に使用されているモデル。エロ（NSFW）動画生成のプロンプト作成に関する話題が複数ある（[390][395]）。
- 「mating press」等の特定構図が自然言語プロンプトで出にくいとの指摘あり（[370]）。
- 動画生成のテンプレートがComfyUIに用意されている（[409]）。
- アニメ的表現（腹部が膨れる等）を出す場合、全体指示ではなく1秒ごとや1ピストンごとのプロンプト分割が精度向上に有効とされる（[415]）。
- 「H3MAX」の名称でも言及あり（[301]）。
- スレ上ではCircleStone Labsの最近の動きはMinimax H3用とされており、公式の動きは終わったとの見方がある（[375]）。
- MiniMax H3でローゲーム機風（ゲームボーイアドバンス程度）の映像を作ろうとしたがまともな映像はほぼ出なかったという報告あり（[389]）。
- minimax h3 ref2va用の改善版触手LoRAが焼かれ、強度0.7くらいから試せる形で共有された（[386]）。
- 古いワークフローで生成すると感じが変わったという報告あり（[332]）。

### Krea2 / Krea
- 性能は突出しているがイラストにならず、その意味ではSDXLにも劣るとの評価がある（[296]）。
- 実写関係の話題で絡んでくる住人がいるとの言及あり（[374]）。
- スレ上の議論では、Krea2はAnimaと比較してベースモデル時点でエロが弱い（版権・二次エロの学習重点度の違い）と指摘された。一方でマージモデルやLoRAを駆使すれば二次エロも表現可能と反論され、ベースモデルの特性と完成品の表現力で議論がすれ違った経緯がある（[387]）。
- アップスケーラ用途ではなく、処理スピード向上を目的とした2pass方式（前半4ステップで縮小サイズ作成→latent拡大→後半3～5ステップで仕上げ）の活用が言及された（[383]）。
- 「それなりに頑張れる」との声もある（[380]）。

### SDXL
- SDXL時代のイラストはキャラは良いが背景が弱すぎるとの振り返りがある（[300]）。
- Krea2はイラストにならない意味でSDXLにも劣るとの比較で言及（[296]）。

### animagine
- wikiの浦島情報が8月更新で止まっているが、最近animagineが流行っているように見えるのは「古いのを引っぼり出してきてみた」というネタでたまたま増えているだけとされる（[317]）。

### Grok / grok君
- エロプロンプト作成に使用されている（[391]）。
- 規制が強くなったとの報告があり、プロンプトに拘束などが入ると「同意のない性行為は生成出来ない」と返されるようになった（[410]）。

### Claude
- 性描写を依頼すると「児童ポルノを見つけました。これ以上お手伝いできません」と拒否されるが、BANはしてこないとの報告がある（[419]）。
- 性描写を断られた場合のフォールバック先としてgeminiが挙げられている（[394]）。

### Gemini（ジェミニ）
- 性描写を少しでも入れるとbanされると思われていたが、実際は新モデルリリースのたびに「ひよこかわいそう」プロンプト等でテストする集団がいるものの全く平気との報告あり（[421][423]）。
- 特殊なコピペ脱獄はban対象だが、中身ではなく脱獄の方が理由とされる（[423]）。
- Claudeに断られた場合の代替として使えるとされる（[394]）。

### ChatGPT（チャッピー）
- 生成拒否の場合、無言で何事もなかったかのように新規欄にして終了になる現象が報告された（[352]）。
- 成人エロ程度でbanしてくるのはopenaiくらいとの指摘あり（[417]）。

### Strata
- コーディングエージェント兼プロンプト作成ツールとして言及。エロ対応LLMとして必須とされる（[415]）。
- VRAM12GB、RAM64GBで普通に使える（RAM32GBだとコーディングエージェントとしてのみ）。SSD等を組み合わせて比較的高速に動作するとされる（[421][418]）。
- アンロードに手間取るという難点がある（[415]）。
- wikiにまとめるよう要望が出ている。128GB必要という印象があるが実際には全部VRAMに載せるわけではない（[385][422]）。

### Ref2VA

### 選ばれている理由
- **MiniMax H3**: 動画生成用の主要モデルとしてテンプレートが用意されており、ComfyUIで手軽に始められる（[409]）。Ref2VAでキャラクター維持検証が可能（[290]）。
- **Grok / ローカルQwen派生**: エロ（NSFW）プロンプト作成用。Grokは規制強化の報告がある一方、ローカルモデルはUncensored指定で自由度高く使用可能（[391][410][392][413]）。
- **Strata**: エロ動画の1秒ごとの詳細プロンプト作成に必須とされる。RAM64GBあれば動く（[415][421]）。
- **Krea2**: 性能は突出しているがイラスト向きではない（[296]）。2pass方式で処理スピード向上が図れる（[383]）。

## ツール・ノード関連

- **aitag.win**: 転載されている画像にはメタデータが残っているが、pixivの元投稿画像にはメタデータが残っていない画像がよくあるとの指摘がある（[388]）。
- **JXL**: 主要ブラウザで整いそうで、出力フォーマットを変更できそうとの期待がある。ワークフロー情報の保存は安定しそうだが、AI画像生成でのメリットは不明（[265][323]）。

# ツール関連話題抽出レポート

## ComfyUI (comfy, comufy)
- **デスクトップ版の更新**: ComfyUI 0.43がデスクトップ版に配信された。mmh3 int8、moss image edit、moss color depth control、fibo2.0がテンプレートに追加されている（792）
- **プロンプト生成アプリの構想からComfyUIノードへ**: moss用のプロンプト生成アプリを作ろうとしていたユーザーが、チャッピーに相談したところ「ComfyUIでお絵描きで指示できるノードがある」と教えられ、アプリ自体が不要と判断した経緯がある。選定理由として「ComfyUIでやるならアプリいらんやん」という判断が示されている（663, 670, 675, 697）
- **スパゲティノード結束バンド**: カスタムノードでノードを束ねる機能が評判を集めている。見た目がキレイになるだけで機能的な利点が分からないという声もある（680, 682, 684）

## MOSS-Image Edit (ツール機能として)
- **ComfyUI標準テンプレート追加**: ComfyUI 0.43のテンプレートにMOSS-Image Editが追加された（792, 793）
- **LoRA差し替えによる利用**: ComfyUI標準のMOSS-Image EditでLoRAを差し替え、edit_formatをai-toolkitに変更するだけで使える。loraをくっつけただけでも袖の変化はあるがbboxとプロンプト指定で使えそうとの評価（816, 826）
- **編集性能の評価**: 現時点では「微妙」「まだワールドエンドせんわ」との否定的な評価がある（828）。一方でmossのeditはkreaのeditと同じ性質であり、純粋なeditモデルとの比較にはならないが、元画像を変化させずに加工する場合は強いという指摘がある（720）
- **bboxを使ったセリフ出しの練習**: moss_image_sft_int8_convrotでbboxを使いセリフを出す練習をしている。bboxのobjは大体分かったがセリフの方はメインに引っ張られる感がある。しかし「ここまで出せればなんとかなりそう」との評価（677）

## grafboアンロック関連ツール（batファイル）
- **3060/4070向けアンロックbat**: 3060のWinアンロックbatが配布されている。二度と戻らない書き換えではなく毎回起動式のため安心とのこと。4060や4060Ti16GB向けのbatも要望がある（778, 779, 795, 783）
- **Proシリーズ**: RTX Pro4000は最初からロックされていない。Proシリーズに制限がないなら2枚保有者に恩恵があるか問う声がある（794, 811）
- **5000番台の状況**: 5000番台はセキュアブート仕組みが変更されており別の突破口が必要。アンロック進めていたユーザーも諦めている（667, 791, 794）

## 画像編集ツール全般
- **画像編集ツールの比較検討**: 「画像編集ならどっちがいい？qwen-image-edit / moss-image-edit」との問いに対し、「お好きな方でどうぞ」との返答。mossかqwenかkreaで画像編集WFを作るべきとの意見もある（715, 716, 767）
- **Muse（画像編集）**: 「画像編集は今流行のmuse使えばよくないか」という提案。ただし画像には検閲がかかっているという指摘もある（725, 729, 789）

## sd-scripts
- **更新**: sd-scriptsが更新された（683）

## fizgig
- **LoRA学習への利用**: fizgigでsam3.1 maskとcleanなんとかslideを使ってlora学習を試みた。背景への侵食を抑えられた気がするが、ポーズによっては脚が3本になりやすくなったとの報告（784）

## エージェント・コンテナツール
- **bwrap制限下での運用**: エージェントのコンテナ使い方が分からなかったためbwrapの制限下で動かしている。AIが実際に動かしてみる挙動をとるため、作業フォルダ以外をリードオンリーで固める必要性を指摘（674）
- **ガバ発見**: find / -maxdepth 3 -name "*.py" -o -name "*.txt" で権限を求めてくる実質丸裸の状態を指摘（671）
- **ローカルPCをAIに触らせる危険性**: GMOの件を受け、「AIにローカルPCの中身を再現なく触らせるのあかんのかもしれん」との反省。AI botにPCを触らせるのが怖いという声（819, 825）

## strata
- **LLM動作確認**: strataでhuihui版のDeepSeek-V4.1-Flash-1017が動いた。クソ遅いが拒否はされないとの報告（681）

## Google AI Studio (gemini利用ツール)
- **無料利用の最強手段**: 無料ならgoogle ai studioでgeminiを使うのが最強。取り消し、やり直し、分岐、システムプロンプト入力欄があり制限がほぼ来ない。ただしログはgoogleに食われている（764）

## VoicePeak / Irodori（TTSツール）
- **イントネーション調整**: VoicePeakのように後からイントネーション調整できる機能がIrodori等にも欲しいという要望。アクセント辞書登録機能の不便さが指摘されている（803, 809）

## その他ツール言及
- **minimaxH3**: 日本語のイントネーションがおかしいまま直らないとの指摘（799）
- **TTS全般**: イントネーションは専門のTTSでも完全に克服できていない。音声は別で作ってrefで与えてリップシンクさせる方法が安牌（802, 805）

## ツール関連話題の抽出レポート

### ComfyUI (comfy)

- **Node 2.0への移行消極的**: Node 2.0は評判が悪く、スレ民も回避している。バグるものができるため見送り報告がある (859, 866, 868)。
- **KJNodes (Kijai製) の代替ノード**: Node 2.0未対応でもBox編集が可能な「MOSS-Image Prompt Builder KJ」がある。`ComfyUI-KJNodes`をアプデすれば利用可能。Ideogram 4.0時代から使い慣れており、標準のBBox editorより使いやすいとの声がある (861, 864, 868)。
- **rgthree脱却の試み**: rgthreeから脱却するためCodexにMuterを作成させた。WF貼り付けで同等機能を求めたところ固定値のものが出たため、拡張性が高いカスタムノードに修正指示を出した。Node 2.0にするとバグるものができた (866)。
- **代替ノードの状況**: Nodes2.0対応のMuter代替は既に何個も存在する。rgthreeで代替がなさそうなのはPower Puterぐらい (941)。
- **バージョンアップとワークフロー**: ComfyUIを43.0にアプデするとテンプレにワークフローが追加される (992)。frontend1.57.4環境で`.json`読み込み時に「ワークフローが見つかりません」となる不具合報告がある (937)。
- **キャプション作成の手法**: 自然文キャプションはStrataとComfyUIでワークフローを組むかハーネスでやる方が早い。健全ならチャッピーを使ってもよい (953)。
- **オーディオ参照**: 参照元の音声を`audio_ref_0`に繋ぐだけで機能する。プロンプトに入れたセリフ以外は参照音声として扱われず、単に再生されるだけになる注意点がある (993)。

### ComfyUI以外のツール・周辺環境

- **アンロックツール (GPU制限解除)**:
  - 起動のたびにおまじないが必要でだるいが、イベントトリガーやUI起動時にBAT実行するように手を加えれば解決できる (891, 892)。
  - パラメーターはデバイスIDやオフセットの違い程度であり、分かっている人間が手動でやれば10分かからない。AI（CodexやClaude）に作らせるのはトークンの無駄との指摘がある (909)。
  - Windows 4090環境向けのツールがgithubにあり、AIに「使えるようにして」と投げたところ1時間以上ゴリゴリと改造・コーディングを続けている報告がある (904)。
  - アンロック永続なら良いが、起動のたびにおまじないが必要なのがクッソだるいという不満がある (891)。

- **fizgig**:
  - danbooruのキャプション付けが可能かという疑問。自然言語のflorenceしか選べない状態で、任意のモデル追加ができるかの問い合わせがある (920)。

- **ボイスピ君 / irodori (TTS)**:
  - ボイスピ君はデフォルトのアクセントや漢字の読みが割と滅茶苦茶なため、ベタ打ちが優秀なirodoriの方が良いという評価がある (887)。

- **Frontend / UI起動時のBAT**:
  - ツール起動時にBAT実行するように手を加える運用が言及されている (892)。

### 環境構築とセキュリティに関する話題

- **ローカル環境のリスク管理**:
  - 個人情報入りは分け、ローカルハイスペ作業用、壊してもいいサブPCで3台くらい必要との見解。メインPCの起動OS切り替えやストレージの認識管理の手間が課題 (849)。
  - ローカル作者がどこの馬の骨か分からない以上、ネットから隔離してコード監視するか、サンドボックスで使うかの議論がある (918)。

- **PCの物理環境（埃対策）**:
  - 床置きは埃を吸い込むためスタンドで浮かせる、または空気清浄機を買うべきかの相談 (939)。
  - 2000円のスタンド (942)、キャスター付きラック (947, 958)、ケースの埃フィルター (940)、電動ブロアーでの清掃 (944)、サンワの有線エアダスター (952) などの対策が提案されている。

### 選ばれている理由

- **KJNodes (Prompt builder KJ)**: Node 2.0を導入せずにBox編集ができるため。標準のBBox editorより使いやすく、過去のモデル（Ideogram 4.0）から使い慣れているため (861, 864, 868)。
- **irodori**: ボイスピ君のデフォルトのアクセントや漢字の読みが滅茶苦茶であるのに対し、ベタ打ちが優秀なため (887)。
- **QI2.1 (Qwen)**: MOSSの公式editは顔も体型も変わってしまうため、現状edit用途ではQI2.1が良いという判断がある (994)。
- **StrataとComfyUIでワークフローを組む**: しょぼいLLMだと見落としが多いため、自然文キャプション作成において早く確実な手法として選ばれている (953)。
- **Codex / Claude (AIコーディングツール)**: カスタムノード作成やアンロックツールの改造を自動で行わせるため。ただし、手動で十分な作業をAIに任せるのはトークンの無駄との批判もある (866, 904, 909)。

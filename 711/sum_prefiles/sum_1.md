# なんJ AIスレ ログ要約レポート

## 1. NVIDIA GPU Tensorコア・リミッター解除騒動

### 概要
NVIDIA製GPU（主にRTX 30/40シリーズ）において、Tensorコアの性能をソフトウェア的に制限していたリミッターを解除する手法が発見され、スレ上で大きな盛り上がりを見せている。

### 性能向上の効果
- 3060でfp8アンロックにより最大80%の処理速度向上（>>53）
- 3060でfp16も2倍近く向上（>>115）
- RTX 30XXのBF16処理能力が倍になる（>>43）
- fp32累積が解除で2倍、LHR品はfp16/bf16累積も制限解除で2倍。INT8等は制限なし（>>130）

### 環境と適用範囲
- Windows単体では適用できず、Linux環境が必要とされる（>>43, >>67, >>80）
- WindowsでもUEFI経由で読み込めば使える可能性があるが「別の怖さがある」（>>88）
- 4000番台も性能アップの報告あり（>>57）
- 2080Tiでも可能という報告（>>55）
- CMP 170HXがアンロックできたのと同じ脆弱性を利用（>>61）

### リミッターの理由と安全性についてのスレ上の議論
- リミッターの目的は業務用ライン（A6000等）との差別化（>>97, >>98）
- kernelレベルで意図的に制限していただけ（>>104）
- 半導体の無効化解除とは異なり、再起動で元に戻る仕組み。fuseへの書き込みなし（>>61）
- マイニングのような極端なハードな使用対策（>>112）
- 間欠命令前提で基板が設計されているか不明のため、人柱待ちが正解との意見（>>117）
- 排熱絡みのリスクを懸念する声（>>94）
- 24時間連続動画生成等の廃人でなければ問題ないとの見方（>>126）

### 反応・市場影響
- 3090の24GB中古が売れまくり、値上がり前の駆け込み購入が発生（>>155）
- グラボ高騰中のためリミット解除は怖いとの懸念（>>90）
- 5090製造減らしてRTX Pro比率増やす報道直後のタイミングで「NVIDIAがやらかした」（>>121）

## 2. MOSSモデル関連

### 基本情報
- Forge neo対応、ComfyUIにテンプレートあり（>>101, >>162）
- リアス（SD1.5等の従来モデル）との違い：モデルがcheckpoint(+VAE)からdiffusion_model+text_encoder(CLIP)+VAEの3つに分かれる（>>148）
- 最低50シリーズが必要とする嘘情報が出たが否定された（>>79, >>81）
- 8700G（APU）でもForge neo経由で動作確認。turboで1k解像度1枚あたり1分半（>>56）

### 生成品質・特徴
- 50ステップが標準的な設定（>>142）
- ほぼdanbooru語でプロンプト可能（>>210）
- リアル系女性の目の下のクマがブサイクという不満（>>140）
- MOSSのチャッピー（ChatGPT）みたいなギラギラ感が良いという評価。Animaでは出ない味わい（>>197）
- CatTowerは実写が弱まっており、STFモデル比較でポリゴンっぽくなる（>>105）

### LoRA学習・トレーニング
- 主なツール：fizgig（>>216, >>217, >>218）、KohakuMossTrainer（>>215）
- AnimaTrainFlowと比較して、fizgigはLook Consistency Filter、masked training、自然語キャプション等の新要素がある（>>216）
- キャプション作成の重要性：テキトーな日本語txtを使うと画風まで吸ってしまう問題（>>208）
- 推奨設定で学習すれば今までのモデルの中ではラクな部類（>>215）
- キャラ・画風・コンセプト確立済みとの報告あり（>>222）

### フォント・文字描画
- MOSSのフォントが味気ないという不満（>>206）
- bboxを使わないと文字がグチャる（>>39）
- ステップ30程度でKrea2よりは文字がなんとかなる（>>40）

## 3. MiniMax・動画生成関連

### MiniMax
- MiniMax製動画の4時間越え作品が再生数60万近く（>>188）
- MiniMaxがWanの完全上位互換という意見（>>203）
- ドパってる（VRAM不足等の環境）と5秒以上の動画が観られない（>>189）
- 声はminimaxではないという指摘（>>159）

### Wanの評価
- もうWanは不要という意見（>>201, >>203）
- 引きでも顔が崩れにくい良さはあった（>>204）
- 単純なループエロならWanの方が良かったため環境再構築した者あり（>>212）

### MiniMax TTS・音声
- IrodoriTTSのvoice designで同一声の固定が困難。SEED Fixedでも別の声になる（>>133）
- 参照音声を使っても別の声になる問題（>>133）
- MiniMaxで音声参照して作る代替案（>>136）
- 8GB VRAMの2080でもMiniMax音声は動く（>>156）

### i2v（画像→動画）の課題
- i2vで顔の雰囲気が変わる問題（>>137）
- EXILEのぐるぐる回る動きをi2vで再現できず（>>4）

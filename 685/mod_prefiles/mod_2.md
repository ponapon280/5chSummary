**抽出結果**

### Anima（Anima LoRA / Anima Tokenizer）
- **言及回数**: 複数（特に265, 294, 295, 305, 308, 417）
- **主な話題**:
  - Anima上で**リアル系変換LoRA**を作成して使用。
  - キャラLoRAと組み合わせ、**イラスト参照＋リアル変換参照**をH3に食わせて生成。
  - 乙女ゲームヒロインのAnima LoRA作成に注力（動画よりそっちを優先）。
  - H3のテキストエンコーダーを使って学習したAnimaについても言及。

- **選ばれている理由（抽出されたもの）**:
  - レトロゲーキャラに比べて**作りやすくて精度が高い**。
  - リアル変換LoRAとの相性が良く、画風をある程度コントロールできる。
  - danbooruタグだけでアニメ生成ができる（Tokenizer使用時）。
  - キャラクターシート的な参照との相性が良いと評価されている。

### illustrious（リアス / ill / IL）
- **言及回数**: 1回（305）
- **主な話題**:
  - 「その程度ならanimaやリアスで十分やな」という文脈でAnimaと並んで言及。

- **選ばれている理由**:
  - Animaと同等レベルで十分なクオリティが出せると判断されている（特に画風統一や変換タスクにおいて）。

### Wan

**抽出されたモデル関連話題（除外リスト対象外のもの）**

### 1. **H3 / MiniMax H3 / MMH3**（最も多く言及されている）
- スレ内で最も活発に話題に上がっているモデル。
- **選ばれている理由・評価点**:
  - 「H3が出てからこのスレワイ以外才能の宝庫なんやなって分かったわ。これまではモデルの性能が足りてなかったんやな...」→ **モデル性能の向上により、生成者の才能が活きるようになった**という評価。
  - 顔の破綻が少なく滑らかに動く。
  - テキストエンコーダーの性能が高く、danbooruタグだけでアニメ生成が可能（ただし実用性は低いという声も）。
  - 参照画像（キャラクターシート、モーションコンテキスト、最終フレーム指定など）との相性が良い。
  - MiniMax H3 Extenderという拡張機能も言及されており、Context Loopと並んで現在の主流ワークフローの一つとして扱われている。

### 2. **sora2（Sora 2）**
- 「sora2から1年たらずでこの進化やし」という文脈で、現在の生成レベルとの比較材料として出てくる。
- 進化速度の指標として軽く触れられている程度。

### 3. **SDXL**
- 過去に使われていたモデルとして言及（hardcore-cosplay ckptなど）。
- 現在はH3などに移行したというニュアンスで出てくる。

### 4. **Grok（特にGrokのプロンプト生成能力）**
- Context Loop用のプロンプト作成や、SEXシーンの指示出しで高く評価されている。
- 「Grokで良ければワイのContex-loop用プロンプター使ってええよ」という具体的なツール提供も見られる。
- 将来的にエロ規制が入る可能性が懸念されている。

### 5. **その他軽く触れられているもの**
- **Krea2**: SDXL時代の変換LoRAの代替として名前が出ている。
- **10Eros / 10Eros-Max**: beta2が出たという言及あり（Int8Conv対応など）。
